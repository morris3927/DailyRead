# 2026-05-08 - Agent Memory

## 今日領域觀察

Agent memory 今天的搜尋結果很密集，且 paper 型內容多。整體看起來正在從「把歷史訊息塞進 RAG」往更結構化的 memory system 移動：動態連結、記憶演化、graph memory、memory OS、以及面向 production agent 的低延遲 / 低 token 成本設計。

## Items

### 1. A-MEM: Agentic Memory for LLM Agents
- Type: paper / method
- Source: arXiv / NeurIPS 2025
- Link: https://arxiv.org/abs/2502.12110
- What it is: 這篇提出 agentic memory system，參考 Zettelkasten 方法，讓新記憶被寫入時產生描述、關鍵字與 tags，並自動與歷史記憶建立連結。
- Why it matters: 它把 memory 從「儲存與檢索」推向「動態組織與演化」。這是 agent memory 很重要的發展方向。
- One-line takeaway: Agent memory 不只是向量資料庫檢索，還可以是一個會自我組織的知識網路。
- Read suggestion: 值得細看。尤其適合看 memory indexing / linking / evolution 的設計。

### 2. A Survey on the Memory Mechanism of Large Language Model based Agents
- Type: survey
- Source: arXiv
- Link: https://arxiv.org/abs/2404.13501
- What it is: 這篇整理 LLM-based agents 的 memory mechanism，討論 memory 是什麼、為什麼需要、如何設計與如何評估。
- Why it matters: 對剛開始看 agent memory 的人，survey 可以建立分類地圖，幫助區分短期記憶、長期記憶、檢索、應用與 evaluation。
- One-line takeaway: Agent memory 已經是 LLM agents 的核心模組，不再只是 context window 不夠時的補丁。
- Read suggestion: 值得收藏。可先略讀 taxonomy，再決定要不要深讀。

### 3. Mem0: Building Production-Ready AI Agents with Scalable Long-Term Memory
- Type: paper / system
- Source: arXiv
- Link: https://arxiv.org/abs/2504.19413
- What it is: 這篇提出 Mem0，一個面向 production-ready AI agents 的長期記憶架構，透過動態萃取、整合與檢索關鍵資訊，支援長期多 session 對話。
- Why it matters: 它很工程導向，除了準確率也強調 latency 與 token cost，這代表 agent memory 的評估正在靠近實際部署需求。
- One-line takeaway: Production agent memory 的關鍵不只是記得多，而是要記得準、取用快、成本低。
- Read suggestion: 值得細看。適合觀察 memory system 如何從研究概念走向產品架構。
