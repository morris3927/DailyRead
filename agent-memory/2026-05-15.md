# Agent Memory — 2026-05-15

今天的 agent memory 有兩篇互補性很強的 paper：一篇是 taxonomy-level 的 survey（2505.00675），把 memory 的原子操作拆成六個核心動作，另一篇是具體的 memory update 機制（2510.09720 PAMU），專攻既有系統忽略的「偏好記憶如何動態更新」問題。兩篇合在一起看，會對 agent memory 的研究全景有更清楚的圖像：survey 告訴你地圖在哪，PAMU 告訴你地圖上最大的洞之一怎麼補。

## 1. Rethinking Memory in LLM based Agents: Representations, Operations, and Emerging Topics

- **arXiv**: 2505.00675
- **Link**: https://arxiv.org/abs/2505.00675
- **版本**: v3 (Dec 2025)

### 這篇在說什麼

這是一篇 agent memory survey，但和常見的「列 paper 列工具」式 survey 不同，它提出了一個以「操作」為核心的分類框架。作者的核心觀察是：既有 survey 多半從應用場景出發（personalized dialogue、task planning 等），但忽略了記憶系統的原子操作本身。這篇把 LLM agent 的記憶拆成兩種表示形式（parametric vs. contextual）和六個核心操作（Consolidation、Updating、Indexing、Forgetting、Retrieval、Condensation），然後用地圖的方式把現有研究、benchmark、工具映射到這個框架上。

### 主要貢獻

1. **六操作分類法**：把記憶動態拆成 Consolidation（新資訊如何寫入）、Updating（既有記憶如何修改）、Indexing（如何組織記憶以便檢索）、Forgetting（如何淘汰過時記憶）、Retrieval（如何取出相關記憶）、Condensation（如何壓縮冗長記憶）。這不是隨意分類，而是從「記憶生命週期」的角度定義必要的操作。
2. **Parametric vs. Contextual 的區分**：parametric memory 是模型權重中隱含的知識，contextual memory 是外部資料（結構化如 KG、非結構化如對話歷史）。這個區分直接影響每個操作的實作方式。
3. **四個研究主題的地圖**：長期記憶、長上下文、參數修改、多源記憶——每個主題都映射了相關的 paper、benchmark、工具。
4. **公開資源**：GitHub 上提供了整理好的 dataset、paper、工具列表（https://github.com/Elvin-Yiming-Du/Survey_Memory_in_AI）。

### 方法 / pipeline

Survey 的方法論是系統性文獻回顧。作者收集了 2022 到 2025 年（部分延伸到 2026 early）的 agent memory 相關 paper，按照「表示形式 × 操作」的二維框架分類，然後從分類結果中識別出四個關鍵研究主題。每個主題下都有詳細的 paper 比較表，涵蓋方法、資料集、主要結果。

六個操作的定義和範例：
- **Consolidation**：把新的互動資訊整合進記憶系統（例如 Mem0 的提取-合併流程）
- **Updating**：修改既有記憶的內容（例如 PAMU 的偏好更新、MemoryBank 的 Ebbinghaus 衰減）
- **Indexing**：組織記憶結構以便高效檢索（例如 A-MEM 的知識圖譜索引）
- **Forgetting**：主動淘汰過時記憶（例如 MemoryBank 的時間衰減、SCM 的主動遺忘）
- **Retrieval**：根據當前任務取出相關記憶（例如 RAG 的向量相似度搜索）
- **Condensation**：壓縮冗長記憶保留核心資訊（例如對話摘要、記憶合併）

### 實驗設計

Survey paper，無新實驗。但作者整理了每個研究主題下的 benchmark 和評估方法：
- 長期記憶：LoCoMo、LongBench、MSC 等對話記憶基準
- 長上下文：Needle in Haystack、LongBench、InfiniteBench 等
- 參數修改：model editing 基準（RIPPLES、KEQAc）
- 多源記憶：跨模態記憶整合基準

### かに讀後判斷

這篇是 DailyRead 追蹤 agent memory 領域的地圖型 paper。和前幾天看過的 2603.07670（Memory for Autonomous LLM Agents survey）相比，這篇更聚焦在「操作」而非「架構」，更適合用來定位具體的研究缺口。特別值得注意的是 Updating 和 Forgetting 兩個操作——這正是 PAMU（今天的另一篇）和前幾天看到的 MemoryOS、A-MEM 都在試圖解決的問題。建議 Morris 優先看 Table 1（操作分類映射）和 Section 4（四個研究主題），之後需要查具體 paper 或 benchmark 時可以直接用它整理好的 GitHub repo。

## 2. Preference-Aware Memory Update for Long-Term LLM Agents (PAMU)

- **arXiv**: 2510.09720
- **Link**: https://arxiv.org/abs/2510.09720

### 這篇在說什麼

現有的 LLM agent memory 系統大多把心力放在記憶的存儲和檢索上——怎麼壓縮、怎麼索引、怎麼用向量搜索或知識圖譜來取出相關記憶。但有一個關鍵問題被忽略了：當用戶的偏好隨時間改變時，記憶系統如何動態更新？PAMU 這篇 paper 就是在補這個洞。它提出一個 Preference-Aware Memory Update Mechanism，用滑動窗口平均（SW）和指數移動平均（EMA）的組合來捕捉短期偏好波動和長期偏好趨勢，並在偵測到偏好變化時觸發記憶更新。

### 主要貢獻

1. **偏好變化感知模組**：PAMU 的核心是 Preference Change Perception Module，它同時計算 SW（短期窗口平均，捕捉最近的偏好波動）和 EMA（指數移動平均，捕捉長期趨勢），然後比較兩者的偏離度作為偏好變化信號。這不是簡單的「每次對話都更新」，而是只在偵測到真正變化時才更新。
2. **SW + EMA 融合表示**：把短期波動和長期趨勢融合成一個 preference-aware representation，既不會因為一次異常對話就劇烈改變記憶，也不會因為累積太多歷史而忽略新的偏好。
3. **Model-agnostic**：PAMU 不需要 fine-tuning 或架構修改，可以無縫整合進任何既有 memory-augmented LLM 框架。這是一個很實際的工程優點。
4. **五個 baseline 上的全面驗證**：在 LoCoMo dataset 的五個 task scenario 上，PAMU 在五個不同的 baseline memory 系統上都顯著提升了 LLM 的輸出品質。

### 方法 / pipeline

PAMU 的架構可以分成三個步驟：

**Step 1: Preference Extraction**
從對話中提取用戶偏好。用 LLM 從每輪對話中抽取偏好描述，形成結構化的偏好向量。

**Step 2: Dual-Perspective Preference Modeling**
- Sliding Window Average (SW)：計算最近 k 輪對話的偏好平均，捕捉短期變化
- Exponential Moving Average (EMA)：對所有歷史偏好做指數衰減加權平均，捕捉長期趨勢
- 兩者的偏離度（deviation）作為偏好變化信號

**Step 3: Preference-Aware Memory Update**
當偏離度超過閾值時，觸發記憶更新。更新方式是融合 SW 和 EMA 的表示，生成新的 preference-aware prompt 注入 LLM 的 context。

整個流程是 plug-in 模組化的：偏好提取、雙視角建模、更新觸發三個步驟可以獨立調整。

### 實驗設計

- **Dataset**: LoCoMo 的五個 task scenario（具體場景包括對話理解、關係推理、用戶畫像、意圖識別等）
- **Baselines**: 五個 memory-augmented LLM framework（MemoryBank、MemGPT、SCM、A-MEM、MemInsight）
- **Metrics**: LLM 輸出品質的多維指標（包括回覆相關性、偏好一致性、對話連貫性等）
- **主要結果**: PAMU 在所有五個 baseline 上的所有五個 task scenario 都有顯著提升
- **Ablation**: 拆解 SW 和 EMA 的個別貢獻，以及偏好變化偵測閾值的敏感性分析
- **限制**: 目前只在 LoCoMo 單一 dataset 上驗證；偏好提取的品質依賴 LLM 本身的能力；偏離度閾值的設定需要手動調整

### かに讀後判斷

PAMU 直接命中了 2505.00675 survey 中 Updating 操作的研究缺口。和前幾天看到的 MemoryOS（三層記憶架構）相比，PAMU 更聚焦——它不是建一個新的完整記憶系統，而是提供一個可以插進既有系統的偏好更新模組。方法簡潔（SW + EMA 是信號處理的經典手法），效果明確（五個 baseline 全部提升），而且 model-agnostic 的設計讓它很容易被採用。

建議 Morris 點開時優先看：（1）SW + EMA 融合的具體計算方式——偏離度怎麼算、閾值怎麼設；（2）五個 baseline 上的提升幅度——是否有些 baseline 受益更大；（3）ablation 中 SW-only vs. EMA-only 的比較。這篇的方法設計很乾淨，應該可以直接借鑑到自己的 agent memory pipeline 裡。
