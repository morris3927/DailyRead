# Agent Memory — 2026-05-18

## 1. Multi-Layered Memory Architectures for LLM Agents: An Experimental Evaluation of Long-Term Context Retention

- **arXiv**: 2603.29194
- **Link**: https://arxiv.org/abs/2603.29194
- **Authors**: Sunil Tiwari et al.
- **Date**: 2026-03-31

### 這篇在說什麼

長對話系統面臨兩個核心問題：semantic drift（語義漂移——越聊越偏離早期主題）和不穩定的記憶保持。現有方法要麼只改善效率但不穩定 retention，要麼改善 recall 但不控制 drift。這篇提出 Multi-Layer Memory Framework，把對話歷史分解為 working / episodic / semantic 三層，加上 adaptive retrieval gating 和 retention regularization，試圖同時控制 drift、保持 bounded context growth、維持計算效率。

研究動機源於一個實際約束：對話記憶不能無限增長，但也不能簡單截斷——截斷會丟失 persona consistency 和 entity 關係。需要一個結構化的記憶架構，把短期互動和長期抽象分開，同時控制跨 session 的語義漂移。

### 主要貢獻

1. **三層記憶分解**：Working memory 保持近期互動（bounded window），episodic memory 累積 compact session summary，semantic memory 維護 structured entity-level abstractions。這個分解跟認知科學的工作記憶/情節記憶/語義記憶三分法對齊。

2. **Adaptive Retrieval Gating**：一個自適應的層權重機制，控制三層記憶在 retrieval 時的相對重要性。不是固定比例，而是根據當前 query 和 session context 動態調整。

3. **Retention Regularization**：一個 retention stability objective，約束跨 session 的語義偏移。這是把「控制 drift」從事後觀察變成訓練時約束的關鍵設計。

### 方法 / pipeline

- **Working Memory Layer**：保留最近 N 個 turn 的 raw dialogue，用 bounded window 控制 token 預算。
- **Episodic Memory Layer**：每個 session 結束時生成 compact summary，存入 episodic store。Summary 是壓縮過的，包含關鍵 entity、事件、態度變化。
- **Semantic Memory Layer**：從 episodic summary 中提取 entity-level 結構化抽象（類似 knowledge graph 的 entity-relation triple），存入 semantic store。
- **Retrieval**：Query 先經過 adaptive gating，決定從 working / episodic / semantic 各取多少資訊。Gating 的權重由一個小型 network 根據 query 特徵和 session context 預測。
- **Retention Regularization**：在訓練或更新時加入 regularization term，懲罰 semantic memory 在跨 session 更新前後的過大變化。

### 實驗設計

- **Benchmarks**：LOCOMO、LOCCO、LoCoMo——三個長對話基準。
- **Metrics**：Success Rate（46.85%）、overall F1（0.618）、multi-hop F1（0.594）、6-period retention（56.90%）、false memory rate（5.1%）、context usage（58.40%）。
- **Baselines**：論文 Table I 比較了多個 prior work：Hu et al.（hierarchical working memory）、Ming et al.（ILSTMA）、Kang et al.（Three-tier Memory OS）、Phadke et al.（four-tier with truth verification）、Jia et al.（parameter-based memory）。
- **Key Result**：Multi-Layer Memory Framework 在 retention 和 reasoning stability 上優於 prior multi-layer 和 compression-based 方法，同時把 false memory rate 降到 5.1%、context usage 降到 58.40%。
- **目前能確認的**：三層架構有效、adaptive gating 和 retention regularization 有貢獻、在 LOCOMO/LOCCO/LoCoMo 上有量化改進。還看不到的：各層的 ablation analysis 細節、adaptive gating network 的具體架構、計算開銷的詳細分析。

### かに讀後判斷

這篇跟之前讀的 Human-Inspired Memory Architecture（2605.08538）是同時期的競爭方案。2605.08538 用生物學啟發的六機制設計（sleep-phase consolidation、interference-based forgetting 等），這篇用更簡潔的三層 + gating + regularization。兩者的核心差異在設計哲學：前者是「模擬認知機制」，後者是「工程約束驅動」。56.90% 的 6-period retention 和 5.1% 的 false memory rate 是不錯的數字，但還需要看 ablation 才能判斷 gating 和 regularization 各自的貢獻。

不是今天最優先深讀，但值得收藏作為 hierarchical memory 方案的比較基準。如果 Morris 要選擇 agent memory 架構，建議把這篇和 2605.08538 對比看：三層 + gating vs. 六機制 + entity KG，哪個更適合你的 use case。

## 2. Hierarchical Memory (H-MEM) for High-Efficiency Long-Term Reasoning in LLM Agents

- **arXiv**: 2507.22925
- **Link**: https://arxiv.org/abs/2507.22925
- **Authors**: Haoran Sun, Shaoning Zeng
- **Date**: 2025-07-23

### 這篇在說什麼

現有 LLM agent 的記憶機制有兩個典型問題：vector-based similarity search 在記憶量增大時計算成本急劇上升，graph-based 組織方式在維護和更新節點間關係時面臨一致性和準確性挑戰。H-MEM 提出一個分層記憶架構，用 positional index encoding 建立層間指標，讓 retrieval 可以逐層路由而不需要 exhaustive similarity computation。

研究動機：記憶檢索的效率是 agent 在長期互動中保持響應速度的關鍵瓶頸。如果每次 retrieval 都要跟所有記憶向量做 similarity comparison，隨著記憶累積延遲會持續增長。H-MEM 用 hierarchical index 把 search space 從「所有記憶」縮小到「相關子樹」。

### 主要貢獻

1. **四層 hierarchical memory**：按語義抽象程度分為 Domain → Sub-domain → Topic → Content 四層，類似學術論文的 section / subsection / subsubsection / content 結構。每層記憶向量嵌入下一層相關子記憶的 positional index。

2. **Positional Index Encoding**：每個上層記憶向量包含指向其語義相關下層子記憶的 index。Retrieval 時先在上層做粗篩，然後根據 index 路由到相關下層，逐層縮小 search space。

3. **Index-Based Routing Retrieval**：取代 exhaustive similarity search。在 reasoning phase，用 index-based routing 逐層檢索，只需要在上層做一次 similarity comparison，然後沿 index 路由到下層相關記憶，計算量是 O(depth × branch_factor) 而非 O(total_memories)。

### 方法 / pipeline

- **Memory Organization**：四層結構——L1（Domain，最抽象）、L2（Sub-domain）、L3（Topic）、L4（Content，最具體）。新記憶進入時先 embedding，然後從 L1 開始找最相關的 domain，沿 index 逐層插入到最合適的位置。如果沒有匹配的 L1 domain，就建立新的 branch。

- **Memory Update**：當新資訊與已有記憶衝突或補充時，H-MEM 的更新機制會在對應層級修改或擴充記憶向量，同時更新 positional index。作者聲稱設計了更科學的更新機制來適應人類心理變化的複雜性，但從目前讀到的內容來看，更新策略的具體規則還需要看全文。

- **Retrieval**：Query → L1 similarity comparison（只比 domain 層）→ 選擇最相關 domain → 沿 index 到 L2 → L2 similarity → 沿 index 到 L3 → L3 similarity → 沿 index 到 L4 → 取出具體記憶。這是 log(N) 級別的 retrieval 而非 linear scan。

### 實驗設計

- **Benchmark**：LoCoMo dataset，5 個 task settings。
- **Baselines**：5 個 baseline methods（包括 MemGPT、MemInsight、A-MEM、MemoryBank 等）。
- **Models**：多個 LLM backbone。
- **Main Result**：H-MEM 在所有 5 個 task settings 上一致優於 5 個 baselines。
- **目前能確認的**：hierarchical index 有效降低 retrieval cost、在 LoCoMo 上有量化改進。還看不到的：各層的 memory capacity 設計、index 更新的 consistency 保證、與 graph-based memory 在複雜關係推理上的比較、long-term retention 的跨 session 穩定性。

### かに讀後判斷

H-MEM 的核心創新是用 positional index encoding 把 retrieval 從 linear scan 變成 hierarchical routing，這在記憶量大的場景下很有價值。但它的限制也很明顯：四層的 Domain→Sub-domain→Topic→Content 結構假設記憶可以乾淨地分類，這對開放域對話可能不適用。跟 Multi-Layered Memory Framework（2603.29194）相比，H-MEM 更注重 retrieval efficiency 而 2603.29194 更注重 drift control 和 retention stability，兩者解的問題不太一樣。

不是今天最優先深讀，但值得收藏。如果 Morris 關心「agent memory 在大規模場景下的 retrieval 效率瓶頸」，H-MEM 的 index-based routing 思路可以直接參考。
