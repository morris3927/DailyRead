# Agent Memory — 2026-05-20

## 1. Governing Evolving Memory in LLM Agents: Risks, Mechanisms, and the Stability and Safety Governed Memory (SSGM) Framework

- **arXiv**: 2603.11768
- **Link**: https://arxiv.org/abs/2603.11768
- **Authors**: Chingkwun Lam, Jiaxin Li, Lingfei Zhang, Kuo Zhao (Jinan University)
- **Date**: March 12, 2026

### 這篇在說什麼

LLM agent 的長期記憶已經從被動的 RAG 資料庫演變為主動的、自我演化的記憶系統（如 Memory-R1 用 RL 訓練記憶子 agent、A-MEM 用 Zettelkasten 自組織記憶網絡、Mem0 用原子操作持續更新記憶）。但這些系統帶來了一個根本性的安全問題：如果 agent 可以重寫自己的記憶，誰來確保記憶的正確性和安全性？semantic drift（反覆摘要導致知識退化）、memory poisoning（惡意注入被固化為長期記憶）、knowledge leakage（敏感上下文被不當持久化）——這些風險在靜態 RAG 系統中是單次錯誤，但在演化記憶系統中是累積性的。

SSGM 提出了一個概念性的治理架構，將記憶演化（memory evolution）與記憶治理（memory governance）解耦，在每次記憶合併前執行一致性驗證、時間衰減建模和動態存取控制。

### 主要貢獻

1. **演化記憶的系統性分類**（Table 1）：將近 30 個記憶系統按儲存結構、演化策略、穩定性機制、安全條款進行分類。涵蓋了 Memory-R1、MemAgent、AtomMem、LEGOMem、AgentSM、A-MEM、HippoRAG、HiMem、Zep、TeleMem、MIRIX 等等。這是目前最全面的 agent memory 系統橫向比較表之一。

2. **記憶損壞的四維失敗分類**（Table 2）：從 Figure 1 的三個粗糙失敗介面（input poisoning → consolidation drift → retrieval hallucination），細化為四個維度的正式風險分類。這不是 ad-hoc 列舉，而是從「內在漂移 vs. 外在威脅」的軸線出發，系統性地識別了 semantic drift、procedural drift、memory poisoning、knowledge leakage、conflict/hallucination 等風險。

3. **SSGM 框架**：三層治理架構：
   - **Consistency Verification Layer**：在每次記憶合併前驗證新記憶與現有知識圖譜的一致性。
   - **Temporal Decay Modeling**：為記憶引入時間衰減，防止過時資訊被無限期保留。
   - **Dynamic Access Control**：基於記憶的敏感性和 agent 的角色，動態調整存取權限。

4. **三個基本 trade-off**：latency-safety trade-off（治理需要時間，但 agent 需要即時回應）、stability-plasticity conflict（保留舊知識 vs. 學習新知識）、graph structure scalability（圖結構的記憶隨節點增長面臨效率挑戰）。

### 方法 / pipeline

SSGM 不是一個實作系統，而是一個概念性治理架構。它的設計原則是：

1. **Decouple evolution from governance**：記憶的更新操作（add, update, delete, summarize）和治理操作（verify, decay, gate）分離。Agent 可以自由演化記憶，但每次合併都必須通過治理層。

2. **Consistency Verification**：使用知識圖譜的結構化約束來驗證新記憶是否與現有知識一致。例如，如果新記憶說「X 是 Y 的子類」但現有知識說「X 是 Y 的父類」，則標記為衝突。

3. **Temporal Decay**：為每個記憶節點附加時間戳和衰減函數。隨時間衰減的記憶如果未被重新激活，最終會被合併或刪除。這解決了「記憶越來越多但越來越舊」的問題。

4. **Dynamic Access Control**：不同角色和敏感度級別的記憶有不同的存取權限。這防止了 topology-induced knowledge leakage（高中心性節點可能洩露多個對話上下文的資訊）。

### かに讀後判斷

這篇填補了 agent memory 文獻中一個重要的空白：大多數既有工作都在設計更好的記憶機制（A-MEM、Memory-R1、Mem0 等），但很少有人系統性地問「如果記憶可以自我演化，我們如何確保它的安全性和正確性？」。SSGM 的價值不在於它提供了一個可即用的系統，而在於它為這個問題提供了統一的詞彙和框架。

和 DailyRead 之前收錄的 agent memory 論文相比：
- HLTM (2604.26197) 解決的是生產環境中的可擴展性問題（hierarchical memory 的工程實踐）。
- Memoria (2604.01707) 提供了模組化記憶架構的統一框架。
- SSGM 解決的是這些系統都忽略的治理問題——如果記憶可以自我演化，誰來防止 drift、poisoning 和 leakage？
