# Agent Memory — 2026-06-17

## 1. Scaling Teams or Scaling Time? Memory Enabled Lifelong Learning in LLM Multi-Agent Systems

- **arXiv**: 2604.03295
- **Link**: https://arxiv.org/abs/2604.03295
- **Authors**: Yuyang Luo, Yueqing Liang, Kaiwen Shi, Yanfang Ye, Ali Payani, Kai Shu (Emory, Notre Dame, Cisco Research)

### 這篇在說什麼

LLM multi-agent system 可以沿兩個維度 scale：加更多 agent（橫向 scaling），或者讓 agent 隨時間積累經驗而改進（縱向 / lifelong learning scaling）。之前的研究分別看了這兩個維度，但它們在真實成本限制下的交互作用不清楚。

這篇的核心觀點是：不應該把「加人」和「加經驗」當成兩個獨立的問題，而應該看成聯合的 scaling space。在這個空間裡，更大的 team 不一定更好——當記憶設計能更好地支持經驗複用時，小 team 可以超越大 team。這揭示了一個新的 trade-off：橫向 scaling（更多 agent）vs. 時間 scaling（更好的終身學習）。

### 主要貢獻

1. **聯合 scaling 視角**：把 team size 和 lifelong learning ability 放在同一個概念空間裡，論證它們是交互的而非獨立的。這挑戰了「more agents are better」的直覺。

2. **LLMA-Mem 框架**：三層記憶架構——episodic memory（經驗基底）、procedural memory（跨任務遷移的主要機制）、transactive memory（團隊層級的能力和協調建模）。記憶拓撲（誰能讀寫哪些記憶）是關鍵設計變項。

3. **Non-monotonic scaling landscape**：實驗證明更大的 team 不一定產生更好的長期性能。更小但記憶更好的 team 可以超越更大但記憶較差的 team。這打破了「加 agent 就能變好」的假設。

4. **成本效率**：LLMA-Mem 在所有 model-environment 設定中都改善了 lifelong learning，同時降低 token 使用量 9.4%–71.7%。

### 方法 / pipeline

LLMA-Mem 的三層記憶設計：

- **Episodic memory**：存儲原始經驗軌跡。作為經驗基底，支持回溯和詳細分析。

- **Procedural memory**：從 episodic 經驗中蒸餾出 compact 的程序性記憶——可重用的工作流程、策略、經驗教訓。這是跨任務遷移的主要機制。設計理念：raw trajectories 太長且太特定，難以跨任務遷移；蒸餾後的 procedural insights 更 compact、更可遷移。

- **Transactive memory**：建模團隊層級的「誰知道什麼、誰擅長什麼」。這解決了 multi-agent 系統中的資訊碎片化問題——agent 不需要知道所有事，只需要知道哪個 teammate 可能有相關經驗。

- **Memory topology**：確定誰可以讀寫哪些記憶。不同的拓撲（shared、partitioned、hierarchical）在 team size 和 communication mechanism 下有不同的效率特性。

### 實驗設計

- **Benchmark**：MultiAgentBench，涵蓋 coding、research、database 三個環境，multi-step、sequential tasks。
- **Baseline**：各種 memory baselines（SimpleMem、AWM 等）。
- **主要結果**：
  - LLMA-Mem 在所有 model-environment 設定中改善 lifelong learning ability。
  - Token 使用量相對 baseline 降低 9.4%–71.7%。
  - Non-monotonic scaling：更大的 team 不一定更好；記憶支持更強的經驗累積和複用時，小 team 可以超越大 team。
- **Scaling 分析**：系統性地量化 team size 增加如何改變經驗的邊際價值。更大的 team 提供更強的平行性（加速早期學習），但引入協調開銷、重複努力、碎片化資訊流（削弱長期收益）。
- **目前能確認的**：框架設計、三層記憶架構、主要結果方向和 scaling 分析從 HTML 全文確認。具體數字、每個環境的詳細結果和 ablation 需看 PDF。

### かに讀後判斷

LLMA-Mem 是 agent memory 領域近期最系統性地處理「multi-agent + lifelong learning」交互的工作。之前的工作要麼只看 single-agent memory（Knowledge Objects、Reflexion），要麼只看 multi-agent coordination 不看跨任務學習。LLMA-Mem 把兩者放在同一個框架裡。

和之前看過的 Knowledge Objects（2603.17781, 2026-06-16）相比：KO 解決的是 single-agent 的 context rot 問題——事實不應該進入 context window。LLMA-Mem 解決的是 multi-agent 的經驗複用問題——如何讓多個 agent 的經驗高效地跨任務遷移。兩者互補。

和今天第二篇 continual learning → memory（2604.27003）也有直接關聯：那篇指出 external memory 沒有解決 continual learning 問題，只是把 bottleneck 從參數更新移到記憶檢索；LLMA-Mem 的三層架構（episodic → procedural → transactive）可以看作是在這個 bottleneck 上做的具體設計選擇。

值得 Morris 點開深讀，特別是：Figure 1 的 scaling space 概念圖、LLMA-Mem 的三層記憶互動細節、non-monotonic scaling 的具體實驗結果、以及 memory topology 的比較。

## 2. When Continual Learning Moves to Memory: A Study of Experience Reuse in LLM Agents

- **arXiv**: 2604.27003
- **Link**: https://arxiv.org/abs/2604.27003
- **Authors**: Qisheng Hu, Quanyu Long, Wenya Wang (Nanyang Technological University)
- **Status**: Working in progress

### 這篇在說什麼

Memory-augmented LLM agent 看起來解決了 continual learning 的核心問題——不用更新模型參數，只要把經驗存在外部記憶裡，就能保留舊知識同時學新知識，彷彿繞過了 stability-plasticity dilemma。但這篇的核心論點是：這個挑戰並沒有消失，只是在記憶層級重新浮現。在有限的 context window 下，新舊經驗在檢索時競爭，continual learning 的 bottleneck 從參數更新移到了記憶檢索。

作者引入 (k,v) 框架來分析這個問題：k 是記憶如何組織以供檢索，v 是經驗如何被表示。這兩個軸線決定了記憶在跨任務遷移中的行為。

### 主要貢獻

1. **Memory 是 continual learning 的新戰場**：明確論證外部記憶沒有解決 continual learning 問題，只是把 bottleneck 從參數更新重定位到記憶檢索。三個具體機制：retrieval pollution（不相關記憶被召回）、context competition（有用經驗被其他 retrieved items 排擠出 context window）、memory dilution（隨記憶庫增長，相關經驗更難找到）。

2. **(k,v) 框架**：把記憶設計分解為兩個正交軸——value v（經驗如何被表示，從 raw trajectory 到 abstract procedural insight）和 key k（記憶如何被組織以供檢索，粒度和頻率）。這提供了系統性分析記憶在 continual learning 中行為的工具。

3. **Abstraction 決定記憶是幫助還是傷害**：raw trajectories 傾向阻礙新任務適應，而 abstract insights 更安全、更可重用，還能減少對舊任務的遺忘。

4. **Negative transfer 集中在困難案例**：跨任務檢索對 agent 自己處理不了的困難 case 傷害最大，已經處理得了的 case 相對穩定。

5. **Finer-grained 不一定更好**：更細的記憶粒度和更頻繁的檢索可能幫助也可能傷害，取決於存儲經驗的多樣性和目標任務的結構。

6. **Stability-plasticity trade-off 在檢索層重現**：支持新任務適應的設計可能同時導致對舊任務的嚴重遺忘。

### 方法 / pipeline

- **實驗範式**：兩個連續階段——Task A 和 Task B，各 200 個 training instances。Agent 從空記憶開始，處理 A 的 instances，然後帶著累積的記憶繼續處理 B。

- **Agent 架構**：ReAct-style 互動 loop + ReMe memory module。檢索到的經驗在第一個 action step 前插入 context。

- **LLM backbone 凍結**：沒有參數遺忘，但行為仍取決於什麼被召回 context window。

- **(k,v) 分析**：
  - Value v：從 raw trajectory → summarized trajectory → abstract procedural insight。越抽象越可遷移，但可能丟失具體細節。
  - Key k：從 coarse（task-level key）→ fine-grained（step-level key）。更細的 key 提供更精確的檢索，但可能碎片化記憶空間。

### 實驗設計

- **環境**：ALFWorld（text-based household tasks）和 BabyAI（grid-world navigation）。
- **主要結果**：
  - Abstract procedural memories 比 detailed trajectories 更可靠地遷移。
  - Negative transfer 集中在 hard cases——agent 自己處理不了的 case 受損最大。
  - Finer-grained memory organization 不普遍有益：yield 強 forward transfer 的設計可能同時導致嚴重遺忘。
  - Stability-plasticity trade-off 在檢索層重現。
- **診斷分析**：subset-level 的診斷分析定位 negative transfer 的來源。
- **目前能確認的**：核心論點、(k,v) 框架設計、主要發現方向從 HTML 全文確認。具體的 per-task 數字和 ablation 細節需看 PDF。值得注意的是這篇標注為 "Working in progress"。

### かに讀後判斷

這篇是 agent memory 領域中少數直接用 continual learning 視角檢視外部記憶的工作。它的核心論點——「外部記憶沒有解決 continual learning，只是重定位了 bottleneck」——是對目前 memory-augmented agent 浪潮的一個重要冷卻。

和 LLMA-Mem（2604.03295，今天第一篇）的直接關聯：LLMA-Mem 的 episodic → procedural 記憶分層可以被 (k,v) 框架解讀——procedural memory 就是在做「v 維度的抽象化」，讓記憶更可遷移。但 (k,v) 框架還指出了一個 LLMA-Mem 沒有明確討論的問題：更細的記憶組織可能同時導致更嚴重的遺忘——stability-plasticity trade-off 在檢索層重現。

和之前看過的 Knowledge Objects（2603.17781, 2026-06-16）的關係：KO 用外部 key-value store + O(1) 查詢來避免 context rot，而這篇指出即使有外部記憶，retrieval pollution、context competition 和 memory dilution 仍然是問題。KO 的解法是 hash 定址（避免 retrieval pollution），但 (k,v) 框架的分析表明 hash 定址可能只是把問題推到 key 的粒度選擇上。

值得注意但目前是 working paper，建議追蹤更新。如果對「agent memory 到底能不能做 continual learning」這個根本問題有興趣，(k,v) 框架是目前最好的分析工具。
