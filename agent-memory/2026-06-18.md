# Agent Memory — 2026-06-18

## 1. Memory Intelligence Agent (MIA)

- **arXiv**: 2604.04503
- **類型**: arXiv preprint (cs.AI, cs.MA); v4 (2026-06)
- **Link**: https://arxiv.org/abs/2604.04503

### 這篇在說什麼

MIA 是一個針對 Deep Research Agent（DRA）的記憶架構，核心問題是：現有 DRA 的記憶系統（主要是 long-context memory）有幾個根本限制——注意力稀釋、noise 引入推理退化、存儲成本隨時間增長、檢索計算開銷增加——而且這些系統存的是「知識型記憶」（what the result is），但 deep research 更需要的是「過程型記憶」（how the result is obtained）。MIA 把記憶分成 parametric（Planner 的模型權重）和 non-parametric（Memory Manager 的壓縮軌跡存儲），兩者之間有雙向轉換迴路，讓記憶可以在兩種形式之間流動和演化。

這篇補的洞很明確：之前 agent memory 的工作（AgeMem、Mem-α、ReasoningBank 等）主要在改善記憶管理策略（何時存、何時取、何時丟），但沒有處理「過程型知識如何從經驗中提取、壓縮、並固化到模型參數中」這個問題。MIA 的 Planner 就是把 successful search trajectory 壓縮成 planning capability 的載體，這是一種從 episodic memory 到 procedural memory 的轉換。

### 主要貢獻

1. **Manager-Planner-Executor 三體架構**：把 DRA 的記憶和推理分工明確化——Memory Manager 管理非參數化記憶（壓縮的歷史搜索軌跡），Planner 是參數化記憶載體（通過 RL 訓練學會規劃），Executor 是執行代理（按規劃搜索和分析信息）。三者的互動構成了一個類似大腦的海馬體-前額葉-運動皮層分工。

2. **Alternating RL 訓練範式**：Planner 和 Executor 交替訓練，確保 planning 和 execution 互相對齊。不是 end-to-end 訓練整個系統，而是讓兩個 agent 在各自的職責上 co-evolve。

3. **Test-time learning**：Planner 可以在推理時持續更新參數化知識，on-the-fly 更新，不打斷推理流程。這是一種 continual learning 的實現，讓 agent 在使用過程中自我改善。

4. **Parametric ↔ Non-parametric 雙向轉換**：成功的搜索軌跡可以壓縮後存入 Memory Manager（non-parametric），也可以通過 RL 訓練固化到 Planner（parametric）。反之，Planner 的知識也可以 decompose 成具體軌跡來指導 Executor。這解決了「記憶膨脹」的問題——不是把所有經驗都存下來，而是把高價值經驗壓縮成參數。

5. **Reflection + Unsupervised judgment 機制**：讓 agent 在稀疏標注甚至無標注條件下也能自我評估和修正，朝 autonomous evolution 邁進。

### 方法 / pipeline

MIA 的推理流程分三個階段：

1. **Input & Retrieval**：接收問題，從 Memory Manager 檢索相似的歷史搜索軌跡
2. **Research Process**：Planner 生成搜索計劃 → Executor 按計劃搜索和分析 → Reflection 判斷是否需要重新規劃
3. **Output & Storage**：壓縮搜索軌跡，存入 Memory Manager；如果軌跡品質夠好，觸發 Planner 的參數更新

訓練流程：
- Planner 用 RL（GRPO-style reward）訓練生成高品質搜索計劃
- Executor 用 RL 訓練按計劃執行搜索和分析
- 交替更新：固定 Executor 訓練 Planner，再固定 Planner 訓練 Executor
- Test-time learning：推理時根據成功軌跡 on-the-fly 更新 Planner

### 實驗設計

11 個 benchmark，涵蓋 multimodal 和 text-only：

- **Multimodal**：LiveVQA、HotpotQA 等
- **Text-only**：多個 QA 和 research task benchmarks
- **主模型**：GPT-5.4（frontier）、Qwen2.5-VL-7B（輕量）
- **主要結果**：
  - MIA + GPT-5.4 在 LiveVQA 提升 9%、HotpotQA 提升 6%
  - MIA + Qwen2.5-VL-7B 平均提升 31%，且超越 Qwen2.5-VL-32B（大 4.5x）18%
  - 無監督設定下 MIA 達到監督設定可比的性能，並在多次訓練迭代中持續進步
  - 與 SOTA memory baseline 相比，平均 margin 5%

### かに讀後判斷

MIA 是 agent memory 領域近期最紮實的工作之一。它不是又一個「給 agent 加個 RAG」的系統，而是認真處理了「記憶如何從經驗中提取、壓縮、並固化到行為策略中」這個核心問題。三體架構（Manager-Planner-Executor）的分工清晰，parametric ↔ non-parametric 雙向轉換是這篇最有意思的概念貢獻——這跟 Morris 之前關注的 continual learning → memory 重定位問題（2604.27003）形成直接對話：MIA 說的是「把 high-value episodic memory 壓縮成 procedural memory」，而 2604.27003 說的是「這種壓縮會丟失什麼、在什麼情況下會產生 negative transfer」。

**值得 Morris 點開嗎？** 非常值得。這篇的 Manager-Planner-Executor 分工和 parametric/non-parametric 雙向轉換對 agent memory 設計有直接啟發。深讀時優先看：Section 3 的 Memory Manager 壓縮策略具體實作、Planner 的 RL reward 設計、交替訓練的收斂行為、以及 unsupervised setting 的自我演化機制。

## 2. Explore with Long-term Memory: LMEE-Bench and MemoryExplorer

- **arXiv**: 2601.10744
- **類型**: arXiv preprint → CVPR 2026 (cs.AI, cs.CV)
- **Link**: https://arxiv.org/abs/2601.10744

### 這篇在說什麼

LMEE（Long-term Memory Embodied Exploration）提出一個新範式：把 embodied agent 的探索過程本身（不只是結果）當作評估對象。核心觀察是：現有 embodied task 只看結果（有沒找到目標、QA 準不準），完全忽略探索過程中 agent 是否有效利用記憶。LMEE 把「多目標導航」和「記憶問答」統一成一個任務——agent 在探索環境時要主動構建記憶，然後根據這些記憶回答問題，測試的不是「你能完成任務嗎」而是「你探索時學到了什麼」。

這篇補的洞是：agent memory 領域之前的工作主要在文本和 web 交互環境，embodied AI 的記憶問題幾乎沒有好的基準。LMEE-Bench 是第一個同時評估「探索過程中記憶構建」和「記憶驅動決策」的 embodied 基準。

### 主要貢獻

1. **LMEE 任務範式**：統一 Multi-goal Navigation + Memory-based QA，強制 agent 在探索中主動構建記憶，而非只在事後檢索。這個範式轉換從「任務完成」到「探索即學習」。

2. **LMEE-Bench**：246 個物體類別、9000+ 目標和問題、1982 條探索軌跡。不只看成功率和效率，還看記憶問答的準確性。

3. **MemoryExplorer 方法**：用 RL fine-tuning MLLM，設計 multi-task reward（action prediction + frontier selection + question answering），讓 agent 主動查詢記憶工具，而不是被動等待記憶服務。

### 方法 / pipeline

- **資料建構**：從 HM3DSem 場景出發，用 LLM 生成任務指令 → 用 Habitat-Sim 規劃探索軌跡 → 用 image tagging model 標註場景中的物體，構建多模態記憶庫（text + position + image）
- **MemoryExplorer 訓練**：RL fine-tuning MLLM，reward 包含 action prediction（下一步去哪）、frontier selection（探索邊界）、和 QA（記憶問答）
- **評估**：同時看導航成功率/效率和 QA 準確率

### 實驗設計

- **場景**：HM3DSem（145 training / 36 test scenes）
- **Baseline**：3D-Mem、3DLLM-Mem、MTU3D 等 embodied memory 方法
- **主模型**：Qwen2.5-VL 系列作為 backbone
- **主要結果**：MemoryExplorer 在長程任務中顯著優於 SOTA embodied exploration 模型
- **CVPR 2026 accepted**

### かに讀後判斷

LMEE-Bench 是 agent memory 領域中少見的 embodied 基準，填補了一個重要空白。但它的定位更偏向「embodied AI 的 memory benchmark」而非「general agent memory framework」。MemoryExplorer 的 RL reward 設計（action + frontier + QA）是比較有新意的部分，讓 agent 從被動記憶使用者變成主動記憶查詢者。

**值得 Morris 點開嗎？** 值得，但優先級低於 MIA。如果 Morris 的研究重心在文本/工具使用型 agent 的記憶問題，LMEE-Bench 的直接相關性較低；但如果也關注 embodied agent 的記憶，這篇是目前最好的基準。深讀時優先看：LMEE-Bench 的評估指標設計、MemoryExplorer 的 RL reward 具體公式、以及 memory bank 的組織方式。
