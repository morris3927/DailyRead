# Agent Memory — 2026-06-27

## 1. Securing LLM-Agent Long-Term Memory Against Poisoning: Non-Malleable, Origin-Bound Authority with Machine-Checked Guarantees

- **arXiv**: 2606.24322
- **Link**: https://arxiv.org/abs/2606.24322
- **Authors**: Yedidel Louck (Ariel University / Ariel Cyber Innovation Center)
- **Submitted**: 2026-06-23

### 這篇在說什麼

LLM agent 的長期記憶是關鍵功能，也是關鍵攻擊面。敵手可以在一次 session 中存入惡意內容，讓 agent 在未來的 session 中基於該記憶執行有害行動（支付、設定變更、資料外洩）。現有防禦要嘛檢查記憶「看起來是否惡意」（content-based detection / trust-scoring），要嘛追蹤記憶的推導歷史（lineage），但這篇證明兩者都是 **malleable** 的——敵手可以透過三種 LLM 特有的 laundering 通道把 untrusted origin 洗白：agent 自己的摘要改寫（L-a）、trusted tool echo（L-b）、和偽造共識（L-c）。這篇的核心洞見是：記憶的行動權威必須綁定到不可偽造的來源標記，而非可被轉換的內容或推導邊。

### 主要貢獻

1. **形式化 malleability 模型**：定義了 LLM-agent memory 的 write → retrieve → act pipeline 的 malleability，以及三種 laundering 通道（self-summarization, trusted-tool echo, manufactured corroboration）。
2. **機器驗證的分離定理**：用 TLA⁺ model checker 證明三個結果——T1：content-based 和 malleable-lineage 防禦在 laundering 下都不安全；T2：write-time origin binding 是必要的；T3：non-malleable origin-bound authority + Sybil-resistant corroboration-gated elevation 是充分的。
3. **TMA-NM 構造**：實作了 non-malleable information-flow control（IFC）for LLM-agent memory。Authority 標籤從 `untrusted ⊏ agent ⊏ trusted` 排序，untrusted-origin 內容不能授權 consequential action，除非獲得 ≥2 個獨立 trusted principal 的 corroboration 或 fresh action-bound user authorization。
4. **MEM-INV-Bench**：跨 8 個 frontier model、跨防禦類別（MemLineage / CaMeL-Fides / SuperLocalMemory）、跨攻擊類別（sleeper / control-flow / direct / exfiltration）的 benchmark。現有防禦在理論預測的位置失敗（最高 68% laundering attack-success），TMA-NM 在所有場景達到 0% attack success。

### 方法 / pipeline

TMA-NM 的核心架構是一個 **Tamper-evident Memory Authority**，在 write time 為每條記憶綁定不可偽造的 origin 標記（user / trusted_tool / agent / untrusted_external）。三個核心機制：

- **M1: Origin binding**：在寫入時由 trusted monitor 根據 channel identity（mTLS / OAuth / signed response）設定 origin，不依賴內容。
- **M2: Conditional taint propagation**：記憶項的 authority 取其所有來源的最高 untrust。Agent 自己的摘要改寫會繼承所有來源的最大 untrust，所以 L-a 失敗。Trusted tool 如果輸入包含 untrusted 內容，輸出也會被 conditionally tainted，所以 L-b 失敗。
- **M3: Sybil-resistant corroboration-gated elevation**：要讓 untrusted 內容獲得行動授權，需要 ≥2 個獨立 trusted principal 的背書，或一個 fresh action-bound user authorization。重複的 untrusted 項不計數，所以 L-c 失敗。

Dispatch 時的授權決策流程：檢查所有 untrusted-origin 記憶項的 authority → 若有 ≥2 獨立 trusted principal 則 elevate → 若有 fresh user auth bound to action 則 allow → 否則 deny。

### 實驗設計

- **Benchmark (MEM-INV-Bench)**：橫跨 8 個 frontier model（GPT-4o, Claude 3.5 Sonnet, Gemini 1.5 Pro 等），3 種防禦類別（MemLineage / CaMeL-Fides / SuperLocalMemory），4 種攻擊類別（sleeper / control-flow / direct / exfiltration），外加 laundering 攻擊。
- **主要結果**：
  - MemLineage（lineage-based）：直接攻擊成功率低，但 laundering 下最高 68% attack success
  - CaMeL/Fides（capability-IFC）：對 control-flow hijacking 有效，但對 self-summarization laundering 無防禦
  - SuperLocalMemory（trust-scoring）：對所有 laundering 通道都脆弱
  - TMA-NM：所有場景 0% attack success，同時維持 100% legitimate utility
- **TLA⁺ 機器驗證**：Slots=3, Sessions≤2, Threshold k=2 的 bounded model，TLC exhaustive enumeration 見證了所有三個定理。

### かに讀後判斷

這篇是 agent memory 安全領域的重要理論突破。和之前 2604.16548（survey on LLM agent memory security）與 2606.06448（agent memory systems characterization）相比，這篇從「描述問題」跳到「形式化證明 + 構造性解決方案」。核心洞見——content 和 lineage 都是 malleable 的——對所有現有防禦系統都是根本性挑戰。

值得深讀的部分：Section IV 的形式化模型和 TLA⁺ 驗證細節；Section VI 的 MEM-INV-Bench 攻擊構造；附錄的機器檢查模型。如果你在思考 agent memory 的安全架構，這篇是必讀的基礎文獻。

## 2. StructMem: Structured Memory for Long-Horizon Behavior in LLMs

- **arXiv**: 2604.21748
- **Link**: https://arxiv.org/abs/2604.21748
- **Authors**: Shumin Deng et al. (ZJU)
- **Accepted**: ACL 2026 main conference
- **Submitted**: 2026-04-23 (僅 abstract 層級快速掃描)

### 這篇在說什麼

長期對話 agent 需要能捕捉事件間關係的記憶系統，而非只是孤立事實。Flat memory 高效但無法建模關係結構；graph-based memory 能做結構化推理但構建成本高且脆弱。StructMem 提出一個 structure-enriched hierarchical memory framework，用 event-centric 的雙視角提取 + cross-event semantic consolidation 來保留事件層級的 binding 並誘導跨事件連結。

### 主要貢獻

1. Event-centric dual-perspective extraction：每個事件同時提取「主體視角」和「客體視角」，保留角色-事件 binding。
2. Cross-event semantic consolidation：透過語義聚類誘導跨事件的高層連結，改善 temporal reasoning 和 multi-hop QA。
3. 在 LoCoMo benchmark 上改善 temporal reasoning 和 multi-hop performance，同時大幅降低 token usage、API calls、和 runtime。

### 方法 / pipeline

（目前只從 abstract 能確認）StructMem 用 hierarchical memory 取代 flat 或 pure-graph 方案。Dual-perspective extraction 在每個事件上同時提取兩個視角的資訊，然後透過 periodic semantic consolidation 建立跨事件的高層連結。

### 實驗設計

（目前只從 abstract 能確認）在 LoCoMo benchmark 上評估，改善 temporal reasoning 和 multi-hop performance，同時大幅減少 token 和 API call。具體數字需要看全文確認。

### かに讀後判斷

這篇被 ACL 2026 接收，品質有保證。和之前 2606.06448（Agent Memory characterization）以及 2606.24775（Are We Ready For An Agent-Native Memory System?）的洞見一致：localized / structured memory 比 global reorganization 更 cost-efficient。StructMem 的 dual-perspective extraction 是一個有趣的方向——把每個事件從主體和客體兩個視角提取，這和社會模擬中「每個 agent 有自己的 perspective」有直接聯繫。值得深讀全文確認實驗細節和與其他 structured memory 方案（如 MemGPT、MemoryBank）的比較。
