# Agent Memory — 2026-06-29

## 1. TrustMem: Learning Trustworthy Memory Consolidation for LLM Agents with Long-Term Memory (2606.25161)

- **arXiv**: 2606.25161
- **Link**: https://arxiv.org/abs/2606.25161
- **Authors**: Samsung Electronics AI Center-Mountain View, University of Notre Dame

### 這篇在說什麼

LLM agent 的長期記憶系統已經從被動檢索進化到主動管理——agent 會 Write/Revise/Prune 記憶條目。但問題是：你能信任這些自主產生的記憶更新嗎？Mem1 和 Mem-T 的輸出顯示，記憶合併過程中會出現三種錯誤：Corruption（把 Voltaire 放進 17 世紀而不是 18 世紀）、Omission（丟失重要時間線）、Hallucination（編造不存在的事實）。這些錯誤一旦存入記憶就會持續影響後續推理，形成「持續性系統狀態失敗」。而且現有的 RL 訓練只用終端標量獎勵（任務是否成功），無法定位到底是哪一步記憶更新出了問題——這就是「信用分配差距」（credit assignment gap）。

TrustMem 的核心洞見是：不要只評估最終記憶狀態，而是監督每一步記憶更新是否可信。它引入 Memory Transition Verifier 評估每個轉換的 coverage（覆蓋度）、preservation（保留度）和 faithfulness（忠實度），並用 Transition-Ranked GRPO 做偏好排序的強化學習，直接優化記憶更新行為。

### 主要貢獻

1. **Memory Transition Verifier**：對每個記憶轉換 $z_t = (c_t, M_{t-1}, a_t, M_t)$ 評估三個維度——coverage（是否涵蓋了輸入中的重要資訊）、preservation（是否保留了已有正確記憶）、faithfulness（是否沒有編造不存在的事實）。這是 transition-level 而不是 trajectory-level 的監督。
2. **Transition-Ranked GRPO**：在同一記憶狀態下對多個候選更新做偏好排序，把 verifier 分數同時用於標量獎勵計算和 transition-level 偏好排名，提供比終端獎勵更精細的信用分配。
3. **全面的錯誤減少**：相比各錯誤類型的最強 baseline，TrustMem 分別減少 omission 40.1%、corruption 79.1%、hallucination 50.0%。
4. **跨 benchmark 的 SOTA**：MemoryAgentBench、HaluMem、Mem-α validation set 上都達到 SOTA，HaluMem 記憶提取提升 12.14 F1 points。

### 方法 / pipeline

TrustMem 的框架：

1. **記憶合併流程**：輸入流 $C = \{c_1, c_2, \ldots, c_T\}$ 被分塊處理。每步 agent 觀察 $(c_t, M_{t-1})$，產生結構化記憶編輯動作 $a_t \sim \pi_\theta(\cdot | c_t, M_{t-1})$，動作空間 $\mathcal{A} = \{\text{Write}, \text{Revise}, \text{Prune}\}$。
2. **記憶執行器**：確定性執行器 $\mathcal{E}$ 將動作 $a_t$ 應用到記憶庫，產生新狀態 $M_t = \mathcal{E}(M_{t-1}, a_t)$。
3. **Memory Transition Verifier**：對每個轉換 $z_t = (c_t, M_{t-1}, a_t, M_t)$ 評估：
   - **Coverage**：$M_t$ 是否涵蓋 $c_t$ 中的重要資訊？
   - **Preservation**：$M_t$ 是否保留了 $M_{t-1}$ 中的正確內容？
   - **Faithfulness**：$M_t$ 中的內容是否都能追溯到 $c_t$ 或 $M_{t-1}$？
4. **Transition-Ranked GRPO**：多個 rollout 在同一記憶狀態下產生候選更新，verifier 對每個候選打分，分數同時用於：
   - 標量獎勵 $v_t = V(z_t) \in [0,1]$（每步的監督信號）
   - 偏好排序（同狀態下候選之間的相對排序）
5. **終端評估**：所有 $T$ 步完成後，終端記憶 $M_T$ 用於下游任務，用 retriever 檢索相關記錄後由 answer model 生成預測。

### 實驗設計

- **Benchmarks**：
  - MemoryAgentBench：準確檢索、test-time learning、長程理解。
  - HaluMem：記憶提取的可靠性（hallucination 偵測）。
  - Mem-α validation set：多組件記憶的序列建構。
- **主要結果**：
  - MemoryAgentBench：比最強 baseline 高 6.5 points。
  - HaluMem：記憶提取 F1 提升 12.14 points。
  - Transition-level 錯誤率：omission -40.1%，corruption -79.1%，hallucination -50.0%（相比各類型最強 baseline）。
- **Ablation**：驗證了 Memory Transition Verifier 和 Transition-Ranked GRPO 各自的貢獻。

### かに讀後判斷

TrustMem 是 agent memory 領域本週最重要的論文。它把記憶可靠性的問題從「終端結果好不好」重新框架為「每一步更新可不可信」，這和昨天的 SAGE（用 novelty gate 在寫入端做 cheap routing）形成互補：SAGE 管效率（哪些需要 LLM 處理），TrustMem 管安全（每步更新是否可信）。兩者都在做「寫入端路由」，但目標不同——一個是成本效率，一個是可靠性。

TrustMem 的 Memory Transition Verifier 設計特別值得注意：coverage/preservation/faithfulness 三個維度抓住了記憶更新的三類主要失敗模式，而且是在 transition-level 而不是 trajectory-level 做監督。這解決了現有 RL-based memory agent 的信用分配差距問題。

## 2. MEMPROBE: Probing Long-Term Agent Memory via Hidden User-State Recovery (2606.24595)

- **arXiv**: 2606.24595
- **Link**: https://arxiv.org/abs/2606.24595
- **Authors**: Enze Ma et al.

### 這篇在說什麼

長期記憶的評估一直有個根本問題：我們測的是 agent 能不能完成任務（比如回答問題、個人化推薦），但這只是間接測量——任務成功不代表記憶本身是正確或完整的。MEMPROBE 提出：記憶應該被當作一個可審計的事後 artifact 來評估——在 agent 和用戶互動之後，我們能從它的記憶中重建出多少用戶狀態？MEMPROBE 用「隱藏用戶狀態恢復」作為直接評估指標：每個模擬用戶有一個隱藏的、基於分類法的用戶狀態庫，agent 在完成任務後，用其記憶重建這個狀態庫，然後和 ground truth 比對。

### 主要貢獻

1. **記憶作為可審計 artifact 的評估範式**：不做下游行為評估，而是直接測量記憶本身能重建多少用戶狀態。
2. **MEMPROBE benchmark**：50 個模擬用戶，每人 31 個隱藏維度（1,550 個恢復目標），5 個代表性記憶系統。
3. **關鍵發現**：任務完成幾乎飽和（即使沒有記憶的 baseline 也是），但類別平衡的恢復率只有約 0.6，在 top-k retrieval 下進一步下降。這說明「任務成功」和「記憶可審計」是兩個不同的能力。

### 方法 / pipeline

MEMPROBE 的流程：
1. 每個模擬用戶有一個 hidden user-state bank（31 個維度的分類法錨定狀態）。
2. Agent 和用戶進行一系列 leak-controlled 任務（任務設計為逐步洩漏用戶狀態資訊）。
3. 互動結束後，從 agent 的記憶中嘗試重建用戶狀態庫。
4. 在 full-store 和 top-k retrieval 兩種條件下評估恢復率。

### 實驗設計

- 50 個模擬用戶，31 個隱藏維度，1,550 個恢復目標。
- 5 個代表性記憶系統。
- 主要結果：
  - 任務完成率接近飽和，即使 memoryless baseline 也能完成大部分任務。
  - 類別平衡恢復率約 0.6，top-k retrieval 下進一步下降。
  - 成功的任務完成和可恢復的記憶是兩個不同的能力維度。

### かに讀後判斷

MEMPROBE 和 TrustMem 形成完美配對：TrustMem 說「每步記憶更新要可信」，MEMPROBE 說「即使任務成功，記憶本身可能很不完整」。兩者共同指向一個結論：記憶評估需要從下游行為轉向直接審計記憶 artifact。
