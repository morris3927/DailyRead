# Agent Memory — 2026-07-01

## 1. Supersede: Diagnosing and Training the Memory-Update Gap in LLM Agents

- **arXiv**: 2606.27472
- **Link**: https://arxiv.org/abs/2606.27472
- **Authors**: Vedant Patel, et al. (Vrin Cloud)

### 這篇在說什麼

LLM agent 在多輪對話中需要處理事實更新：用戶搬家、價格變動、計畫修改。正確行為要求 agent 使用事實的當前值，丟棄已被取代的舊值。這篇把這個能力叫「supersession」，並證明它是一個獨特的、尚未解決的失敗模式——更大的模型修不了，更大的 memory 也修不了，只有訓練才能縮小這個 gap。

### 主要貢獻

1. **隔離診斷**：在 LongMemEval 的 knowledge-update subset 上，把 agent 的 full context 替換成 bounded self-maintained memory，accuracy 從 92% 掉到 77%（gpt-5.4，paired McNemar p<0.005）。這證明瓶頸是 memory maintenance，不是 comprehension。

2. **Scale 不修復**：gpt-4.1-mini 到 gpt-5.4，full-context accuracy 從 82% 升到 92%（隨模型改善），但 bounded-memory accuracy 只從 63% 升到 77%。更大的模型只改善了 comprehension，沒有修復 supersession gap。

3. **Memory size 也不修復**：對話增長 24× 時，accuracy 從 68% 掉到 28%。給 agent 24× 更多 memory（proportional ratio setting），accuracy 還是 28%（n=25，McNemar b=c=4，no net effect）。失敗追蹤的是 conversation length，不是 compression ratio。

4. **Supersede 環境**：基於 verifiers / prime-rl stack 的開源 RL 環境，reward 是 time-indexed supersession correctness——agent 被獎勵回答 current value，被懲罰使用 stale value。這是第一個 reward target 是 temporal fact-currency 的可訓練環境。

5. **Training closes the gap**：GRPO fine-tuning Qwen2.5-3B 在 synthetic supersession 環境上訓練，held-out supersession accuracy on real unseen conversations 從 9.0% 升到 16.7%（單次 run），沿著 monotonic checkpoint curve，說明是 learned policy 而不是 harness 在起作用。

### 方法 / pipeline

Supersede 環境的核心設計：

- **Task**: 多輪對話 + 最終查詢關於一個在對話中被更新過的事實的當前值。Agent 逐 session 處理，維護一個 bounded notes field（上限 B characters）。原始 sessions 不重新饋入（no re-feeding）。

- **Reward**: r_cur = 𝟙[answer conveys current value]，用 programmatic ungameable matcher 評分（normalized variant match + token-overlap fallback）。在已知 stale values 時加 r_stale = −𝟙[answer asserts superseded value]。

- **Data**: LongMemEval knowledge-update subset（真實對話中的 supersession）+ procedural generator（synthetic timelines，用於控制和訓練）。

- **Training**: Qwen2.5-3B-Instruct + GRPO (LoRA rank 32, α=64, lr 10⁻⁵, batch 32, group 8, 4×A10G)。訓練數據是 synthetic generator 的 2000 episodes，held-out evaluation 用 real LongMemEval。

- **關鍵設計理由**：作者發現 synthetic templated supersession 在 frontier models 全 context 下是 saturated（100%）——因為 clean explicit updates 太容易了。所以用真實對話數據做 evaluation，用 synthetic 做訓練 curriculum（小模型即使在 synthetic 上也遠未飽和），測量 transfer from synthetic to real。

### 實驗設計

- **Section 5.1**: 78 oracle questions, 3 models (gpt-4.1-mini, gpt-4.1, gpt-5.4), full-context vs. bounded-memory。 McNemar paired test 顯著。
- **Section 5.2**: Scale study，gpt-4.1-mini, n=25，conversation 從 ~2 sessions 增長到 ~48 sessions（24×），memory 從 300 chars 到 ~7,150 chars。結果：accuracy 68% → 28%（more history）→ 28%（proportional memory, no recovery）。
- **Section 5.3**: Training result，Qwen2.5-3B，synthetic → real transfer。Supersession accuracy 9.0% → 16.7%（monotonic checkpoint curve）。
- **Limitation**: 目前是單次 training run（multi-seed significance 在進行中），只測了 Qwen2.5-3B 一個 model。

### かに讀後判斷

這篇和 DailyRead 之前讀過的幾篇 agent memory paper 有直接對話：

- vs. STALE（2605.06527，5/24 已讀）：STALE 測量的是「agent 能否辨識記憶已過期」，Supersede 測量的是更根本的問題——「agent 在 bounded memory 下能否維持 current value」。STALE 是 evaluation-only，Supersede 是第一個提供 trainable signal 的。
- vs. ForgetEval（2606.15903，6/30 已推薦）：ForgetEval 測量 forgetting 能力，Supersede 測量的是 memory-update（supersession）能力。但 Supersede 的發現更尖銳：更大的 memory 修不了這個問題。
- vs. Memory Contagion（2606.23195，6/30 已推薦）：Memory Contagion 說 evaluator bias 會透過記憶系統傳播。Supersede 從另一個角度說明：即使沒有 bias，純粹的 fact supersession 在 bounded memory 下就是會失敗。

這篇的核心 insight 對設計 agent memory 系統的人來說非常重要：memory maintenance 不是 comprehension 問題，不是 scale 問題，也不是 memory size 問題。它是一個需要專門訓練信號的技能。OpenAI 自己的「Dreaming」和 Anthropic 的 Claude memory 都只有 ~75% 的 update success rate（論文引用），這和 Supersede 測量的 gap 一致。

深讀時建議看：Figure 2 和 Figure 3（full-context vs. bounded-memory 的 gap 和 scale study）、Table 2（proportional memory 沒有 recovery 的關鍵數據）、Section 5.3 的 training curve（monotonic improvement 說明是 learned policy）。

## 2. Transformers Remember First, Forget Last: Dual-Process Interference in LLMs

- **arXiv**: 2603.00270
- **Link**: https://arxiv.org/abs/2603.00270
- **Authors**: Sourav Chattaraj, Kanak Raj (Thomson Reuters)

### 這篇在說什麼

當 LLM 在 context 中遇到衝突資訊時，哪些記憶會存活——早期的還是最新的？這篇從認知心理學借用了 interference paradigm，測試了 39 個 LLM，發現所有模型都表現出同一個模式：proactive interference（PI，舊記憶干擾新記憶）全面壓過 retroactive interference（RI，新記憶干擾舊記憶），Cohen's d=1.73。這和人類記憶完全相反（人類是 RI > PI）。

### 主要貢獻

1. **Inverted interference profile**：所有 39 個模型都顯示 PI >> RI（d=1.73, p<0.0001），和人類記憶中 RI 通常主導的模式相反。Transformer 的 attention 機制產生了 primacy protection。

2. **Dual-process evidence**：RI 和 PI 不相關（R²=0.044），拒絕了「統一記憶容量」的假說。Model size 預測 RI resistance（R²=0.49）但不預測 PI（R²=0.06, n.s.）。這和認知科學的 consolidation-retrieval 區分平行。

3. **Cognitive failure taxonomy**：RI 失敗是被動的（51% 是 retrieval failure，模型「找不到」），PI 失敗是主動的（56% 是 primacy intrusion，舊值主動侵入）。兩者 hallucination < 1%——模型混淆的是位置，不是編造。

### 方法 / pipeline

從認知心理學的 paired-associate learning paradigm 改編：

- **RI condition**: 先學 A-B pair，再學 A-C pair，測試能否回憶 B（initial value）。新學習干擾了對舊記憶的提取。
- **PI condition**: 先學 A-B pair，再學 A-C pair，測試能否回憶 C（recent value）。舊記憶干擾了對新學習的提取。
- 測試了 39 個 LLM（不同架構和規模），N 從 5 到 300（interfering items 數量）。
- Metric: accuracy on recalling the target value under RI vs. PI conditions。

### 實驗設計

- **Models**: 39 LLMs across diverse architectures and scales
- **Conditions**: RI (recall initial after updates) vs. PI (recall recent after prior items)
- **N values**: 5, 10, 25, 50, 100, 200, 300 interfering items
- **Key results**:
  - RI accuracy: 96% at N=50, drops sharply to 27% at N=300
  - PI accuracy: 85% at N=5, collapses to 2% at N=300
  - PI >> RI universally (d=1.73)
  - RI × PI correlation: R²=0.044
  - Model size → RI resistance: R²=0.49
  - Model size → PI resistance: R²=0.06 (n.s.)
- **Error analysis**: RI failures = passive retrieval failures (51%); PI failures = active primacy intrusions (56%); hallucination < 1% in both.

### かに讀後判斷

這篇和 Supersede（今天的推薦篇 1）有直接對話：

- Supersede 發現更大的模型修不了 supersession gap——這篇解釋了為什麼：PI（proactive interference）是 capacity-independent 的，所以 scale 幫不了。
- Supersede 發現更大的 memory 也修不了——這篇的 N-scaling 實驗（more interfering items → more PI failure）和 Supersede 的 conversation length scaling 一致。
- 但這篇用的是 context-window interference，不是 bounded memory，所以結論不能直接搬到 memory system 設計。這是一個需要深讀時注意的 gap。

和 DailyRead 之前的 memory paper 的關係：
- 和 Memory Contagion（2606.23195）的「length bias」呼應——primacy bias 就是 length bias 的機制基礎
- 補充了 ForgetEval（2606.15903）沒有覆蓋的方向：ForgetEval 看 forgetting 的正確性，這篇看 interference 的方向性

這篇是 2026 年 2 月的 paper（v1），但之前沒有在 DailyRead 收錄過。深讀時建議看 Figure 1（PI vs. RI curve）、Figure 2（model size vs. RI/PI correlation）、以及 error analysis 的具體分類。

## 3. FORGE: Self-Evolving Agent Memory via Population Broadcast

- **arXiv**: 2605.16233
- **Link**: https://arxiv.org/abs/2605.16233
- **Authors**: Igor Bogdanov, et al.

### 這篇在說什麼

LLM agent 能否不通過梯度更新，只用 self-generated natural-language memory 來改善決策？FORGE（Failure-Optimized Reflective Graduation and Evolution）提出了一個 population-based protocol：一個 inner loop 用 reflection agent 把失敗軌跡轉成 reusable knowledge artifacts（Rules、Examples、或 Mixed），outer loop 把最佳實例的 memory 廣播給整個 population，同時凍結已收斂的實例。

### 主要貢獻

1. **Population broadcast 機制**：不是單一 agent 自己反思，而是一群 agent 各自嘗試，最好的 memory 會被廣播給所有人。消融實驗確認 broadcast 是 performance gain 的主要來源，graduation 主要省 compute。

2. **三種 memory representation**：Rules（文字 heuristics，最省 token ~40%）、Examples（few-shot demonstrations，最高 return）、Mixed（兩者混合）。三種都有效，但 Examples 在 4 個模型中的 3 個達到最強 return。

3. **弱模型受益更多**：FORGE 可能是在彌補 capability gap 而不是放大強模型，這對實際部署有重要意義。

### 方法 / pipeline

- **Inner loop**: Reflexion-style，dedicated reflection agent（用同一個 underlying LLM，不蒸餾）把失敗軌跡轉成 textual heuristics (Rules)、few-shot demonstrations (Examples)、或兩者 (Mixed)。
- **Outer loop**: Propagate best-performing instance 的 memory 給整個 population。Freeze converged instances via graduation criterion。
- **Evaluation environment**: CybORG CAGE-2，stochastic network-defense POMDP，30-step horizon，against B-line attacker。4 個 LLM families：Gemini-2.5-Flash-Lite, Grok-4-Fast, Llama-4-Maverick, Qwen3-235B。
- **Baseline**: zero-shot baseline 和 isolated Reflexion baseline（single-stream learning）。

### 實驗設計

- **Environment**: CybORG CAGE-2, B-line attacker, 30-step horizon
- **Models**: 4 families (Gemini-2.5-Flash-Lite, Grok-4-Fast, Llama-4-Maverick, Qwen3-235B)
- **Representations**: Rules, Examples, Mixed × 4 models = 12 conditions
- **Results**: 
  - FORGE improves average evaluation return by 1.7–7.7× over zero-shot
  - 29–72% improvement over Reflexion baseline across all 12 conditions
  - Major failure rate (< -100) reduced to ~1%
  - Examples: strongest returns for 3/4 models
  - Rules: best cost-reliability profile, ~40% fewer tokens
  - Weaker models benefit disproportionately
- **Limitation**: 只測了 CAGE-2 B-line 一個場景，cross-family findings 是 directional evidence。

### かに讀後判斷

FORGE 是 agent memory 從「被動存取」走向「主動演化」的一個實例，但它的「演化」是 population-level broadcast，不是單一 agent 的 self-reflection。這和 Supersede 的方向不同：Supersede 解決的是「如何維持 current value」，FORGE 解決的是「如何從失敗中學習 reusable knowledge」。

和之前 DailyRead 的關係：
- 和 Memory Contagion（2606.23195）的對比很有意思：Memory Contagion 說 evaluator bias 會透過記憶傳播，FORGE 的 population broadcast 恰好是利用「好的 memory 傳播給所有人」——但如果 broadcast 的 memory 帶有 bias，FORGE 的機制反而會放大它。
- 和 Multi-Factor Value Model（6/30 已推薦）的 encoding/forgetting/retrieval 三層相比，FORGE 的 memory 只在 encoding 層做事情（從失敗中提取 Rules/Examples），沒有明確的 forgetting 或 retrieval 機制。

深讀時建議看：population broadcast vs. no-graduation ablation 的具體數據、以及 per-model 的 Rules vs. Examples vs. Mixed breakdown。

## 4. Agent Unlearning: Privacy-Driven Forgetting in LLM Agents

- **arXiv**: 2604.00430
- **Link**: https://arxiv.org/abs/2604.00430
- **Authors**: Dayong Ye, et al.

### 這篇在說什麼

LLM agent 會累積敏感或過時的知識，需要選擇性遺忘。這篇提出了一個分類框架，把 agent unlearning 分成三類：state unlearning（遺忘特定狀態或項目）、trajectory unlearning（遺忘行動序列）、environment unlearning（遺忘整個環境或任務類別）。並提出了一個 natural language-based unlearning method，訓練一個 conversion model 把高層 unlearning request 轉成可執行的 unlearning prompts。

### 主要貢獻

1. **三分類框架**：state / trajectory / environment unlearning，涵蓋了 agent 需要遺忘的不同粒度。

2. **Natural language unlearning method**：不是在模型權重上做 machine unlearning，而是訓練一個 conversion model 來生成 unlearning prompts，引導 agent 進入受控的遺忘過程。

3. **Adversarial evaluation**：引入 unlearning inference adversary，用來測試遺忘是否真的有效——adversary 會 craft prompts 來試探推斷被遺忘的知識。

### 方法 / pipeline

目前只從 abstract 和 landing page 確認到以上資訊。論文的 PDF 需要進一步閱讀來確認 conversion model 的架構、訓練數據、以及 evaluation 的具體設計。

### 實驗設計

從 abstract 確認：實驗結果顯示這個方法能有效讓 agent 遺忘目標知識，同時保留非目標任務的表現，並防止 adversary 推斷遺忘的知識。但具體的 dataset、baseline、metric 需要看全文確認。

### かに讀後判斷

這篇和今天的推薦篇 Supersede 有直接對話：Supersede 說「agent 在 bounded memory 下無法維持 current value」，這篇說「有時候我們需要主動遺忘某些 value」。兩者是同一枚硬幣的兩面——一個是「忘不掉舊的」問題，一個是「需要忘掉某些」問題。

和之前 DailyRead 的關係：
- 和 FragFuse（6/30 已推薦）的攻擊面對比：FragFuse 是 fragment + fusion bypass access control，這篇是主動遺忘。如果 unlearning 做不好，可能產生和 FragFuse 類似的漏洞。
- 和 STALE（5/24 已讀）的 implicit conflict detection 對比：STALE 是被動發現記憶過期，這篇是主動遺忘。但 unlearning 的 adversary 可以用類似 STALE 的 implicit conflict 來測試遺忘是否真的有效。
