# Agent Memory — 2026-07-03

## 1. Memory Depth, Not Memory Access: Selective Parametric Consolidation for Long-Running Language Agents

- **arXiv**: 2606.26806
- **Link**: https://arxiv.org/abs/2606.26806

### 這篇在說什麼

長期運行的 language agent 需要的不只是記憶取回（memory access），更需要記憶深度（memory depth）。RAG 可以取回過去的事實，但不決定哪些經驗應該在 working context 卸載後繼續影響行為。這篇把這個區分形式化為「深度翻轉」：在 shallow factual recall 上 RAG 最強，但在 goal persistence 和 post-unload recovery 上 EVAF 遠超 RAG。EVAF 用 surprise × valence gate 選擇性地將行為相關事件寫入 LoRA adapter，只用了 22–33 次 parametric writes per 200 events。

### 主要貢獻

1. **Memory depth vs memory access 的形式化區分**：retrieval 解決「什麼能被取回」，但不解決「什麼應該持續影響行為」。這個區分在 agent memory 文獻中是新的。
2. **Loop-drift protocol**：一個受控壓力測試，retrieval index 保持完整但 working context 被卸載，分離了 access 和 depth。
3. **深度翻轉（depth flip）**：RAG 在 short-fact accuracy 上 0.956–0.973 領先，EVAF 在 goal persistence 上 0.812–0.904 領先——預期的贏家隨記憶深度翻轉。
4. **Selection 和 actuation 是可分離控制因子**：matched random gate 在 GPT-2 上輸給 EVAF（selection 不是只有 sparsity），但 Mistral-7B 上 miscalibrated actuation 反轉比較結果。
5. **Public Memora event streams 作為外部診斷**：EVAF 在 stale-memory rejection 上方向性正向但不顯著，暴露 deletion/update validity 是未解決邊界。

### 方法 / pipeline

- **EVAF selection gate**：對每個 event $x_t$，計算 surprise score $s_t$（token negative log-likelihood）和 valence score $v_t$（embedding similarity to durable goal），寫入分數 $g_t = \sigma(k_s(s_t - \tau_s)) \cdot \sigma(k_v(v_t - \tau_v))$。超過閾值 $\tau_w$ 才進入 buffer。
- **LoRA consolidation**：buffer 滿時，用 buffer + replay + L2 anchor 更新 LoRA adapter，防止 drift。
- **Actuation controllers**：fixed-inner（1/2/3 LoRA steps）、behavior-margin、routed EVAF+RAG。
- **Loop-drift protocol**：10 個 synthetic users × 200 events/user，包含 stable goals、distractors、transient opposite requests、conflicts、sibling-user contamination、factual notes。四個 probe layers：shallow episodic access、noisy episodic access、parametric tendency、post-unload recovery。

### 實驗設計

- **Models**：GPT-2、TinyLlama（4 seeds each）、Mistral-7B（fixed-inner audit）。
- **Baselines**：Frozen、Summary、RAG、Naive-LoRA、EVAF、Routed EVAF+RAG。
- **核心結果（Table 2, Figure 1）**：
  - RAG：short-fact 0.956–0.973，goal 0.396–0.398，post-unload 0.394–0.398。
  - EVAF：short-fact near chance（gate rejects off-topic factual notes），goal 0.833–0.904，post-unload 0.812–0.900。
  - Naive-LoRA：writes every event，costly 但 goal layer 不如 EVAF。
  - Routed EVAF+RAG：GPT-2 上恢復 shallow access 同時略改善 goal layer；TinyLlama 上 trade ~6 points goal/post-unload for near-perfect short-fact recall。
- **Mechanism controls**：matched random gate 在 GPT-2 上輸給 EVAF（selection beyond sparsity）；Mistral-7B fixed-inner audit 顯示 actuation strength 是 model-dependent factor；Mistral-7B matched-gate inversion 顯示 asymmetric selection–actuation coupling under miscalibrated actuation。
- **Memora 外部診斷**：directionally positive 但不顯著的 stale-memory rejection，exposing deletion/update validity as future work。

### かに讀後判斷

這篇在 agent memory 文獻中提出了一個乾淨的概念區分（depth vs access），且實驗設計嚴謹：loop-drift protocol 把 retrieval index 保持完整，只卸載 working context，分離了兩個問題。深度翻轉是核心發現——RAG 和 parametric consolidation 不是競爭關係而是互補關係，routing 可以組合兩者。selection–actuation 分離的控制實驗特別有價值：不是所有寫入都一樣，寫入強度是 model-dependent 的。和昨天的 Mandol（統一 agglomerative memory）以及 MRAgent（主動重建式 graph memory）形成三角：Mandol 解決統一表示和查詢效率，MRAgent 解決動態取回路徑，EVAF 解決「什麼應該留下」的深度問題。值得深讀 Section 3（EVAF 方法細節）、Table 2（深度翻轉數據）、Table 1（Mistral fixed-inner audit）、Section 6（mechanism controls）。
