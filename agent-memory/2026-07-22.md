# Agent Memory — 2026-07-22

## 1. When Does Continual Learning Require Learning (2607.07847)

- **arXiv**: 2607.07847
- **Link**: https://arxiv.org/abs/2607.07847
- **Authors**: Anne Harrington, Nayan Saxena, Michael Murphy, Anastasia Borovykh, Zeyu Yun, Sridhar Kamath, Ara Eindra Kyi, Trevor Darrell, Jitendra Malik, Yutong Bai (UC Berkeley, Independent, Capital Fund Management)

### 這篇在說什麼

Continual learning 在 LLM 領域通常被框定為「防止遺忘」或「context 管理」。這篇論文說這個框定不完整：continual learning 的核心應該是「隨世界變化而增加能力」。作者把變化沿兩個軸拆解——空間（新 domain 到來）和時間（固定 task 下的 data drift）——然後在一個統一的 protocol 下比較 prompt-based、supervised、RL、和 context compression 四大類方法，看每種方法在什麼樣的環境變化下需要什麼樣的更新。

這對 agent memory 領域的意義是：不管你用什麼 memory 結構，新增 memory 時如果沒有考慮到「這是 spatial shift 還是 temporal drift」，就會選錯更新策略。這篇給了什麼時候該用 context/prompt（外部 scaffolding 就夠）、什麼時候必須改 weights（真正需要 learning）的實驗依據。

### 主要貢獻

1. **重新定義 continual learning**：從「防遺忘」轉向「增加能力」，並沿空間/時間兩軸拆解環境變化。時間軸再分三個 sub-regime：slow trends（年報）、discrete fact changes（Wiki 修訂）、agentic accumulation（agent 自己的行為改變了環境狀態）。

2. **統一的 mechanism-agnostic protocol**：把 prompt-based (GEPA, ACE)、supervised (SFT, SDFT)、RL (GRPO, SDPO)、context compression (Cartridges, In-place TTT) 全部放在同一個 sequential evaluation framework 下比較，用 forgetting matrix（每個 stage 之後在所有 stage 的 eval set 上測試）取代單一 accuracy 數字。

3. **系統性的 tradeoff 發現**：
   - Prompt-based 方法（GEPA, ACE）fit 每個新 stage 很快，但嚴重 degrade 在未來 tasks。
   - Distillation-based 方法（SDFT, SDPO）穩定累積知識，但難以更新過時 facts。
   - Context compression（Cartridges, TTT）提升效率但不大幅改善 learning 新 tasks 的能力。
   - Online RL（GRPO）最能適應 knowledge updates，但對 noisy reward 敏感。
   - 在 agentic axis 上，ACE 和 SFT 都能 compound experience，但絕對成功隨 chain 長度衰減。

4. **Continual learning 不是單一能力**：不同形態的環境變化需要根本不同的更新行為。這推翻了「一個方法解決所有 continual learning 問題」的幻想。

### 方法 / pipeline

Protocol 設計：
- Agent 依序看到 stages T_1, ..., T_K，每個 stage 有 training distribution D_k^tr 和 eval set D_k^eval。
- Stage 之間，learner 套用 update operator U_k，可改 model weights、改 system prompt、寫 external memory、或什麼都不改。
- 每個 stage 後，在所有 eval sets 上評估，產生 forgetting matrix R_{i,j} = acc(θ_i, D_j^eval)。

方法分類：
| Family | Where update is stored | Methods |
|--------|----------------------|---------|
| Prompting | Context | GEPA, ACE |
| Fine-tuning | Parameters | SFT, SDFT |
| RL | Parameters | GRPO, SDPO |
| Compression | External state | Cartridges, In-place TTT |

所有方法用同一個 backbone（Qwen3-8B）、同一個 per-stage compute budget。

### 實驗設計

- **Backbone**: Qwen3-8B
- **Benchmarks**: 多個 sequential LLM tasks，包括 domain adaptation, agentic tasks, financial analysis, temporal knowledge updates。
- **Forgetting matrix**: 評估每個 method 在每個 stage 之後在所有 eval sets 上的表現，不只是最終 stage。
- **Agentic axis**: 特別設計了 agent chain 設定，stage ordering 由 agent 自己的行為決定，而非人工指定。
- **Main findings**: 如上所述的四類 tradeoff，以及 agentic setting 下 ACE 和 SFT 的 compound 效應。
- **目前從 HTML 全文能確認到上述所有核心實驗結構和主要發現。** 具體的 per-benchmark 數值、forgetting matrix 的熱圖、和 per-method 的消融細節需要看論文完整表格和圖。

### かに讀後判斷

這篇跟 DailyRead 之前追蹤的 agent memory 主線高度相關。前天推薦的 Do Self-Evolving Agents Forget (2605.09315) 把 catastrophic forgetting 從 model parameter 推廣到所有 self-evolution channel；這篇則從另一個角度切入——不是問「forgetting 怎麼發生」，而是問「什麼時候你真的需要 learning（改 weights），什麼時候外部 scaffolding 就夠了？」

兩篇合在一起看很有意思：Self-Evolving Agents 說每個 channel 都會 erode，CPE 用 retention regularizer 來緩解；When Does CL Require Learning 則說要看環境變化的形態——spatial shift 可能需要 weight update，temporal drift 中的 slow trends 用 context extraction 就夠，但 discrete fact changes 需要真的改 belief。這為 agent memory 的設計提供了更精細的決策框架：不是所有 memory update 都該用同一個策略。

值得 Morris 點開。深讀時優先看：(1) Forgetting matrix 的完整熱圖、(2) Agentic axis 的實驗細節（agent chain 怎麼定義的）、(3) Figure 1 的 unified framework diagram、(4) 各 method 在 financial analysis task 上的表現差異。

## 2. Forget to Improve: On-Device LLM-Agent Continual Learning via Budget-Curated Memory (CURATOR) (2606.25115)

- **arXiv**: 2606.25115
- **Link**: https://arxiv.org/abs/2606.25115
- **Authors**: Beining Wu et al. (Notre Dame)

### 這篇在說什麼

On-device LLM agent 的 memory 是有硬上限的：RAM 有限、能耗有限、uplink 頻寬有限，而且 memory 可被寫入代表它是攻擊面。現有系統各解決一塊問題（agentic memory 無上限成長、on-device 方法只看成功就保留、memory poisoning 只當攻擊看而不當 governance 問題看）。CURATOR 提出一個統一的 net-value-per-byte score 來治理 agent 的 experience-memory 生命週期，用同一把尺決定 KEEP、SHARE、TRUST 三個決策。

### 主要貢獻

1. **Net-value-per-byte score**：一個 memory entry 的 score = value - harm（per byte），讓一個 ruler 同時決定 keep/share/trust。
2. **三個決策**：KEEP（在 RAM/energy 預算下驅逐低價值 bytes）、SHARE（只在 insight 價值超過 uplink cost 時才分享）、TRUST（用 provenance gating 過濾 peer entries）。
3. **攻擊面防禦**：將 injection success 從 0.75 降到 0。

### 方法 / pipeline

Memory lifecycle 由 net-value-per-byte 統一治理。Value 來自 task utility（這個 memory entry 幫了多少），harm 來自 poisoned/stale 的風險。每個 entry 被評分後，KEEP 決策驅逐低價值 entries，SHARE 決策只在高價值超過傳輸成本時分享，TRUST 決策用 provenance 驗證 peer entries。

### 實驗設計

- **Benchmarks**: language-model-agent task-drift benchmarks + 真實 heterogeneous Jetson testbed（兩個 robot-arm nodes + 一個 hub）。
- **Main results**: memory 減少 2.7×，uplink 減少 2.4×，injection success 從 0.75 降到 0，accuracy 在被 poison 或 stale memory 損壞的 cases 上反而提升。
- **目前只能從 abstract 確認以上**。論文有完整的 on-device 實驗設計，但 per-benchmark 細節、net-value-per-byte 的具體計算方式、和與其他 memory management 方法的比較需要看全文。

### かに讀後判斷

CURATOR 是 agent memory 領域少數同時處理 efficiency、communication cost、和 security 三個問題的工作。跟 Infini Memory (2606.10677) 的 topic-structured persistent memory 互補：Infini Memory 處理的是 memory 的組織結構，CURATOR 處理的是 memory 的生命週期治理。兩者可以組合。

目前只有 abstract 層級，建議列為候補。如果 Morris 對 on-device deployment 或 memory security 特別有興趣，值得看全文的 Jetson testbed 實驗和 provenance gating 的實作細節。

## 3. Threading the Maze of Lifelong Memory for LLM Agents (AriadneMem) (2603.03290)

- **arXiv**: 2603.03290
- **Link**: https://arxiv.org/abs/2603.03290
- **Authors**: Wenhui Zhu, Xiwen Chen, Zhipeng Wang, Jingjing Wang, Xuanzhao Dong, Minzhou Huang, Rui Cai, Hejian Sang, Hao Wang, Peijie Qiu, Yueyue Deng, Prayag Tiwari, Brendan Hogan Rappazzo, Yalin Wang

### 這篇在說什麼

Long-horizon LLM agent 的 memory 系統在固定 context budget 下有兩個核心問題：(i) disconnected evidence（multi-hop 答案需要跨時間連結分散的事實）和 (ii) state updates（演變中的資訊跟舊的 static logs 衝突）。AriadneMem 提出一個解耦的兩階段 pipeline：offline construction 用 entropy-aware gating 和 conflict-aware coarsening 處理噪音和重複；online reasoning 用 algorithmic bridge discovery 重建檢索事實間的缺失邏輯路徑。

### 主要貢獻

1. **Entropy-aware gating**：在 offline 階段過濾低資訊量的訊息，減少後續處理量。
2. **Conflict-aware coarsening**：合併 static duplicates 但保留 state transitions 作為 temporal edges，解決 state update 問題。
3. **Algorithmic bridge discovery**：在 online 階段，不用昂貴的 iterative planning，而是用演算法重建檢索事實間缺失的邏輯路徑，解決 disconnected evidence 問題。

### 方法 / pipeline

Two-phase pipeline：
- **Offline construction**: entropy-aware gating 過濾 → LLM extraction → conflict-aware coarsening 合併 duplicates、保留 temporal edges。
- **Online reasoning**: 檢索相關事實 → algorithmic bridge discovery 重建邏輯路徑 → 生成最終答案。

### 實驗設計

- **目前只能從 abstract 確認上述方法設計**。論文的 benchmark、baseline、metric、和具體數值需要看全文。從方法描述推斷，benchmark 可能包含 long-term dialogue 和 multi-hop QA。

### かに讀後判斷

AriadneMem 直接攻擊 agent memory 的兩個經典失敗模式：disconnected evidence 和 state updates。跟 Infini Memory (2606.10677) 的 topic-structured approach 相比，AriadneMem 更偏演算法化（bridge discovery 是 graph search 而非 LLM planning），可能更 deterministic 但彈性較低。跟 STALE (2605.06527) 的 belief revision 問題也有關聯：AriadneMem 用 conflict-aware coarsening 處理 state updates，STALE 用 implicit conflict detection。
