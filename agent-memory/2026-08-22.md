### 這篇在說什麼

FinPerMA 處理的是 agent memory 裡一個比「能不能記得事實」更難的問題：長期個人化 agent 是否能在重大事件後更新使用者模型。作者用金融顧問作為場景，理由很清楚：投資者的風險偏好、資產偏好、反應方式會受到市場崩盤、升息、銀行倒閉、個人事件等影響；如果 agent 只記得使用者以前說過「我風險承受度中等」，卻沒有把 2022 rate-hike cycle 或 2023 SVB collapse 後的行為變化整合進 persistent memory，它給出的建議就會 stale。

這篇對現有 personalized-memory benchmark 的批評有兩點。第一，很多 benchmark 測 factual retention、long-context recall 或 explicit updates，但不太能分離「記得舊資訊」與「重大事件後的 latent preference adaptation」。第二，如果 user trajectory 是弱約束 LLM 生成，標籤本身會混入 generator 的任意性。FinPerMA 因此用 deterministic theory-informed rules 先約束事件衝擊，再產生並凍結 dialogues / labels，讓後續 memory system 都面對同一套 frozen corpus。

### 主要貢獻

第一，FinPerMA 提出 event-grounded personalized-memory benchmark，同時測 stable-profile recall 和 event-conditioned preference adaptation。它的核心不是要 agent 背出 persona，而是要 agent 從 persona、事件 timeline、多 session 對話中推斷更新後的使用者狀態。

第二，它設計 Post-Shock checkpoint，專門檢查 agent 是否在高嚴重度事件後整合新偏好。這比一般「幾輪後問你還記不記得」更接近真實 personal assistant 需求，因為使用者模型不是靜態 facts，而是會被事件改寫。

第三，資料生成 pipeline 有可審計性。它用三層 Impact Model：Layer 1 deterministic rules 產生 ImpactConstraint；Layer 2 LLM narrator 在 hard constraints 下生成 event reaction；Layer 3 validator 檢查 risk direction、magnitude bounds、forbidden biases、evolution type，不合格就 retry，最後才進 frozen corpus。

### 方法 / pipeline

FinPerMA 的 corpus object 包含 persona、persona-specific event timeline、multi-session dialogues、evaluation questions。persona 由 demographic、financial profile、psychometric variables 組成，並分類成四種 Behavioral Investor Types：Passive Preserver、Friendly Follower、Independent Individualist、Active Accumulator。作者用 rejection sampling 確保每類至少佔 20%。

事件 timeline 涵蓋 97 個 2020–2026 的 dated events，包括 17 個 macro、64 個 industry、16 個 personal events。每個 persona 會抽 5–8 個事件，需符合 category diversification 和至少四週間隔。Impact Model 的 rule layer 會根據 BIT、event type、severity、Big-Five trait multiplier、experience-history aggregation、symbolic memory-reference anchor 產生 impact constraint。接著 LLM narrator 依 constraint 生成 preference_deltas、inner_monologue、biases_triggered、confidence；validator 用硬規則檢查方向、幅度、bias 與 evolution type。

Evaluation task 有三個 dimension：Memory Fidelity（persona attributes / past behaviors factual recall）、Preference Reasoning（從行為 traces 推斷 implicit preferences）、Context Adaptation（在新 decision scenario 中使用更新後偏好）。時間上有四個 checkpoint：Zero-memory control、In-timeline、Post-distraction、Post-Shock。Post-Shock 是這篇最重要的 protocol contribution。

### 實驗設計

摘要與方法段落可確認，FinPerMA 最終評估 276 personas 的 2,994 questions，涵蓋 7 個 frontier LLMs 和最多 7 種 memory configurations。結果遠未飽和：full-context configuration 的 overall accuracy 沒有超過約 0.47，multiple-choice accuracy 約 39% 左右。這代表即使把大量上下文塞進去，模型也不一定能穩定整合長期個人化狀態。

作者特別指出 summary-based memory 的問題：它常能保留 factual details，卻丟掉真正影響個人化推薦的 preference signals。更麻煩的是，shock 之後這個 gap 會變大；也就是說 summary 可能把「發生過什麼」記下來，但沒有把「這件事如何改變使用者風險偏好 / 投資行為」記成可被未來決策使用的 state。這也解釋為什麼 simple retrieval 在某些情況下反而可以勝過 purpose-built memory systems。

### かに讀後判斷

這篇很值得 Morris 點開，尤其適合接在 LeanMem、MEM1、STALE、Memora 之後讀。LeanMem 關心的是如何低成本整理 profile / event / record；MEM1 關心是否能把記憶內化成模型行為；STALE 關心舊記憶何時失效；FinPerMA 則把問題釘在「事件後個人化偏好是否更新」這個更高風險場景。

我會建議優先看 Figure 1–3、Section 2.4 的 Impact Model、Section 2.6 的 evaluation grid，以及 results 裡 memory configuration 的 breakdown。要注意的是，FinPerMA 的 deterministic impact rules 不是金融行為的真實 structural model，作者也明確說它是 benchmark operationalization；因此它更適合作為 memory system stress test，而不是拿來推論真實投資者會如何反應。但作為 agent memory benchmark，它的 Post-Shock 設計非常有啟發性。
