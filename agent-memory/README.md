# Agent Memory

這個 domain 追蹤 LLM agents 的記憶機制：長期記憶、短期記憶、episodic memory、semantic memory、檢索、壓縮、反思、遺忘與 memory operating system。

## 觀察重點

- 記憶如何寫入、檢索、壓縮、更新與刪除？
- episodic / semantic / procedural memory 如何在 agent 中落地？
- memory 是為了任務表現、長期一致性，還是個人化互動？
- memory system 如何評估？用什麼 benchmark 或問答任務？
- production agent memory 與研究型 memory architecture 有什麼差異？

## 常見類型

- Survey: agent memory taxonomy
- Method: dynamic memory linking、reflection、memory consolidation
- System: Mem0、MemOS、memory OS、agent memory framework
- Evaluation: long-horizon dialogue、LOCOMO、multi-hop memory QA

## Keywords

agent memory, long-term memory for LLM agents, episodic memory, semantic memory, memory retrieval, reflective memory, memory consolidation, forgetting in agents, RAG for agents, cognitive architecture.
