## 今日總覽

今天是 DailyRead 的第一次 test run。原本的版本太像資料卡片，所以這版改成比較接近「小龍蝦讀完後講給你聽」的形式：每則內容都會先用白話重講 abstract 或文章主旨，再整理主要貢獻、方法、實驗設計，最後補一段閱讀判斷。

今天三個 domain 的狀態如下：

- **Silicon Sampling / Social Simulation**：重點在 persona generation 的可信度，以及 LLM 能不能產生接近真實人群的 opinion distribution。今天看到的 paper 已經開始從「LLM 可以模擬人」走向「怎麼驗證它有沒有偏」。
- **Harness Engineering**：這個領域目前不會只靠 paper，反而很多有價值內容在 framework repo、engineering blog 和 docs。今天的重點是 eval harness、agent trajectory、grader / assertion、以及 agent framework 如何接 benchmark。
- **Agent Memory**：paper 密度最高。今天看到的趨勢是從簡單 retrieval memory 走向 structured memory、memory evolution、graph memory 和 production-ready long-term memory。

## 今日推薦點開

### 1. LLM Generated Persona is a Promise with a Catch

這篇適合理解 silicon sampling 的風險。它的主張不是「LLM 不能模擬人」，而是說現在很多 persona generation 方法太 heuristic，可能在選舉預測或民調模擬這類 population-level tasks 上產生系統性偏差。

如果只記一句話：**LLM persona 的問題不在於單個回答像不像人，而在於聚合後的人群分布是否可信。**

### 2. Demystifying evals for AI agents

這篇是 Anthropic 的工程文章，不是 paper，但很適合 harness engineering。它把 agent eval 拆成 task、trial、grader、assertion、trajectory，說明為什麼 agent evaluation 不能只看最後答案。

如果只記一句話：**Agent eval 的核心是保存並評估整個行動軌跡，而不是只評最後輸出。**

### 3. A-MEM: Agentic Memory for LLM Agents

這篇代表 agent memory 往「記憶會自我組織」的方向走。它借用 Zettelkasten 筆記法，讓新記憶被寫成 structured note，並且自動和歷史記憶建立連結、更新舊記憶。

如果只記一句話：**Agent memory 不只是向量檢索，而可以是一個會演化的知識網路。**
