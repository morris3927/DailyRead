# DailyRead 2026-05-09

## 今日總覽

今天三個 domain 都有可用的新內容，重點不在「又多一個 agent demo」，而是在 agent / simulator 外層的設計空間、驗證機制與記憶控制正在變得更系統化。

- **Silicon Sampling / Social Simulation**：今天最強的是 *The Silicon Society Cookbook*。它直接把 social simulation 的 design choices 拿出來 sweep，顯示 base LLM、fine-tuning、network / population 設定都會改變 aggregate outcome，而且不是所有效果都能用單純加總理解。
- **Harness Engineering**：今天主線是 agent eval harness。Anthropic 把 task、trial、grader、assertion、trajectory、outcome、evaluation harness 的邊界講得很清楚；ICLR blogpost 則把問題推到 general agent evaluation 與 protocol 標準化。
- **Agent Memory**：今天看到 memory 從「外部資料庫 + retrieval」往「agent policy 直接控制記憶操作」移動。AgeMem 把 LTM / STM 操作做成 tool actions，並用 RL 學何時存、取、更新、摘要、丟棄。

## 今日推薦點開

### 1. The *Silicon Society* Cookbook: Design Space of LLM-based Social Simulations

這篇最適合今天優先讀。它的重點不是做新 demo，而是系統性回答：LLM social simulation 裡哪些設計參數真的會改變結果。595 次 roll-out 的 setup 對 silicon sampling 的 validation 很有參考價值。

如果只記一句話：**silicon society 的可信度不能只看單個 agent 像不像人，要看 simulator design 如何改變人群層級的 opinion dynamics。**

### 2. Demystifying evals for AI agents

這篇適合放進 Harness Engineering 基礎閱讀。它把 agent eval 從「評最後答案」改成「保存 trajectory、驗證 environment outcome、組合多種 graders」。

如果只記一句話：**agent evaluation harness 評的是 model + scaffold + tools + environment 的整體，不是只評模型輸出。**

### 3. Agentic Memory: Learning Unified Long-Term and Short-Term Memory Management for LLM Agents

這篇是今天 Agent Memory 最具方法性的內容。AgeMem 把 LTM / STM 管理放進 agent action space，讓 agent 學會何時寫入、取回、更新、摘要、過濾或刪除記憶。

如果只記一句話：**agent memory 的下一步不是存更多，而是學會何時記、何時忘、何時把記憶帶回工作上下文。**
