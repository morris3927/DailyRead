# DailyRead 2026-05-10

## 今日總覽

今天三個 domain 都有可用內容，而且主線都從「做出 agent / simulator」往「如何讓外層系統可驗證、可演化、可治理」移動。

- **Silicon Sampling / Social Simulation**：今天最好的訊號是 heterogeneity 與 environment-aware validation。LLM social simulation 不能只靠平均 persona 或多 agent 對話，必須明確處理 audience segmentation、exposure、scheduling、environment dynamics，否則 aggregate outcome 可能只是 protocol artifact。
- **Harness Engineering**：今天主線是 self-evolving harness。AHE 把 harness components、trajectory evidence、edit predictions 都做成可觀測資料結構，讓 agent 可以自動改善 tools、middleware、memory，而不是只調 system prompt。
- **Agent Memory**：今天看到 memory 從「能記」走向「低延遲、低成本、可治理」。LightMem / SimpleMem 強調壓縮與線上/離線分工；memory security survey 則把 persistent memory 視為新的攻擊面與治理層。

## 今日推薦點開

### 1. Agentic Harness Engineering: Observability-Driven Automatic Evolution of Coding-Agent Harnesses

今天最推薦先讀這篇。它不是泛泛談 harness engineering，而是把自動演化 harness 所需的 observability 拆成 component、experience、decision 三層，並在 Terminal-Bench 2 / SWE-bench-verified 上給出實驗結果。

如果只記一句話：**harness 要能自動進化，前提不是更會寫 prompt，而是每個元件、每段失敗證據、每次改動預測都要可觀測、可回溯、可驗證。**

### 2. Restoring Heterogeneity in LLM-based Social Simulation

這篇最適合 silicon sampling 方向今天優先讀。它提醒我們 persona 不是越長越好，真正要看的是 audience segmentation 能否保留 distributional、structural、predictive fidelity，而且不同 fidelity 之間會 trade off。

如果只記一句話：**synthetic population 的可信度不在於平均回答像不像，而在於 subgroup variation 和 identifier–outcome structure 有沒有被保住。**

### 3. Lightweight LLM Agent Memory with Small Language Models

這篇適合接在昨天 AgeMem 之後讀。AgeMem 問「agent 能不能學會操作記憶」；LightMem 問「記憶系統能不能在 production latency / cost budget 內穩定運作」。

如果只記一句話：**agent memory 不是每次都叫大模型整理歷史，而是要把 online retrieval 和 offline consolidation 分工，讓長期記憶可低延遲調用。**
