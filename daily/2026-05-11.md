# DailyRead 2026-05-11

## 今日總覽

今天三個 domain 的共同主線是：agent / simulator 的外層系統正在被當成真正的研究與工程對象。Silicon sampling 開始研究 design space 本身；harness engineering 開始把 harness 拆成可遷移、可觀測、可驗證的 artifact；agent memory 則從 recall benchmark 走向多 session、會行動、會遺忘與治理的評估。

- **Silicon Sampling / Social Simulation**：今天最好的訊號是 *The Silicon Society Cookbook*。它用 595 個 simulation roll-outs 分析 base model、fine-tuning、network topology、homophily、biased news agent、population proportions 等設計選擇如何改變模擬結果。重點不是「哪個 simulator 最真」，而是 social simulation claim 必須把 design choices 和 metrics 講清楚。
- **Harness Engineering**：今天主線是 harness artifactization。OpenDev 把 terminal-native coding agent 的 scaffolding / harness / context engineering 寫成 system report；Natural-Language Agent Harnesses 則嘗試把 harness control logic 外部化成可執行自然語言 artifact；Addy Osmani 的文章把 practitioner patterns 整理成 checklist。
- **Agent Memory**：今天主線是 evaluation 變嚴格。MemoryArena 要求 memory 在 Memory-Agent-Environment loop 裡改善後續行動；Memora 則把 obsolete memory / forgetting 納入 personalization 評估。這比「能不能從舊對話答題」更接近真實 long-term agents。

## 今日推薦點開

### 1. MemoryArena: Benchmarking Agent Memory in Interdependent Multi-Session Agentic Tasks

今天最推薦先讀這篇。它把 agent memory 評估從 static recall 推到 multi-session agentic tasks：agent 要在前面 session 中行動、獲得回饋、形成記憶，後面再用這些記憶做正確決策。

如果只記一句話：**agent memory 的價值不是記得多少，而是它是否讓 agent 在未來行動中少犯錯、會利用過去經驗。**

### 2. The Silicon Society Cookbook: Design Space of LLM-based Social Simulations

這篇最適合 silicon sampling 方向今天優先讀。它提醒我們，LLM social simulation 的結果可能高度受 base model、fine-tuning、network topology、population proportions 等設計選擇影響；如果不系統化報告這些條件，就很容易把 protocol artifact 誤解成 social phenomenon。

如果只記一句話：**Silicon Society 的可信度不只在 agent 像不像人，而在 simulator design space 有沒有被測量、消融、透明化。**

### 3. Building Effective AI Coding Agents for the Terminal

這篇是 terminal-native coding agent 的架構筆記。它把 OpenDev 的 compound architecture、dual mode safety、lazy tool discovery、adaptive compaction、event-driven reminders、project memory 等設計寫清楚，很適合接在昨天 AHE 後面讀。

如果只記一句話：**coding agent 的能力越來越取決於 harness：工具、權限、context、memory、hooks、persistence 與 feedback loop，而不是只取決於 base model。**
