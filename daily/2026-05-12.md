# DailyRead 2026-05-12

## 今日總覽

今天三個 domain 的共同主線是：外層機制正在變成研究主角。Social simulation 不再滿足於「agents 看起來像人在聊天」，而是要求 environment、scheduling、exposure 與 operational validation；Harness Engineering 開始把 harness formalize 成可比較的架構物件與 evaluation infrastructure；Agent Memory 則把記憶拆成 write–manage–read loop，並用 incremental multi-turn benchmark 測真正的長期能力。

- **Silicon Sampling / Social Simulation**：今天最好的訊號是 validation turn。*AI Agents Alone Are Not (Yet) Sufficient for Social Simulation* 從方法論上提醒：role-playing plausibility 不等於 behavioral validity；*Towards Operational Validation* 則用 30 個 forum simulations 對照 Voat windows，展示 activity、network、toxicity、topic、style 可以怎麼分開驗證。
- **Harness Engineering**：今天主線是 harness artifactization + evaluation infrastructure。*Agent Harness for LLM Agents: A Survey* 把 harness 拆成 E/T/C/S/L/V 六元組；*Holistic Agent Leaderboard* 則把 agent evaluation 做成標準化、平行化、保留 logs 的 infrastructure。
- **Agent Memory**：今天主線是記憶不等於向量庫。*Memory for Autonomous LLM Agents* 把 agent memory 寫成 write–manage–read loop；*MemoryAgentBench* 測 retrieval、test-time learning、long-range understanding、selective forgetting；*A-Mem* 則用 Zettelkasten-style linking 做動態記憶組織。

## 今日推薦點開

### 1. AI Agents Alone Are Not (Yet) Sufficient for Social Simulation

今天最推薦 silicon sampling 方向先讀這篇。它直接指出 LLM social simulation 的過度樂觀：會演角色、會對話，不代表能支撐科學上的 social simulation claim。真正要檢查的是 environment、exposure、scheduling、initial priors 與 collective outcome validity。

如果只記一句話：**social simulation 的可信度不在 agents 講話像不像人，而在 simulator 機制是否可形式化、可審計、可驗證。**

### 2. Holistic Agent Leaderboard: The Missing Infrastructure for AI Agent Evaluation

這篇很適合 Harness Engineering。它把 evaluation harness 當基礎設施來做，跑了 21,730 agent rollouts，跨 9 models / 9 benchmarks，並保留 2.5B tokens logs 做行為分析。

如果只記一句話：**agent evaluation 不能只報 final score；model、scaffold、benchmark、cost、trajectory logs 都是 evaluation artifact。**

### 3. Memory for Autonomous LLM Agents: Mechanisms, Evaluation, and Emerging Frontiers

這篇是今天 Agent Memory 的 map。它把 memory 定義成 write–manage–read loop，並把 context compression、RAG store、reflection、hierarchical virtual context、policy-learned management 放到同一個框架下。

如果只記一句話：**agent memory 不是「把東西存進向量庫」，而是跨互動決定寫什麼、如何整理、何時讀出、何時忘記的控制迴路。**
