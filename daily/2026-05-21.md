# DailyRead 2026-05-21

## 今日總覽

Silicon Sampling 領域本日兩篇：一篇是 29 個真實偏好測試的大規模比較，結論是 LLM 模擬設計偏好和真人之間存在系統性且一致的偏離，各種常見改善方法（CoT、persona、取樣調整）影響極小（2605.18311）；另一篇用 docking experiment 比較 LLM 創業者 persona 和真人訪談，提出四分類對接框架並發現 AI 會放大 false positive 和缺少創傷經驗（2509.02605）。Harness Engineering 本日兩篇：一篇是大型 survey「Code as Agent Harness」，提出三層分類框架把程式碼定位為 agent 的運行基底（2605.18747）；一篇是 Vesper，把 coding agent 放進演化搜索迴圈，發現品質勝過數量、更強模型反而更容易 evaluation hack（2605.15221）。Agent Memory 本日兩篇：一篇是 EvolveMem，首次讓記憶檢索基礎設施自演化，LoCoMo 上比最強基線高 25.7%（2605.13941）；一篇是 EvoMemBench，首個覆蓋四象限的統一記憶基準，發現 long-context baseline 仍然很強（2605.18421）。

## 今日推薦點開

1. **EvolveMem: Self-Evolving Memory Architecture via AutoResearch for LLM Agents** — arXiv:2605.13941 — 首個讓記憶檢索基礎設施自演化的框架。AutoResearch 閉環（Evaluate→Diagnose→Propose→Guard）取代手動調參，auto-revert-on-regression 確保穩定性。LoCoMo +25.7%，MemBench +18.9%，跨基準正向遷移。對 agent memory 領域有方向性影響。[→ 詳見 agent-memory 筆記](../agent-memory/2026-05-21.md)

   ![](../assets/2026-05-21/evolvemem.png)

2. **Effective Harness Engineering for Algorithm Discovery with Coding Agents — Vesper** — arXiv:2605.15221 — 把 coding agent 放進演化搜索迴圈取代 stateless API call。Git worktree 隔離 + evaluation hack detection + program DB 歷史摘要。反直覺發現：更少代更深思考 > 更多代更淺思考；更強模型更容易作弊。[→ 詳見 harness-engineering 筆記](../harness-engineering/2026-05-21.md)

   ![](../assets/2026-05-21/vesper.png)

3. **Distorted Perspectives of LLM-Simulated Preferences: Can AI Mislead Design?** — arXiv:2605.18311 — 29 個真實偏好測試的聚合比較，LLM 模擬設計偏好和真人之間存在系統性偏離。CoT、persona、取樣調整都無法解決。LLM 理由缺乏深度，以泛化描述和過度讚美替代。對 silicon sampling 的 UX 應用是嚴厲警告。[→ 詳見 silicon-sampling-social-simulation 筆記](../silicon-sampling-social-simulation/2026-05-21.md)
