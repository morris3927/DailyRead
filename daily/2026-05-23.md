## 今日推薦點開

### 1. Towards Simulating Social Media Users with LLMs: Evaluating the Operational Validity of Conditioned Comment Prediction

- **arXiv**: 2602.22752
- **Link**: https://arxiv.org/abs/2602.22752
- **Venue**: WASSA @ EACL 2026

![](../assets/2026-05-23/ccp-operational-validity.png)

提出 Conditioned Comment Prediction（CCP）任務，用真實數位痕跡取代抽象 plausibility 來驗證 LLM 模擬社群媒體使用者的 operational validity。關鍵發現：SFT 在低資源語言造成 form-content decoupling（表面結構對齊但語意退化），而行為歷史（implicit conditioning）比生成傳記（explicit conditioning）更可靠。

### 2. What Twelve LLM Agent Benchmark Papers Disclose About Themselves: A Pilot Audit and an Open Scoring Schema

- **arXiv**: 2605.21404
- **Link**: https://arxiv.org/abs/2605.21404
- **Venue**: IEEE Big Data 2026 (submitted)

![](../assets/2026-05-23/benchmark-audit-schema.png)
<!-- image generation rate-limited; placeholder retained -->

對 12 篇知名 agent benchmark 論文做 pilot audit，設計五欄位 audit schema（benchmark identity、harness specification、inference settings、cost reporting、failure breakdown）。Agent benchmark 平均揭露分數僅 0.38/1.0，最大缺口在 cost 與 harness specification。直接回應 harness engineering 領域當前最痛的 reproducibility 問題。

### 3. CALMem: Application-Layer Dual Memory for Conversational AI

- **arXiv**: 2605.20724
- **Link**: https://arxiv.org/abs/2605.20724

![](../assets/2026-05-23/calmem-dual-memory.png)

純 application-layer 雙記憶體架構（episodic + semantic），不需改 model、不需 fine-tune。MOIM 機制根據 context 餘裕自動調節注入深度，關鍵創新是 intra-session retrieval：compaction 後的 turn 仍可被搜尋。Rust production 實作，provider-agnostic。
