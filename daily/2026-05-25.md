### Agent Memory
- **MemLineage** (2605.14421)：溯源引導的記憶安全執行。Merkle log + 衍生 DAG + 敏感操作閘門。今日推薦。
- **GroupMemBench** (2605.14498)：多人對話記憶基準。最強系統僅 46.0%，BM25 超過專用記憶系統。
- **State Contamination** (2605.16746)：記憶洗錢——有毒對話透過摘要壓縮被「洗白」但行為影響仍在。SPG 指標量化隱性傳播。干預位置關鍵：摘要前淨化 > 摘要後淨化。
- **DimMem** (2605.15759)：維度結構化記憶。原子化單元帶顯式欄位，Qwen3-4B 提取器超越 GPT-4.1-mini + LightMem。

### Harness Engineering
- **SkillGenBench** (2605.18693)：首個獨立評估 skill generation pipeline 的基準。Task-agnostic 設定測試一次蒸餾多次重用。雙來源覆蓋（repository + document），不同失敗模式。
- **RealUserSim** (2605.20204)：從 WildChat 提取 7,275 個可執行行為 profile。Formalism Ceiling（6-8% 風格匹配率）+ Directive Amplification（手工指令讓不同模型行為差異巨大）。Grounded simulation 暴露合作模擬器看不到的失敗機制。
