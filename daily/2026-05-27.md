## 今日推薦點開

1. **AgentIR: Workload-Adaptive Cascade Retrieval Substrate for Long-Term Conversational Memory** (agent-memory) — Agent memory 的 retrieval 不是「小規模 IR」，而是有獨特結構的 distinct workload：極端時間偏斜、單調增長索引、異質查詢類型。AgentIR 用二維 cascade routing（fusion 策略 + dense channel 預算）自動適應不同 workload，在 LongMemEval 跳過 63% dense queries（2.67× 加速），在 LoCoMo 自動 100% skip（132× 加速）。時間分區索引在 exponential recency skew 下做到 O(log(1/ε)) per query。[→ 詳細筆記](agent-memory/2026-05-27.md)
