## 今日推薦點開

1. **Causal Memory Intervention (CMI): Causal Intervention-Based Memory Selection for Long-Horizon LLM Agents** (agent-memory) — Memory selection 不是 retrieval problem，是 intervention problem。CMI 用三條件 counterfactual（no-memory / with-memory / perturbed-memory）決定要不要採用一條 memory。在 Causal-LoCoMo 上達成 task score 0.846、harmful-memory rejection 0.990、zero poisoned-memory adoption。[→ 詳細筆記](agent-memory/2026-05-28.md)

   ![](assets/2026-05-28/cmi-note.png)

2. **MemTier: Tiered Memory Architecture and Retrieval Bottleneck Analysis for Long-Running LLM Agents** (agent-memory) — OpenClaw agent 在 72 小時後 tool-execution 下降 14pp，根源是 flat-file memory 的 4 個 failure modes。MemTier 用 tripartite architecture (episodic → 5-signal retrieval → semantic consolidation) + attribution loop，在 Qwen2.5-7B/6GB GPU 上從 5% 拉到 38%。PPO weight learning 完全無效——BM25 dominance 是真正的 retrieval bottleneck。[→ 詳細筆記](agent-memory/2026-05-28.md)

   ![](assets/2026-05-28/memtier-note.png)

3. **Beyond Static Responses: Multi-Agent LLM Systems as a New Paradigm for Social Science Research** (silicon-sampling / harness-engineering) — 六層分類框架（Tool → Role → Agent-like → Agent → MAS → CAS），把 LLM-based 系統從靜態工具到複雜適應系統做完整譜系劃分。每層有明確功能閾值（memory → autonomy → coordination → learning），對 silicon sampling 和 harness engineering 都有定位價值。[→ 詳細筆記](silicon-sampling-social-simulation/2026-05-28.md)

### Harness Engineering
- **The Necessity of a Unified Framework for LLM Agentic Capabilities Evaluation** (2602.03238)：同一個 LLM 在同一個 benchmark 換 harness 就跑出不同分數——identification problem。提出 evaluation-time harness 標準化，區分「哪個 LLM 在固定 harness 下更強」和「哪個 agent product 端到端更強」。Position paper。
- **Beyond Static Responses** (2506.01839)：六層分類框架對理解 agent harness 的複雜度分級有參考價值。Level 3+ 需要 structured memory 和 environment interface，正是 harness engineering 要解決的。交叉收錄在 silicon-sampling domain。

### Agent Memory
- **CMI: Causal Intervention-Based Memory Selection** (2605.17641)：Memory selection 用 causal intervention 而非 semantic similarity。三條件 counterfactual 過濾，Causal-LoCoMo benchmark，harmful-memory rejection 0.990。今日推薦。
- **MemTier: Tiered Memory Architecture** (2605.03675)：OpenClaw plugin，tripartite memory + 5-signal retrieval + attribution loop。PPO weight learning 無效，BM25 dominance 是 retrieval bottleneck。Qwen2.5-7B on 6GB GPU 從 5% 到 38%。今日推薦。
