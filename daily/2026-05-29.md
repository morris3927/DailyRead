## 今日推薦點開

1. **HASP: Harnessing LLM Agents with Skill Programs** (harness-engineering) — Skill 從 passive text 變成 executable Program Functions (PFs)。每個 PF 是 state–action intervention function，有 should_activate 和 intervene 兩部分。Web-search reasoning 上比 ReAct 提升 25%，加上 post-training 和 controlled evolution 後比 Search-R1 提升 30.4%。三階段模組化（inference-time / post-training / self-improvement）共享同一個 PF abstraction。[→ 詳細筆記](harness-engineering/2026-05-29.md)

   ![](assets/2026-05-29/hasp-note.png)

2. **From Storage to Steering: Memory Control Flow Attacks on LLM Agents (MCFA/MEMFLOW)** (agent-memory) — 全新攻擊類別：惡意 policy 被寫入 persistent memory 後，在後續所有 benign task 中持續 hijack agent 的 tool selection 和 tool ordering。一般情況下超過 90% 的 trials 對 MCFA 脆弱，cross-task persistence 達 97.2%~100%，連明確的 repair instruction 都無法恢復正常行為。[→ 詳細筆記](agent-memory/2026-05-29.md)

   ![](assets/2026-05-29/mcfa-note.png)

3. **From Model Scaling to System Scaling: Scaling the Harness in Agentic AI (with CheetahClaws)** (harness-engineering) — Agent performance = Φ(ℛ, ℳ, 𝒞, 𝒮, 𝒪, 𝒢)，model scaling 只改善 ℛ，system scaling 改善其餘五個組件。識別出 context governance、trustworthy memory、dynamic skill routing 三個核心 bottleneck。CheetahClaws 作為 Python-native reference harness，和 Claude Code、OpenClaw 做架構比較。[→ 詳細筆記](harness-engineering/2026-05-29.md)

## Domain 概覽

### Silicon Sampling / Social Simulation
- **LLM-enabled Social Agents** (2605.02335)：Position paper，提出 persona-based role definitions 作為 social agent baseline。Persona Core (stable traits) + Persona State (dynamic context) 區分。六條 baseline criteria：interpretable、action-guiding、LLM-compatible、persistent、norm-integrating、evaluable。和 Silicon Society Cookbook、AI Agents Alone Are Not (Yet) Sufficient 形成對話序列。

### Harness Engineering
- **HASP: Harnessing LLM Agents with Skill Programs** (2605.17734)：Skill 從 text 變成 executable PFs。Inference-time PFs alone 比基線提升 25%，HASP-Evolve + RS 比搜尋類強化學習方法提升 30.4%。三階段共用同一個 PF abstraction。今日推薦。
- **From Model Scaling to System Scaling** (2605.26112)：六組件框架 Φ(ℛ, ℳ, 𝒞, 𝒮, 𝒪, 𝒢)，識別 context governance、trustworthy memory、dynamic skill routing 三個核心 bottleneck。CheetahClaws reference harness。今日推薦。

### Agent Memory
- **From Storage to Steering: Memory Control Flow Attacks (MCFA/MEMFLOW)** (2603.15125)：全新攻擊類別。五個 attack family (Override, Order, M-Scope, Persistence, Resistance)。90%+ trials 脆弱，97.2%~100% cross-task persistence。現有 defense (Llama Guard, A-MemGuard) 無效。今日推薦。
