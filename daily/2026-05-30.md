# DailyRead — 2026-05-30

## 今日推薦點開

1. **ALSO: Adversarial Online Strategy Optimization for Social Agents** (silicon-sampling-social-simulation) — 將多智能體社交互動中的策略選擇建模成 adversarial bandit 問題，每個 arm 是一組「靜態 persona + 動態策略指令」的組合，用 lightweight neural surrogate 預測 sparse reward，實現 sample-efficient 的線上策略適應。在 Sotopia benchmark 上整體 +16.60%，relationship outcome +83.79%。ICML 2026 accepted。[→ 詳細筆記](silicon-sampling-social-simulation/2026-05-30.md)

2. **MemGym: A Long-Horizon Memory Environment for LLM Agents** (agent-memory) — 第一個統一五個 agentic regime（tool-use dialogue、deep-research search、coding、computer use）的 memory benchmark，核心貢獻是 memory-isolated scoring：在固定 reasoner 下做 paired baseline-vs-memory 比較，讓分數差值直接反映 memory 效果而非推理或 tool-use 的混淆。附帶 MemRM reward model（Qwen3-1.7B QLoRA）替換 Docker rollout 做標量壓縮品質評估。[→ 詳細筆記](agent-memory/2026-05-30.md)

3. **Storage Is Not Memory: A Retrieval-Centered Architecture for Agent Recall (True Memory)** (agent-memory) — 六層架構把 agent memory 從「ingestion-time extraction + storage schema」重構為「multi-stage retrieval pipeline over verbatim events」。核心論點：ingestion-time extraction 在 query 還沒到之前就把內容丟掉了，是不可逆的 loss。Encoding gate 用 novelty / salience / prediction-error 三信號做 ingestion filter，整個系統跑在單一 SQLite 檔案上。LoCoMo 93.0%、LongMemEval 87.8%、BEAM-1M 76.6%。[→ 詳細筆記](agent-memory/2026-05-30.md)

## Domain 概覽

### Silicon Sampling / Social Simulation
- **ALSO: Adversarial Online Strategy Optimization for Social Agents** (2605.15768)：第一個把多智能體社交互動中的策略適應建模成 adversarial bandit 的框架。EXP3-inspired 線上策略選擇 + neural surrogate reward prediction。Sotopia 上 +16.60% 整體提升。ICML 2026。今日推薦。
