1. **LLM Agents Make Collective Belief Dynamics Programmable** (silicon-sampling-social-simulation) — 定義「programmable collective belief control」新問題，用 SPINOS 資料集做多智能體模擬 proof-of-concept：80 個 AI agents 可在弱共識主題（Capitalism）翻轉 33.2% 人口立場，強共識主題（Feminism）則只被中性化。識別四個結構性挑戰讓偵測和防禦從根本上困難。[→ 詳細筆記](silicon-sampling-social-simulation/2026-05-31.md)

2. **WorldMemArena: Evaluating Multimodal Agent Memory Through Action–World Interaction** (agent-memory) — 把 agent memory 重構為 Action–World Interaction Loop + 四階段生命週期（Write / Maintain / Retrieve / Use），400 個 multi-session multimodal tasks 涵蓋 Lifelong Evolution 和 Agentic Execution。首次 head-to-head 比較 long-context / manual / harness-based memory，發現更好的 writing ≠ 更好 performance，harness memory 更靈活但更不可靠。[→ 詳細筆記](agent-memory/2026-05-31.md)

   ![](assets/2026-05-31/worldmemarena-note.png)

3. **Code Review Agent Benchmark (c-CRAB)** (harness-engineering) — 把 human review comments 系統性轉成可執行測試，用 test-based oracle 取代文字相似度評估 code review agent。所有 SOTA review agents 加起來只解決 ~40% 的 c-CRAB tasks，AI 和人類 reviewer 關注的面向互補。[→ 詳細筆記](harness-engineering/2026-05-31.md)

## Domain 概覽

### Silicon Sampling / Social Simulation
- **LLM Agents Make Collective Belief Dynamics Programmable** (2605.19915)：Position paper + proof-of-concept。定義 programmable collective belief control，用 SPINOS 資料集展示 AI agents 可系統性操控集體信念，四個結構性挑戰讓防禦困難。今日推薦。
- **EASE Configuration / SiliSocS** (2605.30258)：LLM 社會模擬的模組化配置框架，把 Environment / Agent / Simulation / Evaluation 拆開。目前僅 abstract。
- **Mitigating Adversarial Persuasion with Third-Party Conversational Oversight** (2605.08321)：Warden model 做即時操控偵測，user study N=120 顯示將 adversarial 成功率從 65.4% 降至 30.4%。COAX-Bench 14 場景模擬驗證。目前僅 abstract。

### Harness Engineering
- **Code Review Agent Benchmark (c-CRAB)** (2603.23448)：Test-based oracle 評估 code review agent。PR-Agent / Devin / Claude Code / Codex 加起來只解決 ~40%。今日推薦。

### Agent Memory
- **WorldMemArena** (2605.29341)：Action–World Interaction Loop + 四階段生命週期。400 multi-session multimodal tasks。首次 long-context vs manual vs harness 比較。今日推薦。
- **StructMemEval** (2602.11243)：測試記憶結構組織能力而非事實記憶。LLM 被提示結構時可靠解決問題，但無法自發識別需要的結構。
- **MedMemoryBench** (2605.11814)：醫療場景 memory benchmark，~2,000 sessions，streaming assessment，研究 memory saturation。目前僅 abstract。
