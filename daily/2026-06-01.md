1. **APS: Bias-Controlled Adaptive Prototype Simulation for Population-Scale LLM Agents** (silicon-sampling-social-simulation) — 把 population-scale LLM 模擬重構為 recurrent oracle-allocation 問題。10M-agent 實驗中 381× 呼叫減少、JSD 0.094。Shadow-audit residual correction + tail-protected singleton routing 控制近似偏差。和 SPINOS 互補：APS 解決 scale，SPINOS 解決操控。[→ 詳細筆記](silicon-sampling-social-simulation/2026-06-01.md)

2. **Harness-Bench: Measuring Harness Effects across Models in Realistic Agent Workflows** (harness-engineering) — 第一個把 harness 當成主要評估軸的 diagnostic benchmark。106 sandboxed tasks、5,194 trajectories、8 workflow categories。核心發現：同一模型在不同 harness 下表現差異顯著，execution-alignment failures 是 recurring pattern。建議以 model-harness configuration level 報告 agent capability。[→ 詳細筆記](harness-engineering/2026-06-01.md)

   ![](assets/2026-06-01/harness-bench-note.png)

3. **Is Agent Memory a Database? Rethinking Data Foundations for Long-Term AI Agent Memory (GEM)** (agent-memory) — Position + vision paper。指出所有現有 memory 系統都把記憶當資料庫管，用 record-level CRUD，導致四個 recurring failure modes：unregulated growth、missing semantic revision、capacity-driven forgetting、read-only retrieval。提出 GEM 抽象（四個 state-level operators 取代 CRUD）和三個 impossibility observations。和 DeMem 互補：GEM 回答「怎麼管」，DeMem 回答「記什麼」。[→ 詳細筆記](agent-memory/2026-06-01.md)
