# DailyRead — 2026-06-02

## 今日推薦點開

1. **Are LLM Agents Behaviorally Coherent? Latent Profiles for Social Simulation** (silicon-sampling-social-simulation) — 用 latent profile framework 檢驗 LLM agent 在社會模擬中的行為一致性。發現 LLM agent 雖然在聚合層面看似一致，但在嚴格的實證一致性檢驗下失敗：偏好對立的 agent 仍達成共識，openness 預測力在最關鍵的情境下消失。對 silicon sampling 的替代人類受試者假設提出根本質疑。[→ 詳細筆記](silicon-sampling-social-simulation/2026-06-02.md)

   ![](assets/2026-06-02/behavioral-coherence-note.png)

2. **SkillsBench: Benchmarking How Well Agent Skills Work Across Diverse Tasks** (harness-engineering) — 第一個系統性評估「Agent Skills」（結構化程序知識包）是否真的幫助 LLM agent 的 benchmark。86 tasks × 11 domains，curated Skills 平均提升 16.2pp，但 16/84 tasks 出現負面影響，self-generated Skills 平均無效。這篇直接挑戰「有 skill 就好」的假設，為 harness engineering 提供了以 skill 為變項的診斷視角。[→ 詳細筆記](harness-engineering/2026-06-02.md)

   ![](assets/2026-06-02/skillsbench-note.png)

3. **AtomMem: Learnable Dynamic Agentic Memory with Atomic Memory Operation** (agent-memory) — 將 agent memory management 重新框架為 POMDP 決策問題，用 CRUD 四個原子操作取代手工設計的固定 workflow。透過 GRPO 強化學習讓 agent 學會 task-aligned 的記憶策略，3 個長上下文 QA benchmark + 2 個 web benchmark 上穩定超越靜態 workflow baseline 3–8pp。學到的策略展現出系統性的操作頻率變化，不是隨機摸索。[→ 詳細筆記](agent-memory/2026-06-02.md)

   ![](assets/2026-06-02/atommem-note.png)
