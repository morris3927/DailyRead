# DailyRead — 2026-06-03

## 今日總覽

三個 domain 都有高品質新論文。Silicon sampling 的 faithfulness gap 分解很精準，Harness engineering 一口氣來了三篇互相對話的力作，Agent memory 的 dimensional structuring 乾淨實用。

### Silicon Sampling / Social Simulation

- **2606.00476** — Doing What They Say, Not What They Reason: 把 LLM agent 的 faithfulness gap 拆成 reasoning→conclusion 和 conclusion→action 兩步，發現問題幾乎全在前者：agent 會正確估算輸入、正確重述規則，然後用 hedging 語言推翻自己的結論，方向一致性地偏風險趨避。conclusion→action 不一致率其實只有 0–1.8%，過去報的 22–26% 是量測 artifact。
- **2606.01199** — TaskWeave: 把長期組織模擬定義為 memory-centered coordination problem，用 FPDA 循環和 dependency-aware trace memory 維持跨層級、跨時間的 planning 和 execution state。
- **2605.04886** — BenCSSmark: Position paper，主張把社會科學任務帶進 LLM benchmark。

### Harness Engineering

- **2605.30621** — Harness Updating ≠ Harness Benefit: 拆解 harness self-evolution 的兩種能力，發現 updating flat（小模型和大模型的 harness 更新增益差不多）但 benefit non-monotonic（弱模型用不起來、中階模型受益最大）。設計指引：投資 task-solving agent，不是 evolver。
- **2606.01770** — Adaptive Auto-Harness: 針對 open-ended task stream 的三個部署維度（unbounded history, task heterogeneity, distribution shift），提出 multi-agent evolver + harness-tree routing + HITL。
- **2606.01779** — HarnessForge: 把 harness 和 policy 一起演化，harness–policy pair 的 compatibility 成為顯式優化目標，超過 harness-only 和 policy-only baseline 最多 12%。

### Agent Memory

- **2605.15759** — DimMem: 用帶 dimension fields 的 atomic memory unit 取代 flat text/facts，dimension-aware retrieval 在 LoCoMo-10 和 LongMemEval-S 上超過其他輕量系統，同時減少 24% token cost。
- **2605.29960** — MemPoison: 繞過現代記憶管線的選擇性抽取和改寫，用 semantic relational bridge + entity masquerading + joint embedding optimization 注入 triggerable backdoor，ASR 達 0.95。

## 今日推薦點開

1. 🔥 **2606.00476 — Doing What They Say, Not What They Reason**  
   Silicon sampling 領域今年最精準的 faithfulness 分析。把問題拆成兩步後，發現真正的 gap 不在「說一套做一套」，而在「推理自相矛盾但忠實執行矛盾結論」。對所有拿 LLM 做社會模擬的人都是警告。

2. 🔥 **2605.30621 — Harness Updating Is Not Harness Benefit**  
   Harness engineering 的基本問題拆解：誰能更新 harness 和誰能從 harness 受益是兩回事。Qwen3.5-9B 當 evolver 的增益和 Claude Opus 4.6 相當，但 Qwen3-32B 當 agent 的 harness benefit 幾乎為零。對 self-evolving agent 系統設計有直接指導意義。

3. 🔥 **2605.15759 — DimMem**  
   用 dimensional structuring 解決 agent memory 的 fidelity–efficiency trade-off。想法乾淨：把記憶從 flat text 升級到帶 dimension 的 structured unit，讓 retrieval 可以做 dimension-aware query。Qwen3-4B fine-tuned extractor 就能超過 GPT-4.1-mini + LightMem。
