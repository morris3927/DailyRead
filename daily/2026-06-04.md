# DailyRead 2026-06-04

## 今日推薦點開

### 🧠 PSII — Diversity Collapse 的表徵層解方（Silicon Sampling）

Parametric Social Identity Injection (2603.16142, KDD 2026) 發現 LLM 在高層 hidden states 會發生「Diversity Collapse」——不同社會身份的表徵系統性地收縮成密集聚類。PSII 直接在中間層注入人口統計和價值取向的參數化向量，不依賴 prompt conditioning，也不需要 fine-tuning，效果在 WVS 上持續優於 baseline。這條 representation-level 的路線和之前追蹤的 prompt-based / fine-tuning 方法完全不同。

![](assets/2026-06-04/psii-diversity-collapse.png)

### 💰 Hedge-Bench — 金融推理的真正硬基準（Harness Engineering）

Hedge-Bench 1.0 (2606.03918) 用真實避險基金分析師的推理軌跡建構了 102 個開放式金融推理任務，評分標準是分析師的推理過程而非答案正確性。所有前線模型（包括 GPT-5.5、Claude Opus 4.8）Pass@1 全部低於 16%。Docker 容器化環境 + deterministic grading + 過程導向評分，是 harness 設計的重要參考。

![](assets/2026-06-04/hedge-bench-financial-reasoning.png)

### 🧩 xMemory — Agent Memory 的「先解耦再聚合」原則（Agent Memory）

xMemory (2602.02007) 指出標準 RAG top-k 在 agent memory 上系統性地返回冗余內容而遺漏關鍵差異，提出「decoupling before aggregation」原則：先把互動歷史拆解為記憶元件，再聚合成高層群組供檢索。可修訂的層級結構 + top-down 自適應檢索，在 LoCoMo 和 PerLTQA 上同時提升答案品質和 token 效率。

## Silicon Sampling / Social Simulation

1. **We Need Strong Preconditions For Using Simulations In Policy** (2604.07838, PoliSim@CHI 2026) — 立場論文，提出三個前提條件：不要把邊緣群體模擬當中立技術產出、不要在沒有參與的情況下模擬群體、不要在沒有問責的情況下模擬。和 5/12 的「AI Agents Not Yet Sufficient」互補。

2. **Social Catalysts, Not Moral Agents** (2602.02598) — PGG 實驗顯示利他錨點 agent 能局部提升合作率，但認知分解和轉移測試揭示合作是策略性遵從而非規範內化。GPT-4.1 出現「變色龍效應」。

3. **PSII: Parametric Social Identity Injection** (2603.16142, KDD 2026) — ⭐ 今日推薦

4. **Economy of Minds** (2606.02859) — 把經濟互動（市場機制、價格信號、分工）引入多 agent 系統。概念有趣但確認深度不足。

5. **AI as a Tool for Simulation-Based Experiments in Literary Studies** (2606.02293) — 把 silicon sampling 帶入文學研究，方向性探索。

## Harness Engineering

1. **MCP-Persona** (2606.02470, ICML 2026) — 第一個針對個人化 MCP 工具使用的基準，24 個 MCP server、173 個人工驗證任務。Tool-Traverse + Context-Tree + Persona-Gen 三層方法論值得參考。

2. **Hedge-Bench 1.0** (2606.03918) — ⭐ 今日推薦

3. **InfoMem** (2606.03329) — 把記憶選擇從檢索問題轉為訓練問題，用 answer-conditioned information gain 作為訓練信號。確認深度不足。

## Agent Memory

1. **xMemory** (2602.02007) — ⭐ 今日推薦

2. **MemORAI** (2605.01386) — 圖譜式記憶 + 溯源追蹤 + Dynamic Weighted PageRank。和 xMemory 互補但概念創新性稍低。

3. **MemoryOS** (2506.06326) — OS 記憶體管理原則搬到 agent 記憶，三層架構 + 熱度替換。概念直覺但創新性有限。

4. **ExpGraph** (2605.30712) — Model-agnostic 經驗學習框架，圖譜結構經驗 + 效用感知排名 + 自適應檢索 copilot。聚焦經驗重用而非記憶檢索。

5. **STITCH** (2601.10702) — Contextual intent 作為結構化檢索線索，CAME-Bench 基準測試。和 xMemory 互補但更依賴線上意圖推導。
