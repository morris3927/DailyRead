# DailyRead — 2026-06-08

## 今日推薦點開

1. **Exploring the Topology and Memory of Consensus** (arXiv 2606.04197) — Silicon sampling / social simulation 今天最值得點開。它用 432 次 networked Naming Game 模擬指出：LLM agent 的 memory depth 不能單獨調，因為同一個記憶設定在 decentralized 與 centralized topology 中會產生相反效果；中心化網路的「更快 settled」其實可能是更快鎖進 fragmented plateau。

    ![Consensus topology × memory](assets/2026-06-08/consensus-topology-memory-2606-04197.png)

    → [silicon-sampling-social-simulation/2026-06-08.md](../silicon-sampling-social-simulation/2026-06-08.md)

2. **Retrospective Harness Optimization (RHO)** (arXiv 2606.05922) — Harness engineering 今天最實用。它把過去 unlabeled trajectories 變成自監督 harness optimizer：挑困難 coreset、重跑 rollout、做 self-validation / self-consistency、產生 candidate harness updates，再用 pairwise self-preference 選更新。SWE-Bench Pro 單輪 59% → 78%。

    ![RHO pipeline](assets/2026-06-08/rho-2606-05922.png)

    → [harness-engineering/2026-06-08.md](../harness-engineering/2026-06-08.md)

3. **When Should Memory Stay Silent** (arXiv 2606.06055) — Agent memory 今天最值得警惕。它把評估重點從 retrieval accuracy 推到 memory-use boundary：敏感記憶即使被正確取回，也不代表當前回合應該用。RBI-Eval 顯示 retrieval 只能降低 exposure；一旦敏感記憶進入 generator，多數模型仍會過度整合。

    ![Memory-use boundary](assets/2026-06-08/memory-stay-silent-2606-06055.png)

    → [agent-memory/2026-06-08.md](../agent-memory/2026-06-08.md)
