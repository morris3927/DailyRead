# DailyRead — 2026-06-15

## 今日推薦點開

1. **EvoArena + EvoMem** (agent-memory) — 首個持續環境演化下的 agent 評測基準 + git-like patch 記憶範式。EvoArena 把靜態基準變成版本鏈，測 agent 在「什麼變了、什麼還有效」下的適應力；EvoMem 用 append-only patch history 讓記憶演化可追溯。Agent 在 EvoArena 上平均準確率僅 39.6%，當前記憶系統嚴重退化。[arXiv 2606.13681](https://arxiv.org/abs/2606.13681)

   ![](assets/2026-06-15/evoarena.png)

2. **PrecisionMemBench & Tenure** (agent-memory) — 第一個精度感知的 LLM 記憶檢索基準 + multi-path BM25 記憶系統。核心指控：LoCoMo 等基準測的是生成模型的噪音容忍度，不是記憶系統的檢索品質。Mem0 檢索精度 0.05–0.08，Tenure 89/89 pass、精度 1.0、< 15ms。[arXiv 2605.11325](https://arxiv.org/abs/2605.11325)

   ![](assets/2026-06-15/tenure.png)

3. **CollabSim** (silicon-sampling-social-simulation) — CSCW 理論接地的 LLM agent 協作能力評測框架。四個經典實驗（Shape Factory、DayTrader、Hidden Profile、Map Task）精確分離協作能力維度，加上 mental model probing 模組看得到 agent 的內在狀態。[arXiv 2606.06399](https://arxiv.org/abs/2606.06399)
