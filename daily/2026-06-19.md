1. **AI Coding Agents in Social Science: Methodologically Diverse, Empirically Consistent, Interpretively Vulnerable** (2606.11456)
   - 在 many-analysts 基準上跑 Claude Code 和 Codex 各 20 次，發現設計層 agent 的方法論多樣性不輸人類，但判斷層極度脆弱——confirmatory prompt 翻轉 90% 結論但係數分布不變。Silicon sampling 的方法論風險不在 homogenization，而在 interpretation。
   - → [arXiv](https://arxiv.org/abs/2606.11456) | [Domain Note](silicon-sampling-social-simulation/2026-06-19.md)

2. **WildClawBench: A Benchmark for Real-World, Long-Horizon Agent Evaluation** (2605.10912)
   - 60 個雙語多模態任務跑在真實 CLI harness 上，最強模型僅 62.2%，切換 harness 可讓同模型差 18 分。Native-runtime agent eval 的第一個完整 benchmark。
   - → [arXiv](https://arxiv.org/abs/2605.10912) | [Domain Note](harness-engineering/2026-06-19.md)

3. **MemFactory: Unified Inference & Training Framework for Agent Memory** (2603.29493)
   - Agent memory 領域的「LLaMA-Factory」：把記憶生命週期拆成 Extraction/Update/Retrieval 三個 plug-and-play 模組，原生整合 GRPO，out-of-the-box 支援 Memory-R1 / MemAgent / RMM。
   - → [arXiv](https://arxiv.org/abs/2603.29493) | [Domain Note](agent-memory/2026-06-19.md)
