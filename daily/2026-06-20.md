# DailyRead — 2026-06-20

## 今日推薦點開

1. **Valid Inference with Synthetic Data via Task Exchangeability** (2606.13629)
   - Silicon sampling 的統計有效性終於有了嚴格框架：task exchangeability 讓你用歷史任務上合成 vs 真實的誤差分布來擴張 naive CI，即使合成資料嚴重偏誤也能保證覆蓋率。從「看起來像」到「可以用」的關鍵一步。
   - → [arXiv](https://arxiv.org/abs/2606.13629) | [Domain Note](silicon-sampling-social-simulation/2026-06-20.md)

2. **ComplexMCP: Evaluation of LLM Agents in Dynamic, Interdependent, and Large-Scale Tool Sandbox** (2605.10787)
   - 300+ 工具、7 個 stateful sandbox、seed-driven 動態環境。最強模型 < 60% vs 人類 90%+，三大失敗模式：tool retrieval saturation、over-confidence、strategic defeatism。Harness engineering 領域最完整的真實工具生態評估。
   - → [arXiv](https://arxiv.org/abs/2605.10787) | [Domain Note](harness-engineering/2026-06-20.md)

3. **All-Mem: Agentic Lifelong Memory via Dynamic Topology Evolution** (2603.19595)
   - Online/offline 分離的 lifelong memory 框架，用 Split/Merge/Update 三種非破壞性操作維護記憶 topology，保留 immutable evidence 的可追溯性。解決了 summarization 的不可逆資訊損失和 append-only 的噪音累積問題。
   - → [arXiv](https://arxiv.org/abs/2603.19595) | [Domain Note](agent-memory/2026-06-20.md)
