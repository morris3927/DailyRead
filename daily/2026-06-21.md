1. **Marginal Alignment Does Not Guarantee Joint-Distribution Fidelity** (2606.12433)
   - Silicon sampling 的核心宣稱「marginal alignment = 可以當真人替代樣本」被 IAF audit 原語系統性打臉。用 NPK-Korea 100 萬筆合成 persona 對照 KOSIS/KEIS/兵務廳等六條官方聯合分布軸，marginals 全 PASS 但三個 occupation 相關 joint 全 FAIL。audit artifacts 全部開源可 retarget。
   - → [arXiv](https://arxiv.org/abs/2606.12433) | [Domain Note](silicon-sampling-social-simulation/2026-06-21.md)

2. **Human-on-the-Bridge: Scalable Evaluation for AI Agents** (2606.16871)
   - 把人類專業知識從 HITL 的 per-run bottleneck 變成 reusable evaluation infrastructure：Red-Team Traps、Juror Personas、audit rules 一次 curate、反覆執行。23,500 agent turns、47 configurations，小 Harness LLM 就能 surface frontier agent 的 phantom tool calls、policy drift、safe-but-non-resolving refusals。
   - → [arXiv](https://arxiv.org/abs/2606.16871) | [Domain Note](harness-engineering/2026-06-21.md)

3. **HORMA: Hierarchical Organize-and-Retrieve Memory Agent** (2606.11680)
   - Memory construction 和 retrieval 解耦：construction 用 contrastive skill refinement（不用 RL），retrieval 用 RL-trained lightweight agent 在 file-system-like hierarchy 裡導航。LoCoMo 上只用 baseline 3.07%–22.17% 的 token，LongMemEval OOD generalization 超過所有 baseline（含 full history）。
   - → [arXiv](https://arxiv.org/abs/2606.11680) | [Domain Note](agent-memory/2026-06-21.md)
