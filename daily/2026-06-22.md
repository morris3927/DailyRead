### 1. Infini Memory: Maintainable Topic Documents for Long-Term LLM Agent Memory
- **arXiv**: 2606.10677 | agent-memory
- **推薦理由**: 把 agent 記憶當作「可維護的文件庫」而非 retrieve-and-inject 索引，topic-structured documents + agentic retrieval + buffer/consolidation 分離。MemoryAgentBench 64.7%。和 DCPM 形成有趣對照——文件管理隱喻 vs. 認知架構隱喻。
- [全文](https://arxiv.org/html/2606.10677v1) | [Code](https://github.com/infinigence/Infini-Memory)

### 2. DCPM: Memory Beyond Recall — A Dual-Process Cognitive Memory System for Self-Evolving LLM Agents
- **arXiv**: 2606.09483 | agent-memory
- **推薦理由**: 從雙歷程理論出發，把 agent 記憶分成認知能力層級（passive → structured → proactive）。System 1 同步寫入 supersedes chains，System 2 非同步歸納 schemas + cross-domain patterns。PersonaMem-v2 +5.20 pp。理論框架最完整的 agent memory paper。
- [全文](https://arxiv.org/html/2606.09483v1)
