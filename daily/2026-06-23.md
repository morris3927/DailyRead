## 今日推薦點開

### 1. Contagion Networks: Evaluator Bias Propagation in Multi-Agent LLM Systems
- **arXiv**: 2606.20493 | silicon-sampling-social-simulation
- **推薦理由**: 正式建模 LLM 評估偏誤在多 agent 系統中的傳播——用流行病學框架量化偏誤傳染係數，發現同質模型傳播弱到自然抑制（3 hop 後幾乎完全衰減），但跨模型傳播強得多可能進入級聯 regime。k≥3 多樣化評估者可降低有效傳染 72.4%。對 silicon sampling 的根本關切直接相關。
- [全文](https://arxiv.org/html/2606.20493v1)

### 2. Sovereign Execution Brokers: Enforcing Certificate-Bound Authority in Agentic Control Planes
- **arXiv**: 2606.20520 | harness-engineering
- **推薦理由**: 定義了 agent 安全的 enforcement gap——SAB 認證提案但不執行，IAM 授權身份但不檢查憑證。SEB 是 runtime enforcement boundary：七步驗證 pipeline（簽名→匹配→時效→policy epoch→撤銷→drift→replay），scoped short-lived credentials，bypass-prevention 部署模式。Go 原型在 AWS 和 K8s 上的完整評估。
- [全文](https://arxiv.org/html/2606.20520v1)

### 3. GitOfThoughts: Version-Controlled Reasoning and Agent Memory You Can Replay, Diff, and Merge
- **arXiv**: 2606.14470 | agent-memory
- **推薦理由**: 把 agent 推理樹存成 git repo（thought→commit, scores→notes, outcomes→tags），讓推理可 replay、audit、merge。但更重要的貢獻是 **H-memory 的穩健否決**：五種記憶 substrate 在新問題上都不穩定提升準確率，一個 +15pp 的早期結果在預註冊 replication 下崩塌。記憶只在 copyability threshold（cosine ≳ 0.8）以上有用，且是答案檢索而非方法遷移。Git 的價值是 auditability 和 mergeability，不是準確率。
- [全文](https://arxiv.org/html/2606.14470v1)

## Domain Headlines

- **Silicon Sampling / Social Simulation**: Contagion Networks 用流行病學框架量化 LLM 評估偏誤傳播，同質模型下偏誤自然抑制但跨模型可能級聯，3+ 評估者多樣性降低 72.4% 傳染。
- **Harness Engineering**: SEB 填補 agent 安全的 enforcement gap——從認證到執行之間的最後一哩路；Probabilistic Verification 提供不需獨立假設的 policy violation 上界。
- **Agent Memory**: GitOfThoughts 的預註冊實驗否決了「跨問題記憶幫助新問題」的假設，copyability threshold 是唯一的增益點。LedgerAgent 在同任務內用 ledger + policy gate 追蹤狀態。WRBench 指出 world model 缺乏 persistent state core。MemoryWAM 用 hybrid memory 解決 robotics 的長程記憶效率。
