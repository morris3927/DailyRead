### 1. Hallucination as Context Drift: Synchronization Protocols for Multi-Agent LLM Systems
- **arXiv**: 2606.21666 | silicon-sampling-social-simulation
- **推薦理由**: 把多 agent 幻覺從「模型缺陷」重新定位為「分散式系統的介面問題」。Full-broadcast 同步反而讓幻覺率增加 34%（contamination effect），SSVP 用 CDS 閾值選擇性同步，以 58% 更少的 API calls 達到顯著更低的幻覺率。對 silicon sampling 的根本關切——agent 間的知識同步——直接相關。
- [全文](https://arxiv.org/html/2606.21666v1)

### 2. What makes a harness a harness: necessary and sufficient conditions for an agent harness
- **arXiv**: 2606.10106 | harness-engineering
- **推薦理由**: 給「agent harness」第一個可操作的本質定義：四個必要且充分條件（agent loop, tool interface, context management, control mechanisms），加上 temporal clause（runtime vs. post-hoc）。用六個真實系統和五個邊界案例驗證，分類一致。這是 harness engineering 領域缺乏的基礎概念工作。
- [全文](https://arxiv.org/html/2606.10106v1)

### 3. Contextual Reinstatement for Long-term Agentic Memory (RaMem)
- **arXiv**: 2606.22844 | agent-memory
- **推薦理由**: 定義了 **context collapse**——記憶看似相關但屬於錯誤情境的 failure mode。RaMem 的四階段 pipeline（episodic anchoring → recall condition induction → validity-aware retrieval → context-preserved synthesis）不是改 retrieval，而是在 retrieval 之後加 validity checking。F1 平均改善 >10%。和昨天的 GitOfThoughts 互補：GitOfThoughts 發現跨問題記憶增益有限，RaMem 指出部分原因可能是 context collapse。
- [全文](https://arxiv.org/html/2606.22844v1)

## Domain Headlines

- **Silicon Sampling / Social Simulation**: Context Drrift 把多 agent 幻覺定位為分散式同步問題——full-broadcast 反而擴散偏誤（+34% HR），SSVP 選擇性同步更安全。Collectives of Specialists/Generalists 用網路拓撲量化了任務-結構匹配。SaMAS 用雙層情境感知做經濟模擬但理論深度不足。
- **Harness Engineering**: Harness 定義論文給出四條件 constitutive definition 和 inclusion/exclusion test。Protocol Language 用 DSL 規範人類-agent 邊界。Confidence Laundering 指出不確定性在 agent 交接點被洗掉的 failure mode。
- **Agent Memory**: RaMem 定義 context collapse 並用 contextual reinstatement 解決。AFTER 是最全面的 procedural memory transfer benchmark（382 任務 × 6 角色 × 22 技能）。Negative Knowledge 把失敗變成可共享的研究資產。
