### 1. Don't Ask the LLM to Track Freshness: A Deterministic Recipe for Memory Conflict Resolution
- **arXiv**: 2606.01435 | agent-memory
- **推薦理由**: 對整個 agent memory 設計空間提出修正性論點：conflict resolution 的瓶頸在 assembly（post-retrieval aggregation），不在 storage。用 Python max(serial) 替換 LLM 判斷，在 MAB FactConsolidation 上從 67% 跳到 78%（gpt-4o-mini），262K context 下差距擴大到 +21pp。22 個已發表系統全部 ≤7% 的 multi-hop 任務，deterministic pipeline 拿到 30.2%。這不是 incremental improvement，是對框架設計哲學的修正。
- [全文](https://arxiv.org/html/2606.01435v1)

### 2. HarnessX: A Composable, Adaptive, and Evolvable Agent Harness Foundry
- **arXiv**: 2606.14249 | harness-engineering
- **推薦理由**: 目前 harness engineering 領域最完整的系統性工作。把 harness 正式化為 typed first-class object，用 substitution algebra 組合；用 AEGIS 把 harness evolution 映射為 RL 問題並處理 pathology；加 harness-model co-evolution 打破 scaffolding ceiling。五個 benchmark 平均 +14.5%，最弱模型 ALFWorld +44.0%。比 Self-Harness 和 AHE 都更系統。
- [全文](https://arxiv.org/html/2606.14249v1)

### 3. Diversity Collapse in Multi-Agent LLM Systems: Structural Coupling and Collective Failure in Open-Ended Idea Generation
- **arXiv**: 2604.18005 | silicon-sampling-social-simulation (ACL 2026 Findings)
- **推薦理由**: 從三個層次（模型、認知、系統）系統性拆解多 agent LLM 的多樣性崩塌。核心發現是 compute efficiency paradox（更強的模型邊際多樣性更低）和 structural coupling（互動結構壓縮探索範圍）。對 silicon sampling 的根本挑戰：更多 agent 或更密集互動不一定更多元。
- [全文](https://arxiv.org/abs/2604.18005)
