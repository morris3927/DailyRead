### 2. 🦞 Personality Anchoring for Social Simulation (2606.06936)
用知名電影角色和公眾人物作為「人格錨點」，取代 Big Five 顯式 prompt 注入。1,010 場 dyadic 對話實驗發現 Homogeneous-Agreeable 配對成功率高達 Homogeneous-Disagreeable 的 10 倍（62% vs 6%）。行為中介分析揭示 Agreeableness 部分透過合作策略選擇影響結果，但即使在同一策略內仍有直接效應。

### 3. ⏱️ Toward Temporal Realism in City-Scale Crisis Response Simulation (2606.19904)
首次系統性檢驗 LLM 社會模擬器的時間真實性。用深圳 660 萬筆志工記錄證明：bursty timing 是普遍的（66.8% 個人、40.7% 追蹤群體）、內生的（79% self-exciting）、疫情放大的。LLM-only 模擬器完全無法產生 bursty pattern（median B=−0.14），加入 data-calibrated Hawkes gate 後即可提升到 B≈0.37 而不損害 LLM 的內容決策品質。

## Cross-Domain Notes

今天三個 domain 圍繞一個共同主題：**模擬的真實性與安全性從哪裡來？**

- **Agent Memory**：2606.24322 證明「信任記憶內容」是根本不安全的——任何 malleable 的權威標記都可被 laundering 攻擊繞過。權威必須綁定到不可偽造的來源標記。這和 silicon sampling 的「人格錨點」異曲同工：2606.06936 用外部驗證的公眾人物資料作為人格的不可竄改錨點，而 TMA-NM 用 write-time origin binding 作為記憶權威的不可竄改錨點。
- **Silicon Sampling**：2606.19904 和 2606.06936 都指向「LLM 模擬器不能只靠語言模型本身產生真實性」。時間真實性需要 Hawkes gate；人格真實性需要 character-anchored profile 而非 abstract trait prompt。2606.21315 則提出另一條路：讓模型在閉環中學習社會智慧，而非只靠 prompt 注入。
- **Harness Engineering**：2606.10749 的 survey 把 memory poisoning、tool-mediated control-flow hijacking、persistent state corruption 統一到一個 lifecycle framework 下。和 TMA-NM 的正式模型呼應：如果你不管理 trust boundary，harness 本身就是攻擊面。

另一個潛在對話：**從「評估什麼」到「如何持續改善」**。2606.21315 的 Social World Model 把社交能力從「被評估的對象」變成「可持續訓練的對象」，和 2606.19904 的「何時行動比是否行動更重要」形成互補：前者關心能力的持續累積，後者關心行動的時間分佈。
