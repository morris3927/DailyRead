# DailyRead — 2026-06-30

## 三個 Domain 總覽

### Silicon Sampling / Social Simulation
GenWorld 提出基於實證的城市模擬基礎設施，把 LLM-derived decisions 離線編譯成 lookup policies，讓 196,608 個 synthetic residents 的城市級模擬變得計算可行。解決 scaling 問題，但 lookup policy 是否固化了偏見值得深究。

### Harness Engineering
HARBOR 把 robot RL 自動化框架為 harness engineering 問題，用五個 harness components（agents, commands, artifacts, gates, knowledge）結構化整個 RL workflow，跨 6 個 benchmarks、16 個 tasks 驗證。APEX 在 Self-Harness 之上加了两層演化（behavioral principles + workflow topology），但論文規模較小且缺乏逐層 ablation。

### Agent Memory
三篇重要論文：Memory Contagion 發現 evaluator bias 會透過記憶系統跨時間傳播，即使 consolidation 完美也無法消除（length bias Γ=13.18）；ForgetEval 提出首個系統性的 forgetting 基準，證明 recall 準確度和 forgetting 能力不相關；Multi-Factor Value Model 從認知心理學提取七因子統一控制 encoding/forgetting/retrieval。FragFuse 展示記憶系統的新攻擊面（fragment + fusion bypass access control）。

## 🦞 今日推薦點開

### 1. Memory Contagion (2606.23195)
跨時間的 evaluator bias 傳播——即使 consolidation 完美，length bias 仍會透過記憶傳播（Γ=13.18），但 authority bias 不會（Γ=0.00）。Content contamination dominates retrieval mechanism。對設計 agent memory 系統的人來說，這是一個必須知道的漏洞。

![Memory Contagion 概念圖](assets/2026-06-30/memory-contagion.png)

### 2. ForgetEval (2606.15903)
首個系統性的 forgetting 基準——1385 cases、10 attack categories、13 system configurations。核心發現：recall 好不代表 forgetting 好（MemPalace recall 60/150 但 forgetting 0/385）。LLM 放在 memory pipeline 的位置決定了它能恢復哪些 forgetting failure modes。

![ForgetEval 架構圖](assets/2026-06-30/forgeteval.png)

### 3. HARBOR (2606.08610)
把 robot RL 自動化框架為 harness engineering——五個 harness components 讓長期 autonomous RL workflow 變得結構化、可驗證、可復用。跨 6 simulators、16 tasks 驗證，policies 可 transfer 到真實機器人。
