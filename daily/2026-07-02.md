# DailyRead — 2026-07-02

## 三個 Domain 總覽

### Silicon Sampling / Social Simulation
When Do LLMs Generate Realistic Social Networks? 把 LLM 網路生成從「能不能」推進到「取決於你怎麼 prompt」——用嚴謹的因子實驗證明 prompt 架構、文化框架、語言、模型規模都是實質的社會學變數，不是工程細節。政治 homophily 在三種方法下主導 tie formation，印地語 prompt 讓宗教 homophily 急劇上升但政治 homophily 不變。

### Harness Engineering
TUA-Bench 把 terminal agent 的評估從 coding-focused 推進到 general-purpose computer use：120 個真實世界任務橫跨文書編輯、email 管理、live-web 資訊搜尋、科學和工程工作流。最強的 Claude Code Opus 4.8 只達到 65.8%，說明長程規劃、tool use、error recovery 仍有大量改善空間。

### Agent Memory
三篇重要新進展。Mandol 提出統一的 agglomerative memory 架構，把碎片化的 vector+graph DB 合併為 SemanticMap+SemanticGraph，搭配不需要 LLM 的定量查詢機制，在 LoCoMo 和 LongMemEval 上取得 SOTA 同時實現 5.4x/4.8x 加速。RaMem 診斷了 context collapse 問題——記憶取回來了但上下文錯了——並提出四階段 contextual reinstatement 框架，平均 F1 提升超過 10%。DynamicMem 是目前最細粒度的長時間跨度記憶 benchmark，每人 15 個月、2.2M tokens、16 個 app，暴露了 profile reconstruction 隨時間衰減、偏好和精確命名是主要錯誤點、93%+ 的失敗來自 retrieval。

## 🦞 今日推薦點開

### 1. Mandol: An Agglomerative Agent Memory System (2606.29778)
統一記憶表示、統一儲存、定量查詢——三件事一起解決。不需要 LLM 做 retrieval，但 LoCoMo 92.21%、LongMemEval 88.40% + 5.4x 加速。這是目前 agent memory 系統設計最完整的一篇。

![Mandol 概念圖](../assets/2026-07-02/mandol-agglomerative-memory.png)

### 2. TUA-Bench: A Benchmark for General-Purpose Terminal-Use Agents (2606.28480)
Terminal 不是只有 coding。120 個任務橫跨 5 個 family，最強 agent 只過了 65.8%。對 harness engineering 的啟示：只在 SWE-bench 上調優的 harness 可能撐不起 general-purpose terminal use。

![TUA-Bench 架構圖](../assets/2026-07-02/tua-bench-terminal-use-agents.png)

### 3. When Do LLMs Generate Realistic Social Networks? (2605.12898)
Prompt 架構 = 社會學假設。192 個網路、4 文化 × 4 語言 × 3 模型規模 × 4 方法的因子實驗，發現政治 homophily 在 3/4 方法下主導、global 方法用年齡替代政治、印地語讓宗教 homophily 急升但政治不變。
