# DailyRead — 2026-07-16

## 三個 Domain 總覽

### Silicon Sampling / Social Simulation
兩篇。Silicon Sampling via Cross-Survey Transfer 把評估從分布比較推到個體層級預測——給 LLM 受訪者在 A 半問卷的回答，預測 B 半的回答。Zero-shot LLM 達到 52% 準確率，只差監督式 random forest 6 個百分點，且發現穩定的構念可預測性階層（政黨態度 67% > 主權態度 23%）。BOUNDARY_SYNC 測量多 agent 溝通引起的表徵耦合——文字溝通顯著同質化（CAF=0.803），但耦合是 stateless 的（移除鄰居資訊就消失），且 K=3 時反而趨向分化。

### Harness Engineering
一篇。E3（Estimate, Execute, Expand）提出 task-aware execution：先判斷任務需要多少 effort，用最小可行路徑執行，只在驗證失敗時擴展。形式化了 minimum-sufficient execution 和 ACRR（Agent Cognitive Redundancy Ratio），在 MSE-Bench 上 100% success 同時削減 85% 成本。核心洞見借鑑電力系統 flat start——不是少想，而是先判斷需要想多少。

### Agent Memory
一篇。Apple 提出 shared selective persistent memory：把 agent session 的可重用 context 分解成四個正交類別（task specs / data schemas / tool configs / output constraints），只保留這四類，丟掉推理軌跡。96% task completion（vs 79% 無記憶、71% 全歷史）——naive full-history 反而比無記憶更差。Zero-token data refresh 把程式和資料分離，資料更新零 LLM token。

## 🦞 今日推薦點開

### 1. E3: Do AI Agents Know When a Task Is Simple? (2607.13034)
Agent 不是不知道怎麼做，是不知道需要做多少。E3 把「判斷 effort scope」變成 first-class capability，用 flat-start 類比把 minimum-sufficient execution 形式化為 ACRR。在保持 100% success 的同時砍掉 85% 成本——不是「少做」，是「先判斷再做」。和 Apple 的 selective memory 形成有趣的 session 內 vs 跨 session context 管理對照。

![](../assets/2026-07-16/e3-complexity-aware-execution.png)

### 2. Shared Selective Persistent Memory for Agentic LLM Systems (2607.09493)
Apple 的答案是：不是留更多，是留對的。四類 context 獨立持久化，推理軌跡丟掉。最反直覺的結果是 naive full-history 比 no memory 還差（71% vs 79%）。Zero-token data refresh 是工程亮點——資料更新不需要重新叫 LLM。

![](../assets/2026-07-16/shared-selective-persistent-memory.png)

### 3. Silicon Sampling via Cross-Survey Transfer (2607.03091)
從「LLM 能模擬人口分布嗎」推進到「LLM 能從局部態度推斷個體的完整態度結構嗎」。Cross-survey transfer 是比分布比較嚴格得多的評估。52% zero-shot 準確率只差監督式模型 6pp，且發現穩定的構念階層——政黨態度好預測，主權態度難預測。
