### 2. 🧠 Remember When It Matters: Proactive Memory Agent for Long-Horizon Agents (2607.08716)

![](assets/2026-07-18/proactive-memory-agent.png)

提出「behavioral state decay」作為 long-horizon agent 的核心失敗模式：決策相關資訊在軌跡中逐漸失去影響力。記憶不該只是被動存取，而應是主動介入。獨立的記憶 agent 在固定間隔決定是否注入提醒或保持沉默，Terminal-Bench +8.3pp、τ²-Bench +6.8pp。選擇性介入勝過被動暴露、永遠注入、advisor-only。

→ [arXiv](https://arxiv.org/abs/2607.08716) | [domain note](../agent-memory/2026-07-18.md)

### 3. 🏗️ Self-Evolving Agent Harnesses via Gated Semantic Quality-Diversity (2607.13683)

![](assets/2026-07-18/gsme-self-evolving-harness.png)

Harness self-evolution 的可信度問題怎麼解？分離 proposing 與 crediting：evolver 提出語意 (where×why) patch，但所有抽樣、測量、顯著性檢定由確定性程式碼持有。Gated Semantic MAP-Elites (GSME) 以病理為 key 的品質多樣性封存，anti-overfitting bias。Sealed test +9 到 +15.5pp，保留 86–147% training gain。贏的 patch 追蹤模型的病理而非規模。

→ [arXiv](https://arxiv.org/abs/2607.13683) | [domain note](../harness-engineering/2026-07-18.md)
