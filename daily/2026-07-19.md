### 1. 🧠 MemCon: Memory as a Controlled Process (2607.13591)

![](assets/2026-07-19/memcon-memory-controlled-process.png)

Agent 記憶不是被動的儲存/檢索問題，而是需要 adaptive control 的 sequential decision problem。MemCon 把記憶操作框架為 Memory MDP，用 lightweight tabular UCB bandit 學習何時 retrieve、何時 inject plan、何時 consolidate/forget。不需要額外 LLM call，不需要 pretraining，在數十個任務內收斂。6 benchmarks × 3 frameworks × 3 backbones 上 best or near-best task success，同時減少 5–20% token consumption。跟昨天 Proactive Memory Agent 的「選擇性介入」一脈相承，但更根本——不需要 LLM 當 controller，只需要毫秒級 table lookup。

→ [arXiv](https://arxiv.org/abs/2607.13591) | [domain note](../agent-memory/2026-07-19.md)

### 2. 🏗️ Deterministic Gates Recover Silent Policy-Violation Failures (2607.07405)

![](assets/2026-07-19/deterministic-gates-silent-policy-violation.png)

Tool-using agent 在 policy-permissive 環境中有一種隱蔽失敗模式：agent 違反政策但工具照常執行，沒有任何 error signal。78% 的 observed failures 是 silent wrong-state failures。四個 deterministic, read-only pre-execution gates 把 gpt-4o-mini 成功率從 29.6% 提升到 42.0%（+12.4pp），在 disjoint replication set 上重現（+12.3pp）。即使在 gpt-5.2 上，policy-violating writes 仍然存在，gates 改善 +10.4pp。核心洞察：在 action boundary 上加一個只讀 policy check，可以確定性地阻止一類已知違規行為。

→ [arXiv](https://arxiv.org/abs/2607.07405) | [domain note](../harness-engineering/2026-07-19.md)

### 3. 📊 Will Scaling Improve Social Simulation with LLMs? (2607.02464)

![](assets/2026-07-19/will-scaling-improve-social-simulation.png)

85 個 isoFLOP Qwen3 models + 35 個 open-weight models 的系統性 scaling law 分析：log-linear scaling laws 解釋了 94–97% 的 task loss variance。大部分 opinion 和 behavior simulation tasks 會隨 scale 快速改善，但有 outliers：longitudinal forecasting 和 underrepresented opinions scale 更慢，風險趨避和 correlated-reward learning 即使 fine-tuning 也不改善。Social simulation fidelity 與 general capability（MMLU）的相關性從 r=0 到 r=0.85 不等。結論：scale 會改善大部分 social simulation，但 outliers 需要專門研究投入。

→ [arXiv](https://arxiv.org/abs/2607.02464) | [domain note](../silicon-sampling-social-simulation/2026-07-19.md)
