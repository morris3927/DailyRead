## 今日推薦點開

### 1. 🗣️ Too Open for Opinion? Embracing Open-Endedness in Large Language Models for Social Simulation (2510.13884)

![](assets/2026-07-20/too-open-for-opinion-open-ended-social-simulation.png)

這篇 EACL 2026 position paper 的重點不是再提出一個新的 social simulator，而是直接挑戰目前 LLM social simulation 常見的評估形式：我們為了好計分，常把 simulated respondents 壓進 multiple-choice 或短答框架，但這會把 LLM 最能產生差異、理由、少數觀點與意外主題的部分抹平。作者把 survey methodology 裡 open-ended question 的價值搬回 LLM simulation：如果我們真的在意 social complexity，就不能只看 categorical matching，也要設計能分析 topic、viewpoint、reasoning process 與 expressive individuality 的 workflow。這篇值得 Morris 點開，因為它剛好補在 silicon sampling 最近 scaling / fidelity 討論旁邊：不是問模型像不像平均人，而是問我們的測量介面是不是先把「不像平均人」的訊號刪掉了。

→ [arXiv](https://arxiv.org/abs/2510.13884) | [domain note](../silicon-sampling-social-simulation/2026-07-20.md)

### 2. 🎛️ Learning to Control LLM Agent Harnesses with Offline Reinforcement Learning (2607.05458)

![](assets/2026-07-20/learning-to-control-agent-harnesses-offline-rl.png)

這篇把 harness engineering 往前推了一步：不只是要求 disclose harness、或手寫更好的 workflow，而是把 observe / retrieve / call-tool / draft / check / revise / submit 這些外部控制步驟建成 Harness MDP，讓一個輕量 controller 從離線 rollout buffer 裡用 advantage-weighted regression 學會何時採取哪個 structural action，LLM executor 本身保持 frozen。它另外把 final task quality 和 Harness Maturity Score 分開，避免把「答案剛好對」誤認為「過程可靠」。讀後我覺得這是今天最值得細看的 harness paper：它清楚說明 learnable harness control 的上限也受 offline buffer support 限制，這點比單純宣稱 RL 能自動修好 agent workflow 更可信。

→ [arXiv](https://arxiv.org/abs/2607.05458) | [domain note](../harness-engineering/2026-07-20.md)

### 3. 🧩 PlaceMem: Toward a Compute-Aware Memory Plane for Lifelong Agents (2607.04089)

![](assets/2026-07-20/placemem-compute-aware-memory-plane.png)

PlaceMem 把 agent memory 的問題從「要不要檢索某段文字」拉到 serving/system layer：lifelong agent 不只需要語意記憶，也會產生可重用的 runtime state，例如 prefix / KV cache / placement hints；如果語意資料被修正，但 derivative summaries、indexes 或 runtime artifacts 沒有一起 invalidated，agent 就可能快速但錯誤地重用 stale state。作者提出 versioned memory capsules，把 semantics、provenance、validity、dependencies 與 reusable compute artifacts 綁在同一個 correction-aware identity 下，並做了 vLLM-first control-plane prototype。這篇值得點開，因為它把 memory governance、cache reuse、correction / forgetting 串成一個具體系統問題。

→ [arXiv](https://arxiv.org/abs/2607.04089) | [domain note](../agent-memory/2026-07-20.md)
