### 1. 🧑‍🤝‍🧑 Collective Cooperation without Individual Fidelity in LLM Agents (2606.30454)

![](assets/2026-07-21/collective-cooperation-without-individual-fidelity.png)

這篇用大型人類 Prisoner's Dilemma 實驗當 ground truth，把九個 open-weight LLM 放進完全相同的 network structure 和 payoff matrix 比對，發現 best-match model 在 macro 層面能重現合作率的早期下降和後期穩定，但 micro 層面 LLM 異質性偏低、conditional cooperation pattern 跟人類不同——這是 macro–micro dissociation 的直接實證證明。即使加入隨機 agent 改善 heterogeneity，decision rule 的 mismatch 仍然存在。這補充了之前追蹤的 Boundary paper 和 Open-Ended paper：問題不只是 heterogeneity 不夠，而是 LLM 的決策機制本身就跟人類不同。

→ [arXiv](https://arxiv.org/abs/2606.30454) | [domain note](../silicon-sampling-social-simulation/2026-07-21.md)

### 2. 📖 Harness Handbook: Making Evolving Agent Harnesses Readable, Navigable, and Editable (2607.13285)

![](assets/2026-07-21/harness-handbook-behavior-localization.png)

Harness engineering 裡一直缺的一塊：改 harness 之前要先找到要改哪裡，但 production harness 跨幾百個 function、多個 execution stage，行為散佈在非相鄰位置。Harness Handbook 用靜態程式分析 + LLM-assisted behavioral structuring 自動合成行為導向的 L1–L3 文件樹，搭配 BGPD workflow 讓 coding agent 從行為描述一路導航到 source location。實驗顯示 Handbook-assisted planning 在 behavior localization 和 edit-plan quality 上都優於 baseline，最大收益出現在 scattered sites、rarely executed paths、cross-module interactions——正是最難手動定位的 case。

→ [arXiv](https://arxiv.org/abs/2607.13285) | [domain note](../harness-engineering/2026-07-21.md)

### 3. 🔄 Do Self-Evolving Agents Forget? Capability Erosion and Preservation in Lifelong LLM Agent Adaptation (2605.09315)

![](assets/2026-07-21/capability-erosion-self-evolving-agents.png)

這篇把 catastrophic forgetting 從 model parameter 層面推廣到所有 self-evolution channel：workflow、skill/tool、model、memory 演化都會 erode 舊 capability，而且根源是同一個 interference mechanism——new-task update direction 在 old-task curvature directions 有 non-zero projection。CPE 加入 channel-specific retention regularizer，在每個 channel 都改善了 retained capability stability。對 agent memory 領域的意義：不管你的 memory 用什麼結構，新增 memory 時如果沒有明確考慮 retention，就會 erode 舊 capability。

→ [arXiv](https://arxiv.org/abs/2605.09315) | [domain note](../agent-memory/2026-07-21.md)
