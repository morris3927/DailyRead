### 1. 🕸️ Characterizing Opinion Evolution of Networked LLMs (2606.18276)

![](assets/2026-07-22/opinion-evolution-networked-llms.png)

這篇系統性地比較 DeGroot、Friedkin-Johnsen、和含 bias 項的擴展模型，看哪個最能描述 LLM 網路的意見演變。結論：加入 innate bias 項降低累積誤差最多 88%，遠比 stubbornness 或 homophily 重要。這意味著 LLM 社會模擬的意見分布會被模型先天偏見系統性拉偏，單純調整網路結構或 persona 可能無法修正。三個模型家族、多個話題、多種網路拓撲下結論穩定。

→ [arXiv](https://arxiv.org/abs/2606.18276) | [domain note](../silicon-sampling-social-simulation/2026-07-22.md)

### 2. 🧰 MemoHarness: Agent Harnesses That Learn from Experience (2607.14159)

![](assets/2026-07-22/memoharness-experience-driven-adaptation.png)

Harness engineering 的新進展：MemoHarness 把 harness 分解為六個可編輯控制面（context, tool, generation, orchestration, memory, output），用雙層 experience bank 累積 per-case diagnosis 和 global patterns，在 test time 從 bank 檢索相似案例來做 case-specific adaptation——不需要 label、feedback、或額外搜尋。在 shell-agent benchmark 上從 0.722 提升到 0.806，且在 unseen suites 和 held-out models 上有選擇性正向 transfer。跟 Harness Handbook（讓 harness 可讀可導航）互補。

→ [arXiv](https://arxiv.org/abs/2607.14159) | [domain note](../harness-engineering/2026-07-22.md)

### 3. 🔄 When Does Continual Learning Require Learning (2607.07847)

![](assets/2026-07-22/continual-learning-axes-of-change.png)

Continual learning 不是單一能力。這篇把環境變化拆為空間軸（新 domain）和時間軸（data drift），再細分為 slow trends、discrete fact changes、agentic accumulation 三個 sub-regime。統一 protocol 比較 prompt-based、supervised、RL、和 context compression 四大類方法，發現不同變化形態需要根本不同的更新策略。Prompt methods 快但不持久；distillation 穩定但更新慢；RL 最能適應 knowledge updates 但對 noise 敏感。這為 agent memory 的設計提供了精細的決策框架。

→ [arXiv](https://arxiv.org/abs/2607.07847) | [domain note](../agent-memory/2026-07-22.md)
