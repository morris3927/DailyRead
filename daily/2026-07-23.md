## 交叉觀察

- **記憶系統何時有用？** CL-Bench 發現 naive ICL 優於 memory 系統，Nous 發現 belief updating 只在有 reliability signal 時才有幫助，ProactAgent 發現主動檢索優於被動檢索——三者指向同一結論：記憶系統的價值取決於環境是否提供讓記憶系統發揮的結構（reliability、retrieval 時機、環境經驗）。
- **Harness 評估 ≠ Task completion**：Beyond Task Completion 和 LME-V2 都在說同一件事——binary task completion 看不到行為層面的失敗，需要更細緻的評估框架。
- **模組化 vs 自動化 vs 條件性**：Modular Memory 主張手工設計模組化架構，ALMA 主張讓 Meta Agent 自動探索，Nous 則指出精巧設計只在特定條件下有幫助——三個互補視角構成了 agent memory 的設計圖景。
