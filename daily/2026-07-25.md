1. **Profile-Graph Memory (ProGraph)** (2607.19359) — 多跳記憶的突破：用 profile 內的實體名 substring match 做隱式圖遍歷，不需要建 KG，在 MemHop（K=1–5）上 80.1% 匹配 FullContext，在 LoCoMo 上 78.4% 超過 FullContext 11.3pp。Ablation 顯示 profile expansion 負責多跳（-22.6pp），compression residuals 負責精確回憶（-8.6pp）。[→ domain note](../agent-memory/2026-07-25.md)

2. **Measuring Harness-Induced Belief Divergence** (2607.04528) — Harness 不只影響 outcome，還改變 agent 的信念軌跡。定義 harness six-tuple (O_H, A_H, V_H, G_H, R_H, L_H)，用 K-step belief rollout 診斷 cross-harness belief divergence，分解成 arrival term（立即介面偏移）和 growth term（horizon-dependent 信念漂移）。提出 BIWM 無訓練協議對齊跨 harness 信念。[→ domain note](../harness-engineering/2026-07-25.md)

3. **Distribution-First Population Simulation** (2607.18310) — 獨立 agent 模擬的基礎失敗模式：N 個 grounded LLM agent 的選擇集中到 modal default（concentration 0.36→0.69, entropy 1.46→0.77, 85% 單位崩塌），崩塌嚴重度與 single-rational 結構相關（r=0.55）。VS 修正 under-dispersion 但結構性 over-disperse。提出 distribution-first 校正。[→ domain note](../silicon-sampling-social-simulation/2026-07-25.md)

## 交叉觀察

- **Harness 是實驗變量，不是實作細節**：今天的 Belief Divergence 論文直接量化了 harness 對信念軌跡的影響，和昨天 Rethinking Harness Evaluation 的結論呼應——harness evolution 可能不過是搜尋到更好 harness 配置，而不是模型能力提升。兩者指向同一結論：agent evaluation 需要對 harness 做對照實驗。
- **Memory 系統的多跳 vs 精確度 trade-off**：ProGraph 用 ablation 乾淨地分離了兩個機制——profile expansion 負責多跳，compression residuals 負責精確度。這和 CMI-Mem 的內在/外在 reward 互補架構平行：不同的 memory 功能需要不同的評估維度。
- **Silicon sampling 的獨立 agent 失敗模式**：Distribution-First 論文的核心發現（獨立 agent 崩塌到 modal default）和之前讀的「LLM-Based Social Simulations Require a Boundary」形成互補——前者量化了崩塌，後者提出了邊界條件。VS over-dispersion 是結構性的，這意味著任何修正都需要 distribution-level 校正而非個體層面的調參。
