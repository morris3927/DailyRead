## 三個 domain headline

- **Silicon Sampling / Social Simulation**: Verbalized Sampling 把 mode collapse 重新定位為「取樣介面問題」，用 training-free 的 prompt 策略讓 LLM 先 verbalize 分布再取樣；Geometric Regulation 則從表示空間的幾何崩塌角度理解 mode collapse。
- **Harness Engineering**: SWE-Touch 把 coding agent 評估從「agent 獨自工作」推進到「shared workspace」— 使用者可以在 agent 工作期間修改 codebase，59% 的真實 session 都有這種互動。
- **Agent Memory**: LycheeMemory V2 把記憶建構從 turn-level 改成 semantic segment-level，用語意邊界偵測替代固定窗口，大幅降低 construction token 成本；Temporal Context Reinstatement 則從認知科學角度發現 LLM 內部有專門的 attention head 負責恢復 temporal code。

## 今日推薦點開

### 1. Verbalized Sampling: Mitigate Mode Collapse and Unlock LLM Diversity

- **Domain**: Silicon Sampling / Social Simulation
- **Link**: https://arxiv.org/abs/2510.01171
- **推薦理由**: 這篇提出了一個極低成本、training-free 的方法來增加 LLM 輸出多樣性 — 讓模型先 verbalize 機率分布再取樣。對 silicon sampling 的實務影響很大，因為它提供了一個即插即用的方法來緩解 mode collapse，不需要修改模型或重新訓練。

### 2. SWE-Touch: Benchmarking Coding Agents When Users Touch the Code

- **Domain**: Harness Engineering
- **Link**: https://arxiv.org/abs/2608.02499
- **推薦理由**: 這篇填補了 coding agent 評估的一個重要缺口 — 現有 benchmark 都假設 agent 在孤立環境中工作，但 59% 的真實 session 包含使用者 code edit。SWE-Touch 的 Counter-Edit 框架系統化地測試 agent 的 state awareness，發現強模型在互動條件下退化嚴重。

### 3. LycheeMemory V2: Efficient Long-Term Memory via Semantic Segment-Level Consolidation

- **Domain**: Agent Memory
- **Link**: https://arxiv.org/abs/2608.12990
- **推薦理由**: 這篇提出了一個清晰的設計原則 — 記憶建構粒度應該匹配語意邊界，而不是對話輪次。在 LoCoMo 和 LongMemEval-S 上達到 SOTA，同時減少 86% 的 construction token 成本。對設計實用的 agent memory 系統有直接的工程啟示。
