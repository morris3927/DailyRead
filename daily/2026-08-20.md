## 今日推薦點開

### 1. MEM1: Learning to Synergize Memory and Reasoning for Efficient Long-Horizon Agents

- **Domain**: Agent Memory
- **Link**: https://arxiv.org/abs/2506.15841
- **推薦理由**: 這篇提出了一個根本不同的 agent memory 架構 — 不建構外部記憶紀錄，而是用 RL 訓練 agent 學會在推理過程中內化記憶，每輪只保留一個 compact internal state。MEM1-7B 在 16-objective multi-hop QA 上比 Qwen2.5-14B-Instruct 性能提升 3.5×、記憶使用量降低 3.7×，且能泛化到比訓練更長的互動輪次。這是 agent memory 從「外部記憶 + retrieval」範式轉向「內化記憶 + reasoning」範式的代表性工作。

### 2. Harness the Memory: A Holistic Evaluation of Memory Substrates in Memory Agents

- **Domain**: Agent Memory
- **Link**: https://arxiv.org/abs/2608.15008
- **推薦理由**: agent memory 領域最需要的評估論文 — 第一個系統性地把記憶基質（而非系統）作為唯一實驗變數的 controlled evaluation。11 種方法、7 個基質家族、3 個 backbone、4 個 benchmark、26 個指標。核心發現：最優基質在不同情境之間反轉（structural graph 在 QA 領先但在 agentic 被 Pareto 支配），retrieval depth 在 QA 有幫助但在 agentic tasks 有害（注意力偏移），這些發現直接支援 substrate routing 作為通用記憶系統的必要組件。

### 3. Architectural Design Decisions in AI Agent Harnesses

- **Domain**: Harness Engineering
- **Link**: https://arxiv.org/abs/2604.18071
- **推薦理由**: 第一個對 agent harness 架構做系統性原始碼研究的論文。70 個專案、五個設計維度（subagent architecture、context management、tool systems、safety mechanisms、orchestration）、五個典型架構模式。對理解「包圍 LLM 的非 LLM 工程層怎麼組織」提供了實證基礎，填補了 harness engineering 領域的架構研究空白。
