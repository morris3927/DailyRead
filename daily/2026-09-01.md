# DailyRead — 2026-09-01

## 今日總覽

三個 domain 各有新內容。Silicon sampling 領域迎來一篇重量級實證基礎建設論文（SILICA），harness engineering 出現了整合三大失敗模式的 long-horizon harness（OneDayAgent），agent memory 有記憶結構化路線的最新實證（Memori）。

## 今日推薦點開

1. **SILICA: Benchmarking LLM Agent Societies Against Human Behavioural Distributions** (2608.28182)
   - 把 silicon sampling 三大質疑（fidelity、robustness、contamination）做成可執行、可重現的測量儀器；9,115 次實驗後結論：目前 silicon society 只支持探索性宣稱。
   - ![](assets/2026-09-01/silica-benchmark.png)

2. **OneDayAgent: Towards a Long-Horizon Harness for Autonomous Agents** (2608.05013)
   - 整合任務分解、全局驗證修復、執行記憶的 long-horizon harness；GLM-5.2 達 0.821 SOTA，跨五個 backend 穩定通用。
   - ![](assets/2026-09-01/onedayagent-harness.png)

3. **Memori: A Persistent Memory Layer for Efficient, Context-Aware LLM Agents** (2603.19935)
   - 把對話結構化為 semantic triples + 對話摘要的雙層記憶；81.95% accuracy，每 query 僅 1,294 tokens（~5% full context）。
   - ![](assets/2026-09-01/memori-persistent-memory.png)
