# DailyRead Domains

## Silicon Sampling / Social Simulation

追蹤 LLM 如何用於模擬人類、社會、意見、行為與 synthetic population。重點不是單篇模型效果，而是這個方向如何處理多樣性、代表性、人格設定、群體互動與模擬可信度。

Keywords: silicon sampling, LLM persona simulation, social simulation with LLMs, generative agents, synthetic population, opinion dynamics, survey simulation, behavioral fidelity, demographic conditioning.

## Harness Engineering

追蹤 LLM / agent 實驗與評估基礎設施。這個方向不一定都有 paper，會包含 evaluation framework、benchmark harness、technical blog、GitHub repo、工程實作與 reproducibility 討論。

Keywords: evaluation harness, LLM benchmark, agent evaluation, eval pipeline, reproducible LLM experiments, LLM-as-judge, benchmark contamination, eval infrastructure, task harness.

## Agent Memory

追蹤 AI agents 的長期記憶、短期記憶、檢索、壓縮、反思、遺忘與 cognitive architecture。重點是 memory 如何影響 agent 的任務能力、脈絡一致性與長期互動。

Keywords: agent memory, long-term memory for LLM agents, episodic memory, semantic memory, memory retrieval, reflective memory, memory consolidation, forgetting in agents, RAG for agents, cognitive architecture.
