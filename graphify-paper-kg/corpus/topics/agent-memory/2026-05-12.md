# Agent Memory — 2026-05-12

## 今日篩選判斷

今天 Agent Memory 的主線是「從記憶機制走向評估與組織」。我挑三篇：一篇 survey 把 memory 寫成 write-manage-read loop；一篇 benchmark 把 memory evaluation 變成 incremental multi-turn interactions；一篇 NeurIPS 2025 paper 用 Zettelkasten-style linking 做 agentic memory organization。三者剛好對應 taxonomy、benchmark、mechanism。

## 1. Memory for Autonomous LLM Agents: Mechanisms, Evaluation, and Emerging Frontiers

- URL: https://arxiv.org/abs/2603.07670
- HTML: https://arxiv.org/html/2603.07670v1
- Author: Eric Du
- Date: 2026-03-08
- Source type: arXiv survey

### 這篇在說什麼

這篇 survey 把 agent memory 定義得很乾淨：memory 是讓 stateless text generator 變成 adaptive agent 的能力，重點不只是把資訊存起來，而是跨互動 persist、organize、selectively recall。作者把 memory formalize 成和 perception / action 緊耦合的 **write–manage–read loop**。

這個 loop 很實用：write 決定什麼被寫入；manage 決定如何壓縮、連結、更新、忘記與治理；read 決定任務當下如何召回。很多 memory 系統的問題其實不是 retrieval model 不夠強，而是 write path 太髒、manage path 沒有 contradiction handling、read path 缺 causal grounding。

### 主要貢獻

它提出三維 taxonomy：temporal scope、representational substrate、control policy。並整理五種 mechanism families：context-resident compression、retrieval-augmented stores、reflective self-improvement、hierarchical virtual context、policy-learned management。

評估方面，它追蹤從 static recall benchmark 走向 multi-session agentic tests 的趨勢，並指出 current systems 在 continual consolidation、causally grounded retrieval、trustworthy reflection、learned forgetting、multimodal embodied memory 上還有缺口。

### 方法 / pipeline

這是 survey，不是新系統。它涵蓋 2022 到 early 2026 的 agent memory 工作，從機制、評估、應用和工程現實四個層次整理。應用面包含 personal assistants、coding agents、open-world games、scientific reasoning、multi-agent teamwork。

工程面我覺得特別值得注意：write-path filtering、contradiction handling、latency budgets、privacy governance。這些通常在 research demos 裡被淡化，但對真正 agent memory 是硬問題。

### 實驗設計

沒有新實驗；它是 structured survey。DailyRead 不把 survey 當 benchmark 報分數，而是把它視為 map：讀新 memory paper 時可以問它改的是 write、manage 還是 read？它處理的是 temporal scope、representation 還是 control policy？

### かに讀後判斷

值得點開，尤其適合 Morris 建立 agent memory 閱讀框架。若只記一句話：**agent memory 不是向量庫，而是一個被 perception/action 壓力測試的 write–manage–read 控制迴路。**

## 2. Evaluating Memory in LLM Agents via Incremental Multi-Turn Interactions

- URL: https://arxiv.org/abs/2507.05257
- HTML: https://arxiv.org/html/2507.05257v3
- Authors: Yuanzhe Hu, Y. Wang et al.
- Date: v1 2025-07-07; v3 2026-03-17
- Source type: arXiv benchmark paper

### 這篇在說什麼

這篇指出一個很常見的評估缺口：LLM agent benchmark 大多測 reasoning、planning、execution，但 memory 這個 component 很少被完整測。就算有 long-context QA，也常常是 static setting；真實 memory agent 是在多輪互動裡逐步累積資訊，再於後續任務中 retrieval、update、forget。

作者提出 MemoryAgentBench，專門把 memory evaluation 改造成 incremental multi-turn format。

### 主要貢獻

它基於 memory science / cognitive science 抽出四個核心能力：accurate retrieval、test-time learning、long-range understanding、selective forgetting。這四項很有用，因為它避免把 memory 簡化成「問舊資訊答不答得出來」。

MemoryAgentBench 透過轉換既有 long-context datasets 與新建資料，把資訊餵給 agent 的方式改成多輪累積，模擬 memory agents 逐步處理資訊的情境。作者評估多種 memory agents，從簡單 context-based / RAG 到 external memory modules / tool-integrated agents。

### 方法 / pipeline

這篇的 pipeline 是 benchmark construction：選資料、轉成 multi-turn interaction、覆蓋四種 memory competencies，再讓不同 memory agent 在同一框架下比較。這對 agent memory 很重要，因為如果 benchmark 不要求 incremental accumulation，就很容易讓長 context model 以「一次讀完」的方式繞過真正 memory 問題。

### 實驗設計

從 abstract 可知，實驗結果顯示 current methods 沒有一個能同時掌握四種能力，尤其 selective forgetting / test-time learning 類能力仍是缺口。DailyRead 這裡還沒有逐表讀每個 baseline 的分數，所以不細報單一模型排名。

### かに讀後判斷

值得點開。它和昨天的 MemoryArena 可以一起讀：MemoryAgentBench 更關心 memory competence 的系統覆蓋；MemoryArena 更關心 memory 是否改善 agentic action。兩者都比傳統 static recall 更接近真實 long-term agent。

## 3. A-Mem: Agentic Memory for LLM Agents

- URL: https://proceedings.neurips.cc/paper_files/paper/2025/hash/19909c36f51abc4856b4560aff3d36d6-Abstract-Conference.html
- Venue: NeurIPS 2025
- Source type: conference paper

### 這篇在說什麼

A-Mem 的問題意識是：現有 memory systems 可以 storage / retrieval，但記憶組織通常太固定、太不會自我調整。作者借 Zettelkasten 方法，讓 agentic memory 在新增記憶時產生結構化 note，包含 contextual descriptions、keywords、tags，並主動分析歷史記憶來建立 meaningful links。

這裡的重點不是只把每段 memory embedding 後丟進 vector DB，而是讓 memory network 會被新記憶觸發更新。新 memory 加入時，系統不只連到舊 memory，也可能更新舊 memory 的 contextual representation 和 attributes，形成 memory evolution。

### 主要貢獻

它提出一個動態組織的 agentic memory system：memory entries 不是孤立文件，而是會被 indexing、linking、attribute updating 組成 knowledge network。這對長期 agent 很重要，因為真實使用中記憶不是一次寫入永不改變；新的資訊常常會改寫舊資訊的重要性、語境或關聯。

### 方法 / pipeline

pipeline 大致是：新 memory 進來後，生成包含多個 structured attributes 的 note；再搜尋 / 分析歷史 memories，找出相似或相關的 connections；若新資訊改變了舊資訊的理解，則更新舊 memory 的表示或屬性。這是把 Zettelkasten 的「卡片互連」轉成 agent memory management。

### 實驗設計

NeurIPS abstract 說作者在六個 foundation models 上做 empirical experiments，並相對既有 SOTA baselines 有 superior improvement。但 abstract page 沒提供完整 dataset、metric、baseline 分數；DailyRead 這裡不硬補數字，建議點 PDF 再讀實驗表格。

### かに讀後判斷

值得收藏，尤其適合和 MemoryAgentBench / survey 的 write–manage–read loop 對照。A-Mem 明顯是在 manage path 發力：讓記憶組織與舊記憶更新變成 agentic process，而不是固定資料庫操作。
