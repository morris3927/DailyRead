# Agent Memory — 2026-05-13

## 1. Memory for Autonomous LLM Agents: Mechanisms, Evaluation, and Emerging Frontiers

- **作者**: Eric Du 等
- **arXiv**: [2603.07670](https://arxiv.org/abs/2603.07670)
- **提交日期**: 2026-03-08

這是一篇覆蓋 2022–2026 年的 agent memory survey，核心框架是把 memory 定義成 **write–manage–read loop**，然後在三個維度上分類：

- **Temporal scope**: short-term / long-term / episodic
- **Representational substrate**: token-level / parametric / latent
- **Control policy**: hardcoded / learned / reflective

五個 mechanism families 深入分析：

1. **Context-resident compression** — 在 context window 內壓縮
2. **Retrieval-augmented stores** — 向量庫 + RAG
3. **Reflective self-improvement** — agent 自己反思、整理記憶
4. **Hierarchical virtual context** — 多層記憶結構
5. **Policy-learned management** — 學習何時寫、何時讀、何時忘

Evaluation 部分追蹤了從 static recall benchmark 到 multi-session agentic test 的演變，分析了四個近期 benchmark，指出現有系統在「記憶與決策交織」的場景下仍有 stubborn gaps。

最後列了 open challenges：continual consolidation、causally grounded retrieval、trustworthy reflection、learned forgetting、multimodal embodied memory。

**閱讀判斷**: 這是目前最完整的 agent memory survey，框架清晰、覆蓋面廣。如果你只讀一篇 agent memory 的 paper，這篇是首選。**今日推薦點開。**

## 2. ActMem: Bridging the Gap Between Memory Retrieval and Reasoning in LLM Agents

- **作者**: Wei Hu 等
- **arXiv**: [2603.00026](https://arxiv.org/abs/2603.00026)
- **提交日期**: 2026-02-04

這篇的核心觀察是：現有 memory framework 把 agent 當 passive recorder，retrieve 資訊但不理解其深層含義。在需要衝突檢測和複雜決策的場景下，這會失敗。

ActMem 的做法：

- 把非結構化對話歷史轉成 **structured causal and semantic graph**
- 利用 **counterfactual reasoning** 和 **commonsense completion** 推導隱含約束
- 在 past states 和 current intentions 之間 **resolve conflicts**

他們還引入了 ActMemEval dataset，評估 agent 在 logic-driven scenarios 的推理能力——不再只是 fact retrieval，而是要理解記憶的含義和衝突。

實驗結果顯示 ActMem 顯著超越 SOTA baselines，特別在複雜、memory-dependent 的任務上。

**閱讀判斷**: 這篇把記憶從「存取」推向「理解」，causal graph + counterfactual reasoning 的切入角度很新鮮。方法有具體實驗支撐，值得細看。
