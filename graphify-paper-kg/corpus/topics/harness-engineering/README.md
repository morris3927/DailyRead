# Harness Engineering

這個 domain 追蹤 LLM / agent 實驗、評估與部署前測試的工程方法。它不只看 paper，也會看 technical blog、framework docs、GitHub repo、benchmark infrastructure 與 evaluation practice。

## 觀察重點

- 如何設計可重現、可比較、可自動化的 eval pipeline？
- agent evaluation 如何處理多步驟、工具使用、狀態變化與 trajectory？
- benchmark harness 如何支援不同模型、不同任務與不同 grader？
- LLM-as-judge、unit tests、human eval、trajectory review 分別適合什麼？
- 工程團隊如何把 eval 放進日常開發流程？

## 常見類型

- Paper / survey: agent evaluation、benchmark design
- Framework: lm-evaluation-harness、OpenHands evaluation harness
- Technical blog: agent eval best practices、production eval workflow
- GitHub repo: benchmark adapters、eval pipelines、agent harnesses

## Keywords

evaluation harness, LLM benchmark, agent evaluation, eval pipeline, reproducible LLM experiments, LLM-as-judge, benchmark contamination, eval infrastructure, task harness.
