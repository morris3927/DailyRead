# Silicon Sampling / Social Simulation

這個 domain 追蹤 LLM 如何被用來模擬人類、社會、意見、行為、synthetic population 與 generative agents。

## 觀察重點

- LLM 能不能模擬真實人群的意見分布？
- persona / demographic conditioning 是否有效？
- 模擬結果是否會過度平均、過度一致或帶有模型偏差？
- social simulation 平台如何擴展到多 agent、大規模互動與環境模擬？
- 研究者如何驗證模擬結果與真實世界資料的差距？

## 常見類型

- Paper: silicon sampling、survey simulation、persona generation
- System: generative agents / social simulator platforms
- Benchmark / dataset: synthetic population、survey replication datasets
- Position / critique: 模擬可信度、代表性、偏差與倫理問題

## Keywords

silicon sampling, LLM persona simulation, social simulation with LLMs, generative agents, synthetic population, opinion dynamics, survey simulation, behavioral fidelity, demographic conditioning.
