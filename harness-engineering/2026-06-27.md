# Harness Engineering — 2026-06-27

## 1. Toward Secure LLM Agents: Threat Surfaces, Attacks, Defenses, and Evaluation

- **arXiv**: 2606.10749
- **Link**: https://arxiv.org/abs/2606.10749
- **Authors**: Shengcheng Yu et al.
- **Submitted**: 2026-06-09

### 這篇在說什麼

LLM agent 正從「對話介面」變成「會規劃、呼叫工具、維護記憶、操作外部環境的軟體元件」。這個轉變改變了安全風險的本質：不再只是 unsafe text generation，而是 untrusted content 可以 redirect control flow、misuse tool privileges、corrupt persistent state、leak sensitive information、trigger harmful external actions。這篇 survey 整合 247 篇論文，用 lifecycle-based、systems-oriented framework 把 agent security 問題組織成四個問題：如何建模安全、威脅面和攻擊家族、防禦方案和 tradeoff、以及安全宣稱如何被評估。

### 主要貢獻

1. **Lifecycle-based systems framework**：把 agent security 問題圍繞 information flow、delegated authority、persistent state 三者的互動建模，而非只是列攻擊清單。
2. **Threat surface 分類**：prompt injection 和 tool-mediated control-flow hijacking 仍為主流；persistent state corruption 和 multi-agent propagation 是新興核心關切。
3. **防禦現狀評估**：現有防禦提供有用的 building blocks（content filtering、permission boundaries、sandboxing），但 remains weakly compositional——單一 building block 有效不等於組合後有效。
4. **Evaluation gap**：現有 benchmark 仍 underrepresent long-horizon、stateful、deployment-sensitive risks，這和 harness engineering 社群的發現呼應。

### 方法 / pipeline

Survey 方法論：247 篇論文系統性回顧，按四個問題組織：
- **Modeling**：如何為 LLM agent security 建模——information flow control、capability security、formal verification
- **Threat surfaces**：input manipulation、tool misuse、memory/state corruption、multi-agent propagation
- **Defenses**：detection-based、lineage-based、capability-gated、trust-scoring
- **Evaluation**：benchmark 分析、覆蓋度評估、long-horizon 和 stateful risk 的缺口

### 實驗設計

（Survey 類型，無原創實驗）對 247 篇論文做系統性回顧和分類。核心發現：
- Prompt injection 仍是攻擊主流，tool-mediated control-flow hijacking 緊隨其後
- Persistent state corruption 和 multi-agent propagation 是 emerging concern
- 現有防禦 weakly compositional：單一機制有效但組合後未必
- 評估缺口：現有 benchmark 缺乏 long-horizon、stateful、deployment-sensitive scenarios

### かに讀後判斷

這篇 survey 和 2606.24322（TMA-NM）形成直接對話。TMA-NM 用形式化方法證明了「content-based 和 lineage-based 防禦都 malleable」，這篇 survey 則從實證面確認：現有防禦確實是 building blocks 但 weakly compositional。兩篇一起讀可以看到從「描述問題」到「形式化證明 + 構造性解決方案」的完整弧線。

對 harness engineering 社群來說，這篇的關鍵訊息是：**harness 本身就是攻擊面**。tool interface、memory interface、multi-agent communication interface 都需要 explicit trust boundary。這和之前 2606.25447（Harness Design and Post-Training）的洞見——harness 設計是 performance 的一級變數——疊加起來，harness 既是安全邊界也是能力邊界。

值得深讀 Section 4（防禦分類）和 Section 5（evaluation gap），特別是和 TMA-NM 的 MEM-INV-Bench 比較。
