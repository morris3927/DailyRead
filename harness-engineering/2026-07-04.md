# Harness Engineering — 2026-07-04

## 1. ResearchClawBench: A Benchmark for End-to-End Autonomous Scientific Research

- **arXiv**: 2606.07591 (v4, July 2, 2026)
- **Link**: https://arxiv.org/abs/2606.07591
- **Project**: https://internscience.github.io/ResearchClawBench-Home/
- **Code**: https://github.com/InternScience/ResearchClawBench
- **Data**: https://huggingface.co/datasets/InternScience/ResearchClawBench
- **Authors**: Wanghan Xu, Shuo Li, Tianlin Ye 等 40+ 位作者（多機構合作）

### 這篇在說什麼

AI coding agent 越來越多被行銷為可以「自主做研究」，但沒有原則性的方式驗證這些宣稱。現有基準要麼是科學問答（GPQA、MMLU），要麼是互動環境（ScienceWorld、DiscoveryWorld），要麼是論文重現（PaperBench），但沒有一個要求 AI 從原始實驗數據出發，產出完整的研究成果，然後用可驗證的錨點來評估。ResearchClawBench（RCBench）填補這個缺口：40 個任務來自 10 個科學領域的真實已發表論文，每個任務提供相關文獻和原始數據，隱藏目標論文，用專家策劃的多模態評分標準（rubric）分解目標科學產物為加權子標準，評估目標論文層級的重新發現同時留出新發現的空間。

### 主要貢獻

1. **End-to-end 自主研究基準**：從原始數據 → 文獻回顧 → 實驗設計 → 數據分析 → 結果撰寫，整個研究迴路都在一個任務中。這是目前最完整的科學研究評估基準。

2. **Expert-curated multimodal rubrics**：每個任務的評分不是 LLM-as-judge，而是領域專家把目標論文的科學產物分解為加權的可驗證子標準。例如天文學任務的 rubric：正確載入後驗樣本並總結質量/自旋後驗（20%）、產生 M33 X-7 排除曲線（30%）、推導超輕玻色子自相互作用耦合上限（50%）。這讓評估既可重現又可解釋。

3. **ResearchHarness**：一個輕量級的 tool-use harness，讓原生 LLM（不需要完整 agent scaffold）也能參與 RCBench 評估。三類工具：web 工具（Serper API 搜尋 + Jina Reader 抓網頁）、本地檔案工具（discover/read/inspect/extract）、本地執行工具（one-shot shell + persistent terminal）。支援 context compaction（128k 觸發）。

4. **系統性評估結果**：7 個自主研究 agent + 17 個原生 LLM。最強自主 agent Claude Code 平均 21.5 分（滿分 50 表示達到目標論文水平）；最強 ResearchHarness LLM Claude-Opus-4.7 平均 20.7；LLM frontier mean 只有 26.5。錯誤集中在實驗協議不匹配、證據不匹配、缺失科學核心。

### 方法 / pipeline

**任務建構流程**：
- 領域專家篩選有明確科學問題、可取得原始數據、有研究價值的已發表論文
- 提取核心問題，重寫為可執行的任務描述
- 組織相關文獻和原始數據
- 從目標論文產物建構加權 rubric
- 交叉檢查、修正、過濾不合適樣本

**評估設計**：
- 錨定分數 50 分 = 達到目標論文水平；超過 50 分表示新發現
- 每個任務的 rubric 由領域專家分解為 3–8 個加權子標準
- 多模態：可以評估圖表、表格、文字等不同產物類型

**10 個領域**：Astronomy、Chemistry、Earth Science、Energy Science、Information Science、Life Science、Material Science、Mathematics、Neuroscience、Physics

**兩種評估模式**：
- 完整自主 agent 評估（7 個系統）
- ResearchHarness 輕量級評估（17 個原生 LLM）

### 實驗設計

- **自主 agent 結果**：
  - Claude Code：21.5（最強）
  - 其他 agent 在 10–20 之間
  - 即使取每個任務的最佳自主 agent 結果，frontier mean 只有 24.6
  
- **ResearchHarness LLM 結果**：
  - Claude-Opus-4.7：20.7（最強）
  - LLM frontier mean：26.5
  
- **錯誤分析**：三大失敗模式：
  1. Experimental protocol mismatch（實驗協議不匹配）
  2. Evidence mismatch（證據不匹配）
  3. Missing scientific core（缺失科學核心）

- **領域差異**：不同領域的難度差異顯著，某些領域（如 Information Science）相對表現較好，其他領域（如 Chemistry、Physics）表現較差。

- **已讀來源**：arXiv HTML 全文前半（Introduction、Related Work、Method 前段、部分任務細節和 rubric 範例），完整實驗結果表格和錯誤分析的細節需要看後半部分。

### かに讀後判斷

ResearchClawBench 是 harness engineering 領域的重要里程碑，和昨天看的 RAH（2606.13643）形成互補：RAH 問的是「harness 遞迴能提升多少效能」，RCBench 問的是「自主研究 agent 到底能不能做研究」——答案是「目前還差很遠」。最強的 Claude Code 只有 21.5/50，離目標論文水平還有一倍多距離。

RCBench 的 rubric 設計值得深讀：把目標論文分解為加權子標準，既評估重新發現又留出新發現空間，這比 PaperBench 的層級 rubric 更精細（PaperBench 只評估重現，不評估新發現）。

和之前 Harness-Bench（2605.27922）的對比：Harness-Bench 診斷 harness 配置對 agent 效能的影響（106 sandboxed tasks），RCBench 評估 agent 的端到端研究能力（40 real scientific tasks）。兩者面向不同問題但同樣重要。

深讀優先看：Section 3.4（Evaluation Metric 的完整定義）、Table 5–7（各領域的詳細結果）、Section 5（Error Analysis 的完整分類）、Appendix 中的任務描述和 rubric 範例（特別是天文學和物理學任務，因為它們的 rubric 結構最清楚展示了加權子標準的設計邏輯）。
