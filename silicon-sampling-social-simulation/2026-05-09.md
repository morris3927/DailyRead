# Silicon Sampling / Social Simulation — 2026-05-09

## 今日篩選判斷

今天這個 domain 有兩篇值得放進 DailyRead。一篇是很新的 design-space paper，直接把「LLM social simulation 到底哪些設計選項會改變結果」拿出來做系統性 sweep；另一篇是 AgentSociety 的大規模社會模擬框架，雖然 v1 是 2025，但 2026-04 更新版剛好補上大系統方向。共同訊號很清楚：silicon society 不再只是在問「agent 像不像人」，而是在問 simulator 的設計決策、scale、environment、validation proxy 會怎麼改變最後的社會動態。

## 1. The *Silicon Society* Cookbook: Design Space of LLM-based Social Simulations

- URL: https://arxiv.org/abs/2605.00197
- HTML: https://arxiv.org/html/2605.00197v1
- Authors: Aurélien Bück-Kaeffer, Sneheel Sarangi, Maximilian Puelma Touzel, Reihaneh Rabbany, Zachary Yang, Jean-François Godbout
- Date: 2026-04-30
- Status: arXiv, under review at COLM 2026

### 這篇在說什麼

這篇很像是 silicon society 的「配方參數表」。作者不是再做一個新的社會模擬 demo，而是問：當我們用 LLM 建一個人造社會時，哪些設計選項真的會改變模擬結果？例如 base model、agent 數量、社交網路拓樸、有沒有 homophily、agent 是否知道自己的 survey answer、有沒有 biased news agent、以及 population 裡不同 LoRA persona 的比例。

他們的核心提醒是：LLM social simulation 現在發展很快，但 validation standard 還沒跟上。如果每篇都只說自己的 agent 很 believable，很難累積成科學。這篇改採比較務實的路線：不宣稱哪個 simulator 最真，而是先量測設計空間的幾何形狀，看哪些參數有主效應、哪些參數會交互作用。

### 主要貢獻

最有用的貢獻是把 design choice 從「工程直覺」變成「可量測變因」。作者做了 595 次 simulation roll-out，跨七組參數，並用 survey opinions 當作 agent belief / opinion dynamics 的 proxy。結果顯示 design space 不是單純 additive：有些參數可以看主效應，有些參數會和 model、scale 互相牽動。

最醒目的結果是 base LLM 是最大變因。論文摘要與正文都指出，base model 對 AI-detectability / style realism 和 opinion dynamics 都有最強影響；fine-tuning social media data 會讓文字風格更接近人類社群媒體，也會強化社會動態；但 biased news agent 在他們目前設定下沒有可測得效果。這很值得注意，因為很多人直覺會以為「塞一個 biased news node」會強力左右社會，結果在這個 simulator 裡不是這樣。

### 方法 / pipeline

作者自己建了一個 social network simulator，避免被既有 simulator 的假設綁住。每個 simulation 裡有一組 agents 與 followership network。每一步選 10 個 agents：前 9 個觀察他們 follow 的近期 thread，最後 1 個有機率開新 thread 或回覆既有 thread。simulation 總共跑 2500 steps，每 250 steps 對 agents 做一次 survey。

七個變因包括：agent 數量 64 / 256 / 1024 / 4096；base model，包括 Llama-3.1-Minitaur-8B、Llama-3.1-8B、Qwen2.5-7B-Instruct、gemma-3-4b-pt；network topology，包括 Erdős–Rényi 與 directed scale-free；是否用 homophily 初始化；agent 是否知道自己的 survey answers；是否加入 biased news agent；以及 population proportion 的設定方式。

persona / population 這段尤其有意思：他們用 BluePrint social media data 分出 25 個 persona clusters，對每個 cluster 訓練 LoRA。人口比例不只是 uniform，也測了用 BluePrint 原始比例、用多個 models 加權去 match human opinion distribution、以及只 match average / majority answer 的版本。也就是說，他們直接把「模擬一群人」拆成 distribution matching 問題。

### 實驗設計

實驗是 595 個 randomized parameter roll-outs。simulation 使用 survey questions 追蹤 opinion dynamics，也訓練一個 BERT classifier 來分辨人類社群 thread 與 LLM 產生 thread；若 classifier 較難分辨，作者把它當成風格上較接近人類的 proxy。作者自己也很小心地說，除 AI-detectability 之外，其他 survey metrics 沒有人類 baseline，所以不應直接拿來宣稱某設定「更真實」，只能說它改變了 opinion dynamics。

正文提到每個 simulation 在 A100 GPU 上約需 2 到 11 小時，視參數而定。這也提醒我們：這種 design-space validation 很貴，未來如果要做 silicon sampling 研究，不能只問 prompt 怎麼寫，也要問 simulator budget 能不能支撐足夠的 ablation。

### 小龍蝦讀後判斷

這篇今天最值得點開。它的價值不是又多一個 simulator，而是把 silicon society 的 validation 問題往前推了一步：從「我的 agent 很像人」改成「哪些設計決策會改變 aggregate outcome」。如果 Morris 對 silicon sampling 的可靠性、bias、population distribution 有興趣，這篇比一般 demo paper 更值得讀。

## 2. AgentSociety: Large-Scale Simulation of LLM-Driven Generative Agents Advances Understanding of Human Behaviors and Society

- URL: https://arxiv.org/abs/2502.08691
- HTML: https://arxiv.org/html/2502.08691v2
- Authors: Jinghua Piao et al.
- First version: 2025-02-12; v2: 2026-04-10

### 這篇在說什麼

AgentSociety 是另一條路線：不是只把 LLM agents 放在簡化的聊天網路，而是想做一個「大型、具備城市 / 社會 / 經濟環境」的社會模擬平台。作者的主張是，如果要研究人類行為與社會，單靠 survey response 或 isolated role-play 不夠；社會性來自 agent 之間、agent 與環境之間的長期互動。

這篇把 generative social science 的野心講得很大：用 bottom-up simulation 取代部分昂貴、困難、甚至不容易做的真實社會實驗，讓社會科學家可以用可重複的 computational testbed 探索 polarization、政策介入、災害衝擊、城市永續這類問題。

### 主要貢獻

主要貢獻是 AgentSociety 這個 simulator：它整合 LLM-driven agents、realistic societal environment、以及 large-scale simulation engine。摘要中說他們生成了超過 10k agents 的 social lives，模擬 500 萬次 agent-agent 與 agent-environment interactions。

它和比較小型的 generative agents 差異在於環境與 scale。作者把 agent 設計成有 emotion、needs、motivation、cognition 等 internal states，並讓 mobility、employment、consumption、social interaction 等行為由這些狀態動態驅動。環境則試圖整合 urban、social、economic spaces，而不是只給一個文字場景。

### 方法 / pipeline

pipeline 大致分三層：第一層是 LLM-driven social generative agents，包含 mind、social behaviors、mind-behavior coupling；第二層是 realistic societal environment，讓 agents 可以和城市、社會、經濟空間互動；第三層是 large-scale simulation engine，透過 distributed computing 與 MQTT-powered messaging 支援大量 agents 的互動。

作者也建立了一套 evaluation framing 來比較 social simulators，關注 agent mind / behavior、environment realism、simulation scale、以及是否能支援 social science research methods。這部分很適合拿來當未來讀 social simulation paper 的 checklist。

### 實驗設計

摘要與正文開頭提到五個 social issues 作為案例：polarization、inflammatory messages spread、universal basic income policy、hurricane external shock、urban sustainability。作者說這些 case 涵蓋 surveys、interviews、interventions 等 social research methods，並宣稱 outcomes 與 real-world experimental results 有 alignment。

目前我這次只讀到 abstract、introduction 與 design overview，還沒完整核對每個 case 的 dataset、baseline、metric 與效果量，所以這裡不替它背書到「已嚴格驗證」。比較保守的讀法是：AgentSociety 很適合作為 large-scale simulator / platform paper 來看，但如果 Morris 要引用它的 empirical claim，最好再深讀五個 case 的實驗細節。

### 小龍蝦讀後判斷

值得收藏，但今日推薦順位在 Cookbook 之後。AgentSociety 代表的是 scale + environment 的方向，能看到 social simulation 從「一群聊天 agents」走向「有城市、經濟、政策介入的人工社會」。不過它的 claim 很大，閱讀時要特別盯 validation：哪些結果是真的對齊 real world，哪些只是 simulator 內部看起來合理。
