# Silicon Sampling / Social Simulation — 2026-05-21

## 1. Distorted Perspectives of LLM-Simulated Preferences: Can AI Mislead Design?

- **arXiv / Venue / 類型**: arXiv:2605.18311 / Human-Computer Interaction (cs.HC)
- **Link**: https://arxiv.org/abs/2605.18311

### 這篇在說什麼

這篇直接挑戰 silicon sampling 在 UX 設計偏好模擬上的可靠性。越來越多設計師用 LLM 來模擬使用者偏好、產生設計建議，但目前沒有系統性研究檢驗 LLM 模擬出的設計偏好和真人到底差多少。Kuric 等人收集了 UXtweak 平台上 29 個真實偏好測試研究（共 2073 位真人受試者），把同樣的視覺設計刺激餵給 LLM 做多模態模擬，然後比較兩邊的選擇與理由。結果很嚴重：LLM 的偏好模擬和真人之間有系統性且一致的偏離，而且不管你怎麼調模型推理、取樣、persona 類型或細緻度，偏離的模式都不會消失。

這個問題對 silicon sampling 很重要，因為如果連「給同樣的視覺刺激、同樣的人口統計描述」都無法讓 LLM 模擬出接近真人的偏好分佈，那用 LLM 替代使用者測試的整個前提就站不住腳。更糟糕的是，設計師如果信任 LLM 的建議，可能會做出跟真實使用者需求方向相反的產品。

### 主要貢獻

1. **首次系統性多研究比較**：不是單一實驗，而是 29 個真實偏好測試的聚合比較，外部效度非常高。過去的 LLM 偏好模擬研究多半只看文本型態的偏好（如政治意見、消費意願），這篇是第一個大規模檢驗視覺設計偏好模擬的研究。

2. **六種 LLM 變數操控的全面實驗**：同時操控 chain-of-thought reasoning、temperature/nucleus sampling、persona type（generic vs. specific）、persona specificity，看哪些方法能改善模擬準確度。答案是：幾乎都不能。

3. **合成理由的偏差模式分析**：不只看投票結果的偏離，還分析 LLM 產生的偏好理由和真人的差異。LLM 的理由缺乏真正的深度和細膩度，改用泛化屬性描述、聚焦特定元素、過度讚美和過度闡述來替代。這個分析揭示了 LLM 模擬偏好在認知層面和經驗層面的根本缺陷。

4. **視覺偏好領域的獨特洞察**：過去 silicon sampling 文獻主要看文本態度調查，這篇把焦點轉向視覺設計偏好——一個 LLM 必須同時理解圖像內容和形成審美判斷的場景，而結果顯示 LLM 在感知和意義的再現上系統性地失敗。

### 方法 / pipeline

研究用了 UXtweak 線上研究平台的 29 個真實偏好測試作為 ground truth。每個測試都包含兩個或多個視覺設計選項（如網頁佈局、UI mockup），真人受試者選擇偏好並說明理由。研究者將同樣的視覺刺激（截圖）餵給 LLM，用六種變數組合模擬：模型推理能力（有/無 CoT）、取樣策略（temperature / top-p 調整）、persona 類型（generic user vs. specific persona with demographics）、persona 細緻度（粗略 vs. 詳細描述）。

評估方法分兩層：量化層看投票分佈的一致性（algorithmic fidelity），質化層用主題分析比較 LLM 和真人給出的偏好理由。質化分析特別關注 LLM 理由中的「替代模式」——也就是 LLM 用什麼修辭策略來掩蓋它其實沒有真正理解或體驗的事實。

### 實驗設計

- **Dataset**: 29 個真實偏好測試，來自 UXtweak 平台的不同組織客戶，共 2073 位真人受試者。這不是實驗室合成數據，而是生態效度極高的真實研究數據。
- **Model**: 已讀全文確認使用了多種 LLM 變數組合，但具體模型名稱需看全文 Table 確認（目前從 HTML 前段確認作者操控了 reasoning、sampling、persona 等變數）。
- **Metric**: Algorithmic fidelity（偏好分佈的一致性）、質化主題分析（reasoning pattern comparison）。
- **Main result**: 跨 29 個研究，LLM 模擬的偏好和真人有系統性且一致的偏離。CoT reasoning、persona 設定、取樣參數等常見改善方法對根本問題影響極小。LLM 的偏好理由缺乏深度，以泛化描述、過度讚美、聚焦特定元素等模式替代真正的體驗性敘述。
- **Ablation**: 六種 LLM 變數操控的系統比較，但結果顯示這些操控沒有顯著改善 algorithmic fidelity。

### かに讀後判斷

這篇是近期 silicon sampling 領域對 LLM 模擬可靠性最嚴厲的實證挑戰之一。和之前 2604.19787（LLM agent 不如文本分類器預測社群媒體反應）以及 2506.19806（boundary-aware approach）形成互補——前兩篇從調查/社群預測角度指出限制，這篇從視覺設計偏好角度給了更直接的打擊：LLM 連「看到同一張圖，像人一樣選出偏好」都做不到。

值得 Morris 點開，深讀時優先看：(1) Figure 1 的 research model，了解假說結構；(2) 質化分析那段，看 LLM 理由的替代模式分類，這對理解 silicon sampling 的根本限制比量化偏離更有洞察；(3) 29 個研究的跨研究一致性分析，確認偏離是否真的是系統性的。如果你在做 silicon sampling 相關研究，這篇的結論會直接影響你怎麼定位 LLM 模擬的邊界。

## 2. AI-Generated Social Simulations for Startup Validation Research in Computational Social Science

- **arXiv / Venue / 類型**: arXiv:2509.02605 / Multiagent Systems (cs.MA) / 已投 JASSS
- **Link**: https://arxiv.org/abs/2509.02605

### 這篇在說什麼

這篇做了一個「對接實驗」（docking experiment）：用 LLM 生成創業者和投資人 persona，和 15 位真實早期創業者的訪談數據做主題比較，看 AI 模擬到底對齊了什麼、漏了什麼、多出了什麼。研究動機是：AI 驅動的創業驗證工具越來越多，但我們不知道 LLM 模擬出來的「創業者/投資人」和真實創業者的認知結構差在哪裡。

這個問題在 silicon sampling 的應用端很重要——如果你用 LLM 來做 startup validation，LLM 模擬的「用戶」會不會系統性地忽略某些真實創業者才有的認知？又會不會產生真人不會有的幻覺？

### 主要貢獻

1. **四分類對接框架**：提出 Convergent / Partial Overlap / Human-Only / Synthetic-Only 四類主題分類法，清楚標示哪些主題 AI 和人對齊、哪些 AI 漏掉、哪些 AI 多出。這個分類法對後續 silicon docking 研究有方法論價值。

2. **發現 AI 模擬的特有盲區**：AI 模擬會放大 false positive（高估採納潛力）、缺少「創傷性經驗」（trauma blind spots），以及把 AI 描述為心理緩衝——這些都是真人數據中不出現但 AI 會系統性生成的模式。

3. **Hybrid social simulation 定位**：明確主張 LLM-driven persona 不是傳統 rule-based agent 的升級版，也不等於真人，而是一種「混合社會模擬」——語言表達力更強、適應性更高，但受制於缺乏生活經歷和關係後果。

### 方法 / pipeline

研究設計是標準的 docking experiment：先用半結構化訪談收集 15 位早期創業者對 AI 驅動驗證的看法，然後用相同訪談協議讓 LLM 生成的創業者和投資人 persona 回答。兩組數據做結構化主題合成，產出四類對接結果。

LLM persona 的構建方式需看全文確認（目前從 abstract 能確認使用了 founder 和 investor 兩類 persona，但具體 prompt 策略不清楚）。

### 實驗設計

- **Dataset**: 15 位真實早期創業者的半結構化訪談 + LLM 生成的對應 persona 回覆。
- **Baseline**: 人類數據為 ground truth，AI 數據為模擬。
- **Metric**: 主題合成的一致性/分歧分類（質化分析，非量化 metric）。
- **Main result**: 四類主題中，AI 在 convergent 類表現良好（commitment-based demand signals、black-box trust barriers），但在 human-only 類（關係價值、對 moonshot 市場的懷疑）和 synthetic-only 類（false positive 放大、trauma blind spots）暴露了系統性差異。
- **目前僅 abstract 層級快速掃描**：無法確認具體 LLM 模型、prompt 設計、評估者間信度等細節。

### かに讀後判斷

這篇的四分類對接框架對 silicon sampling 方法論有參考價值，特別是「AI 系統性多出什麼」這個維度——大多數研究只看 AI 漏了什麼，很少分析 AI 無中生有的主題。不過這篇樣本量小（15 人）、是質化研究，和 2605.18311 那種 29 研究 2073 人的量化規模完全不同。兩篇一起看，恰好構成「大規模量化偏離」和「小規模質化差異」的互補視角。不列為今日推薦，但值得注意其方法論貢獻。
