# Silicon Sampling / Social Simulation — 2026-05-26

## 1. Can Large Language Models Revolutionize Survey Research? Experiments with Disaster Preparedness Responses

- **arXiv**: 2605.19229
- **Link**: https://arxiv.org/abs/2605.19229
- **Authors**: Yan Wang, Ziyi Guo, Christopher McCarty (University of Florida)
- **Submitted**: 2026-05-19

### 這篇在說什麼

調查研究正面臨結構性危機：回覆率持續下滑、樣本偏差、高危受訪者區塊缺失，以及線上問卷中 AI 生成造假回答的氾濫。LLM 被提議作為補救方案，但跨整個調查工作流的嚴謹評估仍然稀少——尤其在災害情境下，資料品質與人口覆蓋最關鍵。本文以 2024 年佛州颶風 Milton 防災調查（n=946）為共享實證基準，提出並評估一個五階段 LLM 整合框架（問卷設計→樣本選擇→預試→缺失資料插補→後續分析），系統性地檢視 LLM 在每個調查環節的能力邊界。

這篇的位置很清楚：它不是只做 silicon sampling（用 LLM 模擬人類回應），而是把 silicon sampling 放進更完整的調查方法學框架裡，從設計到分析全流程檢驗，特別是在災害這類高風險情境。這對 DailyRead 追蹤的 silicon sampling 議題是一個重要的方法學深化——之前的 TRAILS 在說「你的模擬可能不穩健」，這篇在說「即使不穩健，這裡有五種使用方式，每種有不同風險和回報」。

### 主要貢獻

1. **五階段調查工作流框架**：問卷設計、樣本選擇、預試、缺失資料插補、後續分析——每個階段獨立評估 LLM 的能力邊界，而不是只看 silicon sampling 的準確度。
2. **PMT-constrained co-occurrence knowledge graph + A-TLM**：引入保護動機理論（PMT）的因果結構來組織知識圖譜檢索，提出 Anchored Marginal Theory-Informed LLM（A-TLM），在 block-wise MNAR 缺失插補上超越三種傳統基線（IPW/MI、MICE+PMM、missForest），RMSE 1.439 vs. 1.496。
3. **子群偏差審計**：揭露 aggregate 層級 near-zero bias 可以掩蓋相反方向的子群偏差——複合弱勢受訪者系統性地被所有 LLM 配置低估。提出 subgroup-stratified bias auditing 作為政策相關 LLM 工作流的必要報告標準。
4. **知識圖譜聊天機器人的幻覺管理**：透過 grounded refusal（檢索約束 + 結構化拒答），展示幻覺風險可以透過架構設計管理，而非依賴模型自律。

### 方法 / pipeline

研究設計是一個五階段框架，以 2024 颶風 Milton 防災調查貫穿：

1. **問卷設計**：用 LLM 生成/改善調查問題，但此階段主要是展示 LLM 能力，非本文核心。
2. **樣本選擇**：以人口統計條件生成 silicon samples，比較與真實樣本的分佈差異。
3. **預試**：用 LLM 模擬預試受訪者，評估問卷理解度與回應模式。
4. **缺失資料插補**（核心貢獻）：七種 LLM 配置——zero-shot inference、RAG baseline、理論驅動變體（含 A-TLM）——對抗三種傳統插補方法。A-TLM 的關鍵設計是將 PMT 因果結構（威脅認知→適應認知→適應行為）用來約束知識圖譜的檢索路徑，而非讓 embedding similarity 自由檢索。
5. **後續分析**：知識圖譜聊天機器人展示 grounded refusal 如何控制幻覺。

知識圖譜建構方式：從調查資料提取 PMT 因果結構下的 co-occurrence 關係，形成有向圖；檢索時沿 PMT 因果鏈走，而非只看 embedding 距離。

### 實驗設計

- **資料集**：2024 Hurricane Milton 防災調查，n=946 佛州居民。四種缺失情境（S1-S4），從完全隨機到區塊式 MNAR。
- **基線**：IPW/MI、MICE+PMM、missForest 三種傳統插補方法；zero-shot、standard RAG、marginal TLM、anchored TLM 等七種 LLM 配置。
- **主要結果**：A-TLM 在最難的 S4（block-wise MNAR）情境 RMSE 1.439，優於 missForest 的 1.496；整體 signed bias -0.121（missForest -0.631）。但 A-TLM 的優勢集中在 aggregate 層級；子群分析顯示複合弱勢受訪者（低收入+少數族群+高風險區）在所有 LLM 配置中被系統性低估。
- **消融分析**：PMT-constrained retrieval 優於 unstructured RAG（MAE 0.993 vs. 1.097），single-call 整合優於 sequential staging。

目前從全文 HTML 可確認上述結果；補充材料中的詳細子群分析需見 PDF。

### かに讀後判斷

這篇對 silicon sampling 領域的貢獻是方法學上的：它不只問「LLM 能不能模擬人」，而是問「在調查研究的哪個環節、以什麼方式使用 LLM，風險和回報各是什麼」。五階段框架讓這個問題有了結構化的答案。PMT-constrained knowledge graph 是一個值得注意的設計——用領域理論的因果結構約束檢索，而非純 embedding similarity，這和 TRAILS 提出的「設計選擇影響結果」是同一個硬幣的另一面：不只是模擬結果對設計敏感，連插補用的檢索路徑也對理論假設敏感。

子群偏差審計的發現非常重要：aggregate near-zero bias 可以掩蓋系統性低估。這對 silicon sampling 的實務應用是個嚴肅警告——如果你只用 aggregate 指標，你可能以為模型表現很好，但對最需要被代表的人群反而最差。

值得深讀的部分：Section 4 的實驗結果（特別是 S4 MNAR 情境和子群分析）、Appendix 的 PMT 知識圖譜建構細節。和前幾天的 TRAILS（2605.18890）直接互補——TRAILS 說「你的模擬宣稱需要穩健性審計」，這篇提供了具體的審計方法（subgroup-stratified bias audit）。

## 2. Diagnosing Korean-Language LLM Political Bias via Census-Grounded Agent Simulation

- **arXiv**: 2605.18395
- **Link**: https://arxiv.org/abs/2605.18395
- **Authors**: Sungwoo Kang et al.
- **Submitted**: 2026-05-18

### 這篇在說什麼

LLM 在選民模擬中展現系統性政治偏見，但背後機制和跨語言泛化能力尚不清楚。本文引入 Dynamo-K，一個基於人口普查的模擬框架，評估韓語 LLM 在六場韓國選舉（2017-2025）中的政治行為。這是 silicon sampling 在非西方、非英語情境下的一次系統性診斷——之前 DailyRead 追蹤的 2605.16193（Cross-Cultural Survey Simulation with Calibrated Value Personas）也是類似方向，但 Dynamo-K 更聚焦在政治偏見的三種具體失敗模式。

### 主要貢獻

1. **Dynamo-K 框架**：census-grounded simulation，以韓國人口普查資料為基礎生成模擬選民，評估四個 LLM 在六場選舉的模擬表現。
2. **三種系統性偏見模式**：進步派偏見（progressive bias）使溫和派代理人也偏左、第三黨顯著性崩塌（模型無法正確表現小黨得票）、區域極化崩塌（模型雙向低估政黨根據地得票率）。
3. **場景重構（scenario reframing）**：恢復 62% 的 2017 年 MAE，透過恢復第三黨可見性。
4. **學習式重新加權適配器**：成功校準對立偏見的模型，且不需在訓練或測試時使用候選人名稱。

### 方法 / pipeline

Dynamo-K 的流程：
1. 從韓國人口普查提取人口統計特徵分佈。
2. 將這些特徵作為 persona 條件輸入 LLM，生成模擬選民行為。
3. 比較模擬結果與六場實際選舉結果（2017 總統大選到 2025 大選）。
4. 診斷三種偏見模式，並測試場景重構和適配器校準兩種干預。

偏見診斷是核心創新：不只看 aggregate MAE，而是拆解成三種結構性失敗——progressive bias 讓溫和代理人偏離中立、third-party salience collapse 讓小黨被吞噬、regional polarization collapse 讓根據地效應消失。

### 實驗設計

- **模型**：四個 LLM（具體型號需見 PDF）。
- **選舉**：六場韓國選舉 2017-2025。
- **主要結果**：Dynamo-K 正確預測 3/3 總統選舉勝者，包括 2022 年極膠著選舉（0.73% 領先幅度，MAE 2.1pp）。顯式偏見緩解可將 MAE 減少 5.2 倍。場景重構恢復 62% 的 2017 MAE。
- **消融**：不同模型展現不同偏見模式——第三黨崩塌有的是顯著性問題，有的是決策偏差。

目前僅從 abstract 和搜尋結果確認，還未見完整 PDF。

### かに讀後判斷

這篇的價值在於：它是 silicon sampling 在非西方情境下的系統性偏見診斷，而且提出了三種可操作的失敗模式分類（progressive bias、third-party collapse、regional collapse），不只是「模型偏左」這種粗略描述。場景重構和學習式適配器兩種干預方式也值得注意——特別是適配器不需要候選人名稱，意味著它可能有跨選舉泛化能力。

和 2605.16193（Cross-Cultural Survey Simulation with Calibrated Value Personas）相比，Dynamo-K 更聚焦於政治偏見的機制拆解，而非一般性的跨文化校準。和 2605.18890（TRAILS）互補：TRAILS 說要審計穩健性，Dynamo-K 提供了具體的偏見模式分類。

值得深讀的部分：三種偏見模式的定量分析、場景重構的具體 prompt 設計、適配器的訓練細節。不過目前只有 abstract 層級的資訊，建議列為候補而非今日推薦。
