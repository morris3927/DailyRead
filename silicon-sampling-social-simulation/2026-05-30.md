# Silicon Sampling / Social Simulation — 2026-05-30

## 1. ALSO: Adversarial Online Strategy Optimization for Social Agents

- **arXiv**: 2605.15768
- **Venue**: ICML 2026 (accepted)
- **Link**: https://arxiv.org/abs/2605.15768

### 這篇在說什麼

現有 LLM 社交模擬裡的 agent 大多使用靜態 persona（角色設定），導致行為同質化、缺乏適應性。ALSO 提出：在社交互動這種本質上 non-stationary 的環境裡，策略應該要能在線上動態調整，而不是離線訓練完就固定。作者把多回合社交互動中的策略選擇建模成一個 adversarial multi-armed bandit 問題——每個 arm 是一組「靜態 persona + 動態策略指令」的組合，因為對手也在適應你，所以 reward 分配不是 stationary 的，這讓標準的 stochastic bandit 方法失效。

這篇補的洞很明確：之前的社交 agent 強化學習方法（如 Sotopia-RL、SDPO）假設 stationarity；external planner 類方法（Sotopia-Ω、EPO）需要離線訓練、不能線上適應；prompt optimization 方法（OPRO、EvoPrompt）用固定 validation set 評估，也假設 reward 是 stationary 的。ALSO 是第一個針對這個 non-stationarity 問題提出 principled 解法的框架。

### 主要貢獻

1. **Adversarial bandit formulation**：把多回合社交互動的策略選擇建模成 adversarial bandit，每個 arm 對應一個 strategy instruction（如 cooperation、competition、deception、rational bargaining），結合 persona 一起形成最終 prompt context。用 EXP3-inspired 演算法做 robust 線上優化，不依賴 stationarity 假設。

2. **Neural surrogate reward model**：標準 bandit 把每個 arm 當獨立的，無法利用語意相關性。ALSO 引入輕量級神經網路 surrogate，從互動歷史預測 reward，讓語意相近的策略可以互相推廣，大幅提升 sample efficiency。這讓 sparse multi-turn feedback 的問題得到緩解。

3. **Closed-loop online system**：策略選擇 → persona-conditioned 互動 → reward 收集 → bandit policy 和 surrogate 更新，形成完整閉環。不需要離線 retraining。

### 方法 / pipeline

整個 ALSO pipeline 可以拆成幾個步驟：

1. **Persona + Strategy 拼接**：Agent 的基礎 persona $b_i^0$（人口統計、性格、背景故事）和選中的策略指令 $\sigma_{k_t}$ 透過 textual concatenation 組合成增強 persona $b_i^{(t)} = b_i^0 \oplus \sigma_{k_t}$。策略指令不改 model weights，只改 prompt context。

2. **Adversarial bandit 選擇**：在每個 episode 開始前，agent 從 K 個 strategy arms 中選一個。使用 smoothing 的 EXP3 演算法，因為 reward 分佈是 adversarial 的（對手也在適應）。每個 arm 的 sampling probability 透過 exponential weight update 計算。

3. **互動與 reward**：兩個 agent 進行 L-turn 多回合對話。結束後用 LLM evaluator 沿 M 個社交維度評分（如 believability、relationship、knowledge、secret、social rules、financial、coordination），然後聚合為 scalar reward。

4. **Neural surrogate 更新**：用互動歷史的 embedding 預測 reward，讓語意相近的策略可以分享觀測。Surrogate model 是輕量級的 MLP。

5. **Bandit policy 更新**：用 observed reward 和 surrogate prediction 更新 arm weights。

整個系統在 Sotopia benchmark 上評估，Sotopia 有七個社交維度的評分和 40 個場景。

### 實驗設計

- **Benchmark**: Sotopia，40 個社交場景，覆蓋 cooperation、competition、deception 等多種社交情境。七個維度的 LLM evaluator 評分。
- **Baselines**: Static persona agents、Sotopia-π（data-centric）、Sotopia-RL（offline RL）、SDPO（preference optimization）、Sotopia-Ω（external planner）、AML（adaptive mode learning）、OPRO / EvoPrompt 等 prompt optimization 方法。
- **Main results**: ALSO 在整體評分上 +16.60%，relationship outcome 上 +83.79%（相對提升），在各個社交維度上都有穩定提升。
- **Ablation**: 作者做了 surrogate model 的消融實驗，證明語意推廣帶來的 sample efficiency 提升是關鍵的。也做了不同 strategy set 大小的實驗。
- **已讀來源**: arXiv HTML 全文已讀。實驗細節和附錄部分從 HTML 前段確認到主要結果表和消融實驗，附錄的完整超參數表和額外 baselines 沒有逐一確認。

### かに讀後判斷

ALSO 是 silicon sampling / social simulation 領域近期很重要的方法論進展。之前的工作要嘛用固定 persona、要嘛用離線 RL/DPO，都沒有處理社交互動中對手也在適應的 non-stationarity 問題。ALSO 用 adversarial bandit 的框架把這個問題形式化，然後用 neural surrogate 來做 sample-efficient 的 reward 推廣，這兩步都是有道理的設計。

和之前 DailyRead 收錄的 Silicon Society Cookbook（2605.00197）和 AI Agents Alone Are Not Sufficient（2603.00113）比起來，ALSO 直接回應了「LLM agent 行為同質化」這個被反覆提到的問題——不是用更好的 persona 描述來解決，而是用動態策略適應。和 Restoring Heterogeneity（2604.06663）的 audience segmentation 方向不同，ALSO 的 heterogeneity 來自策略層面而非 persona 層面。

值得深讀的重點：ICML 2026 的 reviewer comments 和 rebuttal（如果有的話）、appendix 裡的策略集定義和 Sotopia 評估的具體 prompt template、surrogate model 的架構細節。對 Morris 來說，如果你關注「怎麼讓 silicon sampling 的 agent 有更多行為多樣性」，這篇提供了策略層面的新工具。

## 2. Beyond Inefficiency: Systemic Costs of Incivility in Multi-Agent Monte Carlo Simulations

- **arXiv**: 2605.11789
- **Link**: https://arxiv.org/abs/2605.11789

### 這篇在說什麼

這篇用 LLM multi-agent 系統做為 controlled sociological sandbox，系統性地操弄 toxic / uncivil communication，量化它對辯論效率的影響。研究動機是：不文明的溝通對生產力和凝聚力的傷害在社會科學裡已被記錄，但用人類受試者研究這個問題有倫理審查限制、可重複性差、自然場景不可控等困難。LLM multi-agent 系統提供了一個可控的替代方案。

### 主要貢獻

1. 複製了之前研究的 25% convergence latency 結果，並擴展到兩個不同參數量的 LLM，發現 latency 在較小模型上更顯著。
2. 發現 significant first-mover advantage：先發言的 agent 不管在什麼 toxicity 條件下都顯著地更容易贏得辯論。

### 方法 / pipeline

使用 Monte Carlo simulation framework，生成數千個 structured 1-on-1 adversarial debates，在不同 toxicity 條件下測量 convergence time（達成結論所需的回合數）作為 interactional efficiency 的代理指標。控制條件包括 toxicity level、模型大小、辯論主題等。

### 實驗設計

- 數千個 structured debates，不同 toxicity conditions
- 比較多個 LLM（不同參數量）
- 測量 convergence latency 和 first-mover advantage
- 已讀來源：abstract + HTML 前段。完整實驗細節和統計檢定方法還需要看全文。

### かに讀後判斷

這篇作為 silicon sampling 的方法論參考有價值——它展示了用 LLM agent 做 sociological 實驗的可能性，但也揭示了 first-mover advantage 這類模擬 artifact。對 Morris 來說，如果你關注 silicon sampling 的生態系和方法論，這篇值得知道存在，但深度閱讀的優先級低於 ALSO。實驗設計相對簡單，貢獻主要在「展示可以用 LLM agent 做社會科學實驗」而非方法論創新。
