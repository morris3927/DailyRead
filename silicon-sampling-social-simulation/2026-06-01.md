# Silicon Sampling / Social Simulation — 2026-06-01

## 1. APS: Bias-Controlled Adaptive Prototype Simulation for Population-Scale LLM Agents

- **arXiv / Venue / 類型**: arXiv 2605.27419 (cs.MA, cs.CY), 2026-05-19
- **Link**: https://arxiv.org/abs/2605.27419

### 這篇在說什麼

LLM-agent 社會模擬的核心瓶頸是計算成本：N 個 agent 跑 T 輪就需要 O(NT) 次 LLM 呼叫，做 10 萬人以上的模擬根本不現實。現有作法要嘛只跑幾十人的 micro-society（像 Generative Agents、CAMEL），要嘛用學習過的 proxy model 取代 LLM（但這等於換掉了 transition model 本身）。

APS 要解的問題是：能不能在保留指定 LLM 作為 transition oracle（不替換模型本身）的前提下，大幅降低 online LLM 呼叫次數，同時控制近似誤差？

這篇在領域脈絡中的位置很清楚：它是 silicon sampling / LLM 社會模擬從「小規模實驗」走向「千萬級人口模擬」的工程與理論橋樑。和之前我們追蹤的 Silicon Society Cookbook（2605.00197）討論設計空間不同，APS 直接提供一個可跑、可分析誤差的框架。和 OASIS、AgentSociety 等大規模模擬平台相比，APS 不只是 scale up，而是把 scaling 重構成一個 oracle-allocation 問題。

### 主要貢獻

1. **把 population-scale LLM 模擬重構為 recurrent oracle-allocation 問題**：不是隨機採樣、不是學 proxy，而是每輪自適應地分配 LLM 查詢預算給 core prototypes、singleton-tail agents、和 shadow-audit agents，然後把 prototype 回應傳播給鄰近 agent。

2. **Shadow-audit residual correction**：在 prototype propagation 完成後，額外抽查一部分非 prototype agent，用它們的 LLM 回應與 local response surface 預測之間的差異（residual）來校正整體分布估計，同時把 residual risk 分數回饋到下一輪的預算分配——高誤差、高曲率的區域會獲得更多查詢。

3. **Tail-protected singleton routing**：用 feature-space 距離中位數的 robust standardized score 找出異質性高、容易被 smoothing 抹平的 agent，直接查詢它們而不讓它們被 prototype 內插覆蓋。

4. **理論誤差分解與大規模實驗驗證**：把 APS 的誤差分解為 prototype-coverage error、shadow-audit residual-correction error、local-propagation bias、temporal context mismatch 四項。在 10M-agent、8-round 公共輿論模擬中，APS 達到 381.1× 呼叫減少，最終輪次 JSD 0.094（相對於 full-LLM reference）。

### 方法 / pipeline

APS 的每輪（round t）流程如下：

1. **特徵分層（Stratification）**：根據 agent 的靜態 profile features（年齡、性別、教育等）加社交網路位置，將所有 agent 分成 core strata 和一個 singleton-tail 集合 O_N。Core strata 的分法是 K-means 或其他分群演算法；singleton-tail 是 feature-space 中離群或高曲率的 agent。

2. **預算分配（Budget Allocation）**：每輪的 core prototype 預算 B_t^core 按照每個 stratum 的大小和上一輪的 residual risk score R_m,t-1 來分配——高風險的 stratum 獲得更多 prototype 查詢。預算隨 N 增長是次線性的（O(N^η), η<1），所以絕對數量成長但比例遞減。

3. **查詢與傳播（Query & Propagate）**：對每個 stratum 的 core prototypes 和所有 singleton-tail agents 查詢 LLM。然後對非 prototype 的 core agents，用 local response surface（k-nearest prototypes 的加權內插）估計它們的回應分布。

4. **Shadow-audit（Shadow Audit）**：再抽查一批非 prototype core agents（shadow-audit set），同樣用 LLM 查詢。比較 LLM 真實回應與 local response surface 預測的差異，得到 residual correction。這個 correction 同時用來（a）校正人口分布估計，（b）計算下一輪的 residual risk score。

5. **Hard recurrent state vs. Soft reporting ledger**：APS 區分兩種記錄——hard recurrent ledger（每個 agent 的 hard decision，用於下一輪 prompt 的 neighbor summary）和 soft reporting ledger（每個 agent 在每個選項上的概率向量，用於分布估計和 shadow-audit residual correction）。兩者分離讓 APS 可以在報告層面做 audit correction，同時讓 recurrence 的 hard state 保持穩定。

### 實驗設計

- **主實驗**：10M-agent, 8-round public opinion simulation（輿論演化），使用真實人口統計資料建構 agent profiles。Baseline 比較對象包括：full-LLM reference（所有 agent 每輪都查詢）、scale-oriented baselines（隨機採樣相同預算的 agent 直接查詢）、same-budget baselines。

- **指標**：Jensen-Shannon Divergence (JSD) between APS estimated distribution and full-LLM reference distribution，逐輪追蹤。

- **消融實驗（Ablations）**：移除 shadow-audit、移除 tail-protected singleton routing、固定預算分配（不用 residual risk feedback）等，確認各組件的貢獻。

- **穩健性檢查**：跨場景（不同議題）、跨 LLM backend、跨 stratification 方法。

- **主要結果**：APS 的 final-round JSD = 0.094（相較 full-LLM reference），比 same-budget random sampling baseline 低很多。呼叫量降低 381.1×。消融實驗確認 shadow-audit 和 singleton routing 都是必要的。

- **資訊不足的部分**：我已讀完整 HTML 前段與 abstract、method section 3 的詳細描述。實驗結果的具體數值和 ablation 表格在後半段（Appendix），目前從 HTML 前段能確認到的是框架設計、誤差分解公式、和主實驗設定。具體每個 ablation 的 JSD 數值和 robustness check 的完整表格需要看 Appendix。

### かに讀後判斷

這篇是近期 silicon sampling 領域最重要的方法論進展之一。它直接回應了「LLM 社會模擬無法 scale 到真實人口規模」這個根本限制，而且不是用 proxy model 偷換 transition function——這點非常關鍵，因為用 proxy model 替換 LLM 等於換了模擬的本體。

和之前追蹤的 SPINOS（programmable belief control）相比，APS 解決的是不同層面的問題：SPINOS 問的是「能不能用 AI agents 系統性操控集體信念」，APS 問的是「如果要跑千萬級人口的 LLM 模擬，怎麼在保留 LLM 本體的情況下控制成本和誤差」。兩者互補——APS 的框架可以讓 SPINOS 那類實驗 scale up。
