# Silicon Sampling / Social Simulation — 2026-06-02

## 1. Are LLM Agents Behaviorally Coherent? Latent Profiles for Social Simulation

- **arXiv**: 2509.03736
- **Authors**: James Mooney, Josef Woldense, Zheng Robert Jia, Shirley Anugrah Hayati, My Ha Nguyen, Vipul Raheja, Dongyeop Kang
- **Venue**: arXiv preprint (v2: May 2026)
- **Link**: https://arxiv.org/abs/2509.03736

### 這篇在說什麼

這篇論文問了一個比「LLM 能不能模仿人類回答」更根本的問題：LLM agent 在不同實驗情境中，行為是否與自身宣稱的內在特質（偏好、開放性）一致？過去的 silicon sampling 研究多聚焦在 LLM 產生的調查回答是否與人類樣本聚合分布對齊（例如 Bisbee et al. 2024、Wang et al. 2025a），但這些「表面測試」無法驗證 LLM agent 是否真正具備內在行為一致性——即所謂「替代人類受試者」的核心前提。

作者提出了一個 Latent Profile 框架：先讓 agent 回答一系列問題以揭露其 latent profile（偏好 P 和開放性 O），再讓 agent 進行多輪對話，檢驗對話行為是否與 latent profile 預測一致。如果 LLM agent 要替代人類受試者，那麼它的行為必須在跨情境中維持內在一致性，而不只是在單一問卷上「看起來像人」。

### 主要貢獻

1. **Latent Profile 框架**：設計了控制變量（demographics + bias）→ latent states（preference P + openness O）→ external interactions（多輪對話 + agreement 評分）的三層實驗管道。這讓研究者可以系統性地檢驗「agent 的內在特質是否預測其行為」。

2. **六個行為模型的系統性檢驗**：不只看聚合相關，還用六個來自社會科學的行為模型（preference gap → agreement、openness → agreement、bias modulation 等）做嚴格檢驗。從 surface-level 到 in-depth 層層遞進。

3. **核心發現：表面通過、深層失敗**。聚合層面偏好差距大的 agent 對確實達成較少共識、開放性高的 agent 對確實達成較多共識——但這些「表面」趨勢在更嚴格的檢驗下崩潰：偏好完全對立的 agent 不會持續反對、共享負面情緒的對齊弱於正面情緒、openness 在最關鍵情境下失去預測力。

### 方法 / pipeline

1. **Topic Selection**：9 個主題，3 個爭議度層級（C ∈ {1,2,3}），從可口可樂 vs 百事到稅收政策。
2. **Agent Generation**：系統性變異 demographics（5 年齡組 × 2 性別 × 4 地區 × 4 城市化程度 × 6 教育程度）+ bias（B ∈ {1,2,3}）。
3. **Latent State Elicitation**：向每個 agent 提問，獲得其偏好 P 和開放性 O（1–5 整數量尺）。
4. **Agent Pairing**：所有 (P, O, B) 組合的笛卡爾積，確保行為模型的高保真映射。
5. **Conversation Outcome**：多輪對話後用 LLM-as-judge（Qwen3-32B）評分 agreement（1–5）。
6. **Robustness**：跨 Gemma3（4B/12B/27B）、Llama3.x（8B/70B）、Qwen3（8B/32B）三個模型家族 × 不同規模。

### 實驗設計

- **模型**：Gemma-3-12b-it 做定性視覺化，三個家族多規模做 robustness。
- **Judge**：Qwen3-32B，5 個標注樣本校準。
- **Topics**：9 主題（高爭議如 Tax、中爭議如 Remote Work、低爭議如 Coke vs Pepsi）。
- **六個行為假設檢驗**：
  - H1: Preference gap → lower agreement（表面通過，深層失敗）
  - H2: High bias → greater disagreement when P-gap is large（方向正確但效應微弱）
  - H3: Shared positive sentiment → stronger alignment than shared negative（LLM 違反此預測）
  - H4: Openness predicts agreement（聚合通過，細粒度失敗）
  - H5: Biasing prompts restore principled disagreement（不完全有效）
  - H6: Behavioral consistency across model families and sizes（一致地不一致）

- **核心結果**：LLM agent 可以「看起來」像人類受試者（聚合分布匹配），但無法維持實證一致性（latent profile 無法預測對話行為）。模型越大、越「對齊」，一致性反而越差。

### かに讀後判斷

這篇對 silicon sampling 領域是重要的修正性貢獻。過去一年 silicon sampling 文獻大量聚焦在「聚合分布是否匹配人類」，但 Mooney et al. 指出更根本的問題：即使聚合層面看起來對齊，LLM agent 的行為也不具備人類那種內在一致性。這和 05-14 的 Mitigating SDB（2512.22725）互補——SDB 論文關注 social desirability bias 如何扭曲 silicon sample 的分布，而這篇關注的是分布匹配之外的行為一致性問題。也和 SocioVerse（今日另一篇）形成張力：SocioVerse 聲稱 10M user pool 可以做到 population-level alignment，但這篇的結果暗示即使個體層面特質對齊，行為一致性仍是開問題。

值得深讀的方向：Section 4 的六個行為假設檢驗是全文精華，尤其是 Finding #4（openness 在最關鍵情境下失去預測力）和 Finding #6（模型越大一致性越差）——這對「scaling up LLM 就能解決 silicon sampling 問題」的假設構成直接挑戰。Table 1-7 的跨模型結果也值得細看。

## 2. SocioVerse: A World Model for Social Simulation Powered by LLM Agents and A Pool of 10 Million Real-World Users

- **arXiv**: 2504.10157
- **Authors**: Xinnong Zhang, Jiayu Lin, Xinyi Mou, Shiyue Yang, Xiawei Liu, Libo Sun, Hanjia Lyu, Yihang Yang, Weihong Qi, Yue Chen, Guanying Li, Ling Yan, Yao Hu, Siming Chen, Yu Wang, Xuanjing Huang, Jiebo Luo, Shiping Tang, Libo Wu, Baohua Zhou, Zhongyu Wei
- **Venue**: arXiv preprint (v3: July 2025)
- **Link**: https://arxiv.org/abs/2504.10157

### 這篇在說什麼

SocioVerse 是一個 LLM-agent 驅動的社會模擬世界模型，核心賣點是四維對齊框架（environment / user / scenario / behavior）加上 10M 真實用戶池。過去的社會模擬工作在環境動態性、用戶組成、互動機制、行為模式四個面向都存在對齊缺口——SocioVerse 試圖用模組化引擎逐一解決。

### 主要貢獻

1. **四維對齊框架**：Social Environment（注入即時新聞和社會動態）、User Engine（10M 真實用戶池 + 15 維度人口統計標註）、Scenario Engine（問卷 / 訪談 / 行為實驗 / 社交媒體互動四種場景模板）、Behavior Engine（驅動 agent 產生行為）。

2. **10M 用戶池**：從 X（1M 用戶 / 30M 帖子）和小紅書（9.1M 用戶 / 41M 帖子）構建。15 個人口統計維度的分類器標註（age, gender, vocation, race, income, education, settlement type, region, employment, marital status, religious, party, ideology, BigFive personality, hobbies）。

3. **三個跨領域驗證**：總統大選預測、突發新聞回饋、國家經濟調查，證明框架可以跨場景運作。

### 方法 / pipeline

- Social Environment 分三層：社會結構資訊（人口分布、文化規範）、社會動態（即時新聞事件庫）、個人化上下文（推薦系統推送興趣相關內容）。
- User Engine：用戶池 + 人口統計標註系統（多 LLM 標註 → 人類驗證 → 訓練分類器 → 大規模標註）。
- Scenario Engine：四種場景模板（問卷 1:N、深度訪談 1:1、行為實驗 1:N 或 N:N、社交媒體 N:N）。
- Behavior Engine：根據情境、用戶畫像、社會資訊生成行為。

### 實驗設計

三個模擬實驗：
1. 總統大選預測（美國 2024）——問卷場景
2. 突發新聞回饋——社交媒體互動場景
3. 國家經濟調查——行為實驗場景

目前僅從 abstract 和 HTML 前段能確認框架設計和用戶池規模。具體的對齊效果數據、與 baseline 的比較、以及行為模式驗證的細節需要看全文才能確認。

### かに讀後判斷

SocioVerse 是繼 AgentSociety（2502.08691，已在 05-08 讀過）之後另一個大規模社會模擬框架，但方向不同：AgentSociety 聚焦在 10,000 agent 的社會互動模擬，SocioVerse 聚焦在「對齊」問題——環境、用戶、場景、行為四個面向的對齊。10M 用戶池是實質貢獻，但需要看全文確認人口統計分類器的準確度、以及三個實驗的量化結果是否真的優於不使用用戶池的 baseline。

值得注意的是，今天的行為一致性論文（2509.03736）對 SocioVerse 的用戶對齊假設構成了間接挑戰：即使用戶畫像再精確，LLM agent 是否能在行為層面維持一致性仍是開問題。

## 3. Computational Basis of LLM's Decision Making in Social Simulation

- **arXiv**: 2504.11671
- **Authors**: Ji Ma
- **Venue**: Sociological Methodology (forthcoming); arXiv preprint (v4: Dec 2025)
- **Link**: https://arxiv.org/abs/2504.11671

### 這篇在說什麼

這篇研究 LLM 在社會模擬中做決策時計算層面的表示如何影響行為。用 Dictator Game（獨裁者博弈，公平和利他行為的經典實驗）作為實驗場景，提取 LLM 內部表示中的「variable variation vectors」（例如「男性→女性」的向量），並在推理時操縱這些向量，觀察對決策的影響。

### 主要貢獻

1. **Variable variation vectors**：從 LLM 的隱層表示中提取社會變量的方向向量，可以在推理時直接干預 LLM 的社會行為。

2. **可操縱性驗證**：在 Dictator Game 中，操縱這些向量可以實質改變模型決策中變量與行為的關聯。

3. **應用前景**：為 alignment、debiasing 和社會模擬中的 AI agent 設計提供了計算層面的工具。

### 方法 / pipeline

從 LLM 內部表示提取「variable variation vectors」→ 在推理時注入/移除這些向量 → 在 Dictator Game 中測量行為變化。具體方法需要看全文。

### 實驗設計

目前僅從 abstract 能確認使用了 Dictator Game 和 variable variation vectors 的操縱實驗。具體的模型選擇、向量提取方法、效應量、消融實驗等需要看全文。已發表在 Sociological Methodology，品質應有一定保障。

### かに讀後判斷

這篇從計算機制層面研究 LLM 在社會模擬中的行為，和今天推薦的行為一致性論文（2509.03736）形成互補：後者關注行為一致性（輸出層面），這篇關注表示機制（隱層層面）。variable variation vectors 的概念和 activation engineering / representation engineering 有交集，但這篇聚焦在社會模擬場景下的應用。對 Morris 的 silicon sampling 研究有直接參考價值——如果我們能在計算層面干預 LLM 的社會行為變量，那 silicon sampling 的偏差修正就有了新工具。
