# Silicon Sampling / Social Simulation — 2026-06-07

## 1. Think-Before-Speak: From Internal Evaluation to Public Expression in Multi-Agent Social Simulation

- **arXiv**: 2606.03137
- **Link**: https://arxiv.org/abs/2606.03137
- **Authors**: Kaiqi Yang, Tai-Quan Peng, Sanguk Lee, Hui Liu (Michigan State University, Hankuk University of Foreign Studies)

### 這篇在說什麼

現有的多 agent 對話模擬框架主要把互動處理成「可見的輪次交換」或「聚合輸出」，沒有建模 agent 在沉默期間的內部評估歷程——例如對不同意見的感知、對意見氣候的判斷、孤立風險的估計、以及是否要發言的意向。TBS（Think-Before-Speak）補的就是這個洞：把 agent 的內部狀態更新跟公開發言行為解耦，讓所有 agent 在每個 interval 都持續推理，但只有符合條件的 agent 才會產出公開語句。

作者用小鎮市政廳討論氣候政策作為實驗場景，研究三個核心問題：（1）interval-level 的內部狀態更新能否改善模擬的效率、可解釋性與分析價值？（2）agent 能否從內部評估產生發言意願，而非僅僅反應外部輪次分配？（3）輪次分配規則、沉默約束和記憶機制如何影響溝通策略與意見動態？

### 主要貢獻

1. **離散時間模擬協議**：提出 interval-based 的互動協議，將連續時間推理與離散通訊銜接起來，同時處理衝突發言意圖的解決機制。
2. **結構化內部狀態**：agent 在每個 interval 維護一套結構化的內部狀態——包括失諧相關評估（dissonance-related appraisal）、感知意見氣候、感知孤立風險、回應策略、發言意願——讓推理和表達的路徑可以被追蹤與分析。
3. **統一協議**：整合平行推理與競爭式輪次分配，同時改善真實性和效率。
4. **機制敏感分析**：展示內部狀態追蹤如何讓研究者觀察到「失諧評估增加發言意願、沉默壓力降低發言意願、輪次分配規則主要影響公開表達」等機制層次的發現。

### 方法 / pipeline

TBS 的架構分為幾個核心元件：

1. **Interval-based 互動**：模擬被切分為多個 interval，每個 interval 內所有 agent 同時更新內部狀態。狀態包括：dissonance-related appraisal（感知到與自己意見不同的程度）、perceived opinion climate（對多數意見的估計）、perceived isolation risk（認為自己是少數的風險）、response strategy（如何回應）、willingness to speak（是否要發言）。

2. **發言意圖解決機制**：當多個 agent 同時想要發言時，系統根據 estimated response latency 選擇最快回應的 agent，只有一個語句被 commit 到公開對話中。這模擬了連續時間中「先搶到麥克風的人發言」的競爭邏輯。

3. **記憶機制**：agent 維護自己的記憶，包括群組對話的記憶、自己內部狀態的記憶、和發言行為的記憶。

4. **實驗條件**：作者操弄了三個因素——turn-allocation（willing vs. assigned）、silence condition（是否允許不發言）、memory condition（是否提供前幾輪的內部狀態記憶）——在氣候政策市政廳場景中進行 2×2×2 的實驗設計。

### 實驗設計

- **場景**：小鎮市政廳討論氣候政策，agent 被賦予不同初始立場。
- **條件**：2（turn allocation: willing vs. assigned）× 2（silence: allowed vs. required）× 2（memory: with vs. without internal-state memory）。
- **模型**：使用 LLM（從方法章節推斷為 GPT 系列，HTML 全文的中段被截斷，尚無法確認具體模型版本和規模）。
- **主要發現**：
  - Dissonance-related appraisal 增加發言意願。
  - Silence-pressure appraisal 降低發言意願。
  - Turn-allocation 規則一旦確定，主要影響的是公開表達內容而非意願本身。
- **限制**：從已讀到的部分看，論文似乎還是 pre-print/工作論文狀態（摘要中出現 "[PLACEHOLDER: empirical improvements...]"），部分實驗細節可能仍在完善中。目前能從 HTML 確認的是實驗框架和核心發現的定性結論，但定量的完整 ablation 和統計檢驗需要看完整全文。

### かに讀後判斷

TBS 是 silicon sampling 領域少見的、認真建模「沉默中的推理」的框架。大多數多 agent 對話模擬把沉默當作不作用，但這篇指出沉默其實是 active internal evaluation 的表徵。這個切入點跟 spiral of silence 理論、deliberative democracy 的實證研究有直接的對話空間。對 Morris 來說，值得深讀的部分是：

- interval-based 互動協議的設計細節（如何估計 response latency、如何處理衝突）。
- 內部狀態的 prompt 設計（如何讓 LLM 產出結構化的內部評估）。
- 實驗結果中關於 dissonance appraisal → willingness to speak 的因果鏈是否真的 robust。

這篇跟昨天（06-06）的 Synthetic Personalities（2606.04592）形成很好的互補：那篇用 SOEP 微資料建 silicon persona，這篇用結構化內部狀態建模發言意願。兩者結合可以構建更完整的 silicon sampling pipeline——前者決定「誰」，後者決定「誰何時說什麼」。建議深讀 Section 3（Notation and Preliminaries）和實驗條件設計的部分。

## 2. Political Persuasion and Endorsement in Large Language Models

- **arXiv**: 2606.05961
- **Link**: https://arxiv.org/abs/2606.05961
- **Authors**: Alessia Antelmi, Alessia Galdeman, Lucio La Cava, Arianna Pera, Giovanni Da San Martino（Università degli Studi di Torino, Milano, Calabria, University of Copenhagen, Padova）

### 這篇在說什麼

這篇研究 LLM 是否會「認可」含有說服技巧的訊息，以及政治人物設定（left-leaning / right-leaning persona）是否會調節這種認可。過去的研究主要看 LLM 作為說服訊息的「生成器」或「偵測器」，但很少系統性地問：當 LLM 被要求以社交媒體用戶身份評估含有說服技巧的政治訊息時，它們是否會因為說服框架而提高認可度？而當我們給 LLM 一個政治立場 persona 時，這個效應是否會被放大？

### 主要貢獻

1. **從「生成/偵測」轉向「認可」**：把 LLM 在政治說服場景中的角色從生產者或偵測者，轉到評估者——這更貼近 silicon sampling 的核心問題（LLM 模擬的人會不會被說服？）。
2. **跨地緣模型比較**：測了六個來自不同地理區域的開源模型（Llama, Qwen, Mistral, Phi, Aya, Yi），不是只看 GPT/Claude。
3. **雙資料集驗證**：同時用推特（烏俄戰爭）和新聞文章（SemEval-2023 Task 3）兩種媒體，測驗說服認可是否跨媒體穩定。
4. **線性混合效應模型分析**：用 LME 拆解說服技巧、政治立場 persona、模型本身的變異來源。

### 方法 / pipeline

- **資料集**：
  - 烏俄戰爭推特資料集（29,596 條推文，4,037 條含說服技巧標註）
  - SemEval-2023 Task 3 新聞語料（12,625 個標註段落，4,880 含說服技巧）
  - 選了四種最常見的說服技巧：slogans、name calling/labeling、loaded language、appeal to fear/prejudice
- **條件**：三種 persona——neutral、left-leaning、right-leaning social media user
- **測量**：五點 Likert 量表評估認可度
- **模型**：六個開源 instruction-tuned LLM，溫度設 0.01 確保重現性
- **分析**：LME model，以說服技巧有無（P）和政治立場（L）為固定效果，模型為隨機截距

### 實驗設計

- **RQ1**：LLM 是否認可含說服技巧的訊息？→ 在 neutral persona 下，LLM 整體不認可含說服技巧的內容（baseline ≈ 2.9/5，偏中立偏低）。但模型間有差異：Mistral 最低（2.518），Phi 最高（3.23）。
- **RQ2**：政治立場 persona 是否影響認可？→ 會。Left-leaning persona 在推文資料上傾向不認可含說服技巧的內容（估計值 2.786 vs. 無說服 3.356），right-leaning 則反過來（含說服 3.726 vs. 無說服 3.434）。這是 polarization 效應。
- **RQ3**：特定說服技巧或主題是否影響認可？→ 是。不同技巧的認可度不同，且跨推特與新聞有差異。新聞的 polarization 較弱但仍然存在。
- **限制**：只能讀到 HTML 前段和結果部分，完整的 ablation 和所有技巧的交互效應分析需要看完整全文。

### かに讀後判斷

這篇跟 TBS（2606.03137）形成有趣的對照：TBS 模擬的是「內部評估→公開發言」的路徑，而這篇實測的是「LLM 作為被說服者的認可行為」。兩者合在一起告訴我們：silicon sampling 不只要建模誰會發言，還要建模誰會被說服、以及被什麼樣的框架說服。

這篇對 silicon sampling 社群的直接貢獻是：如果你要用 LLM 模擬政治態度分佈，你需要知道（1）neutral persona 下 LLM 傾向不認可說服框架，（2）partisan persona 會放大 polarization，（3）不同模型有不同的 baseline 認可度。這意味著 silicon sampling 的 persona 設定會系統性地影響模擬結果。

不過這篇的方法論有侷限：Likert 量表是自報的，而非行為測量；只測了 endorsement 而非實際意見改變。跟 06-06 的 Synthetic Personalities 比起來，這篇更偏向「效應測量」而非「系統模擬框架」。建議深讀 LME model 的係數表和交互效應分析。
