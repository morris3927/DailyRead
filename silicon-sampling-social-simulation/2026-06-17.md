# Silicon Sampling / Social Simulation — 2026-06-17

## 1. Shachi: A Modular, Controllable Framework for LLM-Based Agent-Based Modeling of Emergent Collective Behavior

- **arXiv**: 2509.21862 (v3, updated June 15, 2026; accepted to ALIFE 2026)
- **Link**: https://arxiv.org/abs/2509.21862
- **Authors**: So Kuroki, Yujin Tang (Sakana AI / University of Tokyo)

### 這篇在說什麼

LLM-based ABM 目前面臨三個方法論障礙，導致這個領域無法做累積性的科學研究。第一，不同框架的 agent 介面不相容，agent 無法跨環境攜帶——你不知道觀察到的行為到底是 agent 本身的特質，還是某個特定任務的 artifact。第二，agent 的內部架構（記憶、工具、人格設定）在各框架間散亂不一致，沒有人可以隔離單一認知元件對集體行為的因果影響。第三，大多數研究只用隔離的合成任務驗證，缺乏外部效度——你不知道模擬出來的市場行為跟真實經濟事件有沒有關係。

Shachi 的核心設計選擇是「解耦」（decoupling）：把 agent 的內部認知架構和外部環境完全分離，透過統一介面讓 agent 可以在不同環境之間攜帶、重組和操控。這不是一個新的 agent toolkit，而是一個為 ABM 科學研究設計的方法論框架。

### 主要貢獻

1. **標準化 agent 架構**：Shachi 把 agent 的認知分解成四個獨立元件——Configuration（內在身份，如人格特質、行為策略）、Memory（上下文連續性）、Tools（延伸能力）、LLM reasoning engine（推理引擎）。每個元件都是可獨立控制的變項，可以做 perturbation study。

2. **跨環境 agent 攜帶**：統一介面讓 agent 可以無縫轉移到不同環境。這解決了「agent 特質 vs. 任務 artifact」的混淆問題——同一個 agent 可以在多個環境中被測試，分離其內在特質的效應。

3. **三層級 benchmark 生態系**：10 個任務，分三層集體複雜度——single-agent、non-communicative multi-agent、communicative multi-agent。這讓研究者可以系統性地追蹤集體複雜度如何塑造湧現行為。

4. **三個探索性研究**：
   - **Memory transfer**：agent 攜帶記憶到新環境時，產生 history-dependent behavioral shift——過去的經驗改變了在新環境中的行為。
   - **Cross-environment interference**：agent 同時居住多個環境時，一個環境中的行為會干擾另一個環境中的行為——這在單環境研究中完全看不到。
   - **Tariff shock case study**：用美國關稅衝擊做真實世界驗證，局部互動的 agent 產生的宏觀市場動態方向上與真實觀察一致。

### 方法 / pipeline

Shachi 的架構設計：

- **Agent-Environment Interface**：借鑑 OpenAI Gym 的強化學習形式化。模擬在離散時間步中進行，由環境的 step() 和 reset() 方法驅動。每個時間步 t，agent i 有內部狀態 S_t^i（記憶），接收觀察 O_t^i，輸出行動 A_t^i。環境同時中介 agent-environment 互動和 agent 間通訊。

- **Decoupling 設計**：agent instantiation 時把 task-specific 的環境設定（如 agent profile）從 task-agnostic 的 agent 設計中分離出來。同一個 agent 可以被放在不同環境中，帶著或不帶著記憶。

- **Configuration 模組**：控制 agent 的內在身份——system prompt、人格設定、行為策略。可以透過調整 configuration 來做 perturbation study。

- **Memory 模組**：維持上下文連續性。關鍵是 memory 可以跨環境攜帶——agent 在環境 A 中積累的經驗可以帶到環境 B，這讓 history-dependent behavioral shift 成為可觀察的現象。

- **Tools 模組**：延伸 agent 的能力邊界。環境透過 tool interface 提供立即反饋。

- **Communication**：環境中介的結構化訊息傳遞，而非直接的 agent 對 agent 通訊。

### 實驗設計

- **Benchmark**：10 個任務，分三層：
  - Single-agent（個體理性測試）
  - Non-communicative multi-agent（去中心化協調測試）
  - Communicative multi-agent（社會動態測試）

- **Memory transfer 實驗**：agent 在環境 A 中積累經驗後，攜帶記憶到環境 B。結果顯示 agent 在 B 中的行為受到 A 中經驗的影響——history-dependent behavioral shift。

- **Multi-world inhabitation 實驗**：agent 同時居住在經濟模擬和社會模擬兩個環境中。結果發現跨環境行為干擾——一個環境中的人格設定或行為傾向會「溢出」到另一個環境。

- **Tariff shock case study**：模擬美國關稅衝擊。局部互動的 agent（每個 agent 只和鄰居互動，看不到全局）產生的宏觀市場動態（如價格波動、供應鏈調整）方向上與 2025 年真實觀察一致。這是外部效度的初步驗證。

- **目前能確認的**：方法論框架、agent 架構、三層 benchmark 設計、三個探索性研究的結論已從 HTML 全文確認。每個 benchmark 任務的具體數字和附錄中的詳細分析需看 PDF。

### かに讀後判斷

Shachi 是 silicon sampling / LLM-ABM 領域近期最認真處理「方法論碎片化」問題的框架。之前的框架（Concordia、AutoGen、EDSL）提供了有用的建構元件，但不是為了 ABM 科學研究設計的——它們無法做 controlled perturbation study，也無法跨環境攜帶 agent。Shachi 的 decoupling 設計直接解決了這個問題。

和之前看過的 Social Digital Twins（2601.06111，今天的第二篇）相比，Shachi 更注重框架的方法論嚴謹性和元件可操控性，而 Social Digital Twins 更注重校準和真實世界預測。兩者互補：Shachi 提供了做受控實驗的能力，Social Digital Twins 提供了做真實世界驗證的方法。

也和之前看過的「Are LLM Agents Behaviorally Coherent?」（2509.03737, mentioned 2026-06-02）有直接關聯——那篇指出 LLM agent 的行為一致性有問題，Shachi 的 modular 設計正好提供了系統性排查行為不一致來源的工具。

值得 Morris 點開深讀，特別是：Figure 2 的方法論概覽、Section 3.1 的 decoupling 設計、tariff shock case study 的具體設定、以及 multi-world inhabitation 的干擾模式。

## 2. LLM Powered Social Digital Twins: A Framework for Simulating Population Behavioral Response to Policy Interventions

- **arXiv**: 2601.06111
- **Link**: https://arxiv.org/abs/2601.06111
- **Authors**: Fatima Koaik, Aayush Gupta, Farahan Raza Sheikh (PwC)

### 這篇在說什麼

預測人口如何回應政策干預是計算社會科學和公共政策的根本挑戰。傳統的 aggregate 統計模型可以捕捉歷史相關性，但缺乏機制可解釋性，面對新穎政策情境時外推能力差。ABM 提供了機制豐富性，但需要手動編寫決策規則——這個知識瓶頸限制了 ABM 的應用範圍。

Social Digital Twins 提出了一個中間路線：用 LLM 作為每個 agent 的認知引擎，取代手寫決策規則，同時透過校正層（calibration layer）把 agent 的行為輸出映射到可觀察的人口層級指標，做到真實世界驗證。和之前 silicon sampling 工作的不同之處在於：之前的工作主要驗證 face validity（看起來像不像），Social Digital Twins 則要求預測準確性——用嚴格的時間切分訓練/測試集來驗證。

### 主要貢獻

1. **Social Digital Twin 框架**：把 LLM-based agent 模擬形式化為四個元件——agent population、LLM cognitive engine、calibration layer、validation protocol。這個架構是 domain-agnostic 的，同一個框架可以模擬疫情、交通、環境、金融等不同領域。

2. **多維行為建模**：不像之前的工作只提取標量合規概率，Social Digital Twins 的 agent 輸出多維行為概率向量（如六個 Google Mobility 類別），可以做更豐富的驗證和捕捉行為間的替代效應。

3. **校正方法論**：用多目標優化（Optuna + TPE）學習 agent 輸出到觀察指標的映射，讓模擬結果可以直接和真實數據比較。

4. **嚴格驗證協議**：strict temporal holdout、per-category metrics、counterfactual sanity checks、ablation studies。

### 方法 / pipeline

框架四步：

1. **Agent Population**：用人口統計和心理特徵描述 N 個合成 persona。屬性分佈來自普查數據。

2. **LLM Cognitive Engine**：對每個 (persona, context) pair，構造 prompt 包含 persona 屬性、當前政策狀態、行為概率輸出任務。LLM 輸出 d 維概率向量 p_i,t ∈ [0,1]^d，每個維度代表特定行為的概率。

3. **Aggregation + Calibration**：個體輸出聚合為人口均值，然後透過 per-dimension 線性映射（clip 後）校正到觀察指標。校正參數用 Optuna 多目標優化學習。

4. **Validation**：strict temporal separation（訓練期 vs. 測試期），per-category metrics，counterfactual sanity checks。

關鍵設計：calibration layer 不是 cheat——它承認 raw LLM 概率和觀察指標不在同一尺度上，需要一個可學習的映射。但校正後的預測在嚴格的 out-of-sample 測試期上驗證。

### 實驗設計

- **Case study**：COVID-19 疫情回應。用 Google Mobility Reports（六個行為類別）和 Oxford COVID-19 Government Response Tracker（每日政策變化）。
- **Baseline**：Gradient boosting。
- **主要結果**：calibrated digital twin 在 macro-averaged prediction error 上比 gradient boosting baseline 改善 20.7%，跨六個行為類別。
- **Counterfactual 實驗**：改變政策強度時，模擬的行為反應是單調且有界的——這建立了行為合理性（behavioral plausibility）。
- **Ablation**：移除校正層、移除心理特徵、減少 persona 數量等，都導致性能下降，說明每個元件都有貢獻。
- **Domain-agnostic claim**：框架架構本身不依賴疫情特定設計，但目前的驗證只在疫情場景完成。
- **目前能確認的**：框架設計、實驗協議、主要結果從 HTML 全文確認。每個 mobility category 的具體數字和 counterfactual 實驗的詳細結果需看 PDF。

### かに讀後判斷

Social Digital Twins 在 silicon sampling 的譜系中填補了一個重要位置：它把「校正」和「真實世界預測」帶進了 LLM-based 社會模擬。之前的工作（Argyle et al. 的 silicon sampling、Park et al. 的 generative agents）主要驗證 face validity，Social Digital Twins 要求 predictive validity。

和 SPIRIT（2603.27056, 2026-06-16）相比：SPIRIT 用調查方法論的抽樣加權讓模擬可以推論到母體；Social Digital Twins 用校正層讓模擬預測可以和真實數據比較。兩者解決的是不同問題——SPIRIT 解決「代不代表」，Social Digital Twins 解決「準不準確」。

和 Shachi（2509.21862，今天第一篇）相比：Shachi 注重方法論嚴謹性和元件可操控性，Social Digital Twins 注重真實世界校準和預測。兩者互補。

值得注意但不需要今天深讀。如果未來要做「LLM-based 社會模擬的預測有效性」研究，這篇是必讀參考，特別是 Section 3.5 的校正方法論和 Section 4 的實驗設計。
