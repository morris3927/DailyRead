# Silicon Sampling / Social Simulation — 2026-06-18

## 1. Do Matching Mechanisms Work with LLM Agents?

- **arXiv**: 2606.03030
- **類型**: arXiv preprint (cs.GT, econ.GN)
- **Link**: https://arxiv.org/abs/2606.03030

### 這篇在說什麼

這篇研究核心問題：在 LLM agent 市場中，人類經濟學裡被廣泛研究的配對機制（matching mechanisms），是否在 LLM agent 作為決策代理人時仍然如預期運作？作者把 LLM agent 放進標準配對市場（one-to-one matching），比較去中心化的自由談判市場與集中式機制市場（包括 DA、EADA、TTC 等），觀察穩定性與效率。這直接觸碰到 silicon sampling / social simulation 領域一個根本問題——如果 LLM agent 要模擬人類社會行為，那麼人類經濟制度設計的理論基礎（機制設計理論），在 agent 版本中是否成立？如果不成立，差距有多大、在哪裡？

這篇補的洞很明確：過去 silicon sampling 文獻主要聚焦在「LLM 能否重現人類個體態度與行為」，但幾乎沒有人系統性檢驗「LLM agent 是否能正確扮演機制設計理論中的理性參與者」。機制設計理論是社會科學與經濟學的核心工具，如果 LLM agent 在配對機制中的行為與理論預測不一致，那用 LLM agent 做 policy simulation 的基礎就必須重新檢視。

### 主要貢獻

1. **首次系統性檢驗 matching mechanisms 在 LLM agent 市場的運作**：作者在 controlled one-to-one matching 環境中，測試 DA (Deferred Acceptance)、EADA、TTC 三種經典機制以及自由談判，這是把經典機制設計理論搬到 LLM agent 場景的首次嘗試。

2. **發現 LLM agent 的 truth-telling 率顯著高於人類受試者**：在 DA 和 EADA 環境中，LLM agent 的 truth-telling rate 遠高於人類實驗中的觀察值。這意味著 LLM agent 比「理論預測的理想參與者」更誠實，但這未必是好事——如果 LLM agent 的策略行為不符合人類行為模式，那用 LLM agent 來模擬人類市場行為的有效性就需要打折扣。

3. **揭露 strategy-proofness 與 truth-telling 的脫鉤**：TTC 雖然理論上是 strategy-proof 的，但 LLM agent 在 TTC 下的 truth-telling rate 並不總是高於 EADA。這挑戰了機制設計理論中「strategy-proof → truth-telling」的直覺假設，暗示 LLM agent 可能不完全理解或遵循理論最適策略。

### 方法 / pipeline

作者設計了一系列 controlled one-to-one matching 實驗：

- **市場結構**：one-to-one matching，有明確的偏好序（preference ordering）
- **機制比較**：去中心化自由談判 vs. 集中式機制（DA、EADA、TTC）
- **Agent 設定**：LLM agent 被賦予明確的偏好，然後在配對機制中做決策
- **評估指標**：stability（穩定配對比例）、efficiency（Pareto 效率）、truth-telling rate（是否如實報告偏好）
- **對照基準**：人類受試者在相同環境下的實驗數據

目前從 abstract 和 landing page 能確認到的是：實驗設計有明確的機制比較框架，但具體的 prompt 設計、agent 數量、偏好分布、以及人類對照實驗的來源，需要看全文才能確認。從目前資訊看，這篇的方法論強項是把經濟學實驗設計完整搬到 LLM agent 場景，而不是只做 opinion polling 式的 silicon sampling。

### 實驗設計

從目前能確認的資訊：

- **環境**：one-to-one matching（配對市場），有 controlled preference profiles
- **機制**：DA、EADA、TTC、自由談判
- **主要發現**：機制市場在穩定性與效率上普遍優於自由談判；LLM agent 的 truth-telling rate 遠高於人類；TTC 的 truth-telling 不總是高於 EADA
- **缺失資訊**：具體使用的 LLM 模型、模型版本、prompt 模板、agent 數量與規模、preference profile 的生成方式、人類對照實驗的樣本規模與來源。這些是判斷結果可推廣性的關鍵資訊。

### かに讀後判斷

這篇在 silicon sampling / social simulation 領域開了一個重要的新方向：不是只看 LLM 能否重現人類的態度分佈，而是看 LLM agent 能否正確扮演經濟制度中的參與者角色。結論是「LLM agent 比「理論上理想的理性參與者」更誠實，但不總是遵循 strategy-proof 機制的理論預測」——這對用 LLM 做 policy simulation 的研究社群是一個值得注意的警示。

**值得 Morris 點開嗎？** 值得。這篇直接觸碰到「silicon sampling 用於制度模擬」的方法論有效性問題，跟之前讀過的 Silicon Society Cookbook、Social World Models 等框架形成互補——那些框架關注 agent 架構與模擬設計，這篇則關注「即使架構沒問題，agent 的策略行為本身是否足夠像人類」。深讀時優先看：實驗設計細節（prompt 如何設定偏好、agent 數量與市場規模）、truth-telling rate 的具體數據、以及 discussion 中對「為什麼 TTC 不總是誘發 truth-telling」的分析。
