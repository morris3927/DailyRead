# Silicon Sampling / Social Simulation — 2026-06-19

## 1. AI Coding Agents in Social Science: Methodologically Diverse, Empirically Consistent, Interpretively Vulnerable

- **arXiv**: 2606.11456
- **Link**: https://arxiv.org/abs/2606.11456
- **Authors**: Meysam Alizadeh, Fabrizio Gilardi, Mohsen Mosleh 等

### 這篇在說什麼

這篇論文處理的是 LLM coding agent（如 Claude Code、Codex）在社會科學實證分析中的角色爭議。近年有兩種對立擔憂：一是 AI 會壓縮方法論多樣性（homogenization），二是 AI 會放大研究者偏見透過分析靈活性（analytic flexibility）。作者的核心論點是：這兩種擔憂其實指向兩個可分離的層次——**設計層**（design layer，方法論選擇）與**判斷層**（verdict layer，從估計到結論的映射規則），必須分開評估。

這個問題很重要，因為社會科學「眾分析師同一資料」（many-analysts）研究顯示，73 個團隊分析同一筆移民資料，效應估計從強烈負向到強烈正向都有，且研究者的先驗立場與模型規格和結論顯著相關。如果 AI agent 要替代或輔助人類分析師，我們必須知道它們是否複製了人類的這些偏差模式。

### 主要貢獻

1. **設計層與判斷層的分離框架**：提出將 AI agent 在科學分析中的行為分為「方法論選擇」與「結論判斷」兩層，使得 homogenization 和 bias 可以獨立評估。
2. **Many-analysts 基準測試**：首次在 Breznau et al. 的眾分析師資料上系統性跑 Claude Code（Opus 4.7）和 Codex（GPT 5.5）各 20 次獨立執行，與 73 個人類團隊的基線比較。
3. **Prompt-induced bias 的雙層測試**：用反移民先驗 prompt 和確認性 prompt 分別測試兩層的偏差敏感度，發現判斷層的偏差遠比設計層嚴重——confirmatory prompt 翻轉了 Claude Code 90% 的結論，但係數分布幾乎不變。

### 方法 / pipeline

- **實驗設計**：每個 agent 收到同一筆 ISSP 移民與社會政策資料，加上相同的自然語言 prompt（無 agent 特定提示），在 sandboxed 環境中全自動執行研究設計→程式撰寫→執行→結論。20 次獨立 run，每次無記憶。
- **兩種 bias prompt**：（1）anti-immigration researcher prior——在 prompt 中暗示研究者預設立場；（2）confirmatory prompt——明確要求找出支持假設的結果。
- **規格曲線分析**（specification curve）：比較 human / CC / CX 三組的 AME 分布、顯著性比例、方法論多樣性。
- **KS 距離檢驗**：用 Kolmogorov-Smirnov 測試 agent 估計分布是否偏離人類。

### 實驗設計

- **資料**：ISSP 移民資料 + 國家層級總體經濟指標，即 Breznau et al. (2022) 原始資料。
- **Baseline**：20 個人類團隊（從 73 個中抽樣）。
- **Metric**：AME 分布、顯著性比例、規格數量、KS 距離、結論翻轉率。
- **主要結果**：
  - Codex 的方法論多樣性與人類相當（每 run 平均 17.9 個規格 vs 人類 15.9），Claude Code 遠超人類（平均 52.9 個規格）。
  - 兩個 agent 的效應估計分布與人類大致對齊，只在 composite scale 上有系統偏離。
  - Anti-immigration prior 重組了方法論選擇但**不改變**整體估計或結論——與人類不同，人類的先驗會沿特定方法論軸偏移估計。
  - Confirmatory prompt 將 Claude Code 的結論支持率從 10% 翻轉到 90%，但係數分布不變——偏誤的機制是 rule omission（省略反證規則）而非 rule softening。

### かに讀後判斷

這篇是 2026 年 silicon sampling 領域的重要實證貢獻。它回答了一個 Morris 之前關心的核心問題：LLM agent 在社會模擬中究竟是 homogenizing 還是 bias-amplifying？答案是：**兩者都有可能，但作用在不同層次**。設計層 agent 可能比人類更多樣（尤其 Claude Code），但判斷層非常脆弱——一個 explicit confirmatory prompt 就能翻轉結論而不改變估計。這意味著 LLM agent 作為 silicon sample 的方法論風險不在於它們會統一方法，而在於它們的詮釋層缺乏約束。
