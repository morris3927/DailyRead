# Silicon Sampling / Social Simulation — 2026-06-21

## 1. Marginal Alignment Does Not Guarantee Joint-Distribution Fidelity: An Official-Reference Audit of Nemotron-Personas-Korea with Cross-Locale Replication

- **arXiv**: 2606.12433
- **Link**: https://arxiv.org/abs/2606.12433
- **Authors**: Joonhyung Bae (KAIST)

### 這篇在說什麼

合成 persona 資料集（silicon samples）的主流驗證方式是宣稱「我們跟官方人口統計的邊際分布對齊」——性別、年齡、地區各別看都 match KOSIS。但 downstream 使用者拿到的是一筆筆 persona，裡面 age×sex×region×occupation×education 等屬性是綁在一起的。邊際對齊不保證聯合分布保真。這篇就是用 NVIDIA 的 Nemotron-Personas-Korea（NPK，100 萬筆韓國合成 persona）當 test case，設計了一個叫 Independence-Assumption Footprint（IAF）的 audit 原語，逐條檢驗資料集卡自己揭露的獨立性假設到底把聯合結構搞壞了哪些。

為什麼這個問題重要？因為 silicon sampling 社群一直在用「marginal alignment = 可以當真人的替代樣本」這個宣稱來正當化把 LLM persona 當調查受訪者。如果 joint structure 是壞的，那你在做子群分析、交叉統計、因果推論時拿到的數字就是錯的，即使每個 marginal 單獨看都漂亮。

### 主要貢獻

1. **IAF（Independence-Assumption Footprint）audit 原語**：對資料集卡自己揭露的獨立性假設，逐條拿外部官方參考資料做聯合分布檢驗。具體用 df-aware Cramér's V ratio（R_V = V_NPK / V_ref），threshold 0.7，加上 Feldman 4/5 parity band 和描述性 reference ratio q_b。這不是泛用的 fairness audit，而是針對「dataset card 說了哪些屬性是獨立生成的」這個揭露做定點打擊。

2. **NPK-Korea 六軸實證審計**：用 KOSIS、KEIS GOMS、韓國最高法院姓名統計、兵務廳徵兵資料等公開官方來源，設計了六條審計軸（occupation×sex、major×occupation、military service×age、name cohort 等），其中兩條是預指定的 negative control。結果：marginal spine（age、sex、province）對齊良好，但三個 occupation 相關聯合分布 fail：major×occupation 在 KEIS GOMS 參考上出現大的條件失配、兵役年齡 profile 與機構資料不一致、男性主導職業的女性比例被系統性 over-flatten toward parity。

3. **跨七個 NPK locale 的可轉移性展示**：把同樣的診斷流程拿到 NPK-USA、NPK-Japan 等六個 locale，發現診斷結果是 locale-dependent 而非 universal，參考分類的 cardinality 會 confound 跨 locale 的 flag 數量比較。

### 方法 / pipeline

整個 audit 的核心流程：

1. **揭露抽取**：從 NPK dataset card 中抽取生成假設——NPK 明確說了「sex, income, education, major field influence occupation assignment independently and interaction effects are not modelled」。這就是 audit 的錨點：你說獨立，那我就驗證獨立假設下的聯合結構跟官方聯合分布差多少。

2. **參考資料匹配**：用 KOSIS 的 occupation×sex 列聯表（直接聯合表）、KEIS GOMS 的 major×occupation 微觀資料、韓國最高法院的姓名年齡群統計（negative control）、兵務廳徵役年齡資料（rule-implied check）。每條軸標明是 direct table 還是 rule-implied。

3. **KSCO crosswalk**：NPK 的職業是自由文本，需要映射到 KSCO 分類。作者用 rule-based regex 達到 96.1% 覆蓋率，邊界案例用三個 LLM 的 consensus matrix（n=757）做 mapping uncertainty 估計。

4. **三層指標**：(a) R_V = V_NPK / V_ref，threshold 0.7 → FAIL；(b) 4/5 parity band（r_share ∈ [0.80, 1.25]）；(c) 描述性 reference ratio q_b。三個指標測不同的東西：R_V 測聯合結構衰減、parity band 測 within-NPK 平權偏離、q_b 測 NPK vs reference 的描述性對比。

5. **Negative control 驗證**：Supreme Court name cohort（應該 PASS）和 KOSIS marital register（應該 PASS）都 PASS，確認 audit 不會過度 flag。

### 實驗設計

- **資料集**：NPK-Korea 100 萬筆（19–99 歲，26 欄，77 叙事欄位）。對照組為 KOSIS DT_1B040M1_1（2025）、KEIS GOMS、兵務廳年鑑、最高法院姓名統計。
- **六條審計軸**：occupation×sex（direct table）、major×occupation（KEIS microdata）、military service×age（rule-implied）、name cohort×birth year（negative control）、marital status×sex（negative control）、occupation×income。
- **主要發現**：
  - Marginals（age, sex, province）與 KOSIS 高度對齊，KL divergence 極低。
  - occupation×sex 聯合：R_V = 0.55（FAIL），男性主導職業的女性比例被 over-flatten，reference ratio q_b 在部分 KSCO bucket 遠超 4/5 parity band。
  - major×occupation：NPK 的獨立生成假設導致 major-choice 與 occupation 的條件分布嚴重偏離 KEIS 實際。
  - 兵役年齡 profile 與兵務廳資料不一致。
  - Negative controls 全部 PASS。
- **跨 locale**：六個額外 locale 的 flag 數量是 locale-dependent，不能直接比較 flag 數。
- **API 成本**：整個 audit 的外部 API 花費約 $14 USD（主要是三 LLM consensus matrix），所有快取已釋出可重製。

### かに讀後判斷

這篇是 silicon sampling 社群目前最嚴格的 joint-distribution audit，直接打在「marginal alignment 足夠」這個核心宣稱上。方法論上的創新是 IAF 原語——不是泛用的 fairness 檢驗，而是以 dataset card 自己揭露的生成假設為錨點，逐一對照官方聯合分布。這讓 audit 結果有明確的歸因：不是「你的資料有偏」，而是「你宣稱獨立生成的那些屬性組合，在官方聯合分布上就是對不上」。

對 Morris 的研究關聯：(1) IAF 可以直接套用到其他 synthetic persona 資料集（PersonaHub 等），(2) 跨 locale 可轉移性展示說明了這不只是韓國問題，(3) audit artifacts 全部開源（MIT license），可以直接 retarget。
