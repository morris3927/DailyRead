# Silicon Sampling / Social Simulation — 2026-06-23

## 1. Contagion Networks: Evaluator Bias Propagation in Multi-Agent LLM Systems

- **arXiv**: 2606.20493
- **Link**: https://arxiv.org/abs/2606.20493
- **Authors**: Zewen Liu (Qilu Institute of Technology)
- **Subjects**: cs.LG, cs.AI, cs.MA

### 這篇在說什麼

當 LLM 作為評估者在多 agent 系統中互相評價彼此的輸出時，評估者的系統性偏誤會沿著 agent 網路傳播——這篇論文把這個現象正式建模為「傳染網路」（Contagion Networks），用流行病學的框架來量化偏誷如何在 agent 之間擴散。問題核心是：多 agent 系統之所以有價值，是因為認知多樣性；但如果評估偏誤會互相傳染，多 agent 系統可能反而收斂到單一策略，消滅了它本應利用的多樣性。這跟 silicon sampling 的根本關切直接相關——用 LLM 當受試者做社會模擬時，評估偏誤的傳染會導致整個模擬系統的策略崩塌。

### 主要貢獻

1. **Cross-Agent Contagion Matrix Γ_N**：把 MM-EPC 的 2×2 跨模態傳染矩陣推廣到 N 個 agent 的情況，提供量化框架測量任意 agent 拓撲下的偏誤傳播係數。這是把流行病學建模引入 multi-agent LLM 系統的第一個正式框架。

2. **傳播 regime 定理**：根據傳染矩陣的譜半徑 ρ(Γ_N) 區分三種 regime——抑制（suppression, ρ<1）、持續（persistence, ρ=1）、級聯（cascade, ρ>1）。在完全連接的網路中，ρ>1 是級聯條件。

3. **同質模型傳染的實證驗證**：用 DeepSeek-chat 搭配三種評估偏誤 profile（structured、balanced、evidence-based）做 3-agent chain 實驗。結果顯示同質模型的傳染係數 γ∈[0.157, 0.352]，比跨模型係數（MM-EPC 的 γ≈0.85–1.3）弱 3–5 倍，落在抑制 regime。累積傳播因子 β₃=0.0055，代表偏誤在 3 hop 後幾乎完全衰減。

4. **多樣性閾值**：證明 k≥3 的多樣化評估者可以把有效傳染降低 72.4%（從 k=1 到 k=3），即使在抑制 regime 下也有實質效果。這給了一個可操作的緩解策略。

5. **開源框架**：釋出 Contagion Network 實驗框架，讓社群可以測量任意 agent 集的 Γ_N。

### 方法 / pipeline

整個方法建立在 Test-Time Reinforcement Learning (TTRL) 之上，這是一個不需參數更新的策略調整機制：

1. **策略空間與權重分佈**：每個 agent A_i 維護一個策略權重向量 w_i，策略從 Softmax(w_i) 採樣。每回合，agent 生成兩個回應 y_a, y_b，由評估者比較勝負。

2. **TTRL 權重更新**：贏的策略乘以 (1+α_win)，輸的乘以 (1-α_lose)，然後正規化。這是乘法更新，不需要 LLM 參數更新——完全在 API 層級就能操作。

3. **傳染係數測量**：γ_{j→i} = ||w_{j→i} - w_i||₂ / ||w_i||₂，量化 agent i 在被 agent j 評估後策略偏移了多少。

4. **實驗設計四階段**：(1) 基線偏好 profile 建立、(2) 兩兩傳染測量、(3) 鏈式傳播實驗、(4) 評估者多樣性緩解實驗。

### 實驗設計

- **模型**：DeepSeek-chat（同一底層模型），三種評估偏誤 profile（structured / balanced / evidence-based）
- **基線偏好指標**：PCI (Preference Concentration Index)，三個 agent 的 PCI 分別為 0.185、0.340、0.208，遠低於 GPT-4o 自評的 1.464，確認 DeepSeek 的評估行為比 GPT-4o 更平衡
- **兩兩傳染結果**：六個 off-diagonal 傳染係數全為正（γ∈[0.143, 0.304]），確認同模型內偏誤仍會傳播。但全都 <1.0，滿足鏈式抑制條件。
- **不對稱傳染**：Agent C（evidence-biased）的外向傳染最強（γ̄_{C→·}=0.241），Agent A（structured-biased）最弱（γ̄_{A→·}=0.154）
- **鏈式傳播**：Hop 1 的 γ=0.254，Hop 2 降到 γ=0.113，累積 β₃=0.0055——近完全衰減
- **多樣性緩解**：k=1→3 評估者，有效傳染降低 72.4%
- **與跨模型對照**：同質模型的傳染係數比 MM-EPC 的跨模型係數弱 3–5 倍

### かに讀後判斷

這篇對 silicon sampling / social simulation 社群非常重要。它正式回答了一個關鍵問題：**當我們用多個 LLM agent 組成模擬社會，並讓它們互相評估時，評估偏誤會不會像傳染病一樣擴散？**答案是會，但同質模型下的傳染力弱到會自然抑制（3 hop 後幾乎完全衰減）。然而跨模型系統的傳染力強得多（γ≈0.85–1.3），可能進入級聯 regime。

對 Morris 的直接意義：如果做 silicon sampling 實驗時讓 LLM 互相評估（而非獨立人類評估者），需要特別注意跨模型評估的偏誤傳染風險。多樣性委員會（k≥3）是實用的緩解手段。
