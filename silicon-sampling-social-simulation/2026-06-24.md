# Silicon Sampling / Social Simulation — 2026-06-24

## 1. Hallucination as Context Drift: Synchronization Protocols for Multi-Agent LLM Systems

- **arXiv**: 2606.21666 | cs.AI, cs.MA
- **Link**: [arXiv HTML](https://arxiv.org/html/2606.21666v1)
- **深度**: 全文 HTML（~20K chars），已讀至實驗結果與討論

### 這篇在說什麼

多 agent LLM 系統常常產生「幻覺」——但作者認為，很大一部分幻覺根本不是模型本身的問題，而是 agent 之間「context drift」造成的。當多個 agent 各自帶著不同步、過時或互相矛盾的內部知識狀態進入協作，就算每個 agent 單獨看都沒問題，聯合推理就會產生矛盾。這不是模型能力問題，是分散式系統的同步問題。這篇論文把多 agent 幻覺從「模型缺陷」重新定位為「介面瓶頸」，並提出偵測與緩解的協定。

這跟 silicon sampling 的根本關切直接相關：當我們用多個 LLM 取樣模擬社會行為，agent 之間的知識狀態是否同步？如果不同步，觀察到的「分歧」到底是社會現象還是系統 artifact？

### 主要貢獻

1. **Context Divergence Score (CDS)**：一個輕量級純量指標，用 cosine distance 衡量 agent 之間 context embedding 的語義距離，區分空間（不同環境信念）、時間（過時資訊）、任務（不同任務歷史）三個維度的飄移。

2. **Shared State Verification Protocol (SSVP)**：不是每次都廣播全部 context，而是只在 CDS 超過閾值 τ 時才觸發同步。這避免了「contamination effect」——也就是無差別地把自己的錯誤狀態傳播給所有 agent。

3. **Contamination effect 的實證發現**：在旅行規劃任務中，naive full-broadcast 同步反而讓幻覺率比不同步高出 34%（HR: 0.658 vs 0.492, p=0.0022, d=1.18）。SSVP 則用 58% 更少的 API calls，達到比 full-broadcast 顯著更低的幻覺率（p=0.0005, d=1.47）。

### 方法 / pipeline

整個框架有三個核心元件：

- **Agent Context Model**：每個 agent 在時間 t 有一個 context vector c_i^t = f_θ(s_i^t || h_i^t || g_i^t)，由 spatial-environmental state、task history、goal state 組成，壓縮成語義 embedding。

- **CDS 計算**：兩個 agent 的 CDS 就是 context vector 的 cosine distance。系統級 CDS 是所有 agent pair 的最大值。閾值 τ = 0.25 是從校正分析中選的：在 180 個 no-sync 觀測中只有 1.1% 自然超過這個值，保持低假陽性率。

- **SSVP 同步流程**：每個 reasoning step，agent 計算 CDS；如果超過 τ，就交換壓縮的 state summary 並驗證共享狀態；如果沒超過，就不同步，繼續各做各的。

實驗用 Claude Haiku (claude-haiku-4-5-20251001) 作為底層模型，兩個任務域：multi-agent travel planning (n=30/condition) 和 software project planning (n=10/condition)。三個條件：No-Sync、Full-Broadcast、SSVP。評估指標包括 Hallucination Rate (HR)、Task Coherence Score (TCS)、Recovery Steps、CDS over time。

### 實驗設計

- **旅行規劃域**：三個 agent（Travel Planner、Hotel Booking、Activity Coordinator），8 個情境，每個情境注入一個「booking agent 持有錯誤目的地」的偏誤。n=30 per condition。

- **軟體規劃域**：三個 agent（Product Manager、Developer、QA），n=10 per condition。這個域的 contamination effect 不顯著，因為單一錯誤信念不會跨多個評估維度級聯。

- **主要結果**：
  - No-Sync HR: 0.492, SSVP HR: 0.463 (−5.9%, d=0.30, 未達統計顯著)
  - Full-Broadcast HR: 0.658 (+34% vs No-Sync, p=0.0022, d=1.18)
  - SSVP vs Full-Broadcast: p=0.0005, d=1.47
  - SSVP 用 58% 更少的 API calls

- **TCS**：No-Sync 0.342, SSVP 0.350, Full-Broadcast 0.229。SSVP 在 coherence 上略好但未達顯著。

- **CDS 預測有效性**：系統級 CDS 與 HR 有正相關，但在旅行域特別強（因為 contamination），軟體域則不然。

### かに讀後判斷

這篇對 silicon sampling 社群非常重要。核心 insight 是：多 agent 系統的幻覺不只是模型問題，更是「介面問題」——agent 之間的狀態同步協定決定了系統行為的可靠性。對做 silicon sampling 的人來說，這意味著：

1. 如果你的模擬用多輪對話讓 agent 互相影響，你觀察到的「社會共識」或「群體偏誤」可能有一部分是 context drift 的 artifact，而不是真正的社會現象。
2. Full-broadcast（讓所有 agent 每步都看到全部 context）不是解方，反而會傳播偏誤。
3. SSVP 的選擇性同步思路值得借鑒：只在偵測到飄移時才同步。

值得深讀的部分：Section 5 的 contamination effect 分析、Section 6 的軟體域 null result（說明 contamination 是任務結構相關的）、Appendix 的 CDS 校正細節。Morris 如果對多 agent 模擬方法論有興趣，這篇應該優先看。

## 2. Artificial collectives of specialists and generalists excel at different tasks

- **arXiv**: 2606.20877 | cs.AI, cs.MA
- **Link**: [arXiv HTML](https://arxiv.org/html/2606.20877v1)
- **深度**: 全文 HTML（~20K chars），已讀至 Results 中段

### 這篇在說什麼

這篇問了一個 silicon sampling 的根本問題：在 multi-agent 系統裡，agent 的「理解能力廣度」（interpretive abilities）應該怎麼設計？專家型 agent（窄理解、深專注）跟通才型 agent（寬理解、淺覆蓋）在不同任務上有不同表現。作者把 interpretive abilities 映射成網路結構——通才型對應密集、去中心化網路，專家型對應稀疏、中心化網路——然後系統性地研究網路拓撲、任務類型、理性邊界三者的交互作用。

### 主要貢獻

1. **Interpretive network 的系統性映射**：把 agent 的理解能力範圍（窄 vs 寬）映射到網路連結密度、去中心化程度、最短路徑長度，讓「專家/通才」不再是口語描述而是可量化的網路屬性。

2. **Task quality 的調節效應**：網路屬性的 main effect 很小（0.07 SD），但針對特定任務類型，效應大 4.5 倍（0.33 SD），某些條件下可達 1.84 SD。Generate/Choose/Coordinate 任務受益於密集、去中心化網路（通才型）；Negotiate 任務受益於稀疏、中心化網路（專家型 + 少數通才中介）。

3. **Bounded rationality 的調節效應**：寬鬆理性邊界下專家勝出（高維決策空間的有效取樣），嚴格理性邊界下通才勝出（更好的梯度估計），適中邊界則暴露 speed-quality trade-off。

### 方法 / pipeline

- 用抽象 optimizer 取代特定 LLM 實作（保持 external validity），30 個數學目標函數代表四類任務品質（generate, choose, coordinate, negotiate）。
- 系統性變異：group size (2/4/8/16), interpretive network (18 種拓撲), rationality bound (±0.1%/1%/10%/100%)。
- 250 trials per task，OLS 迴歸分析網路屬性 × 任務品質的交互效應。

### 實驗設計

- **Main effects**：網路密度 +0.07 SD, 去中心化 −0.13 SD, 路徑長度 −0.18 SD。平均很小。
- **Conditional effects**：
  - Coordinate tasks: 密度 +1.60 SD, 去中心化 +1.84 SD
  - Negotiate tasks: 密度 −0.55 SD, 去中心化 −0.68 SD
  - Generate tasks: 密度 +0.87 SD, 去中心化 +0.77 SD
  - Choose tasks: 密度 +0.97 SD, 去中心化 +1.10 SD
- **Rationality moderation**: Loose bounds 專家 +6.7%, tight bounds 通才 +7.3%。
- 所有效應 p<0.05，multivariate OLS with robust SE。

### かに讀後判斷

對 silicon sampling 來說，這篇的貢獻是給了「什麼任務該用什麼 agent 組合」的量化指引。Negotiate 任務（需要妥協的任務）用專家 + 少數通才中介最好——這跟昨天 Contagion Networks 的「k≥3 多樣化評估者降低傳染」有呼應。Coordinate/Generate 任務則反過來，通才越多越好。

限制：用的是抽象 optimizer，不是真正的 LLM。外推到 silicon sampling 的 LLM agent 時需要驗證。建議深讀 Section 3（方法）和 Figure 3 的 heatmap。Morris 如果在設計模擬實驗，這篇的 interpretive network 框架可以直接拿來設計 agent 的角色理解範圍。

## 3. SaMAS: Empowering Economic Simulation through Situation-aware LLM-driven Generative System

- **arXiv**: 2606.20720 | cs.AI, cs.MA
- **Link**: [arXiv HTML](https://arxiv.org/html/2606.20720v1)
- **深度**: 全文 HTML（~20K chars），已讀至實驗結果

### 這篇在說什麼

SaMAS 把 LLM 角色扮演 agent 引入經濟模擬（ABM），核心 idea 是讓每個 agent 同時具備「長期感知」（LLM 參數中的宏觀經濟常識，如 1929 大蕭條、2008 金融海嘯）和「短期感知」（agent 在模擬中的個人軌跡摘要 + 群體軌跡 + Ebbinghaus 遺忘曲線衰減），兩者結合產生動態風險感知參數，驅動消費/勞動意願決策。

### 主要貢獻

1. **雙層情境感知架構**：Long-term Awareness（LLM 內建常識）+ Short-term Awareness（個人軌跡 + 群體軌跡 + 遺忘衰減），這比單純 LLM prompt 更像人類的「歷史類比 + 近期偏誤」決策模式。

2. **群體感知**：按職業分組聚合軌跡，讓白領、企業主、藍領展現不同的風險偏好和消費行為模式。

3. **Volatility Realism 81.5% 和年度 Hit Rate >70%**，超過 random/rule-based/RL/simple LLM baselines。

### 方法 / pipeline

- 100 個 LLM agent，各有職業/年齡/收入 profile
- 每步：LLM 生成決策（消費/勞動意願），基於宏觀環境 + 個人軌跡摘要 + 群體軌跡
- 用 Ebbinghaus 遺忘曲線衰減歷史記憶權重
- 宏觀指標更新：收集所有 agent 決策 → JSON 統計 → 更新 GDP/CPI 等指標 → 下一步

### 實驗設計

- Baselines: Random, Simple Rule, Complex Rule, RL-based, Simple LLM-driven
- Metrics: Volatility Realism（模擬統計與真實數據的相似度）, Turning-Point Hit Rate（波峰波谷預測準確率）
- SaMAS 在 daily/monthly/yearly 三個時間尺度上都優於所有 baseline
- LLM 選擇（DeepSeek/Grok/其他）不顯著影響結果
- Agent 數量從 50 增加到 200 持續改善表現

### かに讀後判斷

這篇在 silicon sampling 領域算是一個不錯的實作展示，但理論貢獻偏薄。雙層感知架構是合理的工程設計，但 Ebbinghaus 遺忘曲線用來衰減記憶權重是比較粗略的類比。真正的問題是：LLM 的宏觀常識和短期軌跡怎麼交互？作者只給了「風險感知參數」這個黑盒介面。

值得注意的限制：
- 沒有開源代碼連結
- 沒有與 Generative Agents (Park et al. 2023) 或其他 LLM 模擬系統的直接比較
- LLM 基座只有 DeepSeek 和 Grok，沒有 GPT-4/Claude
- Volatility Realism 和 Hit Rate 的計算方式不夠透明

如果 Morris 對經濟模擬的 LLM 應用有興趣，可以快速掃過，但不需要深讀。核心 idea 是「用 LLM 做經濟 ABM 的情境感知」，但方法論深度不及 Generative Agents 或今天的主推薦 Context Drift 那篇。
