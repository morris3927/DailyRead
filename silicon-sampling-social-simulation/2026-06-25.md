# Silicon Sampling / Social Simulation — 2026-06-25

## 1. Diversity Collapse in Multi-Agent LLM Systems: Structural Coupling and Collective Failure in Open-Ended Idea Generation

- **arXiv**: 2604.18005 | ACL 2026 Findings
- **Link**: https://arxiv.org/abs/2604.18005

### 這篇在說什麼

多 agent LLM 系統常被期待能藉由互動拓展探索的多樣性，但這篇論文系統性地指出這種期待可能被高估了。作者研究多 agent 系統在開放式創意發想任務中的「多樣性崩塌」（diversity collapse）現象——當 agent 之間的互動結構使得原本應該發散的探索反而收斂到同質化的結果。這不是模型能力不足的問題，而是互動結構本身造成的集體失敗。

研究問題是：為什麼多 agent 協作反而比獨立運作更不多元？作者提出「structural coupling」作為核心機制：互動結構讓 agent 的探索範圍被壓縮，造成多樣性崩塌。

### 主要貢獻

1. **三層次系統性分析**：從模型層（compute efficiency paradox：越強的模型邊際多樣性越低）、認知層（authority-driven dynamics 壓抑語意多樣性）、系統層（群體規模擴增報酬遞減，密集通訊拓撲加速收斂）三個層次拆解多樣性崩塌。
2. **Structural coupling 的定位**：明確指出崩塌主要來自互動結構而非模型本身不足，這對 silicon sampling 社群是重要提醒——更多 agent 或更密集的互動不一定更好。
3. **Inverse scaling 的反直覺發現**：更強、更 aligned 的模型反而產出更多同質結果，這對用 LLM 做社會模擬的 validity 有根本性挑戰。

### 方法 / pipeline

- 三層實驗設計：
  - **模型層**：比較不同能力等級的 LLM（強模型 vs 弱模型），測量每樣本品質 vs 多樣性的 trade-off。
  - **認知層**：操控 agent 群體的角色分配（authority vs junior），觀察語意多樣性的變化。
  - **系統層**：改變群體規模和通訊拓撲（dense vs sparse），測量收斂速度和多樣性保留。
- 使用 semantic diversity metrics 評估開放式發想的探索廣度。
- 完整程式碼開源（GitHub: Xtra-Computing/MAS_Diversity）。

### 實驗設計

- 多組 LLM 在開放式 idea generation 任務上進行 MAS 協作 vs 獨立運作的對照實驗。
- 模型層：觀察到 compute efficiency paradox——強模型產出品質高但邊際多樣性低。
- 認知層：authority-driven 群體的語意多樣性顯著低於 junior-dominated 群體。
- 系統層：群體規模擴增的邊際多樣性報酬遞減；密集通訊拓撲加速過早收斂。
- 核心發現：多樣性崩塌來自互動結構，而非模型本身。

### かに讀後判斷

這篇直接回應 silicon sampling 的核心關切：LLM agent 的多樣性是否足以代表人類群體的異質性？答案是「在密集互動下不行」。對 DailyRead 追蹤脈絡來說，這和之前 PSII（2603.16142）的 diversity collapse 問題一脈相承，但從多 agent 互動結構的角度給出更機制性的解釋。建議深讀時優先看實驗設計（尤其是 semantic diversity 的操作定義）和系統層的拓撲實驗。值得 Morris 點開，但需要看全文 PDF 確認 metric 和 ablation 的細節。
