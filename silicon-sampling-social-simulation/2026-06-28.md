## 1. The Model as One Rater Among Several: Measuring Political Positions in Data-Sparse Regions with a Language-Model Panel

- **arXiv**: 2606.23042
- **Link**: https://arxiv.org/abs/2606.23042

### 這篇在說什麼

現有的政治立場測量工具——manifesto coding、expert survey、text-scaling——都是在西方政黨體系上建立並驗證的，一旦搬到中東北非（MENA）這種許多重要政治行為者從不發表西式政綱、從不參與競爭選舉、或憲章說一套執政做另一套的區域，這些工具就幾乎完全失效。作者提出一個方法論上的立場轉換：不要把 LLM 當作測量儀器（oracle），而是把它當成一個「有偏見的評分者」，和專家調查裡的一位專家一樣對待——價值來自多個評分者的彙整，而非信任任何單一評分者。作者實作了 Tayyar，一個 MENA 地區的政策定位資料集，用多個 LLM 組成 panel 來對政黨和公眾人物在區域性軸線上打分。

這篇直接回應 silicon sampling 的核心問題：用 LLM 模擬人類行為時，模型到底是在「測量」還是在「產生」？作者選擇了更保守但更誠實的路線——承認模型的限制，把模型放入一個已有成熟方法論框架的專家調查傳統中，讓彙整和分歧分析來告訴你結果可靠到什麼程度。

### 主要貢獻

1. **Model-as-rater stance 與 panel design**：不是把 LLM 當 oracle 讀出答案，而是把它當成專家調查裡的一個評分者，用 Krippendorff's α 等聚合指標來衡量 panel 內一致性。這個立場轉換把問題從「模型對不對」變成「多個評分者之間的一致性結構是什麼」。

2. **Built-in rubric experiment**：固定一個 definition-free 的第一輪，然後加入書面軸線定義，觀察分數變化。結果：定義使分數平均移動 1.8 點（21 點量表），並且讓獨立評分者之間的間距從 2.81 縮小到 2.50、相關從 0.81 升到 0.89。這不是隨便推一把——定義讓不同評分者更一致，說明 rubric 做的是校準而非任意引導。

3. **跨模型可靠性與分歧的資訊性**：九個來自八個實驗室的模型，Krippendorff's α 在 interval 和 ordinal 量度上都達到 0.86，且從五個擴展到九個評分者時保持穩定。但作者特別強調：高可靠性 ≠ 有效性，因為重疊訓練資料造成的相關偏差無法從模型本身偵測。更有趣的是，panel 最大的分歧——對一個行為者對國家根本秩序的立場出現雙峰分歧——追溯到一個指涉問題（referent problem）：模型同意事實但對「哪個秩序算作 the regime」有不同解讀，而選擇指涉本身就是政治判斷。三盲編碼把這分歧的約三分之二歸因為詮釋性而非事實性或定義模糊。

### 方法 / pipeline

Tayyar 的設計圍繞幾個關鍵元件：

- **Panel of raters**：九個 LLM（跨八個實驗室、兩個國家）作為評分者，每個對每個 actor × axis cell 打分。打分結果用中位數彙整，但保留分歧。
- **Applicability rule**：區分「真的打了零分」和「不適用/留白」。這在 data-sparse 區域很重要——不是所有 actor 在所有軸線上都有立場。
- **Declared vs. Behavioural lens**：分開「說了什麼」和「做了什麼」兩個視角，因為 MENA 行為者的公開立場和實際行為之間常有巨大落差。
- **Rubric experiment**：兩輪設計——第一輪無定義，第二輪加入書面軸線定義。比較兩輪的差異來量化 rubric 的效應。
- **Inclusion gate on aggregation**：只聚合 applicable cells，避免不適用的評分稀釋結果。

### 實驗設計

- **資料集**：MENA 地區的政黨和公眾人物，跨多個區域性軸線（宗教在國家中的角色、抵抗 vs. 正常化、巴勒斯坦問題等）。
- **Panel 組成**：9 個模型來自 8 個實驗室、2 個國家，涵蓋不同訓練資料和架構。
- **可靠性指標**：Krippendorff's α 在 interval 和 ordinal 量度上都為 0.86。
- **Rubric 效應**：定義使平均分數移動 1.8 點（21 點量表），評分者間 MAE 從 2.81 降到 2.50，相關從 0.81 升到 0.89。
- **分歧分析**：最大分歧發生在 actor 對國家根本秩序的立場，三盲編碼歸因約 67% 為詮釋性分歧。
- **有效性檢驗**：作者明確承認缺乏外部效標驗證，這是方法目前的限制。已有的 grounded pilot 顯示，從引用文件重新打分對單一模型定位的影響大於換模型。

### かに讀後判斷

這篇對 silicon sampling 領域有直接的方法論貢獻。它不是又一個「用 LLM 模擬人類」的 paper，而是在問一個更根本的問題：當你把 LLM 放進測量框架時，它到底是什麼角色？作者的回答——「一個有偏見的評分者」——比目前主流的 oracle 模式誠實得多，也更有方法論上的嚴謹性。

和 2026-06-27 的 Personality Anchoring（2606.06936）形成有趣的對比：Personality Anchoring 用外部人格錨點來穩定模擬，而 Tayyar 用 panel 彙整和分歧分析來管理模型偏差。兩者都在回答「如何信任 LLM 的社會/政治判斷」，但策略不同——前者加固輸入，後者加固測量過程。

和前幾天的 Temporal Realism（2606.19904）也有呼應：Tayyar 的 applicability rule 和 declared-behavioural lens 類似於「何時行動」和「行動什麼」的分離——都是承認 LLM 模擬的某個維度需要外部校準。

**值得 Morris 點開**。優先看 §2 Related Work（和 expert survey / text scaling 傳統的對話很清楚）和 §4 的分歧分析（referent problem 是一個新的 silicon sampling 議題）。如果對 silicon sampling 的效度問題感興趣，這篇的 model-as-rater 立場是比主流更紮實的替代路線。

## 2. 𝒪dysSim: Building Foundation Models for Human Behavior Simulation

- **arXiv**: 2606.14199
- **Link**: https://arxiv.org/abs/2606.14199

### 這篇在說什麼

目前用 LLM 模擬人類行為有一個系統性問題：helpfulness-driven 的 post-training（RLHF 等）把模型拉向一個均質的、過度合作的助手語域（assistant register），造成行為上的 Sim2Real gap——模擬出來的行為比真人更禮貌、更一致、更不會展現人類自然的「不良」行為。作者提出 OdysSim，是目前最大規模的 open behavioral foundation model 計畫，涵蓋 23 個任務的 benchmark、21.4M 交互的中訓練語料、以及一個 end-to-end 的 RL 訓練配方。

這篇直接回應 silicon sampling 的核心挑戰：如何讓 LLM 不只是「有用的助手」而是「像人的模擬器」？答案是重新思考整個訓練管線——從評估什麼（Soul-Index）、到學什麼資料（OdysSim corpus）、到優化什麼目標（behavioral fidelity vs. task success）。

### 主要貢獻

1. **Soul Framework**：定義了五個行為模擬能力軸——CONV（對話動態）、SS（社交技能）、COG（認知/心智狀態推理）、ROLE（角色扮演與教學）、EVAL（判斷與偏好）——把 62 個資料集和 23 個 benchmark 任務統一在一個框架下。這不是又一個分類法，而是讓訓練、評估和彙整在同一套軸線上對齊。

2. **OdysSim Corpus**：21.4M 交互（約 10B tokens）的中訓練語料，來自 62 個公開來源。關鍵創新是 retrofit pipeline：對每段對話 back-generate 社會語境（角色描述、互動目標），因為許多原始資料（如 WildChat、ConvoKit）有對話但缺乏社會接地。實驗證明帶有社會語境的訓練對學習行為模擬是重要的。

3. **End-to-end training recipe**：三階段——midtraining on OdysSim corpus → task-specific RL（GRPO for verifiable rewards, RLVF for LLM-judged tasks）→ expert distillation 合併成單一模型。結果：𝒪sim-8B 在 Soul-Index 的 23 個任務中 8 個排名第一或並列第一，超過任何單一 frontier model。在零樣本 τ-USI 用戶模擬上幾乎追平真人（93.2 vs. 93.5 reaction alignment）。

### 方法 / pipeline

完整的三階段管線：

1. **Midtraining**：在 OdysSim corpus 上繼續訓練 Qwen3 base models → 𝒪sim-Mid。這一步的效果是讓輸出從助手語域移向人類語域——更短的句子、更少的助手式用語。
2. **Task-specific RL**：對 Soul-Index 的每個任務分別訓練一個 expert。有可驗證獎勵的任務用 GRPO，需要 LLM 評判的任務用 RLVF（同時給分數和文字回饋）。
3. **Expert distillation**：把所有 task-specific experts 合併成單一 𝒪sim 模型。

消融實驗顯示兩個階段的貢獻性質不同：midtraining 主要改善長度、格式、用詞的人類性；task-specific RL 主要改善角色扮演和對話任務的精確度。

另外作者發現 LLM-as-judge RL 會誘發 reward-hacking pattern，並提出 detector 在 post-training 中緩解。

### 實驗設計

- **Benchmark**：Soul-Index，23 個任務跨 5 個軸線，是目前最全面的 open 行為模擬評估。
- **Base models**：Qwen3 系列（主要 8B）。
- **Comparison**：𝒪sim-8B vs. 多個 frontier models（GPT-4o、Claude、Gemini 等）。
- **Main results**：8/23 任務排名第一或並列第一，超過任何單一 frontier model。CONV 和 SS 軸線上進步最大。
- **Zero-shot transfer**：在 τ-USI（工具使用代理的用戶模擬）上達到 93.2 reaction alignment，幾乎追平真人的 93.5。
- **Ablation**：midtraining 把 Qwen3-8B-Base 從 26.9 提升到 41.1（Soul-Index 總分），task-specific RL 再提升 ROLE 和 CONV。
- **已知限制**：模型仍然是 8B 參數，更大規模的行為 foundation model 尚待探索；Soul 五軸不是人類行為的窮盡分類；reward-hacking 的緩解仍是開放問題。

### かに讀後判斷

這篇是 silicon sampling 領域的一個重要里程碑，因為它不只是用 LLM 模擬人類，而是系統性地重新思考了「模擬人類」這件事的整個訓練管線。Soul framework 的五軸分類和 OdysSim corpus 的 retrofit pipeline 都有方法論上的創新，而不只是工程規模的擴大。

和前幾天的 Social World Model（2606.21315）形成互補：Social World Model 用閉環學習讓模型持續習得社交能力，而 OdysSim 用 midtraining + task RL + distillation 的三階段管線讓模型一次性學會行為模擬。兩者都認為 helpfulness post-training 是 Sim2Real gap 的根源，但解決路徑不同。

和今天另一篇 Tayyar（2606.23042）也有對話空間：Tayyar 把 LLM 當作 panel 中的一個評分者，而 OdysSim 把 LLM 當作行為模擬器本身。兩者面對同一個根本問題——LLM 的偏差從哪裡來、如何管理——但給出不同的答案：Tayyar 用彙整和分歧分析管理偏差，OdysSim 用訓練管線重新校準。

**值得 Morris 點開**。優先看 §3 Soul Framework（五軸定義如何同時索引語料和評估）、§5 的 reward-hacking 分析、以及 Figure 2（三階段管線的全局視角）。如果對 silicon sampling 的訓練側感興趣，這篇是目前最完整的 open 資源。
