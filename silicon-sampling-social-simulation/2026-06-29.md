# Silicon Sampling / Social Simulation — 2026-06-29

## 1. Group Selection Promotes Prosocial Prompts in Populations of LLM Agents (2606.23343)

- **arXiv**: 2606.23343
- **Link**: https://arxiv.org/abs/2606.23343
- **Authors**: Luis Celiktemel, Edward Eichhorn, Levin Brinkmann, Robin Schimmelpfennig, Aron Vallinder, Yaomin Jiang, Edward Hughes, Iyad Rahwan
- **Affiliations**: Max Planck Institute for Human Development, Eberhard Karls University Tübingen, Inherent Laboratories London

### 這篇在說什麼

目前讓 LLM agent 變得「利他」的方法，大多是在個體層面由人類指定行為（比如用 system prompt 說「你要合作」），但這種做法無法保證 LLM 群體真的會合作。同時，frontier model 的後訓練正從偏好對齊轉向可驗證獎勵（數學、程式碼），這類個人獎勵最適化的結果在多 agent 環境下很可能催生自私行為。這篇的核心問題是：如果不用人類設計的規範，能不能讓 LLM agent 群體透過演化機制自發形成合作？作者借用人類學裡的文化群選擇理論——群體間競爭讓內部合作的群體勝出——設計了一套多代模擬框架，讓 LLM agent 玤重複社會困境遊戲並把策略 prompt 傳給下一代。結果顯示：在群選擇下，利他 prompt 穩定繁衍；在個體選擇下，自私 prompt 全面佔優，群體陷入集體背叛。

### 主要貢獻

1. **演化框架 + 自然語言 prompt 作為遺傳物質**：agent 的策略是一段自由文字 prompt（strategy string），在世代間傳遞並被 LLM 變異（mutation）。不需要手動設計行為空間，所有多樣性來自 LLM 採樣的隨機性。
2. **群選擇 vs 個體選擇的乾淨對比**：同樣的 agent、同樣的遊戲、同樣的變異機制，只改變選擇層級（選個體 vs 選群體），就能讓合作或背叛成為穩定均衡。這是一個非常明確的因果展示。
3. **replicator-mutator 模型的理論重現**：作者從模擬中提取經驗性的 transmission kernel（prompt 變異的機率分佈），代入多層 replicator-mutator 方程，成功預測了合作率隨群選擇強度的相變。
4. **GPT-5.4 的先 anticipatory 行為**：當在 prompt 中告知選擇機制時，GPT-5.4 會在第一代就調整捐款水準，表現出對選擇壓力的預期行為——其他模型沒有這種現象。

### 方法 / pipeline

框架分三個 phase，每代重複執行：

1. **Game phase**：N 個 agent 組成 M 個群體，玩 repeated donor game（每次捐出 cost c、收到乘數 a > 1 的利益）。有 individual mode（全群隨機配對）和 group mode（群內配對）兩種。Agent 的決策由 LLM call 產生，輸入是 system prompt（遊戲描述）+ user message（目前餘額 + strategy string），無對話歷史。
2. **Selection phase**：計算 fitness。群選擇用群體平均 payoff；個體選擇用個體 payoff。高 fitness 的 agent 成為 parent，其 strategy prompt 傳給下一代。
3. **Transmission phase**：子代接收 parent 的 strategy prompt，LLM 以較高溫度對 prompt 進行變異（mutation），產生新的 strategy string。沒有任何人類設計的 prompt template，所有初始策略由 LLM 自己生成。

核心變數：selection level α ∈ [0,1]，α=0 是純個體選擇，α=1 是純群選擇。作者用 replicator-mutator 方程（含經驗 transmission kernel）做理論建模，展示相變發生在臨界 α 值。

### 實驗設計

- **遊戲**：Repeated donor game，multiplier a > 1。Baseline 設定在附錄 B.1。
- **模型**：多個 LLM（包含 GPT-5.4 在內的 frontier 模型）。初始化和傳輸用高溫度，決策用低溫度。
- **主要結果**：
  - 群選擇下合作率隨代數上升並穩定；個體選擇下合作率崩潰到接近零。
  - 這個 gap 在 prompt ablation（移除策略文字中的規範性內容）、alternative game framing（改變遊戲描述）、model swap（換不同 LLM）下都 robust。
  - Replicator-mutator 模型準確預測了相變位置。
  - GPT-5.4 在被告知選擇機制後，第一代就開始調整捐款（anticipatory behavior），其他模型不會。
- **Ablation**：作者測試了多種 prompt 變體和遊戲框架設定，確認群選擇效應不是特定 prompt 或框架的 artifact。

### かに讀後判斷

這篇是 silicon sampling / social simulation 領域本週最重要的論文。它直接回答了「如何讓 LLM agent 群體自發合作」這個根本問題，而不是在個體層面寫 prompt 或做 RLHF。群選擇 vs 個體選擇的實驗設計乾淨有力，replicator-mutator 模型的理論重現更讓結論不只是 empirical observation。對 Morris 的價值：

- 和 2026-05-08～05-12 的 silicon sampling 筆記直接相關：那時討論的是 LLM 能否模擬社會態度，這篇則是在群體層級問「LLM 群體能否自發演化出合作規範」。
- GPT-5.4 的 anticipatory 行為值得深讀——這可能是 model scale 到某個程度後的新興行為，對 silicon sampling 的效度問題有新的啟示。
- 和 CAREB-MAS（本日 2606.23764）形成對比：Group Selection 用演化壓力讓 prompt 篩選出合作，CAREB-MAS 用情感-倫理-信念鏈讓 agent 穩定出現差序格局。前者是 bottom-up 選擇，後者是 top-down 社會認知。

**深讀時優先看**：Figure 1（框架總覽）、Section 3（方法細節，特別是 strategy string 和 mutation 的具體實現）、Appendix B.1（超參數設定）、replicator-mutator 相變圖、GPT-5.4 anticipatory 行為的分析。

## 2. Emergent Relational Order in LLM Agent Societies: From Collective Affect to Authority Stratification (2606.23764)

- **arXiv**: 2606.23764
- **Link**: https://arxiv.org/abs/2606.23764
- **Authors**: Zhiyuan Ji, Xinyu Chen, Ziqi Dai, Shiyun Tang, Chunyu Wei, Yueguo Chen
- **Affiliations**: Renmin University of China, Beihang University, Minzu University of China

### 這篇在說什麼

費孝通的差序格局描述中國鄉村社會是「以自我為中心的同心圓」，合作強度隨關係距離衰減。這篇問的是：差序格局是中國文化的特殊產物，還是某種跨文化通用社會機制的湧現結果？作者提出 CAREB-MAS 框架，把情感控制理論、社會認同理論、涂爾幹集體情感嵌入一個 augmented BDI agent 架構，讓 agent 經過情感-倫理-信念鏈做推理，同時只給環境設定最基本的規則（親屬關係、互惠分配、無中央權威），然後觀察長時間模擬後是否會自發產出差序格局的五個核心現象。

### 主要貢獻

1. **CAREB-MAS 框架**：結合 Affect Control Theory（情感知覺）、Durkheimian ethics（倫理判斷）、Social Identity Theory（群體認同）的 multi-agent simulation，不做文化特定規則編碼。
2. **五個生成命題的驗證**：穩定分工、關係倫理、合作衰減、權威分層、核心-邊緣結構，全部從最小規則集合中湧現。
3. **生產結構對湧現的影響**：對稱稟賦產生機械連帶式的親屬中心整合；互補稟賦產生有機連帶式的功能互賴——這直接對應了涂爾幹的機械/有機連帶分類。
4. **LLM 架構依賴性**：在兩個 LLM 上的 ablation 顯示結果依賴認知架構，不是 generic LLM artifact。

### 方法 / pipeline

CAREB-MAS 的 agent 認知架構：
- **EC（Emotion Component）**：基於 Affect Control Theory，計算情感偏移。
- **ER（Ethical Reasoning）**：基於 Durkheimian 倫理，判斷義務和可接受成本。
- **SIM（Social Identity Module）**：基於 Social Identity Theory，維護自我分類和群體偏好。
- **A-BDI（Affective BDI）**：集體情感約束理性行動，形成 augmented BDI 架構。

環境四階段循環：community formation → deliberation → division of labor → production + psychological update。

只給三個環境規則：親屬關係、基於偏好的分配、最小交互協議。沒有預設的文化特定制度或權威結構。

### 實驗設計

- **驗證五個命題**：P1（穩定分工）、P2（關係倫理）、P3（合作隨距離衰減）、P4（權威分層）、P5（核心-邊緣結構）。
- **對稱 vs 互補稟賦**：兩種生產結構對比，前者產生類似機械連帶的整合，後者產生功能互賴的有機連帶。
- **兩個 LLM 的 ablation**：確認結果不是單一模型的 artifact。
- 主要結果：五個命題全部從最小規則中湧現，且隨生產結構系統性變化。

### かに讀後判斷

這篇和 Group Selection（2606.23343）形成有趣對照：Group Selection 從演化壓力出發讓群體篩選出合作 prompt；CAREB-MAS 從社會認知機制出發讓個體推理出關係格局。前者是外在選擇壓力驅動，後者是內在認知架構驅動。對 silicon sampling 的貢獻在於：差序格局不是中國特有，而是某些普遍社會機制（親屬、互惠、無中央權威）的湧現結果——這讓 LLM 社會模擬可以超越單一文化場景。

不過目前只讀到 HTML 前段，完整實驗結果和定量指標需要看 PDF 的 Section 5 以後。對 Morris 來說，如果對社會模擬的跨文化有效性有興趣，值得深讀；但今日推薦位置留給 Group Selection 和 Harness-MU，因為這兩篇的方法創新更直接。

## 3. EconSimulacra: A Digital Twin Platform of Socio-Economic Systems Powered by LLM Agents (2606.26883)

- **arXiv**: 2606.26883
- **Link**: https://arxiv.org/abs/2606.26883
- **Authors**: Ryu Hashimoto et al.

### 這篇在說什麼

現有的 LLM 社會模擬器通常把經濟、移動、社交網路分開建模，但真實社會行為是跨領域耦合的。EconSimulacra 提出一個多 agent 模擬器，透過共享內部狀態（stress level）將消費經濟、移動和社交網路耦合在一起。Agent 在不同領域累積的經驗被存入記憶並轉換為共享內部狀態，連接異質領域的決策。作者用一個案例研究展示：共享內部狀態機制重現了線上社交注意力和線下本地知名度之間的非線性關係。

### 主要貢獻

1. **跨領域耦合的多 agent 社會模擬器**：透過共享內部狀態機制連接經濟、移動、社交三個領域。
2. **共享內部狀態機制**：stress level 作為跨領域的仲介變數，讓 agent 能在不同決策領域間權衡。
3. **非線性跨領域動力的湧現驗證**：線上注意力 vs 線下知名度的冪律/非線性關係被重現。

### 方法 / pipeline

EconSimulacra 的核心設計是：
- 三個領域（消費經濟、移動、社交網路）各有自己的決策邏輯。
- Agent 在每個領域的經驗被存入記憶，並轉換為 stress level。
- Stress level 反過來影響所有領域的決策——這就是跨領域耦合的機制。
- 沒有人為設定跨領域的規則或約束；耦合完全透過共享內部狀態實現。

### 實驗設計

目前只從 abstract 和 landing page 確認到：50 個模擬用戶、1,550 個恢復目標。案例研究重現了線上社交注意力和線下知名度的非線性關係。具體的 baseline、metric、ablation 需要看全文 PDF。

### かに讀後判斷

這篇的跨領域耦合思路對 silicon sampling 有意義——真實社會行為不會只在單一領域內發生。但目前只能確認 abstract 層級的資訊，無法驗證方法細節和實驗品質。作為一般收錄篇，標記為「僅 abstract 層級快速掃描」。如果 Morris 對數位孿生社會模擬有興趣，可以深讀 PDF 看 agent 記憶和跨領域狀態的具體實現。
