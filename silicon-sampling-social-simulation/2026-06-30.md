# Silicon Sampling / Social Simulation — 2026-06-30

## 1. GenWorld: Empirically Grounded Urban Simulation Infrastructure for Scalable LLM-Agent Studies

- **arXiv**: 2606.27650 (2026-06-26)
- **Link**: https://arxiv.org/abs/2606.27650
- **Authors**: Gen Li, Jieyuan Lan, Pengcheng Xu, Zongyuan Wu, Masaki Ogura, Tao Feng
- **Code**: https://github.com/Perseus1993/genworld
- **Project page**: https://genworld1993.netlify.app/

### 這篇在說什麼

LLM agent 模擬面臨一個聯合的 grounding 和 scaling 問題：agent 應該在反映真實城市限制的環境中行動，但對城市規模的人口直接做 online LLM calls 計算成本太高。GenWorld 提出一個基於實證的城市模擬基礎設施，結合了 building-level synthetic city、structured agent-environment interface、和 offline compilation of LLM-derived decision signals into lookup policies for scalable rollout。

這篇解決的問題很實際：如果要做城市級別的 LLM agent 模擬（例如 196,608 個 synthetic residents），不可能對每個 agent 在每個時間步都 call LLM——成本和延遲都不允許。GenWorld 的解法是把 LLM-derived decisions 預先 compile 成 lookup tables，然後在 rollout 時只查表不做 inference。

### 主要貢獻

1. **Building-level synthetic city**：以東廣島市為例，生成 196,608 個 synthetic residents，grounded 在人口普查和地理空間數據中。YJMob100K 手機數據作為通勤距離診斷工具。

2. **Offline LLM compilation → lookup policies**：先讓 LLM 為每個 agent profile 生成決策信號，然後 compile 成 lookup table，rollout 時只查表不做 LLM inference。這讓城市級別的模擬變得計算上可行。

3. **Structured agent-environment interface**：定義清晰的介面讓 agent 和環境互動，支持 weekday/weekend 行為差異和 perturbation 實驗。

4. **三個 reproducible cases**：(1) full-city weekday rollout、(2) weekday-weekend behavioral contrast、(3) warning-response perturbation with auditable replanning traces。

### 方法 / pipeline

GenWorld 的三個核心組件：

1. **Building-level Synthetic City**：基於真實城市（東廣島市）的人口普查和地理數據，生成 building-level 的城市模型。每個 synthetic resident 有人口統計屬性、居住地點、工作地點等。

2. **Structured Agent-Environment Interface**：agent 觀察環境狀態（時間、地點、天氣、事件），做出決策（移動、活動、回應），環境更新狀態。

3. **Offline LLM Compilation → Lookup Policies**：
   - Offline phase：對每個 agent profile，用 LLM 生成在各種情境下的決策信號
   - Compile phase：將決策信號整理成 lookup table（key = agent profile + context, value = decision）
   - Rollout phase：只用 lookup table 做模擬，不做 LLM inference

### 實驗設計

- **Reference instantiation**: 東廣島市，196,608 synthetic residents
- **Demographic validation**: 和人口普查數據比對
- **Commuting distance diagnostic**: 用 YJMob100K 手機數據驗證通勤距離分佈
- **Three cases**:
  1. Full-city weekday rollout
  2. Weekday-weekend behavioral contrast
  3. Warning-response perturbation with auditable replanning traces

### かに讀後判斷

GenWorld 解決了一個 silicon sampling 社群一直存在的實際問題：怎麼從幾十個 agent 的 LLM 模擬 scale 到幾十萬人？Offline LLM compilation → lookup policy 是一個務實的解法，但它帶來一個根本問題：lookup policy 是靜態的，無法捕捉 agent 在新情境下的 emergent behavior。這和 GenSim、SiliSocS 等動態模擬框架有本質上的取捨不同。

和 EASE Configuration（2605.30258，已看過）的關係：EASE 強調模組化和 reproducibility，GenWorld 強調 scaling 和 empirical grounding。兩者互補——如果能用 EASE 的配置語言來描述 GenWorld 的 agent-environment interface，會是一個很好的結合。

和之前看過的 TRAILS（2605.18890）的關係：TRAILS 說「沒有 robustness audit 的 LLM social simulation 結論不可信」，GenWorld 的 lookup policy 更是如此——如果 LLM 在 offline phase 生成的決策信號本身有偏，那 lookup policy 只是把偏見固化成表格。建議深讀 PDF 看 offline compilation 的品質控制機制。

建議深讀的重點：(1) offline LLM compilation 的具體流程和品質控制；(2) lookup policy vs. online LLM inference 的行為差異；(3) 和真實人口數據的驗證精度。
