# Silicon Sampling / Social Simulation — 2026-07-03

## 1. Calibrating the Instrument: Controllability of an LLM-Driven Synthetic Population

- **arXiv**: 2607.00910
- **Link**: https://arxiv.org/abs/2607.00910

### 這篇在說什麼

Generative Synthetic Populations（GSP）——統計人口合成 + agent-based modeling + LLM agent 的交匯——正快速發展，用於城市模擬和機構溝通研究。但這篇問的不是「GSP 能不能模擬真人」（外部效度），而是更基本的問題：GSP 能不能追蹤自己施加的潛在結構？作者稱之為「可控性」（controllability）。這是物理學家的直覺：在用新探測器量測未知訊號之前，先用已知強度的源來校準儀器反應函數。

作者建構了虛構城鎮 Montelago，120 個有已知潛在態度結構的合成 persona，暴露於七種從強正向到強負向的實驗條件（關於市立自來水管的機構溝通），在三個溫度下（0.2, 0.5, 0.7）評估七項預註冊準則（fidelity、stability、noise floor、specificity、sensitivity、ordering）。全部通過。

更重要的發現來自一個校準失敗轉診斷的成功：一個設計為「弱正向」的訊息被儀器判讀為功能負向，追蹤後發現文字中包含未解問題、不確定性和機構被動性。重新設計後恢復預期排序，效果與 agent 潛在信任產生交互作用——這不是設計時預期的。

### 主要貢獻

1. **首次系統性提出 GSP 可控性問題**：在問外部效度之前，先問內部效度——GSP 是否對已知刺激做出有序、可複製、有群體結構的反應。這在文獻中是新的定位。
2. **SIVE 實驗設計**：虛構 Montelago 城鎮 + 120 persona + 七種實驗條件 + 七項預註冊準則，刻意去除真實情境的混雜因素，只保留校準所需的最小結構。
3. **校準失敗的診斷價值**：「弱正向」訊息被判讀為負向，這不是 bug 而是儀器在告訴你：你的刺激文字裡有不確定性和被動性。重新設計後恢復排序，且效果與潛在信任交互作用——這是設計時沒預期的微觀動力學。
4. **單一 profile 雜訊子實驗**：儀器內在量測雜訊約為跨 agent 估計的一半，且跨溫度穩定——儀器比表面看起來更精確。

### 方法 / pipeline

- **人口生成**：用統計力學方法（Gibbs–Glauber dynamics + persistent contrastive divergence）從官方統計 marginals 合成人口，再嵌入 LLM persona。
- **實驗設計**：七個實驗條件（從強正向到強負向），每個 persona 在三個溫度下各跑一次。
- **評估準則**：C1–C7 分別對應 fidelity、stability、noise floor、specificity、sensitivity、ordering 等。
- **刺激設計**：關於市立自來水管系統的機構溝通文字，刻意選擇無真實對應、無倫理重量的虛構場景。
- **微觀分析**：除聚合指標外，也追蹤個別 agent 的反應軌跡，發現心理連貫的微觀動力學。

### 實驗設計

- **人口**：120 synthetic personas，已知潛在態度結構（信任、風險感知等維度）。
- **刺激**：7 個實驗條件，3 個溫度設定，1 個單一 profile 雜訊子實驗。
- **主要結果**：七項準則在所有溫度下通過。「弱正向」訊息被判讀為負向→重新設計→排序恢復且效果與潛在信任交互作用。
- **雜訊估計**：單一 profile 雜訊約為跨 agent 估計的 50%，跨溫度穩定。
- **開放資源**：互動式 explorer（https://mirko-degli-esposti.github.io/montelago-explorer/）。
- **限制**：最小模型——無空間嵌入、無移動、無社交網路、無 agent 間互動。外部效度問題被刻意擱置。

### かに讀後判斷

這篇是 silicon sampling 文獻中少見的「儀器校準」視角，而非直接比較 GSP 與真人。它問的問題邏輯上先於外部效度，且校準失敗轉診斷的發現很有說服力。和昨天 2605.12898（When Do LLMs Generate Realistic Social Networks?）互補：那篇問網路結構忠實度，這篇問態度回應可控性。值得深讀 Section 4（Montelago 設計細節）、Section 6（量化結果表格）、Section 7（微觀軌跡分析）。對 Morris 當前研究最相關的是可控性框架本身——如果你要用 silicon sampling 做社會模擬，SIVE 的七項準則是可以直接用的工具。

## 2. Not-quite-human Tastes: The Stylized Omnivorousness of LLM Survey Surrogates

- **arXiv**: 2606.30085
- **Link**: https://arxiv.org/abs/2606.30085

### 這篇在說什麼

過去 silicon sampling 文獻集中在政治態度（投票、政策偏好），這篇把視角延伸到文化品味——人們喜歡什麼音樂、什麼類型的藝術。用 OpenAI、Anthropic、DeepSeek 的 LLM 模擬 Survey of Public Participation in the Arts（SPPA）的 9249 個受訪者，每個生成 30 個硅樣本，共 277,470 個硅受訪者。三個核心發現：（1）硅樣本有系統性正向偏差，喜歡什麼都說喜歡，導致生態估計膨脹；（2）品味之間的複雜關聯結構在硅樣本中完全喪失；（3）品味與社會空間的已知關聯幾乎沒有保留——年齡關聯被衰減、階級關聯被復古式 resurrected、性別和種族關聯被漫畫化。

### 主要貢獻

1. **把 silicon sampling 從政治態度延伸到文化品味領域**——這是品味社會學和 silicon sampling 的交叉新領域。
2. **三層忠實度分析框架**：生態忠實度（ecological fidelity）、關聯忠實度（relationality fidelity）、社會空間忠實度（taste-space alignment），分層診斷硅樣本在不同面向的偏差。
3. **發現系統性正向偏差不是 WEIRD 偏差**：硅樣本的個體層面正向偏好無法用 LLM 的 WEIRD 偏差解釋。
4. **品味關聯結構崩潰**：真實品味之間的複雜相關結構在硅樣本中完全消失。

### 方法 / pipeline

- **資料**：SPPA（Survey of Public Participation in the Arts），9249 個真實受訪者，17 個音樂類型。
- **硅樣本生成**：每個受訪者 × 3 模型 × 30 次 = 277,470 個硅受訪者。
- **分析**：（1）生態忠實度：Jaccard 距離比較真實和硅樣本的品味分布；（2）關聯忠實度：比較真實和硅樣本的品味相關矩陣；（3）社會空間忠實度：mixed-effects meta-regression 比較品味與社會變量的關聯。

### 實驗設計

- **三個模型**：OpenAI、Anthropic、DeepSeek（具體模型版本需看全文）。
- **核心結果**：（1）系統性正向偏差——硅樣本說什麼都喜歡，不是 WEIRD 偏差；（2）相關矩陣結構崩潰；（3）年齡關聯衰減、階級關聯復古、性別/種族關聯漫畫化。
- **限制**：目前只從 abstract 和 HTML 前段確認到三層分析框架和主要發現，具體模型版本、meta-regression 細節、所有 17 個類型的結果需要看全文 PDF。

### かに讀後判斷

這篇和 2607.00910 是同一週 silicon sampling 的兩個重要視角：2607.00910 問「儀器可控性」，這篇問「外部效度的三個層面」。對品味社會學的研究者來說，三層分析框架很有用。但要注意正向偏差的解釋：是模型訓練資料的偏差，還是 prompt 架構的偏差？全文的 mixed-effects 分析應該有更細的分解。值得深讀 Section 2.2（忠實度框架）、Section 4（結果）和 Discussion。和前幾天的 2605.12898（LLM 社會網路生成）形成互補：那篇問網路結構，這篇問品味結構。

## 3. Using AI Agents to Automate Black-Box Audits of Personalization Algorithms at Scale

- **arXiv**: 2606.30801
- **Link**: https://arxiv.org/abs/2606.30801
- **閱讀層級**: 僅 abstract 層級快速掃描（HTML 轉換失敗，無法取得全文）

### 這篇在說什麼

用生成式 AI agent 作為行為引擎，驅動合成帳號對個人化演算法做黑箱審計。每個 agent 被賦予固定 persona（基於人口統計和政治調查資料），透過推理平台內容並選擇行動來互動。因為行為在每個 persona 內固定，但平台可見的訊號（年齡、性別、地點）可以實驗性地操控，這使得反事實審計成為可能。案例研究：在 2024 美國大選後部署 1120 個 agent 在 X 平台上，14 個 persona × 三個反事實條件，收集超過 20 萬次內容曝光。發現 X 的演算法 feed 相對於時間排序 feed 放大了有毒、極化、政治性和右傾內容，放大程度隨用戶意識形態變化。

### 主要貢獻

1. **反事實審計框架**：行為固定、屬性可操控，解耦用戶屬性與行為的混淆。
2. **大規模部署**：1120 個 agent、14 個 persona、3 個反事實條件、20 萬+ 內容曝光。
3. **因果分解**：群體效應多為 null，但子群效應在方向和大小上變化顯著——這是個人化演算法審計的重要發現。

### 方法 / pipeline

（僅 abstract 層級）每個 agent 被賦予固定 persona → agent 透過推理選擇行動（like、retweet、scroll）→ 平台演算法根據可見屬性個人化內容 → 比較演算法 feed vs 時間排序 feed → 反事實條件下改變可見屬性。

### 實驗設計

（僅 abstract 層級）1120 agents × 14 personas × 3 counterfactual conditions；超過 200,000 內容曝光；X 平台；2024 美國大選後。群體效應 null，子群效應方向和大小異質。具體指標、統計方法、agent 架構細節需看全文 PDF。

### かに讀後判斷

這篇站在 silicon sampling 和演算法審計的交叉點，和 2607.00910 的 GSP 可控性以及 2606.30085 的品味忠實度形成三角。反事實設計是亮點。但只能從 abstract 確認框架和大致結果，agent 架構、prompt 設計、統計檢定方法都需要全文。若 Morris 對演算法審計有興趣，值得深讀 PDF；如果重點在 silicon sampling 本身，2607.00910 和 2606.30085 更直接相關。
