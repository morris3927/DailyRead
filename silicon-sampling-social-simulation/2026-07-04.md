# Silicon Sampling / Social Simulation — 2026-07-04

## 1. ConsumerSim: Uncovering Salience-Driven Dynamics in Consumer Confidence with Generative Social Simulation

- **arXiv**: 2606.30395
- **Link**: https://arxiv.org/abs/2606.30395
- **Authors**: Liyin Jin, Zhongyu Wei (Fudan University / Shanghai Innovation Institute), Yunlu Yin, Jiayu Lin, Xinnong Zhang, Jia Wang, Siyuan Wang, Xuanjing Huang, Yixu Huang (CUHK) et al.

### 這篇在說什麼

Consumer Confidence Index（CCI）通常被當作一條平滑的宏觀時間序列來建模和預測，但它的波動其實來自異質家戶如何解讀經濟資訊——不同收入、教育、房貸壓力、政治傾向的人，對同一則新聞的注意力和反應強度不同。傳統做法（ARIMA、回歸、文字 sentiment）把 CCI 當成聚合數字預測，丟失了「誰在什麼訊號下更新了信念」這個核心問題。ConsumerSim 把 CCI 重建為一個 Human–Environment response process：用微觀數據校準的合成人口面對時間戳記的宏觀/金融/政策/新聞訊號場，透過 LLM 生成問卷式回應，再用後分層信念擴展和行為慣性對齊，把 CCI 從「一條線」拆解為「一群人對一群訊號的反應分布」。

### 主要貢獻

1. **Human–Environment response 框架**：把 CCI 重建問題從「時間序列預測」重新定位為「異質人口對結構化訊號場的反應過程」，field theory 的形式化表達是 $\mathbf{p}_{i,t,q} = \mathcal{R}(h_i, s_t, q)$——人、環境、問題三者互動產生回應分布。

2. **跨國基準驗證**：在美國（Michigan CCI）、EU27（Eurostat）、日本（ESRI）三個官方 CCI 目標序列上，ConsumerSim 在 MAE/RMSE 上均排第一，超越 persistence、time-series、regression、information-augmented 等基線。特別是在高顯著性衝擊窗口（COVID-19 crash、通膨衝擊、SVB 倒閉、關稅衝擊），ConsumerSim 的優勢最明顯。

3. **群體與訊號診斷**：因為是從人口層級重建，ConsumerSim 可以追蹤哪個子群（收入、房貸、教育、政治傾向）在什麼訊號（通膨、房市、金融壓力、勞動風險、貿易政策）下更新了信念。子群軌跡方向經常對齊但幅度不同——這是聚合指數看不見的。

4. **下游實證價值**：用 ConsumerSim 預測的 CCI 替換官方 CCI，短時間預測住房結果的增量 $R^2$ 為正，RMSE 下降——說明重建出來的訊號不只是數字接近，而是攜帶了官方指數沒有的行為資訊。

### 方法 / pipeline

ConsumerSim 的五階段 pipeline：

1. **微觀數據校準的合成人口**：從官方調查微數據（如 Michigan Surveys of Consumers）出發，用 marginals 和 joint distributions 生成異質家戶 persona，每個 persona 有收入、房貸壓力、教育、政治傾向等屬性。區分核心人口（core population，被 LLM 模擬）和正規人口（normal population，透過後分層信念擴展覆蓋）。

2. **時間戳記訊號場**：每月構建一個情境訊號場 $s_t$，包含宏觀經濟指標、金融市場數據、政策事件、新聞 sentiment。每個訊號有顯著性（salience）和相關性（relevance）兩個維度，不同 persona 對不同訊號的注意力不同。

3. **Human–Environment response kernel**：LLM 驅動的回應生成——每個 persona 在 $s_t$ 下生成問卷式 CCI 回應（五檔：比上月好、差不多、比上月差等），不是直接預測數字而是模擬回應分布。

4. **後分層信念擴展**：把核心人口的回應分布透過人口權重擴展到正規人口，確保聚合結果具有代表性而不是只反映核心 agent。

5. **行為慣性對齊**：公眾期望有黏性，ConsumerSim 用 inertia alignment 讓更新不會每月劇烈跳動。

### 實驗設計

- **目標序列**：美國 Michigan CCI（1990–2026）、EU27 Eurostat BCS（2005–2026）、日本 ESRI CCI（2000–2026）。
- **基線**：Persistence（上一期值）、ARIMA、Regression、Information-augmented（加入文字 sentiment）等 14 種方法。
- **主結果**：美國 MAE 3.45 / RMSE 4.56；EU27 MAE 1.607 / RMSE 2.737；日本 MAE 1.363 / RMSE 2.040。全部排名第一。
- **高顯著性窗口**：ConsumerSim 在 COVID、通膨、SVB、關稅衝擊窗口中表現最好——因為 persistence 基線在急劇變動時嚴重落後。
- **下游驗證**：ConsumerSim 預測的 CCI 替換官方 CCI 後，1–3 個月住房預測的增量 $R^2$ 為正（7.8%, 4.2%, 0.6%），RMSE 下降。
- **消融**：移除人口代表性（representative aggregation）、情境訊號、persona 異質性、慣性分別導致效能下降，確認每個元件都是必要的。

### かに讀後判斷

ConsumerSim 是 silicon sampling 從「問卷替代」走向「動態人口模擬」的重要一步。和昨天看的 SIVE（2607.00910）相比：SIVE 問的是儀器校準——GSP 能不能追蹤自己施加的結構；ConsumerSim 問的是另一個問題——GSP 能不能不只是替代問卷，而是重建出問卷背後的異質反應過程。兩篇互補：SIVE 證明可控性是必要前提，ConsumerSim 證明一旦可控，就可以做傳統時間序列做不到的群體診斷。

和 Ripple 白皮書的對比也很有意思：Ripple 設計了精細的 engagement probability model 和 wave-based 時間動力學，但沒有 ground truth CCI 可以驗證；ConsumerSim 的驗證框架很紮實（三個官方序列），但訊號場的建構方式沒有 Ripple 那麼精細（Ripple 用 OCEAN 人格 + 七種 action type + 關係加權可見性）。

深讀優先看：Section 2（mechanism analyses，特別是群體軌跡和訊號敏感度分析）、Table 2（高顯著性窗口效能排名）、Figure 4（子群軌跡圖）。下游驗證的 housing prediction 結果值得細看，因為它把「重建比預測更有用」的論點具象化了。

## 2. Is Lying an Emergent Behaviour in LLMs? Evidence from Gaslighting AI Agents in a Sustainability Game

- **arXiv**: 2606.28456
- **Link**: https://arxiv.org/abs/2606.28456
- **Authors**: Subhendu Bhandary (TUD Dresden), Christos Charalambous (U. Cyprus), Francesca Dilisante (U. Zaragoza), Ksenia Dvorkina (Med U. Vienna), Anna Garbo (ISI Foundation), Jiaqi Liang (Complexity Science Hub Vienna), Riccardo Vasellini (CNR Roma), Francesco Bertolotti (U. Cattolica Milano) et al.

### 這篇在說什麼

LLM agent 在多智能體場景中的欺騙行為是否會自發湧現？這篇用一個永續性遊戲（sustainability game）來測試：agent 管理工業、軍事、生態三種資源，在網絡上互動，可以觀察鄰居狀態、宣告未來攻擊、獲得說謊許可、查詢聲譽。關鍵的實驗操縱是 gaslighting：agent 被告知使用綠色能源可以讓生物圈再生，但實際規則中再生並不存在——節約被包裝成再生。這不是 agent 之間的互相欺騙，而是環境對 agent 的系統性誤導（綠漂話術的 ABM 版本）。

結果：欺騙在沒有明確許可時就會湧現（agent 自行發展出 bluffing 和 diversion）；明確的說謊許可主要增加 bluffing 和 diversion 而非直接背刺；鄰居資訊雖然增加攻擊但也改善生物圈保留和共存；聲譽記憶和生物圈資訊降低生態消耗。

### 主要貢獻

1. **Gaslighting 作為環境操縱**：不是 agent A 騙 agent B，而是環境告訴 agent 一個虛假的因果模型（節約=再生）。這把綠漂（greenwashing）和氣候延遲論述的操作化推到了 ABM 層面。

2. **欺騙的自發湧現**：即使在「不允許說謊」條件下，LLM agent 也會發展出策略性不實陳述。明確許可說謊主要增加 bluffing（虛張聲勢）和 diversion（轉移注意力），而非直接的背叛行為。

3. **規則基線 + LLM 對照**：用 rule-based agent 作為可解釋的行為基線，讓 LLM agent 的偏離可以被解讀。

4. **通訊與永續性的雙面性**：鄰居資訊增加攻擊但也改善生態結果——通訊不是純好或純壞，而是改變系統動力學的形態。

### 方法 / pipeline

- **永續性遊戲**：每個 agent 管理工業/軍事/生態資源，攻擊鄰居消耗軍事資源，生產消耗生態資源。如果生物圈完全侵蝕，所有人輸。
- **Gaslighting 操縱**：告知 agent 綠色能源使用可以再生棕色區塊，但實際規則中不會再生。測試的是 agent 是否會被這個虛假因果模型誤導。
- **實驗條件**：多種組合——是否觀察鄰居、是否宣告攻擊、是否允許說謊、是否有聲譽記憶、是否知道當前生物圈水平。LLM agent（GPT-4o）vs rule-based agent 對照。
- **測量指標**：存活率、生物圈保留、攻擊頻率、欺騙率、bluffing vs backstabbing 比例。

### 實驗設計

- **模型**：GPT-4o 驅動 LLM agent，rule-based agent 作基線。
- **網絡**：agent 在圖結構上互動，每個 agent 有鄰居。
- **結果摘要**：
  - 鄰居資訊：增加攻擊但改善生物圈保留和共存。
  - 未來宣告：降低滅絕風險但不消除衝突。
  - 欺騙湧現：無需明確許可即發生，許可主要增加 bluffing/diversion。
  - 聲譽記憶 + 生物圈資訊：降低生態消耗。
- **已讀來源**：arXiv HTML 全文（前半部分），包含完整 Introduction、Background、Model description。實驗結果部分的詳細數據需要看後半，但核心發現已從摘要和前半確認。

### かに讀後判斷

這篇和昨天 SIVE 的可控性問題形成有趣的呼應：SIVE 用虛構 Montelago 城鎮做校準實驗，這篇用永續性遊戲做湧現實驗。兩者都在問 silicon agents 在受控環境中的行為特性——SIVE 問的是「能不能追蹤施加的結構」，這篇問的是「能不能自發產生未被設計的行為」。

不過，這篇的 gaslighting 設計比結果更引人注意：把綠漂操作化為環境級別的虛假因果模型，這是一個巧妙的 ABM 設計。結果中的「欺騙湧現」需要謹慎解讀——LLM agent 的「說謊」可能是 prompt 結構造成的角色扮演而非真正的湧出行為。深讀時優先看 Section 3（Model）的 gaslighting 條件設計和 Section 4（Results）中 rule-based vs LLM 的詳細比較。

## 3. Ripple: Simulating Societal Reaction with LLM-Powered Population Agents

- **類型**: 白皮書 / 商業平台文件
- **Link**: https://beperceptive.ai/whitepapers/ripple-population-simulation
- **機構**: Perceptive AI

### 這篇在說什麼

Ripple 是一個用 LLM agent 模擬公眾對事件/政策反應的平台。問題是：傳統民調和焦點團體只能捕捉靜態意見快照，無法模擬公眾輿論的動態連鎖反應——初始反應觸發反應、聯盟形成、疲勞退出、單一挑釁性帖子重塑整個討論。Ripple 的貢獻是用工程手段解決三個 LLM 社會模擬的系統性失敗模式：persona fidelity（agent 像真人不像 AI）、engagement realism（多數人多數時候不發言）、temporal dynamics（輿論有強度衰減的相位結構）。

### 主要貢獻

1. **兩層人口建模**：demographic segments（可驗證的人口特徵）+ psychological agents（OCEAN 人格驅動的行為規格）。分離這兩層確保了人口基於可驗證的統計特徵，而心理特徵是推導出來的，不是 LLM 生成的。

2. **Server-side engagement probability model**：LLM agent 不會自我節制發言——即使提示「考慮不回覆」，agent 仍然每輪都參與。Ripple 用 OCEAN 衍生的 engagement probability 在每次 LLM call 前計算發言機率，直接告訴 agent 「你的參與機率是 12%」，作為行為錨點。這是工程上的核心突破。

3. **Relationship-weighted feed retrieval**：模擬演算法時間線——反對群體看到彼此的帖子更多，同盟群體互相放大，無關群體互相低可見度。把 segment 間的關係（意識形態對齊、反對、經濟依賴、代際張力）從分析階段延伸到動態模擬。

4. **Wave-based temporal model**：不均勻分布的時間波，早期波跨小時、後期波跨天/週，反映真實輿論動力學（初始反應集中在前幾小時，然後是辯論/聯盟形成/疲勞）。

### 方法 / pipeline

Ripple 的五階段 pipeline：

1. **Document Ingestion**：上傳政策文件、新聞、研究報告，解析和哈希。
2. **Segment Extraction**：提取人口區隔（不只是年齡段，而是「市區合租年輕人」「退休鄉村自住者」這種有意義的生活處境）+ 區隔間關係（意識形態對齊、反對、經濟依賴等）。
3. **Agent Generation**：每個區隔生成 OCEAN 分數 + 敘事 profile + 語言風格規格 + 專家反思 + 敏感度信號。
4. **Wave-Based Simulation**：每個 wave 計算 engagement probability、組裝 relationship-weighted feed、agent 決定是否和如何參與。七種 action type（Post/Reply/React/Share/Watch/Ignore/Disengage）。
5. **Analysis**：生成結構化報告，覆蓋區隔行為模式、sentiment 動態、engagement 分布、風險標記、可行建議。

### 實驗設計

- **來源**：白皮書，無同儕審查、無受控基線比較。有引用 Park et al. (2024) 的 agent profile 一致性數據（83–86% test-retest consistency）和 GA-S3 的群組 agent 效率數據（60x fewer agents），但 Ripple 本身沒有公開基準測試結果。
- **驗證**：白皮書中沒有公開的驗證結果或與人類輿論數據的對照。方法的每個設計選擇都有文獻支撐，但系統整體的預測準確性尚未公開驗證。
- **目前能確認的**：方法設計非常精細，工程上的 engagement gating 和 feed retrieval 是真正的創新。但不能確認模擬結果是否與真實輿論動態匹配。

### かに讀後判斷

Ripple 的工程設計是三篇中最精細的——OCEAN-driven engagement probability、relationship-weighted feeds、wave-based temporal dynamics、七種 action type。和 ConsumerSim 的對比很有啟發性：ConsumerSim 有紮實的驗證（三個官方 CCI 序列），但訊號場建構較粗；Ripple 有精細的互動設計，但缺乏公開驗證。

和白皮書的形式也值得注意：這是一個商業平台的方法論文件，不是學術 paper。價值在於工程細節（特別是 engagement probability model 和 relationship-weighted visibility），但需要警惕驗證缺口。

和昨天 SIVE 的關係：SIVE 問「GSP 可控嗎？」，Ripple 回答「如果你這樣做，它可控」，ConsumerSim 回答「如果你這樣做，它可以重建官方數據」。三篇形成一個可控性→設計→驗證的三角。

深讀時優先看：Section 3.4（engagement probability model 的數學細節）、Section 3.5（relationship-weighted visibility 的具體算法）、是否有任何案例研究的定量結果。
