# Silicon Sampling / Social Simulation — 2026-07-16

## 1. Silicon Sampling via Cross-Survey Transfer (2607.03091)

- **arXiv**: [2607.03091](https://arxiv.org/abs/2607.03091)
- **Authors**: Yihuang Kang et al.
- **Submitted**: 2026-07-03

### 這篇在說什麼

Silicon sampling——用 LLM 模擬人類問卷受訪者——近兩年吸引了很多關注，但現有評估幾乎都停留在分布層級比較（例如看 LLM 產生的意見分布是否接近真實民調分布）。這篇論文指出：分布接近不代表 LLM 真的在「個體層級」上正確預測了特定受訪者的回答——它可能只是在做模式匹配。為了解決這個問題，作者提出了 **cross-survey transfer**：給 LLM 某位受訪者在一份子問卷上的回答，要求它預測同一人在另一份完全不同的子問卷上的回答。這比分布比較嚴格得多，因為它測的是 LLM 能否從局部資訊推斷個體的完整態度結構。

### 主要貢獻

1. **Cross-survey transfer 評估框架**：超越分布比較，進入個體層級預測——這是 silicon sampling 評估方法論的一個重要進步。之前很少有研究要求模型在沒看過目標題目的情況下，根據同一受訪者的其他回答來做預測。
2. **穩定的構念可預測性階層**：在台灣 TEDS 2024 資料上，政黨態度（67%）> 其他態度 > 主權態度（23%），這個階層在不同模型間穩定出現，暗示 LLM 對某些政治態度的內建知識比其他更強。
3. **對 variance collapse 和 safety alignment 的細緻化理解**：這兩個常被視為 LLM silicon sampling 根本限制的問題，實驗發現比想像中更 nuanced——variance collapse 也影響監督式模型（不只是 LLM 的問題），alignment effects 在不同模型家族之間差異很大。

### 方法 / pipeline

- **資料來源**：TEDS 2024（台灣選舉與民主化調查），包含政黨認同、統獨立場、政策態度等多維度問卷。
- **Cross-survey transfer 設計**：將問卷題目分成兩半（A 和 B），給模型受訪者在 A 半的回答，要求預測 B 半的回答。這樣每個預測目標都是模型「沒看過」的題目。
- **模型**：三個開源 LLM（27B–120B 參數），加上 supervised baselines（random forest）。
- **比較基準**：zero-shot LLM vs. 同人口的 supervised random forest。關鍵比較是「zero-shot LLM 在完全沒看過目標題目的情況下，能多接近用同人口資料訓練的監督式模型」。

### 實驗設計

- **主要 metric**：個體層級預測準確率（accuracy）。
- **核心結果**：
  - Zero-shot LLMs 達到 52% 準確率（在真正沒看過的題目上）。
  - 與監督式 random forest 的差距只有 6 個百分點（58% vs 52%）。
  - 構念可預測性從高到低：政黨態度（67%）→ … → 主權態度（23%）。
  - Variance collapse 不是 LLM 獨有問題，supervised 模型也受影響。
  - Alignment effects 因模型家族而異，不能一概而論。
- **已讀來源**：arXiv abstract + 網路搜尋取得的詳細摘要。arXiv HTML 版本不可用，PDF 全文未直接抽取。目前能確認：評估框架設計、主要數字、構念階層結論；無法確認細節如具體題目劃分方式、模型名稱、完整 ablation。

### かに讀後判斷

這篇是 silicon sampling 方法論的重要進展。之前的 silicon sampling 評估（包含我們追蹤過的 ConsumerSim 等）大多停留在分布比較，cross-survey transfer 把評估推到個體層級，是一個有意義的嚴格化。特別值得注意的是：

1. **台灣 TEDS 作為測試場景**很有意義——台灣的政黨認同和統獨態度是高度結構化的，LLM 對政黨態度的 67% 準確率說明模型確實從訓練資料中學到了某種態度結構，但 23% 的主權態度預測準確率說明這種結構不延伸到所有議題。
2. **與我們追蹤的 ConsumerSim（2606.30395）互補**：ConsumerSim 處理的是「LLM 能否從訊號場重建人群的動態反應」，這篇處理的是「LLM 能否從局部態度重建個體的完整態度結構」。兩者都在問 LLM 的社會模擬能力到底到哪裡，但切入角度不同。
3. **值得深讀的 section**：方法論的 cross-survey transfer 設計（如何切分問卷）、variance collapse 和 alignment 的細部分析、以及台灣特定政治脈絡下的解讀。

## 2. BOUNDARY_SYNC: Measuring Communication-Induced Representational Coupling in Multi-Agent LLM Systems (2607.01600)

- **arXiv**: [2607.01600](https://arxiv.org/abs/2607.01600)
- **Authors**: Zewen Liu et al.
- **Submitted**: 2026-07-02

### 這篇在說什麼

當多個 LLM agent 互相溝通時，它們的輸出會趨同嗎？這個問題對 multi-agent 系統設計至關重要——如果溝通導致同質化，那多 agent 系統的「多樣性優勢」可能被侵蝕。BOUNDARY_SYNC 提出了一個測量協議，用 **Coupling Amplification Factor (CAF)** 來量化溝通引起的表徵耦合。CAF = JSD_cond / JSD_baseline：<1 表示同質化，>1 表示分化，≈1 表示獨立。核心發現是：在 GPT-4o 上，文字溝通確實造成顯著同質化（CAF=0.803），但這個效應是 **stateless** 的——只要從 prompt 中拿掉鄰居資訊，耦合就消失，沒有跨回合的累積收斂。

### 主要貢獻

1. **CAF 測量協議**：把「溝通是否讓 agent 更像」這個模糊問題變成一個可量化、可比較的指標。CAF 用 Jensen-Shannon divergence 的比率正規化，讓不同條件、不同模型的結果可以直接比較。
2. **因果性控制**：不只測了溝通條件，還設計了 no-communication ablation（CAF=0.978，接近獨立）和 prompt perturbation control（用無關 Wikipedia 文字取代鄰居共識，CAF=1.082），證明同質化效應是社交性的，不是「prompt 裡多加任何文字都會這樣」。
3. **群體大小調節方向**：K=5 時同質化，K=3 時 CAF > 1.0（分化趨勢）。這意味著 multi-agent 系統的群體大小不只是參數，而是耦合方向的決定因素。
4. **Stateless 耦合**：per-round JSD 軌跡呈現鋸齒狀——有鄰居資訊時 JSD 下降，移除後立即反彈——沒有累積漂移。這與古典意見動力學模型的預測相反。

### 方法 / pipeline

- **BOUNDARY_SYNC 協議**：Agent 在每回合對刺激物（文字或圖像）產出結構化機率評估，然後收到混合了鄰居輸出的 protocol message。下一回合基於 blended strategy 產出新的評估。
- **CAF 定義**：CAF = mean(JSD_cond) / mean(JSD_baseline)，其中 baseline 是無溝通條件下的 JSD。Bootstrap 95% CI，ratio-of-means resampling。
- **實驗條件**：C1（isolated baseline, K=3）、C3（文字溝通, K=5）、C5（圖像溝通, K=3），加上多個控制組（blend ratio robustness、prompt perturbation、group size variation）。
- **模型**：GPT-4o (N=30) 為主，DeepSeek V4 Pro (N=30) 和 Qwen3.7-Plus (N=10) 為複製。

### 實驗設計

- **核心結果**：
  - GPT-4o 文字溝通：CAF=0.803 [0.740, 0.873]，d=1.30，p<0.001 → 顯著同質化
  - 無溝通 ablation：CAF=0.978 → 效應消失
  - Prompt perturbation control：CAF=1.082 → 無關文字不造成同質化
  - 圖像溝通：CAF=0.834，比例效應與文字可比
  - K=3 時 CAF > 1.0 → 分化趨勢
  - 跨模型差異極大：DeepSeek CAF≈0.034（但受格式 artifact 主導），Qwen 0.391
  - Stateless：toggled consensus 呈鋸齒狀 JSD 軌跡，continuous consensus 在 10 回合內從 JSD 0.44 單調收斂到 0.001
- **已讀來源**：arXiv HTML 全文（主要 section），含方法論、結果、控制實驗。圖表未直接檢視但文字描述完整。

### かに讀後判斷

這篇和 silicon sampling 領域的連結很直接：BOUNDARY_SYNC 測量的是 LLM agent 之間通過溝通產生的意見動力學效應，這正是 silicon sampling 模擬的底層機制之一。如果 agent 溝通天然會同質化（尤其在 K≥5 時），那所有用多 agent 討論/辯論/共識機制的 silicon sampling 設計都需要重新思考多樣性保護策略。

幾個值得注意的點：
1. **Stateless 耦合**是對 DeGroot 模型預測的反例——古典意見動力學假設累積更新，但 LLM agent 的耦合完全由 prompt context 驅動，移除就消失。這對 silicon sampling 模型設計有直接啟示。
2. **K=3 vs K=5 的方向翻轉**非常有趣，暗示小群體可能反而因溝通而分化。但作者自己也標注 K=3 的 CI 尚未完成，需要後續驗證。
3. **DeepSeek 的 near-zero CAF** 被 format artifact 主導而非真正社會耦合，這提醒我們在跨模型比較時要小心格式差異。
4. 值得深讀：Section 4.6 per-round dynamics、Section 5 discussion（特別是對意見動力學的連結）、以及 no-communication ablation 的具體設計。
