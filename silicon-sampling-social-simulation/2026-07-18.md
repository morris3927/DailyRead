# Silicon Sampling / Social Simulation — 2026-07-18

## 1. A Large Language Model-Driven Agent-Based Modeling Framework with Multi-Round Communication for Simulating Vaccine Opinion Dynamics

- **arXiv**: 2607.07387
- **Link**: https://arxiv.org/abs/2607.07387
- **Authors**: Bo Zhang, Na Jiang (HKUST Guangzhou, Xi'an Jiaotong University)
- **Submitted**: 2026-07-08

### 這篇在說什麼

這篇用 Qwen3-8B 整合到 agent-based model 中模擬疫苗意見動態。核心研究問題是：不同的認知模組（記憶模組、prompt 多樣性模組）如何驅動個體決策，進而影響宏觀層級的意見極化？這是一個方法論導向的工作——不是在說「LLM 能完美模擬人類意見」，而是在建立一個框架來系統性地測試哪些認知模組會產生什麼樣的宏觀湧現行為。

### 主要貢獻

1. **LLM-ABM 整合框架**：把 LLM（Qwen3-8B）整合進 agent-based model，用於模擬多輪對話驅動的意見形成。框架使用合成人口資料集和社會網路（household network + scale-free cyber network），共 95 個 agent。
2. **認知模組的系統性比較**：分別啟用和禁用記憶模組和 prompt 多樣性模組，觀察它們對意見極化的影響。發現這兩個模組有相反的效果。
3. **重現非線性行為模式**：框架重現了社會影響的非線性行為模式，達到 agent-based model 的 level 3 validation。

### 方法 / pipeline

- **Agent 初始化**：使用合成人口資料集（Jiang et al., 2024），提取 30 個同工作場所的 agent 及其 65 個延伸網路連結（household + cyber），共 95 個 agent。每個 agent 有社會經濟屬性（年齡、性別、收入、教育程度、醫療保險）。
- **社會網路**：雙層網路——physical household network + scale-free cyber network（社交媒體）。
- **核心模擬引擎**：
  1. Agent 之間進行多輪對話（由 Qwen3-8B 生成）。
  2. 對話後，agent 根據 reflection 調整疫苗意見。
  3. 數學聚合：agent 與所有鄰居互動後，用數學公式更新最終意見。
- **認知模組**：
  - Memory module：agent 記住之前的對話和意見。
  - Prompt diversity module：增加 prompt 的多樣性，避免所有 agent 產生同質化的對話。

### 實驗設計

- **Scenarios**：比較啟用/禁用記憶模組和 prompt 多樣性模組的不同組合。
- **Main findings**：
  - 記憶模組和 prompt 多樣性模組對意見極化有相反的影響（一個促進極化，一個抑制極化）。
  - 框架重現了社會影響的非線性行為模式（level 3 validation）。
- **Limitations**：
  - 只用了 Qwen3-8B 一個模型，未測其他模型。
  - 只有 95 個 agent，規模較小。
  - 疫苗意見動態只是一個 case study，未測其他議題。
- 已讀來源：arXiv HTML 全文前段約 8000 字，涵蓋 abstract、introduction 和部分 methodology；後段結果和討論需 PDF 確認。

### かに讀後判斷

這篇是一個踏實的方法論工作，但創新性有限。它跟之前 2607.00910（Calibrating the Instrument）形成有趣的對比：那篇在做「校準」，問 LLM 模擬的人口是否對已知刺激有有序、可複製、有群體結構的反應；這篇在做「模組化」，問哪些認知模組驅動哪些宏觀行為。兩篇都在回答同一個根本問題：LLM-ABM 的內部效度如何保證？但這篇的方法論深度不如 2607.00910，且只有一個模型、一個議題、95 個 agent。對 Morris 來說，如果正在做 silicon sampling 相關工作，這篇提供了「認知模組對意見極化有相反效果」這個有趣觀察，但不建議作為今日推薦。深讀優先看 Figure 3-4（記憶模組和 prompt 多樣性模組的影響對比）。
