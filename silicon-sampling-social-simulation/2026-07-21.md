# Silicon Sampling / Social Simulation — 2026-07-21

## 1. Collective Cooperation without Individual Fidelity in LLM Agents (2606.30454)

- **arXiv**: 2606.30454
- **Link**: https://arxiv.org/abs/2606.30454
- **Authors**: Henrique Ferraz De Arruda, Carlos Gracia-Lázaro, Alberto Aleta, Yamir Moreno 等
- **Submitted**: 2026-06-29

### 這篇在說什麼

這篇要回答的問題非常尖銳：當我們用 LLM agent 替代人類做 social simulation 時，如果我們只在 aggregate 層面看起來像人（cooperation rate 隨時間的變化趨勢接近），能不能就說 LLM 是 human decision-making 的 faithful proxy？作者用一個大型 networked Prisoner's Dilemma 實驗當 benchmark——這是真人實驗，不是模擬——把九個 open-weight LLM 放進完全相同的 network structure 和 payoff matrix 裡跑，然後在三個層級比較 LLM 與人類：macro dynamics（合作率隨時間的變化）、micro distribution（個人合作傾向的異質性）、decision rule（conditional cooperation 的模式）。結果發現：選出來的 best-match model（llama4:16x17b）在 macro 層面確實能重現合作率的早期下降和後期穩定，但在 micro 層面，LLM population 低估了 individual heterogeneity，conditional cooperation 的 pattern 也跟人類不同——這不是微小的偏差，而是一個系統性的 macro–micro dissociation。

這篇的重要性在於它直接測試了 silicon sampling 目前最核心的 validity 問題之一：如果你只看 aggregate outcome，很多 silicon sample 看起來都通過了「像不像人」的測試；但一旦你拆到個體層級和 decision rule 層級，LLM 的行為機制跟人類不同。這跟 DailyRead 之前追蹤的「LLM-Based Social Simulations Require a Boundary」（2506.19806）和「Too Open for Opinion?」（2510.13884）形成明確對話：Boundary 那篇說 heterogeneity 不夠，Open-Ended 那篇說測量介面會把異質性抹平，而這篇用實驗數據直接證明 macro agreement 不保證 micro fidelity。

### 主要貢獻

1. **Macro–micro dissociation 的實證建立**：用同一個 human experiment 的 network structure、interaction protocol、payoff matrix 當 ground truth，證明 LLM 在 macro 層面可以看起來跟人很像，但個體異質性和 conditional decision rule 都系統性偏離人類。這是目前 silicon sampling 文獻裡少見的三層級驗證框架。

2. **九個 open-weight LLM 的系統性比較**：不只是測一個模型，而是系統性地比較九個模型（包括 ablated 版本），顯示不同模型和 alignment 策略會產生非常不同的合作行為，且 ablated 版本（移除 alignment）也會系統性地改變軌跡——這代表你不能隨便換模型就當成同一個 silicon sample。

3. **Mixed population 實驗**：加入隨機 agent 來改善 micro-level agreement，但發現這雖然能增加 heterogeneity，卻不能修復 decision rule 的 mismatch。這代表問題的根源不在 population diversity 不夠，而在 LLM 本身的 decision mechanism 跟人類不同。

### 方法 / pipeline

整個實驗框架建立在 Gracia-Lázaro et al. (2012) 的大型 networked Prisoner's Dilemma 實驗之上。原實驗讓人類參與者在 lattice 和 heterogeneous network 上反覆玩 Prisoner's Dilemma，觀察合作率如何隨時間演變。

模擬端的做法：
- 每個 network node 是一個獨立的 LLM agent
- 每一輪，agent 收到 prompt：包含上一輪鄰居的選擇和 normalized payoff
- Agent 回傳 cooperate 或 defect
- Payoff 按照原實驗的 pairwise matrix 計算，每位 agent 的總 payoff 是所有 pairwise interaction 的加總
- Network structure：lattice (625 nodes, avg degree 4) 和 heterogeneous network (604 nodes, degree 2–16)
- Control 條件：time-varying network（每輪 random rewire，保留 degree sequence）

分析分三層：
- **Macro**：cooperation rate 隨時間的演變，比較 LLM 與人類的 trajectory
- **Micro**：個體合作傾向的分佈（cooperation propensity 的 heterogeneity）
- **Decision rule**：conditional cooperation pattern——agent 在鄰居合作/背叛時如何調整自己的選擇

### 實驗設計

- **Benchmark**: Gracia-Lázaro et al. (2012) 的人類 Prisoner's Dilemma 實驗數據
- **Models tested**: 9 open-weight LLMs（llama3.1:8b, llama3.1:70b, llama4:16x17b, deepseek-llm:67b, deepseek-llm:7b, qwen3:32b, smolLM2.1:7b, 以及兩個 ablated 版本）
- **Network structures**: Lattice (625 nodes) 和 heterogeneous (604 nodes)，加上 control 條件（random rewiring）
- **Main results**:
  - Macro: llama4:16x17b 最接近人類數據，reproduces 早期下降和後期穩定的 pattern
  - Micro: 所有 LLM population 的 heterogeneity 都低於人類，即 LLM agents 的行為比人類更 homogenous
  - Decision rule: LLM 的 conditional cooperation pattern（根據鄰居行為調整策略的方式）與人類 quantitatively 不同
  - Mixed population（加入隨機 agent）：改善了一些 micro-level 指標，但 decision rule 的 mismatch 仍然存在
- **Ablation**: Ablated models（移除 alignment）產生系統性不同的合作軌跡，顯示 alignment 對 social simulation 結果有重大影響

### かに讀後判斷

這篇是近期 silicon sampling 領域最值得細看的 empirical paper 之一。它不只在 macro 層面做對比，而是把驗證拉到 micro 和 decision rule 層面，這正是 DailyRead 之前反覆追蹤的 heterogeneity 和 fidelity 問題的關鍵證據。和之前看過的「Will Scaling Improve Social Simulation?」（2607.02464，已推薦）形成互補：scaling 那篇問 scaling law 能不能改善 fidelity，這篇直接告訴你即使選到 best-match model，micro 層面仍然系統性偏離。

值得深讀的部分：Figure 2 的 cooperation trajectory 比較、Figure 3 的 individual heterogeneity distribution、以及 mixed population 實驗的詳細分析。特別值得注意的是 ablated model 的結果——它直接證明 alignment procedure 本身就是 silicon sampling fidelity 的一個變數，這對 silicon sampling 的 methodological 立場有重要影響。
