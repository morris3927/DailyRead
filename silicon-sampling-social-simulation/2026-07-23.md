# Silicon Sampling / Social Simulation — 2026-07-23

## 1. Survey Transfer Learning: Recycling Data with Silicon Responses (2501.06577)

- **arXiv**: 2501.06577
- **Link**: https://arxiv.org/abs/2501.06577
- **已讀來源**: arXiv HTML 全文

### 這篇在說什麼

這篇是 silicon sampling 方法論的系統性整理。作者提出 Survey Transfer Learning（STL），把機器學習裡的 transfer learning 概念搬到問卷研究：用既有調查資料訓練 LLM 模擬特定人口群體的問卷回應，然後把學到的「回應模式」遷移到新問卷或新族群，省去重新採樣的成本。核心問題是：我們能不能用一個調查的資料讓 LLM 學會某群體的回應風格，然後把這個風格搬到另一個調查？

### 主要貢獻

1. **STL 框架**：正式把 silicon sampling 定位成一個 transfer learning 問題，不是只做一次性的 persona 模擬。分為 in-domain（同一問卷不同題目）和 cross-domain（不同問卷）兩個層級。
2. **Cross-survey transfer 評估協議**：設計了比隨機 persona 更嚴格的評估方式，不只看回應分布是否接近真實，還看遷移後的回應是否保持結構一致性。
3. **系統性失敗模式分析**：指出 silicon sampling 的三大問題——同質化（average persona）、社會期許偏誤（SDB）、結構不一致性——並整理現有緩解策略的證據。

### 方法 / pipeline

STL 的 pipeline 是：(1) 從來源調查資料中抽樣，(2) 用 few-shot prompting 或 fine-tuning 讓 LLM 學會該群體的回應模式，(3) 把學到的模式遷移到目標調查的題目上。作者特別強調 in-domain transfer（同一問卷內部）跟 cross-domain transfer（跨問卷）是不同難度的問題。cross-domain 的挑戰在於不同調查的題目結構、回應尺度、語境都不同，遷移不是簡單的 copy-paste。

### 實驗設計

這是一篇 survey/position paper，不是實驗論文。作者整理了多個 silicon sampling 實驗的結果（包括自己團隊的 Cross-Survey Transfer paper 2607.03091），指出：
- In-domain transfer 效果不錯，但 cross-domain 明顯下降
- SDB 可以透過第三人稱改寫 prompt 緩解，但不能完全消除
- 受眾分段（audience segmentation）是恢復異質性的關鍵策略

### かに讀後判斷

這篇是 silicon sampling 領域 2026 年初的綜述定位文章，跟 2607.03091（Cross-Survey Transfer）是姊妹作。如果你已經讀過 2607.03091，這篇的增量主要在於把整個方法論生態系統講清楚，特別是失敗模式整理。值得快速掃過，但不一定是今日推薦首選——除非你正在寫 silicon sampling 的相關文獻回顧。深讀建議優先看 §2-3 的 STL 定義和 cross-domain transfer 評估協議。

## 2. In-Context Learning for Imputation in Silicon Sampling (2606.09351)

- **arXiv**: 2606.09351
- **Link**: https://arxiv.org/abs/2606.09351
- **已讀來源**: arXiv HTML 全文

### 這篇在說什麼

這篇把 silicon sampling 問題重新框架成「缺失值插補」：真實調查裡本來就有很多缺失值，與其用 LLM 模擬完整回應然後再跟真實資料比對，不如直接讓 LLM 做插補——給它觀察到的部分回應，讓它補完剩下的。作者提出 ICL-based imputation pipeline，用 few-shot prompting 讓 LLM 根據人口特徵和已回應題目來插補缺失題目。

### 主要貢獻

1. **插補框架**：把 silicon sampling 從「模擬完整回應」轉成「插補缺失值」，這樣評估標準更直接——插補準不準就是結果。
2. **ICL pipeline 設計**：用 persona description + observed responses 作為 context，讓 LLM 插補 unobserved responses。不需要 fine-tuning，純 few-shot。
3. **與傳統插補方法比較**：和 MICE、mean/mode imputation 等傳統方法做系統比較，在 ANES 和 GSS 資料集上 ICL imputation 在分布對齊和相關結構保持上都更好。

### 方法 / pipeline

Pipeline：(1) 從調查資料中構建 persona（人口特徵 + 已回應題目），(2) 用 few-shot prompting 讓 LLM 插補未回應題目，(3) 評估插補品質（分布匹配、相關結構保持、個體層級準確度）。作者特別注意了 persona granularity 的影響——粗粒度 persona 插補效果差，但細粒度 persona 又可能過度指定。

### 實驗設計

在 ANES（American National Election Studies）和 GSS（General Social Survey）上評估。指標包括：
- 分布對齊：KL divergence、Wasserstein distance
- 結構保持：變數間相關矩陣的對齊
- 個體層級：插補值與真實值的匹配率
ICL imputation 在分布對齊上大幅領先 MICE，在結構保持上也有優勢，但個體層級準確度仍有限。

### かに讀後判斷

這篇的插補框架是 silicon sampling 方法論的一個有意義的進展：不再評估「LLM 能不能模擬人的回答」，而是評估「LLM 能不能補完缺失的回答」。這更貼近實際調查使用場景。方法創新度中等（主要是框架轉換 + ICL 應用），但實驗設計扎實。如果你在做 silicon sampling 的方法論研究，這篇值得點開看實驗細節和 ablation（特別是 persona 粒度的影響）。深讀建議看 §4 的實驗和 §5 的 ablation。

## 3. Integrating LLM and Diffusion-Based Agents for Social Simulation (2510.16366)

- **arXiv**: 2510.16366
- **Link**: https://arxiv.org/abs/2510.16366
- **已讀來源**: arXiv HTML 全文（前半+方法段落）

### 這篇在說什麼

這篇提出一個混合框架：用 LLM-based agents 模擬少數核心使用者（有語義理解），用擴散模型處理其餘大多數使用者（有效率但無語義理解），兩者透過協調模擬過程互動。核心問題：LLM agents 很強但太貴，擴散模型很快但不能理解文字內容——能不能各取所長？

### 主要貢獻

1. **混合架構**：不是純 LLM 也不是純擴散，而是讓 LLM agents 處理核心使用者子集，擴散模型處理剩餘使用者。兩者都納入使用者個人興趣、社交影響、和內容特徵。
2. **Seed cascade 設計**：LLM agents 的回應作為擴散模型的初始種子，解決了擴散模型的冷啟動問題。
3. **多資料集驗證**：在微博和知乎資料集上驗證，混合方法在預測準確度上優於純 LLM 模擬和純擴散模型。

### 方法 / pipeline

Pipeline：(1) 選擇核心使用者子集，為每個構建 LLM agent（含個人資料、歷史互動、多階段決策框架），(2) LLM agents 產生初始種子級聯，(3) 擴散模型基於種子和歷史互動推斷所有使用者的啟動機率，(4) 合併兩者結果得到完整擴散預測。

LLM agent 的多階段決策框架包含：閱讀貼文 → 評估個人興趣 → 評估社交影響 → 做出決策。擴散模型則學習使用者歷史行為中的協同過濾模式。

### 實驗設計

在微博（3 個資料集）和知乎（1 個資料集）上評估。指標：macro-F1、micro-F1、MAE。混合方法在所有資料集上都優於：
- 純擴散模型（如 DeepCas、DeepINF）
- 純 LLM 模擬（所有使用者都用 LLM agent）
- 傳統資訊擴散模型

Ablation 顯示 LLM agent 的語義理解貢獻最大，社交影響模組次之。核心使用者子集大小的選擇有明顯的效率-準確度 tradeoff。

### かに讀後判斷

這篇在 silicon sampling / 社會模擬的脈絡裡是一個務實的工程貢獻：不是追求每個人都是 LLM agent，而是承認計算成本的限制，用混合策略處理。框架本身不算新穎（seed cascade + collaborative filtering 是經典組合），但把 LLM 的語義理解跟擴散模型的效率結合起來的實驗驗證是有價值的。對 Morris 來說，如果你對「LLM 社會模擬的規模化」感興趣，這篇的混合設計值得參考，特別是 core user selection 策略和 seed cascade 的實驗分析。深讀建議看 §3.3-3.4 的 LLM agent 設計和 §4.3-4.4 的 ablation。

## 4. The Social Laboratory: A Psychometric Framework for Multi-Agent LLM Evaluation (2510.01295)

- **arXiv**: 2510.01295
- **Link**: https://arxiv.org/abs/2510.01295
- **已讀來源**: arXiv HTML 全文

### 這篇在說什麼

這篇不是做 silicon sampling 本身，而是用多 agent 辯論作為「社會實驗室」來評估 LLM 的社會行為。核心發現：LLM agents 在辯論中有一個強烈且穩健的共識傾向，即使被指派對立角色，最終也會趨向語義一致（μ>0.88）。作者提出了一套心理計量和語義指標來量化辯論動態。

### 主要貢獻

1. **社會實驗室框架**：把多 agent 辯論從任務導向工具轉為評估工具——辯論的目的不是得到更好答案，而是觀察 LLM 的社會行為。
2. **心理計量指標套件**：語義收斂度、認知努力、立場轉移、偏見放大等指標，從簡單的準確度走向更豐富的行為描述。
3. **共識傾向發現**：362 場辯論中，LLM agents 自然趨向共識，即便討論敏感話題也不顯著降低收斂。
4. **主持人效應**：Consensus Builder 主持人可以顯著影響對立 agents 的收斂程度，但不改變 agents 的內在心理計量特徵。

### 方法 / pipeline

兩個實驗：(1) 362 個主題的 Llama-3.2-3B-Instruct agents 辯論（3 輪 vs 7 輪），一人是 evidence-driven analyst，一人是 values-focused ethicist；(2) gpt-oss-20B 對立 agents 在 Neutral vs Consensus Builder 主持人下的辯論。所有辯論使用 Change-My-View 資料集的主題。

### 實驗設計

指標包括 Final Stance Convergence（語義相似度）、Semantic Diversity per round、Cognitive Effort、Confidence、Empathy/ToM Score。統計檢定用 Levene's Test 比較 contentious vs non-contentious 主題的變異數。

主要結果：3 輪辯論收斂度 μ=0.880, 7 輪 μ=0.892。共識傾向在敏感話題上也穩定（p>0.5）。Consensus Builder 主持人顯著提升對立 agents 的收斂。

### かに讀後判斷

這篇對 silicon sampling 的貢獻是間接的：它告訴我們 LLM 在社會互動中的行為特徵——特別是強烈的共識傾向——這直接影響我們如何解讀 silicon sampling 的結果。如果你在做 LLM 社會模擬，這個共識偏誤是一個需要認真處理的 confound。方法論上，心理計量指標套件是一個有用的貢獻。但樣本只有兩個模型（Llama-3.2-3B 和 gpt-oss-20B），且 self-report 指標的信效度有疑問。深讀建議看 §3 的結果和 Appendix 的指標定義。
