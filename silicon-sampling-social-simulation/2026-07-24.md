# Silicon Sampling / Social Simulation — 2026-07-24

## 1. Characterizing the Ability of LLMs to Recapitulate Americans' Distributional Responses to Public Opinion Polling Questions across Political Issues

- **arXiv**: 2603.20229
- **Authors**: Eric Gong, Nathan E. Sanders, Bruce Schneier (Harvard)
- **Link**: https://arxiv.org/abs/2603.20229

### 這篇在說什麼

這篇要解決的問題很清楚：傳統民意調查越來越難做——成本上升、回覆率下降、弱勢群體覆蓋不足——研究者想知道 LLM 能不能補上這個缺口。但之前做 silicon sampling 的方法有個根本困境：要嘛一個一個模擬個體（「silicon respondents」），要嘛從 next-token probability 反推分布。前者很貴（要反覆 query）、後者不穩（低估或高估分布集中度都有人觀察到）。Gong 等人提出第三條路：直接請 LLM 預測整個分布，不要模擬個體，不要從 token probability 拆解，就給它人口統計條件和題目，請它輸出「這個群體的回覆分布會是什麼」。

### 主要貢獻

1. **提出「distribution prediction」框架**：有別於「反覆模擬個體」（silicon sampling / repeated querying）和「next-token probability estimation」，直接讓 LLM 預測群體回覆分布。這大幅降低了成本，也讓預測更可解釋。
2. **系統性的 cross-demographic 和 cross-topic 評估**：用 2022 Cooperative Election Study（CES）的 84 題、20 個人口統計組合（種族 × 性別 × 意識形態），共 1680 個 question-demographic permutations 做全面比較。不只看整體表現，還拆解了 LLM 在不同人口統計群、不同議題上的表現差異。
3. **可預測的誤差結構**：distribution prediction 的誤差在人口統計和議題之間有系統性、可預測的模式，讓使用者在 query 之前就能用先驗知識估計模型表現。這是比個體模擬框架更大的實用優勢。

### 方法 / pipeline

- **資料來源**：CES 2022，約 60,000 美國成人，手動篩選出 84 題政策意見題（排除事實知識題、與人口統計共線的題目等）。
- **人口統計分組**：Race（White / Non-white）× Gender（Man / Woman）× Ideology（Very Liberal / Liberal / Moderate / Conservative / Very Conservative），共 20 組。
- **Distribution prediction 框架**：prompt GPT-4o-mini 給出人口統計條件 + 題目，要求模型直接輸出各選項的預期回覆比例（percentage distribution）。
- **對比基線**：反覆模擬個體的「silicon sampling」方法（同模型、同人口統計條件，但逐次模擬單一個體）。
- **評估指標**：比較 LLM 預測分布與 CES 實際分布的吻合度（主要是 KL divergence 和總變異距離等），並分析誤差在人口統計和議題類型之間的結構。

### 實驗設計

- 模型：OpenAI GPT-4o-mini。
- 1680 個 question-demographic permutations。
- Distribution prediction 一致性地比 individual querying 更準、成本更低。
- 誤差有系統性模式：某些人口統計群（如非白人群體、極端意識形態群體）的表現較差，但這種差異可以用先驗知識近似預測。
- 目前只從 abstract 和 HTML 前段能確認上述設計和主要結論；具體的 KL 散度數值、各 subgroup 的 breakdown、以及 distribution prediction 的 prompt template 細節需要看全文確認。
