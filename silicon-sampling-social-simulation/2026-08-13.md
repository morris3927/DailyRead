# Silicon Sampling / Social Simulation — 2026-08-13

## 1. CastVectors: Role Steering of Language Models for Social Simulations

- **arXiv**: 2608.00023
- **Link**: https://arxiv.org/abs/2608.00023
- **Venue**: Social Sim'26 Workshop, COLM 2026

### 這篇在說什麼

Silicon sampling 和 LLM-based social simulation 領域一直有個核心問題：你怎麼確保 simulation 裡的 agent 真的表現出你要的 role 行為，而不是被 prompt 措辭、模型偏見、或隱性 assistant 傾向給稀釋掉？目前主流做法是用 prompt 做 role conditioning（「你是一個⋯⋯」），但這很脆弱——小改動就會改行為，多 agent 放在一起又容易塌縮成同一種語調。這篇論文提出了一個 pre-deployment 的解決方案：用 activation steering（在模型內部表示空間上加一個方向向量）來控制 role 行為，並且在 agent 放進模擬之前就先篩選、校正，而不是跑完模擬才發現 agent 行為不對。

### 主要貢獻

1. **CastVectors 工作流**：定義 role profile → 提取 role-specific activation direction → sweep steering coefficients → evaluate role-profile alignment → pass 或 flag 每個候選配置。這是一個完整的 pre-deployment calibration pipeline，把 role conditioning 從「寫個好 prompt」變成一個可量化、可重複的工程流程。

2. **275 角色大規模實驗**：在 OLMo-3-7B-Instruct 上測試了 275 個角色，用 228 個 role-agnostic 問題，GPT-4.1-mini 當 judge。CastVectors 的 mean overall score 是 63.2，而之前 persona-vector work 的 assistant-axis 控制只有 41.1。同時 CastVectors 保留了高 lexical diversity，而 assistant-axis 在大係數時 diversity 急劇下降。

3. **Failure-aware 分類**：最重要的實用貢獻可能不是「大多數角色變好」，而是「38 個角色在所有維度上都隨 steering 增加而下降」。論文把角色分為 controllable、partially deteriorating、和 anti-controllable 三類，告訴 simulation builder 必須 per-role 選係數，不能一刀切用 uniform high-strength。

### 方法 / pipeline

整個流程分五步：

1. **Role profile 定義**：每個角色有一個結構化 profile，包含 15 個 behavioral directives（core drive、decision style、conflict stance、risk orientation、inner contradiction 等），從 O*NET 職業資料庫 seed，用 Kimi-k2.5 生成。

2. **CastVector 提取**：對每個角色，收集 prompted 和 default（Assistant）條件下的 response，用 LLM judge 分四類（fully role-playing / partially / task-responsive / non role-playing），只保留 fully role-playing 正例和 Assistant-style 負例，在 layer 16 取 mean-of-differences 作為角色方向向量。

3. **Steering coefficient sweep**：在 α ∈ {1.0, 1.5, 2.0, 2.5} 四個強度上 steering，每個 (role, α) cell 回答 228 個 role-agnostic 問題。

4. **Alignment 評估**：GPT-4.1-mini judge 在六個維度上打分，產生 per-role coefficient-response curve。

5. **Screening**：per-role screen 決定每個角色該用哪個係數，或者根本不該用 steering（anti-controllable 的角色）。

值得注意的是，CastVector 的 ℓ2 norm（3.79）遠小於 assistant-axis 的（9.68），所以 equal coefficients 不代表 equal perturbation magnitude。這是個方法論上的重要細節。

### 實驗設計

- **模型**：OLMo-3-7B-Instruct，steering 在 layer 16（residual stream）。
- **Role inventory**：275 個角色，包含職業和 broader archetypal roles。
- **問題**：228 個 role-agnostic alignment questions，涵蓋 resource conflict、ambiguity response、identity under removal 等情境，不測 domain knowledge 而是測 decision-making trade-off。
- **Judge**：GPT-4.1-mini，六維度評分。
- **主要結果**：CastVectors > assistant-axis 在 mean alignment（63.2 vs 41.1）和 lexical diversity 保持上。74% 角色隨 α 增加而改善（median per-role correlation r = +0.98），但 38 個角色在所有維度上 decline。
- **幾何分析**：向量 norm、reference distance、RSA、PCA、trait projections 作為探索性輔助，但不取代 behavioral screen。

### かに讀後判斷

這篇是 silicon sampling 社群的「model internal steering meets simulation calibration」路線的最新一步。跟之前的 personality anchoring（2606.06936）、population-aligned persona generation（2509.10127）、和 silicon sampling boundary paper（2506.19806）相比，CastVectors 的獨特貢獻在於：

1. 它把 steering 從單一軸線（assistant vs anti-assistant）推到 per-role direction，這在 simulation 實務上非常關鍵——你不是只要關掉 assistant 味，而是要精準轉到特定角色。
2. 它明確承認 steering 不是萬能的：38 個 anti-controllable 角色說明了有些角色用 steering 反而更差，這比「universal steering」的樂觀敘事更誠實。
3. pre-deployment screening 的概念對實際做 simulation 的研究者來說是直接可用的工具。

值得深讀的部分：Section 3 的完整 pipeline、Section 5 的 per-role failure analysis、和 Appendix 裡的 275 角色分類。對 Morris 來說，這篇直接回應了 silicon sampling 領域一直面臨的 heterogeneity 塌縮問題，而且提供了具體工具。建議深讀。
