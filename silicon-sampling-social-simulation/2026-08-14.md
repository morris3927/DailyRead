# Silicon Sampling / Social Simulation — 2026-08-14

## 1. Mind the Gaps: Mixture-of-Minds for Human Simulation

![](../assets/2026-08-14/mixture-of-minds-human-simulation.png)

- **arXiv / Venue / 類型**: arXiv:2608.06115 / cs.AI / audience simulation model
- **Link**: https://arxiv.org/abs/2608.06115

### 這篇在說什麼

這篇把 silicon sampling 的核心問題講得很直接：很多 LLM simulator 能抓到「人口平均」但抓不到「個體差異」。也就是說，模型看起來可以重現某個群體的 central tendency，但 minority position、個體異質性、選項順序造成的 prompt brittleness、以及後訓練模型常見的 agreeable / positive bias，會讓它更像一個平滑過的平均人，而不是一組真正不同的人。作者提出 Anacreon，目標不是讓一個通用模型回答所有社會問題，而是在 narrow, well-specified domain 裡，從公開文字中建立可區分個體的「mixture of minds」。這和前幾天 CastVectors 的角色 steering 很接近：兩者都不再相信單一 prompt persona 足夠穩定，而是把 persona / individual fidelity 當成需要校準、驗證、甚至訓練的對象。

### 主要貢獻

第一，它把 human simulation 的評估焦點從 aggregate fidelity 推到 individual-level fidelity：不是只問「整體比例像不像」，而是問模型能否保留人的差異。第二，Anacreon 用 authorship embedding 把真實 qualitative corpus 按人或近似個體群聚，再為每個 cluster 訓練專用 adapter，形成 mixture-of-minds，而不是單模型 + 人口統計 prompt。第三，系統加入 chain-of-emotion augmentation、選項順序 shuffle、以及正負表述 balancing，明確對抗 prompt brittleness 和 positive bias。第四，作者在 externally sourced survey 上回報 ordinal alignment 0.775，宣稱達到 field converged individual-level accuracy measure 的 SOTA，並指出仍有 small residual bias。

### 方法 / pipeline

pipeline 是：先收集公開文字與 seed population；用 contrastive authorship-representation objective 訓練 embedding，讓同一個人的不同 text sample 靠近、不同人的樣本分開；接著把整個 corpus 分配到 nearest seed individual，形成 clusters。每個 cluster 以時間切分成 train/test，避免後期資訊外洩。資料增強部分由 LLM-as-judge 從文字中抽 demographics、psychological traits、survey-like responses；抽不到穩定 majority vote 就留下 unknown，不硬猜。Chain-of-emotion 則把 stimulus 到 response 的情緒狀態演變納入 record。最後在 Gemma 4 12B base 上訓練 per-cluster adapter，讓每群「mind」以自己的資料學習回答模式。

### 實驗設計

我讀到 arXiv HTML 的 introduction、background、method 與部分 pipeline；abstract 和前文確認主實驗是大型外部 survey，主要指標是 ordinal alignment，Anacreon 達到 0.775，且作者說 residual bias 小。HTML 擷取沒有完整覆蓋所有 result table 與 ablation，因此今天不能細講每個 baseline 的精確數字。不過能確認作者至少在設計上有三個關鍵測試點：個體層級 alignment、prompt brittleness 對抗（選項 shuffle / 正負 framing）、以及 bias reduction（training distribution balancing）。若要深讀，應補看完整 PDF 的 results section、ablation 表、cluster 數量與 adapter 選擇策略。

### かに讀後判斷

值得 Morris 點開。它的位置很清楚：如果 CastVectors 是「用 activation steering 讓角色行為可校準」，Anacreon 則是「用分群 adapter 和個體資料讓 simulator 不再只有平均人」。我會把它視為 silicon sampling 從 demographic prompting 轉向 data-grounded individual simulators 的重要訊號。深讀優先看 Figure 1 pipeline、authorship embedding/clustering 的細節、chain-of-emotion 是否真的有 ablation，以及 0.775 alignment 對哪些 survey 題型最有效、哪些 subgroup 仍有 residual bias。

## 2. Emulate or Estimate? The Divergent Strengths of Base and Post-Trained Language Models for Opinion Simulation

- **arXiv / Venue / 類型**: arXiv:2608.03044 / cs.CL, cs.AI / opinion simulation evaluation
- **Link**: https://arxiv.org/abs/2608.03044

### 這篇在說什麼

這篇試圖解開 opinion simulation 文獻裡一直互相矛盾的結果：有些研究說 LLM 能對齊人類 survey，有些研究說 persona collapse、人口統計 prompt 沒用、輸出太同質。作者的說法是，大家其實混在一起評估了兩種不同任務。第一種叫 emulation：模型生成個體回應，最後聚合成人口分布。第二種叫 estimation：模型直接預測整體人口分布。這兩種任務需要的能力不一樣，所以 base model 和 post-trained / instruct model 的強弱也不一樣。

### 主要貢獻

第一，提出 emulation vs estimation 的任務切分，讓「模型是不是好的人類模擬器」不再是一個混雜問題。第二，用 matched base/post-trained model pairs 在 Pew American Trends Panel 上比較，發現 base models 更適合 emulation，因為它們生成的分布更接近 human ground truth，也比較能保留 demographic structure。第三，post-trained models 更適合 estimation，當被要求直接回傳分布時更穩定、更校準。第四，作者採用 open-response emulation，再用 LLM judge 對應到選項，避免 first-token probability extraction 被位置偏誤污染。

### 方法 / pipeline

emulation pipeline 是讓模型以開放文字回答 survey 問題，不直接給多選選項；之後用 LLM judge 把自由回答映射到答案類別。base model 被設計成 interviewer-participant dialogue，人口統計條件放在前一輪對話；post-trained model 則透過 system instruction 扮演特定人口。estimation pipeline 則把題目與選項直接給模型，要求輸出 JSON probability distribution。評估 metric 包含 Total Variation Distance 與 Wasserstein distance；前者看分布差距，後者保留 ordinal answer 的距離結構。

### 實驗設計

全文 HTML 顯示資料來自 Pew Research Center American Trends Panel Wave 54，使用 59 個四選項 economic opinion items，並比較 unconditioned marginal 與六個 demographic conditions。LLM judge 在 200 個 response-category pairs 上和人類標註者比較，整體 Cohen's κ=0.66、raw agreement 74%；限制在雙方都有明確 letter category 的 146 筆時 κ=0.72。主要結果是 base models 在 emulation 下 TVD/Wasserstein 較接近人類分布，post-trained models 在直接 estimation 下較好。限制也很重要：survey 是 2019 年資料，而模型訓練語料延伸到 2024–2025，因此 temporal alignment 可能混雜。

### かに讀後判斷

這篇是今天 silicon sampling 的好補充，但我會把 Anacreon 排在更值得點開的位置。它提醒 Morris：如果任務是「生成一群可互動的 synthetic humans」，base model 或較少後訓練的 substrate 可能比 instruct assistant 更合適；但如果任務只是「估一個分布」，post-trained model 反而可能更可靠。這對 social simulation harness 很實用，因為未來設計 silicon sampling pipeline 時，不能只問模型強不強，而要先分清楚 downstream 是 emulation 還是 estimation。
