# Silicon Sampling / Social Simulation — 2026-08-18

今天兩篇 NOT_SEEN 候選都在處理 mode collapse / 多樣性不足的問題，但切入角度不同。Verbalized Sampling 從 prompt 層面重新設計抽樣介面，讓 LLM 先 verbalize 再從分布取樣；Geometric Regulation 則從 representation space 的幾何結構切入，把 mode collapse 重新理解為 internal state 的幾何崩塌。

## 1. Verbalized Sampling: Mitigate Mode Collapse and Unlock LLM Diversity

- **arXiv / Venue**: arXiv:2510.01171v4 (NeurIPS 2026 accepted)
- **Link**: https://arxiv.org/abs/2510.01171

### 這篇在說什麼

這篇論文要解決的問題是 LLM 在 social simulation / survey / creative writing 等需要多樣性輸出的場景中，普遍出現 mode collapse — LLM 傾向反覆產生相似、保守、社會期望正確的回應，而無法重現人類群體回應分布的多元性。作者把這個問題歸因於兩個層面：（一）post-training alignment（特別是 RLHF / preference learning）中的 typicality bias — 人類 annotator 本來就偏好熟悉、看起來「正常」的文字，這間接訓練模型往高機率、低多樣性方向收斂；（二）標準的 top-k / top-p / temperature 取樣介面沒有讓模型有機會先表達自己的分布，而是直接從隱含的 logits 取樣。

Verbalized Sampling 的核心想法很簡潔：不靠修改訓練或調整取樣參數，而是在 prompt 層面要求模型先「verbalize」一個機率分布，再從這個 verbalized distribution 取樣。這讓模型的輸出多樣性不只是取樣策略的結果，而是模型在文字空間中顯式表達的分布結構。

### 主要貢獻

1. **提出 Verbalized Sampling (VS)**：一種 training-free 的 prompting 策略，讓 LLM 在產生回應之前先 verbalize 一個機率分布，再從這個分布抽樣。這把 mode collapse 從「模型能力問題」重新定位為「取樣介面問題」。

2. **系統性實驗驗證**：在 social dialogue simulation、creative writing、survey response 等多個任務上驗證 VS 的多樣性提升，同時確認不會降低 safety 或 factual accuracy。

3. **Typicality bias 的分析**：作者追溯 mode collapse 的根源到 preference data 中人類 annotator 的 typicality bias，提供了從偏好數據到輸出多樣性下降的因果鏈分析。

### 方法 / pipeline

VS 的流程如下：

1. **Input prompt**：給 LLM 一個需要多樣性回應的 prompt（例如 social survey question 或 creative writing prompt）。
2. **Verbalize distribution**：要求模型先輸出一組候選回應及其對應的機率（或相對頻率），而不是直接產生單一回應。這一步把模型隱含的回應分布外化。
3. **Sample from verbalized distribution**：從 verbalized 的分布中取樣，得到最終回應。

整個方法不需要修改模型權重或訓練資料，只需要在 prompt 中加入 verbalization instruction。作者也在論文中討論了 verbalized distribution 的校準議題 — 模型 verbalize 的分布是否真實反映其內部狀態，以及如何驗證。

### 實驗設計

作者在以下任務上評估 VS：

- **Social dialogue simulation**：用 LLM 模擬不同人口群體的對話回應，測量回應多樣性。
- **Creative writing**：測量 LLM 在開放式創意寫作中的輸出多樣性。
- **Survey response simulation**：用 LLM 模擬問卷回應，比較與人類分布的吻合度。

主要結果顯示 VS 在多樣性指標（如 entropy、distinct n-grams、分布距離）上顯著優於標準取樣，且不會在 safety 或 factuality 指標上退步。典型性偏好的分析實驗也顯示，偏好數據中的人類典型性偏好與模型輸出的低多樣性之間存在顯著相關。

### かに讀後判斷

這篇和 8/15 推薦的 SSR (Semantic Similarity Rating, 2607.28550) 是互補的：SSR 解決的是「LLM 直接吐 survey 數字導致分布不像人類」的問題，而 VS 解決的是更根本的「LLM 輸出分布缺乏多樣性」的問題。VS 的訓練不需要修改、只需 prompt 層面介入，實作成本極低，這在實務上很有吸引力。

不過從 silicon sampling 的角度看，VS verbalize 的分布是否足夠細粒度來捕捉人類群體的子群差異（例如不同人口統計群體的態度分布），還需要更深入的驗證。作者的 survey simulation 實驗提供了初步證據，但還沒有達到 SSR 那種把文字態度映射回數值分布的精度。

值得深讀的部分：Section 4 的 typicality bias 分析、Appendix 中的分布校準實驗。這篇對做 silicon sampling / social simulation 的人來說是必讀，因為它提供了一個低成本、直覺的方法來增加模擬多樣性。

## 2. Escaping Mode Collapse via Geometric Regulation in Representation Space

- **arXiv / Venue**: arXiv:2605.00435v3 (ICML 2026 accepted)
- **Link**: https://arxiv.org/abs/2605.00435

### 這篇在說什麼

這篇論文從一個更根本的角度看 mode collapse：不是把它視為取樣或 alignment 的表面症狀，而是把它理解為模型內部表示空間中的「幾何崩塌」（geometric collapse）。當模型的 internal representations 趨向聚集到少數幾個點、維度退化、或各層的表示變得高度相似時，輸出多樣性自然就會下降。作者把這個現象形式化為「mode collapse 是 representation space 的幾何問題」，並提出 Geometric Regularization（GeomReg）來直接約束表示空間的幾何結構。

這篇和 Verbalized Sampling 的核心差異在於：VS 是在 inference time 修改取樣介面，不碰模型本身；GeomReg 則是在訓練時直接正則化表示空間，從源頭防止幾何崩塌。

### 主要貢獻

1. **Mode collapse 的幾何理解**：把 mode collapse 重新框架為 internal representation space 的維度退化、表示聚集、和層間趨同，而不是單純的輸出分布問題。

2. **Geometric Regularization (GeomReg)**：在訓練損失中加入幾何正則項，約束表示的 singular value 分布（防止維度退化）、表示間距離（防止聚集）、和層間表示的 CKA 相似度（防止層間趨同）。

3. **跨任務驗證**：在 conditional generation（image / text）、dialogue、和多種生成任務上驗證 GeomReg 的多樣性提升。

### 方法 / pipeline

GeomReg 的三個正則項：

1. **Singular value regularization**：對每一層的表示矩陣計算奇異值分布，正則化使其不會退化到少數幾個主方向。這防止表示空間的維度崩塌。
2. **Inter-sample distance regularization**：在同一 batch 中計算樣本間的表示距離，正則化使其保持足夠的分散度。這防止表示聚集。
3. **Inter-layer CKA regularization**：計算相鄰層之間的 CKA (Centered Kernel Alignment) 相似度，正則化使其不會過度趨同。這防止層間表示的複製效應。

三項正則可以獨立或聯合使用，作者也提供了係數調整的建議。

### 實驗設計

已從 HTML 全文確認到的實驗：

- **Conditional generation**：在 image generation 和 text generation 任務上，GeomReg 顯著提升輸出多樣性（Entropy、Distinct-n 指標），同時維持或略微提升生成品質（FID、BLEU 等）。
- **Dialogue generation**：在多輪對話中，GeomReg 減少重複回應的比率。
- **Ablation study**：三個正則項的消融實驗顯示，三項聯合使用效果最好，但 singular value regularization 單獨使用已有顯著改善。
- **ICML 2026 accepted**，表示經過同行審查。

### かに讀後判斷

這篇對 silicon sampling 的直接幫助比 VS 更間接 — GeomReg 是訓練時的方法，大部分做 silicon sampling 的研究者不會想重訓模型。但它的幾何視角很重要：如果 mode collapse 的根源在表示空間的幾何崩塌，那任何 inference-time 的方法（VS、SSR、temperature 調整）都只是在表面修補，無法從根本上恢復表示的多樣性。

和 8/15 的 SSR (2607.28550) 比較：SSR 是在輸出介面做映射，GeomReg 是在表示空間做正則。兩者互補但層次不同。如果 Morris 想深入了解 mode collapse 的機制，GeomReg 的幾何分析比 SSR 的介面方法更根本。
