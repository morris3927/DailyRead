## 1. Representational Equality in Cross-country Value Simulation: A Systematic Analysis of Large Language Models

- **arXiv / Venue**: arXiv:2608.08058 (cs.CY) | Accepted by Computational Linguistics
- **Link**: https://arxiv.org/abs/2608.08058

### 這篇在說什麼

Silicon sampling 的核心承諾是：LLM 可以作為可擴展的人類意見代理人。但這個承諾有一個被忽視的前提 — 如果 LLM 對不同人群的模擬準確度差異很大，那麼用 silicon sample 做出的研究結論就會系統性地偏向被模擬得更準確的人群。這篇論文把這個問題形式化為「代表性平等」（representational equality）：LLM 應該對不同人群達到可比的模擬準確度，而不是只在平均意義上準確。

作者系統性分析了 59 國的 LLM 價值模擬，發現富裕和技術先進國家被模擬得更準確 — 這不是隨機噪音，而是系統性的不平等。然後測試了兩條干預路徑（contextual adaptation 和 parametric modification），發現改善平均準確度或目標群體準確度不一定改善代表性平等。

### 主要貢獻

1. **形式化「代表性平等」概念和指標**：不是要求 LLM 對所有群體產生相同回應，而是要求模擬準確度在不同群體之間可比。作者提出了一個量化指標來衡量跨國代表性平等。

2. **59 國系統性分析**：跨 59 國分析 LLM 價值模擬的準確度分佈，發現模擬品質與國家的經濟和技術發展水準正相關 — 富裕國家的價值被模擬得更好。

3. **兩條干預路徑的系統比較**：
   - Contextual adaptation（母語提示、額外資訊）：母語提示通常提升準確度但效果依模型而定；額外資訊更常同時提升準確度和平等。
   - Parametric modification（語言特定繼續後訓練、偏好對齊）：語言特定後訓練提升目標語言群準確度但不均勻；偏好對齊對準確度和平等都沒有系統性改善。

4. **診斷分析**：分析國家級特徵（經濟、技術、政治、文化指標）與模擬準確度的關聯，提供不平等的宏觀結構性解釋。

### 方法 / pipeline

1. **模擬設定**：用多個 LLM（GPT-4o、Claude、Gemini 等）模擬 59 國的價值問卷回應。每個國家的模擬準確度從可比的子群體 cell 聚合（國家 × 人口統計屬性）。

2. **代表性平等指標**：定義量化指標衡量跨國模擬準確度的離散程度，作為平等的診斷工具和評估目標。

3. **Contextual adaptation 實驗**：
   - 母語提示 vs. 英文提示
   - 額外人口統計資訊提示
   - 組合條件

4. **Parametric modification 實驗**：
   - 語言特定繼續後訓練（在不同語言語料上微調）
   - 偏好對齊（人類標註 vs. AI 標註偏好資料）

5. **診斷分析**：用國家級指標（GDP、上網率、政治自由度、文化維度）回歸模擬準確度。

### 實驗設計

- 已從 HTML 全文確認完整方法、59 國分析、兩條干預路徑的系統比較。
- **資料**：使用世界價值觀調查（WVS）和歐洲價值研究（EVS）作為人類基線。
- **模擬**：每個國家的子群體 cell 由國家 + 人口統計屬性（性別、年齡、教育、收入）構建。
- **核心發現**：模擬準確度的跨國變異系統性偏高；改善平均或目標群體準確度不一定改善代表性平等；人類標註偏好資料在保持準確度方面優於 AI 標註資料。

### かに讀後判斷

這篇對 silicon sampling 社群非常重要。之前的工作（包括我們 5/8–5/12 覆蓋的隨機矽抽樣系列）主要關注分佈層面的相似度，而這篇指出了一個更深層的問題：就算分佈匹配得不錯，不同國家之間的模擬品質可能系統性地不平等。干預路徑的比較結果也很務實 — 告訴研究者「加更多資訊」比「換語言」更有效，而偏好對齊可能無效甚至有害。

值得深讀的部分：Section 3 的代表性平等指標定義、Section 5 的國家級特徵回歸分析、以及 Appendix 中的跨模型比較。這篇和 5/14 的「Mitigating Social Desirability Bias」形成互補 — 那篇處理社會期許偏差，這篇處理代表性的系統性不平等。

## 2. CiteAgent: Leveraging LLM-based Agents for Social Science Research — Insights from Citation Network Simulations

- **arXiv / Venue**: arXiv:2511.03758 (physics.soc-ph, cs.AI, cs.CY, cs.MA, cs.SI) | Accepted by HSSCOMMS'25
- **Link**: https://arxiv.org/abs/2511.03758

### 這篇在說什麼

傳統的引用網路研究用隨機圖模型（Erdős–Rényi、Barabási–Albert、小世界網路）來建模學術引用的宏觀結構，但這些模型把人類行為簡化為固定統計機制（如優先連接），忽略了異質性和策略性適應。CiteAgent 用 LLM-based agent 來模擬人類引用行為，生成更真實的引用網路，並在此基礎上建立 LLM-SE（LLM-based Survey Experiment）和 LLM-LE（LLM-based Laboratory Experiment）兩種社會科學研究範式。

### 主要貢獻

1. **CiteAgent 框架**：一個用 LLM agent 模擬引用網路生成的框架，每個 agent 擁有作者屬性（引用數、機構、專長、主題、國籍），通過初始化、社交、創建三個階段迭代生成引用網路。

2. **三個網路科學理論的驗證**：CiteAgent 生成的網路成功再現了冪律分佈、引用失真（citational distortion）、收縮直徑（shrinking diameter）三個真實引用網路的經典現象。

3. **LLM-SE 和 LLM-LE 兩種實驗範式**：
   - LLM-SE：用結構化問卷給 LLM agent，分析引用行為的影響因素。
   - LLM-LE：設計對照實驗（如不同推薦演算法），隔離因果效應。

4. **理想化社會實驗**：用 CiteAgent 做傳統觀察研究無法做的理想化實驗，提供對真實學術環境的見解。

### 方法 / pipeline

- **初始化**：從真實引用網路資料集（CiteSeer、Cora、LLM-Agent）提取種子網路，為每個作者構建 LLM-based agent，賦予屬性。
- **社交階段**：活躍作者群組討論，合作開發論文草稿。
- **創建階段**：用學術搜尋引擎檢索相關論文，完成引用選擇並更新論文集。
- **迭代**：重複以上步驟，網路逐步擴展。
- **驗證**：用 Kolmogorov-Smirnov 統計量和 goodness-of-fit 測試驗證冪律分佈、引用失真、收縮直徑。

### 實驗設計

- 已從 HTML 全文確認方法、三個資料集、三個網路理論驗證。
- **資料集**：CiteSeer（2,997 節點）、Cora（2,542 節點）、LLM-Agent（165 節點，2021–2023 年 LLM agent 領域）。
- **LLM**：GPT-3.5、GPT-4o-mini、LLAMA-3-70B。
- **驗證指標**：冪律指數 α、KS 統計量 D*、goodness-of-fit p-value。

### かに讀後判斷

CiteAgent 把 silicon sampling 從「模擬個人意見」延伸到「模擬集體學術行為」，是一個有趣的應用。LLM-SE 和 LLM-LE 的範式設計也為用 LLM 做社會科學實驗提供了結構化方法論。但目前只從全文確認了框架設計和網路驗證部分，LLM-SE/LLM-LE 的具體實驗結果和因果推斷需要看論文後半部分。這篇和之前的 silicon sampling 論文（如 Cross-Survey Transfer）互補 — 那些做意見模擬，這篇做行為模擬，特別是學術引用行為。

對 Morris 來說，如果對「LLM 能不能模擬社會科學實驗」這個問題感興趣，值得看 Section 2 的 LLM-SE 和 LLM-LE 範式設計，以及理想化實驗的結果。
